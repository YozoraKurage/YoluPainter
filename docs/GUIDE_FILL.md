# 塗りつぶしと効果

[English](en/GUIDE_FILL.md)

値・画像・グラデーションで面を塗る塗りつぶしレイヤー、レイヤーの画素やマスクに重ねる効果、素材を使い回すアセットとライブラリ、操作の記録と再生の頁です。

## 塗りつぶしレイヤーを作る

レイヤーのパネルの「新規塗りつぶしレイヤー」ボタン（メニューバーの「レイヤー」にもあります）から、種類を選びます。選んでいるレイヤーのすぐ上（グループの中のレイヤーを選んでいれば、そのグループの中）に作られます。

| 種類 | 作られる物 |
|---|---|
| 単色 | チャンネルごとの値で塗るレイヤー |
| グラデーションデカール | 3D ビューの範囲（ボックス・球・平面（線形））で値を塗り分けるレイヤー |
| 画像 | アセットの画像で塗るレイヤー。一覧の「ファイルから取り込む…」で PNG も使えます |
| デカール | アセットの画像を、モデルに貼る形で置くレイヤー |

プロパティの「塗りつぶし」の節で、チャンネルごとの値を決めます。値の右のボタンで描画色からその値を追加し、削除ボタンで外します。色のチャンネル（Color・Emission）は見本を押して色のウィンドウで、スカラーのチャンネル（Roughness・Metallic・Height）は 0〜1 のスライダーで決めます。

### 複数のチャンネルを一度に塗る

ツールプロパティの「塗るチャンネル」（ブラシ・消しゴム・バケツ・ポリゴン塗りつぶし・グラデーション・図形・パス・スポイトと、選択のツール（長方形選択・楕円形選択・なげなわ・多角形選択・自動選択・選択ペン）のツールプロパティの終わりにあります。初めは閉じています。選択のツールでは、選択範囲の塗りつぶし・消去がこの組を使います）で「複数のチャンネルを一度に塗る」を入れると、チェックしたチャンネルを、それぞれの値で 1 回のストロークで塗ります（Color は描画色、Emission は色、Roughness・Metallic・Height は 0〜1、Normal は傾き）。2D・3D・バケツ・ポリゴン塗りつぶし・パスで効き、1 回の取り消しで全チャンネルが戻ります。切ると、選んでいるチャンネルを描画色で塗ります。

## 画像で塗る

「画像」の節で、描くチャンネルが読む画像を決めます。アセットのパネルから欄へドラッグするか、欄を押して一覧から選びます。「読み方」は画像の値が色（sRGB）かデータ（リニア）かで、その画像を読む全部のレイヤーに効きます。「異方性フィルター」ははじめから入っていて、斜めから当てた画像や縦横の繰り返しが違う画像のにじみを減らします。

### 投影と置き場所

「投影」の節で、画像のモデルへの当て方を選びます。

- UV: 画像を UV の正方形に敷きます。
- トライプラナー: 箱の 3 つの軸から当て、面の向きで混ぜます（「混ぜ幅」）。UV の継ぎ目が出ません。
- 平面・球・円柱: 箱の正面から、または箱の中心のまわりに当てます。
- デカール: 箱の正面から、箱の中だけに、画像のアルファで切り抜いて当てます。「奥行きの縁」「裏向き」「面の縁」で消え方を変えます。

「タイル」「オフセット」「回転」「外側」（繰り返す・端を伸ばす・透明）でも当て方を直せます。UV 以外の投影は、位置と法線の焼いたメッシュマップを読みます（ベイクは [GUIDE_3D.md](GUIDE_3D.md)）。マップが無いあいだは理由が欄に出て、画像でなく値が見えます。開いた `.ylp` で必要なマップや画像が足りないセットは、そろうまで読み取り専用になります。

UV 以外では、「3D ビューのハンドル」（`Q` でも出し入れ）で箱を動かします。矢印と中心の四角が移動、輪が回転（`Ctrl` で 15° ずつ）、面のつまみが大きさ（`Shift` で両側）で、1 つのギズモに同時に出ます。「中心」「回転」「大きさ」は数値でも直せ、「モデルに合わせる（外形）」で箱をモデルの外形に合わせられます。

アセットの画像を 3D ビューのモデルへドラッグして落とすと、落とした所の面に向けた、画像の縦横比のデカールが、今の描くチャンネルに 1 回の取り消しで追加されます（ビューの上が画像の上）。ほかのテクスチャセットの面には置けません。

## グラデーションで塗る

どちらも Normal 以外のチャンネルに置けます。

### グラデーションデカール

「グラデーションデカール」の節の「3D ビューで編集」で形（ボックス・球・平面（線形））のハンドルを出し、範囲を決めます。範囲の中の値を塗り分け、モデルの位置で決まるので UV の継ぎ目が出ません。位置のメッシュマップが要ります。

「減衰」（平面以外）で縁の消え方、「反転」でグラデーションの向きを決めます。色と不透明度の分岐点・階調のプリセット・値のカーブは、グラデーションマップと同じランプの欄です（[GRADIENT_MAP.md](GRADIENT_MAP.md)）。

### 点のグラデーション

「点のグラデーション」の節で点を置くと、点ごとの色と不透明度が、点からの距離で滑らかにつながります。「モデル」はモデルの面の上の位置（位置のメッシュマップが要り、UV の継ぎ目で切れません）、「UV」はテクスチャの UV の上の位置でつなぎます。

「点を編集」の間は、3D ビューか 2D のキャンバスで、面を押して点を追加し、印をドラッグして動かし、`Delete` で選んだ点を消します（最後の 1 つは消せません）。点の色は一覧の見本から色のウィンドウで直し、「広がり」で点の周りの平らさを決めます。点は 64 個までで、画像・グラデーションデカールと同じチャンネルには置けません。

## 効果を重ねる

効果は、レイヤーの画素かマスクに重ねるフィルター（画素を直す）とジェネレーター（値を作る）です。標準のチャンネルが対象で、レイヤーの行の下に字下げして並びます（上の行ほど後に掛かります）。

### 追加する

「フィルターを追加」と「ジェネレーターを追加」は別の入り口です。

- レイヤーのパネルの下の帯の 2 つのボタン
- プロパティの「レイヤー」と「レイヤーマスク」の欄（マスクの欄は「マスクにフィルターを追加」「マスクにジェネレーターを追加」）
- レイヤーの右クリックと、メニューバーの「レイヤー」の「フィルターを追加 ▸」「ジェネレーターを追加 ▸」
- メニューバーの「フィルター」（フィルターとアンカーだけ）

レイヤーに付けるかマスクに付けるかは、サムネイルで選びます。レイヤーのサムネイルを押すとレイヤーの画素、マスクのサムネイルを押すとマスクが対象になり（対象のサムネイルに青い枠）、追加のボタンもプロパティも今の対象に向きます。マスクの効果の行を押してもマスクが対象です。マスクのサムネイルの右クリックでは、マスクへの追加と、反転・有効・マスクの削除を選べます。

行の目で有効・無効、上へ・下へで順番、削除で外します（右クリックのメニューにも同じ項目があります）。行を押すと、プロパティにその設定が出ます。どの効果にも「強さ」があり、ジェネレーターは「合成」で下の値との合わせ方（乗算・置き換え・スクリーン・最大・最小・加算・減算）を選びます。

1 つの操作が取り消し 1 回で、スライダーのドラッグは 1 回にまとまります。「すべて」をロックしたレイヤー（親のグループを含む）には追加できません。

### 効果の種類

フィルターは 23 種が、ぼかし・輪郭と形・ノイズ・値の調整・色調補正の順に並びます。ぼかし（ガウス）、シャープ（アンシャープマスク）、ノイズ、レベル補正、階調の反転、正規化（レイヤー全体）、調整レイヤーと同じ欄の色調補正のほかに、次の 10 種があります。

| 名前 | 何をするか |
|---|---|
| 値の切り出し | 位置より上を 1、下を 0 へ寄せ、コントラストで境目を鋭くします（スカラーとマスクだけ） |
| 値の幅 | 値を位置のまわりの幅へ縮めます（スカラーとマスクだけ） |
| ノイズに沿ったぼかし | 内蔵のノイズの坂の向きへ値を引き伸ばします |
| 方向ぼかし | 角度の向きの両側へ、線のようにぼかします |
| ゆがみ | 内蔵のノイズの坂で読む位置をずらしてゆがめます |
| 太らせる・細らせる | 丸い範囲の最大で太らせ、最小で細らせます（スカラーとマスクだけ） |
| 輪郭の検出 | ぼかしてから輪郭の強さを取り出します（スカラーとマスクだけ） |
| ハイパス | ぼかした画像との差を、0.5 の灰色のまわりに残します |
| メディアン | 正方形の範囲の中央値で、細かいごみを消します |
| グロー | しきい値より明るい所をぼかして足し、光らせます（色のチャンネルだけ） |

ジェネレーターは 15 種で、次のように分かれます。

- 焼いたメッシュマップから値を作る: エッジの摩耗、汚れ・隙間、位置の勾配、形のグラデーション、厚み、向き、ライト（焼いた法線と光の向きから明暗を作る）、マスクの組み立て（曲率・AO（アンビエントオクルージョン）・位置の高さ・厚みを重みとレベルで合わせる）、ID の色
- モデルの UV アイランドから作る: アイランドごとのばらつき（アイランドごとに 1 つの値）
- マップが無くても効く: ノイズ、グランジ、模様（UV の縞・市松・水玉・縁・格子）、画像（アセットの画像を、塗りつぶしレイヤーと同じ投影で読む）。ノイズとグランジは、位置のマップがあればモデルの上で、無ければ UV の上で作ります
- アンカー: 下のレイヤーの結果を読みます

読むマップが無い・古い・モデルと照合できないジェネレーターは、行に印と理由が出て、入力のまま通します（焼くと効きます）。ID の色は、プロパティの「ID マップから選ぶ」を押してから 2D のキャンバスか 3D ビューを押すと、その所の色を追加します（`Ctrl` を押していれば外し、32 色まで。もう一度押すと終わります）。アンカーは、レイヤーやマスクに名前を付けて置く目印で、上のレイヤーのアンカーのジェネレーターが読みます。

### 継ぎ目をまたいで読む

ぼかしやシャープのように周りの画素を読むフィルターは、モデルがあれば、UV アイランドの縁の向こう（3D で隣の面）の画素も読みます。効果の欄の「UV の継ぎ目をまたぐ」で切り替えられ、そのテクスチャセットのすべてのフィルターに効きます。

## アセットに保存して使い回す

右上の「アセット」のパネルには 2 つの置き場があります。「プロジェクト」はこのプロジェクトのアセットで、`.ylp` に保存されます（256 個まで）。「ライブラリ」は自分のフォルダ（場所は設定の「ライブラリの場所」）で、ほかのプロジェクトからも使えます。

素材は画像・ブラシ・マテリアル・スマートマテリアル・スマートマスクの 5 種で、上のアイコンで絞り、名前で探せます。すぐ置ける同梱のスマートマテリアルも並びます。

- 「レイヤーを保存」: 選んだレイヤー（グループは中身ごと）をスマートマテリアルとして、プロジェクトのアセットに入れます。「マスクを保存」は、マスクをスマートマスクにします。保存は別のスレッドで進み、パネルに「保存中」と「やめる」が出ます。その間、アセットの消す・読み込むは「保存中です」と断ります。ユーザーチャンネル・ノイズ・グランジ・色調補正・0.5.0 の効果を使うレイヤーは `.ylsmart` に書けないので、理由を出して保存しません。
- 「置く」（ダブルクリック・右クリック・レイヤーの一覧へのドラッグでも）: 選んだレイヤーの上に新しいレイヤーとして置きます。大きさが違うテクスチャセットには引き伸ばして置き、1 回の取り消しで戻ります。スマートマスクは「マスクに適用」で、選んだレイヤーのマスクと入れ替えます。置けない素材は、並ぶだけで理由が出ます。
- 「ライブラリへ入れる」「プロジェクトで使う」: アセットとライブラリの間で素材を移します。
- `.ylsmart` は読み込み・書き出しができます（0.4.x までの Unity 版でも読めます。Unity ブリッジ 0.5.0 からは取り込みません）。

塗りつぶしレイヤーの右クリックの「マテリアルとして保存」は、塗りつぶしの値・グラデーション・投影・フィルターを、ライブラリの `Materials` に `.ylmaterial` として書きます（名前はレイヤーの名前で、同じ名前には番号が付きます）。マスク・クリッピング・不透明度・合成モード・表示・ロックは持たず、置くと新しい塗りつぶしレイヤーの既定になります。アセットの画像を使う塗りつぶしは保存できません（項目が押せず、理由がツールチップに出ます）。

## 操作を記録して再生する

「ウィンドウ」→「アクション」のパネルで、レイヤー・マスク・効果の操作（追加・削除・並べ替え・表示・不透明度・合成モード・クリッピング・ロック・チャンネルの有効・塗りつぶしの値・調整や効果の値）を記録し、別のテクスチャセットや文書で再生できます。

1. 「記録」を押して、レイヤーや効果を操作します。描く操作・選択範囲・変形・結合・複製のように記録できない操作があると、パネルに印が出ます。書き出しと保存は記録しません。
2. 「記録を止める」を押すと、一覧にアクションが加わります。ダブルクリックで名前を変え、ドラッグで並べ替えられます。
3. 一覧で選んで「再生」を押すと、今のテクスチャセットに当てます。全体が取り消し 1 回で戻ります。

記録を始めたときに選んでいたレイヤーと、記録の中で作ったレイヤー・効果は、別の文書でも同じ所を指します。ほかのレイヤーは名前で指し、同じ名前が複数あれば記録しません。アクションは設定のフォルダの `actions/` に置かれ、`.ylp` には入りません。コマンドラインの `run-action`（[CLI.md](CLI.md)）や MCP のツール `action_run`（[MCP.md](MCP.md)）でも当てられます。

## 古い版や Unity 版へ渡す

点のグラデーション・異方性フィルターを切った画像・0.5.0 の効果のどれかを使った `.ylp` は、0.4.x のスタンドアロンと 0.4.x までの Unity 版では開けません。渡すときの注意は [GUIDE_FILES.md](GUIDE_FILES.md) にあります。
