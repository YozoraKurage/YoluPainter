# 選択と変形

[English](en/GUIDE_SELECT.md)

選択範囲の作り方と使い方、覚えておく方法、レイヤーの移動・変形、コピーとペーストの頁です。選択範囲は 2D のキャンバスでも 3D ビューでも作れます。今の選択範囲は、テクスチャセットごとに `.ylp` へ保存されます。

## 選択範囲を作る

| ツール | キー | 使い方 |
|---|---|---|
| 長方形選択・楕円形選択 | `M` / `Shift+M` | ドラッグ。長方形は「角の丸め」を決められます |
| なげなわ | `L` | 囲むようにドラッグ |
| 多角形選択 | `Shift+L` | クリックで点を置きます。`Enter`（始めの点やダブルクリックでも）で閉じ、`Backspace` で最後の点を消します |
| 自動選択 | `W` | 押した画素に近い色を選びます。「許容値」「隣接」「全レイヤーを対象」を決められます。2D のキャンバスで対称の定規が効いていて、「対称定規にスナップ」（初めは入）が入っているときは、押した点の写しの全部の点からそれぞれ選び、その和を今の作成方法で 1 回の選択範囲にします（1 回の取り消し。キャンバスの外の写しは使わず、同じ画素に重なる写しは 1 回です）。キャンバスの外を押したときは、端の画素を押したものとして、その写しを選びます。3D ビューでは写しません（2D のキャンバスが出ていないあいだは、この切り替えを押せません） |
| 選択ペン・選択消し | `S` | ブラシのように塗って、量を描き加える・消す。直径・硬さ・不透明度はブラシと共通です |
| ID の色で選択 | `Shift+W` | 焼いた ID マップの色から選びます |

3D ビューでは、長方形選択・楕円形選択・なげなわ・多角形選択・自動選択・ID の色で選択が使えます。形を 3D ビューの画面の上で引いて、見えている面のテクスチャの画素へ写し、2D のキャンバスと同じ選択範囲にします（[GUIDE_3D.md](GUIDE_3D.md) の「画面の上で引いて選ぶ」）。選択ペン・選択消しも 3D ビューで使え、押した面のテクスチャの画素に塗って選択範囲へ追加・削除します（クイックマスクのあいだは、ブラシと消しゴムも同じ働きをします）。選択範囲の縁は、2D のキャンバスにも、3D ビューの見えている面の上にも出ます。

「サブツール」のパネルの一覧には、これらの選択ツールが並び、行を押すとツールが替わります。作成方法は、オプションバーの「新規」「追加」「削除」「共通」で選べます。「ツールプロパティ」のいちばん上にも同じ帯があり、初めは「新規」「追加」「削除」と「⋯」（すべての作成方法）だけを出します。「⋯」を押すと「共通」も出ます（共通を選んでいるあいだは、畳む設定でも 4 つ出ます）。選択ペンの帯は「選択ペン」と「選択消し」の 2 つです。`Shift` を押しながらで追加、`Ctrl` で削除、`Shift+Ctrl` で共通です。選択ペンでは、`Shift` で選択ペン、`Ctrl` で選択消しになります。長方形と楕円は、押し始めたあとに `Shift` を押すあいだ縦横比を固定し、`Alt` を押すあいだ押した点を中心にします。「縦横比を固定」「中心から」を入れておくこともできます。「アンチエイリアス」で縁の滑らかさを決めます。

全体の操作は「選択範囲」メニューにもあります。

| 操作 | キー |
|---|---|
| すべてを選択 / 選択を解除 / 選択範囲を反転 | `Ctrl+A` / `Ctrl+D` / `Ctrl+Shift+I` |
| クイックマスク | `Shift+Q` |

`Esc` は、操作の途中なら取りやめ、何も無ければ選択範囲を解除します。

### ID の色で選ぶ

焼いた ID マップの色が、押した画素（3D ビューでは押した面の UV の位置）と近い所を選びます（「許容」で幅を決めます）。メッシュの塊ごとの色を手で付けることもでき、手動の ID の色は `.ylp` に保存されて、開き直すと戻ります。色を付けたモデルと違うモデルを開いたときは、別のモデルの色として残り、編集と ID マップのベイクは断ります。ID マップのベイクは [GUIDE_3D.md](GUIDE_3D.md) にあります。

## 選択範囲を整える・使う

- **整える**: 「選択範囲」メニューの「拡張」「縮小」「境界線」「境界をぼかす」「境界をくっきり」で形を変えます。`…` の付いた項目は、「半径」と「端を固定」を決めるウィンドウを開きます。「端を固定」を入れると、選択範囲がキャンバスの外へ続くものとして扱い、縮小・境界線・ぼかしがキャンバスの端から離れません。
- **クイックマスク**: 選択範囲を赤い重ねで見せ、ブラシと消しゴムで直せます。3D ビューのブラシと消しゴムでも、押した面のテクスチャの画素で直せて、赤い重ねは 3D ビューの面の上にも出ます（[GUIDE_3D.md](GUIDE_3D.md)）。
- **選択範囲の中だけに描く**: ブラシと消しゴムは、選択範囲の内側だけに効きます。バケツと図形の「塗る」も同じです。
- **ボタンの帯**: 選択範囲を作ると、その下に出ます。解除・反転・拡張・縮小・境界をぼかす・描画色で塗りつぶす・選択範囲を消去（`Delete`）・コピーして新しいレイヤーに（`Ctrl+J`）・選択範囲をレイヤーマスクにする・選択範囲を覚える、が並びます。左端の持ち手でずらせます。「選択範囲」メニューの「選択範囲のボタンの帯を表示」で、出さないこともできます。選択範囲が無いときの `Ctrl+J` は、レイヤーの複製です。

## 選択範囲を覚える

「選択範囲」メニューの「覚えた選択範囲…」か、帯の「選択範囲を覚える…」で、「覚えた選択範囲」のウィンドウが開きます。名前を付けて「覚える」と、今の選択範囲を残せます（1 つのテクスチャセットに 32 個まで）。覚えたものは、「新規」「追加」「削除」「共通」のどれかで呼び出せ、名前の変更と削除もできます。どれも 1 回の取り消しで戻ります。テクスチャセットの大きさを変えたときは、覚えた選択範囲も今の選択範囲と同じように作り直し、縮小で何も残らないものは外して知らせます。

覚えた選択範囲を使う `.ylp` は、古い形式のアプリ（0.3.x のスタンドアロンと Unity 版）では理由つきで開けません（[UNITY.md](UNITY.md)）。

## 移動・変形する

移動・変形（`V`）は、選んだレイヤーを動かします。グループなら中身ごと、複数選んでいればその全部、選択範囲があればその中の画素と選択範囲を動かします。

- ドラッグの途中は、変形後の外枠だけを見せます。離したところで確定し、途中の `Enter` でも確定します。`Esc`・ウィンドウのフォーカスを失う・ツールの切り替えでは、何も変えずにやめます。どれも 1 回の取り消しで戻ります。
- 外枠のハンドルで移動・拡大縮小（`Shift` で縦横比を保つ）・回転（`Shift` で 15° 刻み）します。矢印キーで 1 画素、`Shift` も押すと 10 画素動きます。
- 「左右反転」「上下反転」「時計回りに 90° 回転」「反時計回りに 90° 回転」は、「編集」メニューとオプションバーにあります。
- 「ツールプロパティ」のパネルの「数値」で、位置（X・Y）・拡大率（幅・高さ）・角度を数で決めて「適用」できます（「戻す」で初めの値に戻します）。「補間」は「バイリニア」（なめらか）か「ニアレストネイバー」（画素の硬さを保つ）で、オプションバーにもあります。

変形の種類は、サブツールで選びます。「通常」は上の変形、「自由」と「遠近」は角を動かして形を変え、「メッシュ」は格子の点（列と行は 1〜32）を動かします。`Ctrl` を押して動かし始めると自由変形になります。遠近は、角を動かすと同じ辺のもう 1 つの角が左右逆に動きます。

「ゆがみ」は、ツールバーのボタンで選びます（キーはありません）。画素をブラシのように動かします。サブツールで「プッシュ」「右回転」「左回転」「縮小」「膨張」「戻す」を選び、「直径」と「強さ」を決めます。「戻す」は、このゆがみを始めたときの画素へ戻します。

テキストレイヤーを動かすと、テキストの位置・回転・サイズが変わります。反転・縦横の比を変える拡大・傾け・選択範囲の中だけの変形はできません（[GUIDE_PAINT.md](GUIDE_PAINT.md)）。

## コピー・カット・ペースト

「編集」メニューにも並びます。

| 操作 | キー |
|---|---|
| コピー | `Ctrl+C` |
| カット | `Ctrl+X` |
| 結合してコピー | `Ctrl+Shift+C` |
| ペースト | `Ctrl+V` |

コピーとカットは、選択範囲（無ければレイヤー全体）の画素を、描くチャンネル（マスクを描いているならマスク）から写します。「結合してコピー」は、見えている合成を写します。同じ画素を OS のクリップボードへ画像でも書くので、ほかのアプリへ貼れます。ペーストは新しいレイヤーになり（1 回の取り消し）、ほかのアプリでコピーした画像も貼れます。テクスチャセットより大きい画像は貼れません。
