# 機能と操作

[English](en/GUIDE.md)

## できること

- ブラシと消しゴムで描画。組み込みのブラシ 13 個、直径・硬さ・間隔・不透明度・流量、筆先の画像・ゆらぎ・紙の質感・デュアルブラシ・色の変化・フェード・ペンの傾きと回転・筆の速さ・手ぶれ補正と入り抜き、効果のブラシ（ぼかし・指先・クローン）、下の色を拾って混ぜる色の混ぜ（混ぜる・ぼかしのように伸ばす。絵の具の量・濃さ・色延び・混ぜる下地）と、それを使う組み込みの厚塗りの筆（油彩・ガッシュ・混色）。Windows Ink の筆圧を直径・不透明度・流量・硬さ（と、色の混ぜの量・濃さ）に割り当て、項目ごとに最小値（筆圧 0 のときの値）と曲線で応えを調整できます。ペンごとの筆圧の出方の違いは、「表示 → 筆圧の調整…」で下限・上限と曲線を合わせて直せます（枠の中で普段の強さで描いた線の分布から自動でも決められ、曲線は枠の中で点を足す・動かす・消せます。端末ごとの設定で、文書にもブラシにも入りません）。
- サブツールとブラシの画面: 左の「サブツール」のパネル（英語の表示は Tools）は、選んでいる道具に合わせて中身が替わります。ブラシでは、グループ別（ペン・筆・エアブラシ・効果・特殊、取り込んだブラシがあれば取り込み）の一覧に、各ブラシの名前とその設定で描いた見本のストロークが並びます。消しゴムにはブラシと共有しない消しゴムだけの一覧があり、バケツ・ポリゴン塗りつぶし・グラデーション・図形・定規・スポイト・移動・ゆがみは設定の組の一覧、選択の道具はツールの帯と同じ並びの一覧を持ちます（設定の組の一覧と自分の設定の組の保存は [docs/SUBTOOLS.md](SUBTOOLS.md)）。行を押して替え、右下の「+」で今の設定を自分のブラシ（消しゴムの一覧では自分の消しゴム）にでき、複製・名前の変更（ダブルクリック）・削除・ドラッグでの並べ替え・元に戻すができます。組み込みのブラシは消せず、設定を変えると「変更あり」の印が付きます。その下のツールプロパティ（ブラシと消しゴムは直径・不透明度・硬さ・流量・間隔・筆圧の切り替え・手ぶれ補正。ほかの道具もその道具の設定の全部）と、決まった直径の丸（ブラシサイズ。大きさを持つ道具だけ）で素早く調整し、調整のボタンで「ブラシの詳細」の窓（形状・ストローク・筆圧・入り抜きとペン・ゆらぎ・テクスチャ・デュアルブラシ・色の揺らぎ・色の混ぜ・効果・対称）を開きます。「筆圧」では、直径・不透明度・流量・硬さのそれぞれに、筆圧を使うかどうかと最小値と曲線（点を足す・動かす・消す）を決められます。窓は動かせて、開いたまま描けます。消しゴム（`E`）は、消しゴムの一覧で最後に選んだ消しゴムで消します。自分のブラシと消しゴムは設定のフォルダの `brushes/` に 1 つ 1 ファイルで保存し、壊れたファイルは読み飛ばして、起動のときに知らせます。筆圧の最小値などの応えを使うブラシのファイルは新しい形式（版 2）で、色の混ぜを使うブラシは版 3 で書き、古いアプリは、理由を知らせて読み飛ばします（使わないブラシは今までと同じ版・同じ中身です）。
- レイヤーの追加・削除・複製・名前変更・ドラッグでの並べ替え、グループ（入れ子・開閉）、レイヤーマスク（有効・反転・濃度、マスクへの描画）、塗りつぶし、調整（階調の反転・レベル補正・色相/彩度/明度・グラデーションマップ・トーンカーブ・カラーバランス・明るさ/コントラスト・2 値化・ポスタリゼーション）、クリッピング、表示・不透明度・26 種類の合成モード、取り消しとやり直し。
- レイヤーの複数選択（`Ctrl`／`Shift` クリック）。選んだ層をまとめて削除・複製・グループにまとめる・結合・表示の切り替え・1 段上下・ドラッグで移動・ロックできます（描く先は 1 つのままです）。
- レイヤーの結合: 下のレイヤーと（`Ctrl+E`）、グループを、選んだ層を、表示している層を（`Ctrl+Shift+E`）。1 回の取り消しで元に戻ります。結合すると見た目が丸めの 1 段を超えて変わるときは、変わる画素の数を見せて確かめます。結合できない理由（下に層が無い・非表示の層がある・ロックなど）は短い文で出し、何も変えません。
- レイヤーのロック（透明部分・画素・位置・すべて）。レイヤーの欄の行の錠の印（自分のロックは押すと外す）、右クリック、プロパティの「ロック」で付け外しします。グループのロックは中身に効きます。ロックは `.ylp`・PSD（`lspf`）・`.ylsmart` に保存して戻ります。
- 移動・変形（`V`）。選んだ層（グループなら中身ごと、複数選んでいればその全部、選択範囲があればその中の画素と選択範囲）を、外枠のハンドルで移動・拡大縮小（`Shift` で縦横比を保つ）・回転（`Shift` で 15° 刻み）します。ドラッグの途中は変形後の外枠だけを見せ、離したところ（か `Enter`）で確定し、`Esc`・窓のフォーカスを失う・道具の切り替えでは何も変えずにやめます。矢印キーは 1 画素（`Shift` で 10）。90° 回転・左右反転・上下反転は、レイヤーと編集のメニューとオプションバーから、数値の変形・補間（バイリニア・ニアレスト）は、左の「サブツール」のパネルのツールプロパティから（補間はオプションバーにもあります）。どれも 1 回の取り消しで戻ります。
- マテリアルで塗る: 「マテリアル」のタブで、Color・Roughness・Metallic・Height・Normal・Emission から塗るチャンネルを選び、それぞれの値（Color は描画色、Emission は色、データは 0〜1、Normal は傾き）で 1 回のストロークを塗れます。2D・3D・バケツ・ポリゴン塗りつぶしで効き、1 回の取り消しで全チャンネルが戻ります。
- バケツ（`G`）とポリゴン塗りつぶし（`4`）: 範囲は三角形・メッシュの塊・UV アイランド・マテリアル（バケツは 2D で近い色も）。ポインタの下の範囲を 3D では面で、2D では UV の輪郭で強調します。バケツは今の選択範囲の内側だけを塗り、ポリゴン塗りつぶしは押したまま通った範囲を足して、離したときに 1 回の取り消しになります。
- パス（`P`）: 2D のキャンバスと 3D のモデルの面の上に、点を順に通る編集できる曲線を引きます。押して点を足し、曲線の上を押すとその区間に差し込み、点を掴んで動かし、`Delete` で消します。閉じる・開く、点ごとの太さ（筆圧の代わり。曲線に沿って滑らかに変わります）、パスのブラシ（直径・硬さ・間隔・不透明度・流量と、太さを直径・不透明度・流量に効かせる切り替え）、「ブラシのマテリアル」で選んだチャンネルの組（組の全部を 1 回で描く）を持てます。点の操作は 1 つが 1 回の取り消しで、点のドラッグは離したときに描き直します（`Esc` で捨て、窓がフォーカスを失うとそこまでを確定します）。パスのレイヤーには手で描けず、ロックされたレイヤーは編集を断ります。「ラスタライズ」（レイヤーの右クリックにもあります）で、今の画素を残してパスを外します。3D のパスはモデルの三角形と重心座標に結び付き、`.ylp` に保存されます。別のモデルで描いたパスは編集せず、モデルを差し替えると、近い同じマテリアルの面へ付け直して描き直します（付け直せないものは、画素・透明度のロックで描き直せないものも含めて、今の画素を残してパスを外し、すべてのロックのレイヤーだけは前のモデルに結び付けたまま残します。結果は件数と最初の理由を知らせます）。曲線は点を通る Catmull-Rom で、取っ手（ベジェ）はありません。閉じたパスは始めの点と終わりの点が同じ場所で、そこは角になります。
- ID の色で選択（`Shift+W`）: 焼いた ID マップの色から選択範囲を作ります（`Shift` 追加・`Ctrl` 削除）。メッシュの塊ごとの手動の ID の色も付けられます。手動の ID の色は `.ylp` にまだ書けないので、付けた文書の保存は理由つきで断ります。
- 選択範囲: 長方形（角の丸め）・楕円形・なげなわ・多角形・自動選択（許容値・隣接・全レイヤー）・選択ペン／選択消し（ブラシの直径・硬さ・不透明度・筆圧で、量を描き足す・消す）を、作成方法（新規・追加・削除・共通。`Shift`／`Ctrl` でも）で組み合わせられます。縦横比の固定・中心から・アンチエイリアスの入り切りは選択の道具の設定から。反転・拡張・縮小・境界線・境界をぼかす・境界をくっきりで変え、ブラシと消しゴムは選択範囲の内側だけに効きます。クイックマスクは選択範囲を赤い重ねで見せ、ブラシと消しゴムで直せます。名前を付けて覚えた選択範囲（「選択範囲」メニューの「覚えた選択範囲…」か、選択範囲の下の帯の「選択範囲を覚える…」で開く窓。1 つのテクスチャセットに 32 個まで）は、新規・追加・削除・共通で呼び出せ、名前の変更・削除もできます（どれも 1 回の取り消し。大きさを変える操作は、覚えた選択範囲も今の選択範囲と同じように作り直し、縮小で何も残らないものは外して結果の文で知らせます）。選択範囲は 2D のキャンバスで作り、今の選択範囲も覚えた選択範囲も、テクスチャセットごとに `.ylp` へ保存されます（覚えた選択範囲を使う `.ylp` は形式 8 になり、0.3.x のスタンドアロンと Unity 版は理由を出して開きません。互換は [docs/UNITY.md](UNITY.md)）。
- 対称: 2D は縦・横・両方・放射状（2〜16）で、中心を動かせます（キャンバスに軸を表示）。3D はモデルの X・Y・Z に直交する面でのミラーと、軸のまわりの放射状（2〜16）で、面はモデルの原点か境界の中央に置け、写しを見えない面にも塗るか選べます（3D ビューに面と軸を表示）。写しが面に届かない・別のテクスチャセットのときは、その写しだけ飛ばします。指先・クローンとは組めません。
- チャンネル: 標準の 6 つとユーザーチャンネル（追加・名前・種類）。描くチャンネルの選択と、2D に表示するチャンネルの切り替え。チャンネルごとに層の有効・合成モード・不透明度を持てます。
- 日本語と英語の表示（「表示」メニューで切り替え）。
- 2D 表示の拡大縮小・移動・回転・左右反転。表示だけを変え、保存する画像は回転・反転しません。
- 2D キャンバスの合成: 使える GPU があれば、アプリの描画と同じ GPU で変わったタイルだけを合成します。調整の層（全種類）・独立したグループ・法線のチャンネル・効果（フィルター・Generator・塗りつぶしのグラデーションと投影・マスクのフィルター。効果の計算は CPU で行い、できた画素を GPU へ上げます）を含む文書も GPU で合成します。ソフトウェアの GPU、描いたタイルを全部載せると GPU のメモリの予算（512 MiB。タイルは GPU と CPU に写しを持つ。効果のある層は持ち得るタイルの上限で数えます）を超える文書、装置のテクスチャの上限（既定 8192）を超える大きさ、グループの入れ子が深すぎる（独立したグループで 32 段を超える）文書では、CPU の合成に切り替えます。画面に出す合成だけが対象で、保存・書き出し・3D ビューの値は常に CPU の結果です（GPU の画素は CPU の結果と最大 2 ほど違うことがあります）。環境変数 `YOLUPAINTER_CANVAS`（`auto`・`gpu`・`cpu`）で固定できます。
- 3D ビューの試しの立方体、または Live Link で受け取ったモデルに描画。マテリアルごとにテクスチャセットを切り替えられます。3D で効くのは直径・硬さ・流量・不透明度・筆圧・色・色の変化・色の混ぜ・消しゴム・ステンシルと、効果のブラシ（ぼかし・指先・クローン）で、筆先・ゆらぎ・質感・デュアルブラシ・フェード・ペンの傾きと回転・筆の速さ・手ぶれ補正は 2D のキャンバスだけです。3D の指先・クローンは UV の島の継ぎ目をまたいで読みます。クローンの元は、Alt を押して動かさずに離したクリックで決めます（「揃える」で前のストロークの位置関係を続け、「全レイヤーから」で見えているレイヤーの重なりを読みます）。
- 3D ビューの見た目: マテリアル（Unity の Standard と同じ BRDF の PBR。Roughness・Metallic・法線・Emission が見える）・中立・チャンネルだけを見出しで切り替え、環境（空・スタジオ）・光・トーンマッピングを小さなパネルで設定できます。詳しくは [docs/PREVIEW.md](PREVIEW.md)。
- FBX のモデルを開き、ボーンの位置・回転・大きさと BlendShape でポーズを付けて、その形の上から描画（今のポーズは、プロジェクトのモデルのものが `.ylp` に保存され、同じモデルを開くと戻ります。合わないボーンや BlendShape は理由つきで飛ばします。Live Link の相手のポーズは `.ylp` の `livelink.json` に保存します）。マテリアルごとにテクスチャセットが付き、今のセットのマテリアルの面に描けます。ポーズの欄はドックのタブ「ポーズ」（モデルを読むとプロパティと同じ組に出て、別の窓にも出せます）で、選んだボーンの位置・回転（Unity のインスペクターと同じ並びのオイラー角）・大きさを数値で直し、項目・ボーン・ボーンと子・全部・BlendShape 1 つずつを戻せます（どれもポーズの取り消し 1 段）。ボーンの影響のある面（面の 3 頂点のウェイトの平均がしきい値以上。子を含められる）は 3D ビューから隠せ、描く・範囲・スポイトの当たりにも使いません（2D のキャンバスと保存には影響しません）。隠し方は名前を付けて設定のフォルダの `hide_presets/` に保存でき、複数を同時に入れられます（ボーンの名前の道が合うモデルで使え、合わない項目は理由つきで飛ばします。`.ylp` には入れません）。ポーズも「ポーズのプリセット」で名前を付けて設定のフォルダの `pose_presets/` に保存できます（休みの形と違うボーンの位置・回転・大きさの差を、ボーンの名前の道で持ちます。ボーンの名前の組が同じモデルに当てられ、合わないボーンは理由つきで飛ばします。BlendShape と `.ylp` には入れません）。名前を押して当てる（ポーズの取り消し 1 段。描いている間は当てません）・左右を反転して当てる・今のポーズで上書き・名前を変える・消すができ、左右反転は名前の決まり（`.L`/`.R`・`_L`/`_R`・`Left`/`Right`・左/右）で対になるボーンへ移します（対にならないボーンはそのまま。左右の休みの形が鏡像でない対は理由つきで飛ばします）。
- `.ylp` の新規作成・読み込み・保存。Unity 版との互換性は[Unity との連携](UNITY.md#unity-版との-ylp-の受け渡し)を参照してください。
- 保存は別のスレッドで進みます（右下の札に「保存しています」と進み具合が出ます。取り消しはありません）。保存の間も描け、見られますが、保存の間に描いた分はその保存には入らず、終わったあとも「変更あり」のままです。保存の間は、もう 1 度の保存・開く・新規・配布用に保存は理由を出して断ります。保存の途中で窓を閉じる・終了すると、保存が終わるのを待ち、その結果のあとで（保存していない変更が残っていれば確かめてから）閉じます。保存できなかったときは、何も変えずに理由を出します。
- 落ちても失わない（復旧）。保存していない変更があると、変更を見つけてから 15 秒（連続して描いているときは前の書き置きから 15 秒）か、終わったストロークが 10 本たまったとき、フォーカスを失ったとき、終わるときに、別のスレッドが復旧用の世代を書きます（描いている最中・PSD の取り込みの途中は取らず、描き終えてから）。世代は `.ylp` と同じ形で、変わっていないセットは前の世代と共有します（置き場のディスクの形は Unity 版と同じで、Unity 版が書いた世代は読めます。開いた `.ylp` の合成の PNG を含む世代は、Unity 版では読めません）。書き置きの失敗は画面の下の知らせで理由を出すだけで、描くのは止めません。落ちた次の起動で「復旧」の窓が開き、世代の一覧（元の名前・セットの数・経過時間）から開く・捨てるを選べます（ファイル → 復旧… からいつでも開けます）。開いたものは「名称未設定（復旧）」で、元の `.ylp` には書きません（保存先は保存のときに選びます）。間隔（10 秒〜5 分）と残す世代（2〜20）は窓から選べ、設定のフォルダの `recovery.conf`（`interval`・`strokes`・`generations`・`directory`・`disk`）に書きます。世代は、正しく閉じた実行の分が合わせて設定の数だけ残ります。落ちた実行は、実行ごとのいちばん新しい世代が、捨てるか 30 日経つまで残ります。復旧が使うディスクの量には上限があり（窓の「使う量」。既定は 2 GB と、復旧が使えるディスクの 10% の小さいほう。`recovery.conf` の `disk`）、超えたぶんは古い世代から消えます（この実行と落ちた実行ごとの最新は残ります）。ディスクの空きが 1 GB とディスク全体の 5% の大きいほう（10 GB まで）を割るときは、書き置きを見送り、画面の下の知らせで理由を出します。`recovery.conf` を読めないときは、既定の間隔で動いて理由を画面の下の知らせで出し、選んだ世代の数が分からないので世代は整理せず、ファイルも書き換えません。合成の PNG とメッシュマップは世代に入れません（派生物。開いた `.ylp` にあったものは残ります）。層のロックと手動の ID の色は `.ylp` にまだ書けないので、それを含む文書は書き置きも理由つきで断ります。Windows の実機ではまだ確かめていません。
- メッシュマップのベイク（「表示 → メッシュマップをベイク…」）。3D ビューのモデルから、チェックしたテクスチャセットごとに、ワールド法線・位置・AO・曲率・厚み・ID などを別のスレッドで焼きます（進み具合と取消つき）。焼く場所は「自動・GPU・CPU」から選べます（自動は使えるハードウェアの GPU があれば GPU、なければ CPU。GPU が使えない・予算を超える・途中で失敗したときは、理由を窓に出して CPU で焼き直します）。GPU で焼いた値は CPU と全バイト一致しません（f32 と f64 の丸めと光線の当たり外れで、AO・厚み・ベントノーマルは最大でおよそ 3%、測った値は [`crates/yolu-gpu/README.md`](https://github.com/YozoraKurage/YoluPainter/blob/main/crates/yolu-gpu/README.md)）。焼いた場所は保存しないので、同じ設定で焼き直すと GPU のある機械では値がその差の分だけ変わり、書き出す AO の PNG も変わります。焼いたマップは `.ylp` にセットごとに保存し、2D のキャンバスに重ねて見られます。モデルや設定が変わったマップは「古い」と表示し、書き出しの AO にも使いません。高ポリからの投影は選べません。
- 効果（「フィルター」メニュー、プロパティの「フィルターを足す」、レイヤーの一覧）: 層の行の下に、その層のアンカー・画素の効果・マスクのアンカー・マスクの効果が字下げした行で並びます（上が後に掛かる）。ぼかし・シャープ・ノイズ・レベル補正・階調の反転・正規化・色調補正（グラデーションマップ・トーンカーブ・カラーバランス・明るさ/コントラスト・2 値化・ポスタリゼーション。調整のレイヤーと同じ欄で、グラデーションマップとカラーバランスは色のチャンネルだけに足せます）と、焼いたメッシュマップから値を作る Generator（エッジの摩耗・汚れ・位置の勾配・形のグラデーション・厚み・向き・ID の色・アンカー）を、描くチャンネルの画素か、マスクに足します。行の目で有効・無効、上へ・下へ・消す、押すとプロパティの欄にその設定（値・強さ・読むマップとその状態・範囲・崩し・合成）が出ます。1 つの操作が 1 回の取り消しで、スライダーのドラッグは 1 回にまとまります。「すべて」のロック（親のグループのものを含む）の層には足せません（画素・透明部分・位置のロックだけなら足せます）。Generator が読むマップが無い・古い・モデルを照合できないときは行に印を付け、理由を見せて、入力のまま通します（焼くと効きます）。アンカーは層・マスクに名前を付けて置き、上の層のアンカーの Generator が読みます。使えなくなった参照（並べ替え・削除）は画面の下の知らせで伝えます。ID の色の Generator の色は、プロパティの「ID マップから選ぶ」で 2D のキャンバスか 3D ビューを押した所の色を足します（`Ctrl` を押していれば外し、32 色まで）。形のグラデーションのランプと 3D ビューでのハンドル、フィルターの画素への焼き込みはまだありません。
- テンプレートでの書き出し（「ファイル → 書き出し → テンプレート」）。Unity の Standard / URP Lit・HDRP Lit・lilToon が読む詰め合わせの PNG を、全テクスチャセットぶんフォルダへ書きます。名前は `<名前>[_<セット名>]_<画像>.png`。UV の外へ色を塗り広げ（パディング。モデルが無ければ掛けません）、焼いた AO があれば使います。もうあるファイルは確かめてから置き換えます。取消や、最後の置き換えを始める前の失敗では、元のファイルを変えません。画面と同じ効果（フィルター・メッシュマップを読む Generator・棚の画像）が入り、読むマップが無いなどで効いていない効果が残るときは、書き出した画像に入っていないことを知らせます。
- PSD（RGB8）の読み込み（「ファイル → 読み込み」。新しいテクスチャセットとして足すか、今のセットの文書に替える。窓に .psd を落としても、新しいテクスチャセットとして同じ流れで取り込みます。複数を落としたときは最初の 1 つだけ）と書き出し（「ファイル → 書き出し → PSD」）。PSD は元のファイルへ書き戻さない写しとして取り込み、ラスター・グループ・単色の塗りつぶし・調整（反転・レベル補正・色相/彩度・グラデーションマップ・トーンカーブ・カラーバランス・明るさ/コントラスト・2 値化・ポスタリゼーション）・マスク・クリッピングはレイヤーになります。色調補正の 6 種は Photoshop の調整レイヤー（`grdm`・`curv`・`blnc`・`brit` と `CgEd`・`thrs`・`post`）として読み書きし、このアプリで表せない中身（ノイズ型のグラデーション・点が 16 を超えるか両端の入力が 0 と 255 でないか隣の点が近すぎる曲線・旧式の明るさ/コントラストなど）は取り込みで落とします。レイヤー効果・スマートオブジェクト・未対応の調整など落とすものや見え方が変わるものは、取り込む前に層の名前つきで確かめます（見え方に効かない情報だけなら確かめずに取り込みます）。ファイルは流して読み、大きさの上限は設定の「レイヤーのメモリ」の予算から決まります。PSB・RGB8 以外・予算を超えるものは理由を見せて何も変えません（扱いの一覧は `docs/PSD.md`）。層のロック（透明部分・画素・位置・すべて）は、書き出しでは `lspf` に書き、読み込みでは層へ戻します（PSD が持たないビットは読み込みの結果に出します）。書き出しは「ファイル → 書き出し → PSD…」の窓で方式（焼き込んで書く・平らに 1 枚）とチャンネル（既定は Color だけ）を選び、チャンネルごとに 1 つの PSD を書きます（複数のチャンネルは `名前_チャンネル.psd` を並べて書き、層の合成モード・不透明度・表示はそのチャンネルの値。Normal は文書のファイルの向き）。焼き込みでは、PSD に形の無いもの（フィルター・Generator・塗りつぶしの画像・投影・デカール・グラデーション・半透明の塗りつぶし・マスクのフィルターと反転・クリッピングされたグループ・パス）を評価した画素にして書き、Anchor と効いていないフィルターの段・何にもクリッピングされないグループのクリッピングの印は落とし、PSD の刻みの間の調整（レベル補正・色相/彩度・トーンカーブ・カラーバランス・明るさ/コントラスト・グラデーションマップ。2 値化・ポスタリゼーションは整数だけで刻みの間がありません）は調整レイヤーのまま最寄りの刻みへ丸め、グラデーションマップの値のカーブ（PSD のグラデーションに形が無い）は、カーブを通した色・不透明度の停止点の列（各 32 個まで）に展開して調整レイヤーのまま書きます。展開は、その調整の層 1 枚の出力の差（通常の合成モード・不透明度 100% で、下の色によらない最悪）が 1 以下になる最小の数を目指し、不透明度が動いて足りなければ 2・4 まで緩め、それでも 32 個に収まらないものは、そのチャンネルの合成に出る層なら層の名前つきで断ります（表示を切った層・そのチャンネルに効かない層は、最良の展開を隠した層で書きます）。この差は文書の合成の差の上限ではなく、層の合成モード・上の層で増えることがあるので、確かめの窓の注記には文書の合成の実測の最大の差が出ます。した事は書く前の確かめの窓に層の名前つきで並び（丸めは値と合成の最大の差つき、展開は停止点の数と最大の差つき）、「書く」を押すまで何も書きません。書き出しは文書の写しで、文書は変わりません（効果は文書に残り、焼いた層は効果の設定を持たないので、PSD を取り込み直しても効果は戻りません）。そのチャンネルに効かない層（無効・面や値が無い・色のチャンネルだけの調整）は隠した層で書きます。読み戻した合成が書き出したチャンネルの今の合成と一致することは Yolu の読みで確かめていますが、一致しないものがあります: 丸める・展開する調整、1/255 の刻みの外の不透明度とマスクの濃度（PSD が丸めます）、Normal の層が重なる所（PSD は色の式で重ねます。確かめの窓に注記が出ます）。反転したマスクを焼いた層が重なる所は、浮動小数の最後の桁の違いでまれに 1 画素が 1 ずれ得ます。ファイルの向きが DirectX の Normal は層の緑を反転して書き、PSD の 1 つのレベル補正で書けないレベル補正の層があれば断ります。色のチャンネル以外（スカラーのチャンネル）のトーンカーブは RGB 全体の曲線だけが効くので、R・G・B の曲線は直線で書きます。色調補正 6 種の式はこのアプリのもので、書き出した PSD の統合画像もこのアプリの式の結果です。Photoshop・CLIP STUDIO で開いて調整レイヤーが再評価されると、見た目が変わることがあります（実機では確かめていません）。取り込んだ PSD は書き換えません（同じファイルへ書くときは置き換える前に確かめます）。
- アセットの棚（左の「アセット」）。選んだレイヤー（グループなら中身ごと）・レイヤーのマスクを「層を保存」「マスクを保存」でスマートマテリアル・スマートマスクとして棚に入れ、棚の素材をダブルクリック・右クリック・「置く」・レイヤーの一覧へのドラッグで今のテクスチャセットへ置きます（スマートマテリアルは落とした行の間かグループの中、スマートマスクは落とした行のマスク。1 回の取り消しで戻ります）。大きさが違うテクスチャセットには引き伸ばして置きます。棚は `.ylp` の resources に保存され、開くと戻ります。外の `.ylsmart` を棚へ読み込み・書き出せます（窓へ落としても読み込めます）。棚の画像は 1 枚のレイヤーとして置けます。画像を同梱した素材・Generator の再固定のある素材・フィルターなど core が持てない中身を含む素材は並ぶだけで、理由を見せて置きません（書き出せば原本のまま Unity 版で使えます）。ブラシとマテリアルも並ぶだけです。ユーザーチャンネルを使うレイヤーと、ノイズ・グランジ（Rust 版だけの Generator の種類）や色調補正 6 種（調整の層・フィルターの段）を使うレイヤーは `.ylsmart` に書けないので、理由を見せて保存しません（層のロックは素材に残ります）。棚の後ろには、コードで組んだ組み込みのスマートマテリアル 14 個（錆びた鉄・塗装の剥げた金属・木など。画像を持たず、すべてノイズ・グランジを使う）が並びます。置くだけで、消す・書き出す・「層を保存」の対象にはならず、`.ylp` の棚にも入りません（置いたグループは普通の層で、その `.ylp` は下の表のとおり文書形式 23 になります）。棚に入れられるのは 256 個までで、いっぱいのときは足さずに理由を出します。大きな素材やいっぱいに近い棚への「層を保存」は別のスレッドで進み（その間は消す・読み込むを断ります）、消す・読み込むは棚の大きさに応じて、数百 MiB の棚では数秒止まります。
- ステンシル（プロパティの「ステンシル」タブ）。PNG を読み、画面に半透明で重ねた画像を通して、2D のキャンバスと 3D のビューの両方に塗れます。灰色の画像は量（輝度 × 透明度）、色の画像は色として読み（自動・量・色から選べます）、繰り返し（横・縦・縦横）・反転・重ねの濃さ・大きさ・角度を変えられます。置き場は画面に貼り付き、`T` を押したままドラッグして動かします（[操作の表](#最初の操作)）。2D のキャンバスでも 3D のビューでも、効果のブラシ（ぼかし・指先・クローン）にも効きます。ステンシルはアプリの状態で、`.ylp` にもブラシのプリセットにも保存しません（新規作成や開き直しでも残ります）。Linux の試験で確かめた機能で、Windows の Direct3D 12・Vulkan の実機、ペン、高 DPI の画面ではまだ確かめていません。
- スポイト（`I`）: 2D のキャンバスと 3D のビューの押した所の値を、描くチャンネルの描画色に取ります（選んだレイヤーだけ。オプションバーで全レイヤーの合成にもできます）。「マテリアルで塗る」がオンなら、6 つのチャンネルの値をマテリアルの値に取ります（塗るチャンネルの組は変えません）。2D ではブラシ・消しゴム・バケツ・ポリゴン塗りつぶしの `Alt` + クリックでも一時的に取れます（3D の `Alt` は回転です）。
- チャンネルの書き出し（「ファイル → 書き出し → チャンネルを PNG…／全チャンネルを画像に…」）: 描くチャンネルを 1 枚の PNG に、または全テクスチャセットの使っている全チャンネルをフォルダへ。値はチャンネルの合成そのまま（詰めず、色も掛けません）で、Normal だけは Normal の設定のファイルの Y の向きです。名前は `<名前>[_<セット名>]_<チャンネル>.png`、余白（UV の外への塗り広げ）・置き換えの確かめ・取消はテンプレートの書き出しと同じです。
- Normal の設定（チャンネルのパネルの「ノーマル」）: ハイト → ノーマル（強さ・端のクランプ／ラップ）とファイルの Y の向き（OpenGL／DirectX）。文書の設定で、`.ylp` に保存され、変更は取り消せます。3D のプレビューと書き出しの Normal に同じ値で効きます。
- 設定（「編集 → 設定…」（Ctrl+,））: 言語、書き出しの余白、メモリの予算（取り消し履歴・レイヤーのメモリはプロジェクト全体の合計で、今のテクスチャセットには「設定 − ほかのセットの使用量」が入ります。1 回の操作は書き出しの作業にも使い、最小の取り消し段数はセットごとです。自動は物理メモリから決めます（レイヤーのメモリは半分・取り消し履歴は 1/8・1 回の操作は 1/16。それぞれ上限があります）。どれも使える量の上限で、先に確保はしません。.ylp を開くときの画素は、設定（256 MiB を下回らない）まで読みます）、CPU のスレッド（次の起動から）、表示の合成（2D のキャンバスの表示。保存・書き出し・3D ビューの値は常に CPU）、棚の場所、退避を残す数、外からの操作を受ける（既定は切。入れている間だけ、AI のアシスタント（MCP）やコマンドラインからの操作を `http://127.0.0.1:<番号>/mcp`（この PC の中だけ。番号は既定で 17347、入れている間その下に出る「ポート番号」で変えられます）で待ち受け、状態の帯の右端に小さな丸を出します（ツールチップに URL）。合言葉は無いので、入れている間はこの PC のほかのアカウントのプログラムもつなげます。1 つの命令が画面の取り消しの 1 段になり、描いている最中・保存の途中の編集と、読むだけのテクスチャセットの編集は理由つきで断ります。文書を開き替える命令は受けません。消す・上書き保存・置き換える書き出しが済んだときだけ短く知らせます。切ると待ち受けをやめ、返事を待っていた要求には受け付けをやめたことを返します。[詳しくは](MCP.md)）。設定のフォルダの `YoluPainter/settings.conf` に、既定でない値だけを書きます。正しくない値はその項目だけ既定に戻し、理由を状態欄に出します。
- 塗りつぶしの画像と投影: 塗りつぶしのレイヤーの「画像」の欄で、描くチャンネルが読む画像を、アセットの棚から欄へドラッグするか、欄を押して一覧（ファイルから PNG を取り込めます）から選びます。「投影」の欄で UV・トライプラナー・平面・球・円柱・デカールを選び、タイル・オフセット・回転・トライプラナーのぼかし、デカールの奥行きと裏向きの縁を変えます。UV 以外の投影は 3D ビューに箱とハンドル（移動の矢印・回す輪・面の大きさのつまみ。`Shift` で両側、`Ctrl` で刻み）を出して置き場を動かせ（`Q` で隠す・出す）、中心・回転・大きさは数値でも直せます。データのチャンネルは画像の値のまま、色のチャンネルでリニアの画像は sRGB に直して読みます。投影の位置と法線は焼いたメッシュマップから読むので、マップが無い・古い間は理由を欄に出して、画像でなく値を見せます。画像は棚から、位置と法線は焼いたメッシュマップから評価へ渡します。開いた `.ylp` でマップや画像がそろわない間は、そのセットを読み取り専用にして足りない入力を表示し、そろえば（ベイクする・画像が棚に入る）編集できます。
- デカール: 棚の画像を 3D ビューのモデルへドラッグして落とすと、落とした所の面に向けて、画像の縦横比で置いた塗りつぶしのレイヤーが 1 回の取り消しで足されます（ビューの上が画像の上）。置いたあとはハンドルで動かし、「投影」の欄で間引きを変えます。位置と法線のマップを評価へ渡すまでは、理由を欄に出して画像が出ません。
- グラデーションデカール: 塗りつぶしのレイヤーの「グラデーションデカール」で、描くチャンネル（Normal を除く）に、ボックス・球・平面の範囲を 3D ビューのハンドルで決めて値を塗り分けます（モデルの位置で決まるので UV の継ぎ目が出ません）。色（データのチャンネルでは値）と不透明度の分岐点は別々で、分岐点の間の中点、階調のプリセット 5 つ、値のカーブ（プリセット 4 つ・点の追加と移動）を持ちます。位置を決めるメッシュマップ（位置）が要ります。マップを評価へ渡すまでは、理由を欄に出して値のままです。
- グラデーション（`Shift+G`）: 2D のキャンバスをドラッグして、始点（描画色）から終点（透明かサブの色）へ、線形か放射で塗ります。補間は乗算済みアルファです。選んだレイヤーの描くチャンネル、マテリアルで塗るときはその組の全部（終点を今のマテリアルにして 2 つのマテリアルの間も）、マスクを描くときはマスクに（白・黒）。1 回の取り消しで戻ります。3D ビューでは使えません。
- 直線: ブラシ・消しゴム・効果のブラシで、`Shift` を押しながらクリックすると、前のストロークの終わりの点から、そのクリックした点まで直線を 1 本のストロークとして引きます（1 回の取り消しで戻ります。筆圧はクリックした点の値で一定で、入り抜きの設定に従います）。終わりの点は文書の座標で覚えるので、表示を拡大縮小・回転・反転しても同じ点です。前の点が無いとき（文書やテクスチャセットを替えた後・取り消した後）は普通に描き始め、`Shift` で押したままドラッグすると、最初の動きに近い 0・45・90° などの 45° 刻みの向きに固定します。2D のキャンバスだけです。
- 図形（`U`）: 直線・長方形（角の丸みを選べます）・楕円を、ドラッグで決めて描きます。「線で描く」は今のブラシで輪郭を 1 本のストロークとして、「塗る」は描画色で形の中を塗ります（選択範囲があればその中だけ。マテリアルで塗るときとマスクを描くときも同じ）。`Shift` で 45° 刻み・正方形・正円、`Alt` で中心から、`Esc` で取りやめ。ドラッグの途中は輪郭を重ねて見せ、離したところで 1 回の取り消しにまとめます。輪郭の線では手ぶれ補正と曲線補間だけを使わず、入り抜き・対称・ステンシルは今のブラシのとおり効きます。ロックされた層・画素を持たない層は理由つきで断ります。2D のキャンバスだけです。
- 定規（`Shift+U`）とスナップ（`Ctrl+1`）: 直線定規・平行線・同心円・パース（1 点・2 点）を、ドラッグで置き、端点か線をドラッグして動かし、オプションバーの「削除」で消します。1 つのテクスチャセットに 1 つで（セットを替えても、それぞれの定規は残ります）、画面に薄い線で重ねます。スナップ（オプションバー・「表示」メニュー・`Ctrl+1`）が入っているあいだ、ブラシと消しゴムのストローク（`Shift` の直線も）の点を定規へ寄せます（直線定規は線の上、平行線は押した点を通る平行線の上、同心円は押した点を通る円の上、パースは押した点と消失点を結ぶ線の上）。`Shift` と合わせたときは定規の寄せ先が優先です。定規は表示の状態で、`.ylp` には保存せず、プロジェクトを開くと消えます。

PNG の取り込みはステンシルと、塗りつぶしの画像（棚の画像として入ります）だけです。棚へ `.ylsmart` を読み込めます。

## 最初の操作

起動すると、2048 × 2048 のキャンバスと試しの立方体が表示されます。カラー欄で色を選び、2D または 3D ビューを左ドラッグすると描けます。レイヤー欄で描く層を選び、必要に応じて「レイヤー」メニューから新しい層を追加してください。

| 操作 | 入力 |
|---|---|
| ブラシ／消しゴム | `B` / `E` |
| バケツ／グラデーション／ポリゴン塗りつぶし／ID の色で選択 | `G` / `Shift+G` / `4` / `Shift+W` |
| 図形（直線・長方形・楕円）／定規 | `U` / `Shift+U`（図形は `Shift` で 45° 刻み・正方形・正円、`Alt` で中心から） |
| 定規へのスナップのオン・オフ | `Ctrl+1` |
| 前のストロークの終わりから直線を引く | ブラシ・消しゴムで `Shift`＋クリック（`Shift` で押したままドラッグなら 45° 刻みの向きに固定） |
| パス（クリックで点を足す・曲線の上に差し込む・点を掴んで動かす） | `P` |
| パスの選んだ点（無ければ最後の点）を消す | `Delete` / `Backspace` |
| ブラシを小さく／大きく | `[` / `]` |
| 選択の道具（長方形／楕円形／なげなわ／多角形／自動選択／選択ペン） | `M` / `Shift+M` / `L` / `Shift+L` / `W` / `S` |
| すべてを選択／選択を解除／選択範囲を反転 | `Ctrl+A` / `Ctrl+D` / `Ctrl+Shift+I` |
| 選択範囲を追加／削除／共通（選択ペンは `Shift` で選択ペン・`Ctrl` で選択消し）／クイックマスク | 選択の道具で `Shift`／`Ctrl`／`Shift+Ctrl`＋ドラッグ（オプションバーでも選べます）／`Shift+Q`。縦横比の固定は押し始めたあとの `Shift`、中心からは `Alt` |
| 選択範囲の下のボタンの帯（解除・反転・拡張・縮小・境界をぼかす・塗りつぶし・消去・コピーして新しいレイヤー・マスクにする・選択範囲を覚える） | 選択範囲を作ると、その下に出ます（左端の持ち手でずらせます。「選択範囲」メニューで出さないこともできます）。消去は `Delete`、コピーして新しいレイヤーは `Ctrl+J`（選択範囲が無いときの `Ctrl+J` はレイヤーの複製） |
| 多角形を閉じる／最後の点を消す | `Enter`（始めの点・ダブルクリックでも）／`Backspace` |
| 移動・変形の道具 | `V`（ドラッグで移動・拡大縮小・回転。矢印キーで 1 画素、`Shift` で 10。ドラッグの途中の `Enter` で確定、`Esc` で取消） |
| レイヤーを選ぶ（足し引き／範囲／範囲を足す） | レイヤー欄で `Ctrl`＋クリック／`Shift`＋クリック／`Ctrl+Shift`＋クリック |
| 下と結合／表示を結合／複製／グループにまとめる | `Ctrl+E` / `Ctrl+Shift+E` / `Ctrl+J`（選択範囲があるときは、選択範囲をコピーして新しいレイヤーにします） / `Ctrl+G` |
| 取り消し／やり直し | `Ctrl+Z` / `Ctrl+Shift+Z` または `Ctrl+Y` |
| コピー／カット／結合してコピー／ペースト | `Ctrl+C` / `Ctrl+X` / `Ctrl+Shift+C` / `Ctrl+V`（「編集」メニューにも） |
| 描いているストローク・図形や定規のドラッグ・選択の途中・パスの点の移動の取消（何も無ければ選んだ点を外し、点も無ければ選択範囲を解除。入力欄・メニュー・窓が使っている間は、そちらが先） | `Esc` |
| 2D の拡大縮小 | ホイール、または `Ctrl+Space`＋左ドラッグ（左右に動かす。押した点が中心。動かさずに離すと拡大、`Alt` を足すと縮小） |
| 2D の移動 | 中ボタンドラッグ、または `Space`＋左ドラッグ |
| 2D の回転 | `R`＋左ドラッグ、または `Shift`＋中ボタンドラッグ |

| 2D を画面に合わせる | `Ctrl+0` |
| ステンシルを回す／動かす／大きさを変える | `T` を押したまま、左ドラッグ（`Shift` で 15° 刻み）／中ボタンドラッグか `Ctrl`＋左ドラッグ／右ドラッグか `Alt`＋左ドラッグ（2D・3D とも） |

| ペン | サイドボタンは右ボタン、`Alt`・`Space`・`Ctrl+Space`・`R` はマウスの左ボタンと同じ。描くのは、`Ctrl` もサイドボタンも押していないペン先（と消しゴムの端）だけで、`Shift` を押したペン先は直線になる |
| 新規／開く／保存／別名で保存 | `Ctrl+N` / `Ctrl+O` / `Ctrl+S` / `Ctrl+Shift+S` |

コピー・カットは選択範囲（無ければ層全体）の画素を、描くチャンネル（マスクを描いているならマスク）から写し、同じ画素を OS のクリップボードへ画像でも書きます。ペーストは新しい層になり、ほかのアプリでコピーした画像も貼れます（テクスチャセットより大きい画像は貼れません）。Linux は Wayland の data-control に対応していれば Wayland で、そうでなければ X11 で OS のクリップボードを使います。

Mac では表の `Ctrl` を `Command` に読み替えてください。メニューの表示は `Ctrl` です。`.ylp` はウィンドウへドラッグ＆ドロップしても開けます。モデル全体を見失ったら「表示 → 3D ビューでモデル全体を見る」、パネルを戻すには「表示 → パネルの並びを戻す」を使います。
