# 使い方

[English](en/GUIDE.md)

YoluPainter は、3D モデルのテクスチャを、2D のキャンバスと 3D ビューの両方に描いて作るアプリです。レイヤー・マスク・効果・チャンネルごとの塗りを使い、作業を `.ylp` に保存して、PNG や PSD に書き出します。

この使い方は、やりたい事ごとの頁に分かれています。初めてなら「はじめに」から読んでください。

## 頁の一覧

- [はじめに](GUIDE_START.md): 画面の見方、モード、プロジェクトの作り方と開き方、最初の一筆、2D の表示の動かし方、パネルの並べ方、知らせとログ
- [描く](GUIDE_PAINT.md): ブラシと消しゴム、ブラシの組み替え、筆圧と描き心地、直線・図形・定規、対称、バケツとグラデーション、色、ステンシル、テキスト
- [選択と変形](GUIDE_SELECT.md): 選択範囲の作り方と使い方、覚えた選択範囲、移動・変形、コピーとペースト
- [レイヤーとチャンネル](GUIDE_LAYERS.md): レイヤー・グループ・結合・ロック・マスク・調整レイヤー、チャンネルとノーマルの設定
- [塗りつぶしと効果](GUIDE_FILL.md): 塗りつぶしレイヤー、フィルターとジェネレーター、アセットとライブラリ、アクション
- [パス](GUIDE_PATHS.md): 2D と 3D のパス、パスの一覧、角と取っ手、種類、筆先
- [3D ビューとモデル](GUIDE_3D.md): 3D ビューの操作と見た目、3D に描く、FBX とポーズ、メッシュマップのベイク、重なった UV
- [保存・書き出し・取り込み](GUIDE_FILES.md): 保存、配布用の保存、書き出し、PSD と PNG、復旧、大きな文書
- [設定](GUIDE_SETTINGS.md): 「編集 → 設定…」の項目
- [キーの一覧](GUIDE_KEYS.md): ショートカットの変え方、モードとパイメニュー、キーボード・マウス・ペンの操作
