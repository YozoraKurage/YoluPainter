# グラデーションマップとグラデーションセット

調整レイヤー・フィルターの「グラデーションマップ」は、元の色の明るさ（輝度）を、グラデーション（ランプ）の位置に当てて色を置き換えます。塗りつぶしレイヤーのグラデーション
（グラデーションデカールなど）も同じランプの欄を使います。

## ランプの欄

上から次の順に並びます。細いパネルでは、ボタンと見本は折り返します。

| 欄 | 内容 |
|---|---|
| 逆向き | 暗い所と明るい所の色を入れ替えます（グラデーションマップだけ）。 |
| 混色モード・輝度の補正 | 隣り合う色の分岐点の間の混ぜ方（グラデーションマップだけ。下の「混色」）。 |
| グラデーションセット | 組（グループ）のボタン、見本の一覧、追加・名前を変える・消すボタン。見本を押すとそのグラデーションを当てます。 |
| 分岐点の編集 | 上の行が不透明度の分岐点、下の行が色の分岐点、小さなひし形が中点です。何も無い所を押すと追加し、ドラッグで動かし、右クリックか行の外へ離すと消します（2 つは残します）。Esc でドラッグをやめます。 |
| 選んでいる分岐点 | 前・次の分岐点へ移るボタンと消すボタン、位置（0〜100%）。 |
| 色（色の分岐点） | メイン・サブ・指定、色の見本、スポイト。 |
| 不透明度（不透明度の分岐点） | 不透明度（0% なら元の色のまま）。 |
| 中点・混合率曲線 | その分岐点から次の分岐点までの区間の混ざり方。 |
| 値のカーブ | ランプ全体の入力のゆがめ方（塗りつぶしのグラデーションだけ）。 |

### 色の選び方

- 色の分岐点を**ダブルクリック**するか、色の見本を押すと、色のウィンドウ（色相の円と中の四角・16 進の欄・描画色を入れるボタン・今のカラーセットの色）が出ます。
  ほかの色の欄（塗りつぶしレイヤーの値・lilToon の色など）と同じウィンドウで、ウィンドウは 1 つです。ドラッグ・入力はその場で色に反映され、円・四角のドラッグは離すまで、
  16 進・ボタン・カラーセットの色は 1 回ごとに、1 回の取り消しになります。描画色は動きません。
  見出しの帯をドラッグして動かせ、次に開くときも同じ場所に出ます。ウィンドウの外を押しても閉じません。別の分岐点を選ぶと、ウィンドウはそのままでその分岐点の色を決めます。
  Esc で開いたとき（分岐点を替えたとき）の色へ戻して閉じます（戻した変更も取り消しで辿れます）。閉じるボタンは今の色のまま閉じます。
  不透明度の分岐点を選ぶ・分岐点を消す・別のレイヤーを選ぶと閉じます。
- **メイン**・**サブ**を選ぶと、分岐点の色をメインの色・サブの色（描画色）にして、描画色を替えると付いていきます。付いていく印は画面の状態で、文書には入りません。
  分岐点ごとに 1 つで、いくつでも同時に付いていけます（0 をメイン、最後をサブ、など）。どの分岐点を選んでいても付いていきます。
  その分岐点の色を色の選び・スポイトで決めると、その分岐点だけ付いていくのをやめます（**指定**を押しても同じ）。グラデーションセットを当てるか、文書が別の操作（取り消しなど）で
  分岐点の並びを替えると、全部やめます。分岐点を追加・消すでは、残る分岐点の印は付いたままです（消した分岐点の印だけ無くなります）。
- **スポイト**（Windows のみ）は画面の色を取って、選んでいる色の分岐点に入れます。描画色は動きません。
- 色の分岐点が持つのは RGB だけです。透けは不透明度の分岐点が決めます。
- 値のチャンネル（Roughness など）に当てる塗りつぶしのグラデーションは、色の代わりに値（0〜1）の欄を出します。

## 混色

隣り合う色の分岐点の間の色の混ぜ方で、グラデーションマップのランプにあります。欄の名前は「混色モード」「輝度の補正」で、
**式はこのアプリのもの**です（ほかのアプリの同名のモードと画素まで一致するとは限りません）。

| 混色モード | 式 |
|---|---|
| 通常 | sRGB の値（0〜255）をそのまま線形に補間します。これまでの混ぜ方で、PSD のグラデーションと同じです。 |
| リニア | sRGB を線形の光へ戻して補間し、sRGB へ戻します。暗い色どうしを混ぜても沈みません。 |
| 知覚的 | 線形の光から Oklab（Björn Ottosson）へ移して L・a・b を補間し、戻します。色が濁りにくく、鮮やかに混ざります。sRGB の外へ出た色は、各チャンネルを 0〜1 に収めます。 |

混ぜる重みは、区間の中点（または混合率曲線）が決めます。分岐点の上（重み 0 と 1）の色は、どの混色モードでも分岐点の色そのものです。

### 輝度の補正

知覚的のときだけ使える 5 段階（なし・低・中・高・最大）で、強いほど混ぜた色が明るくなります。両端の彩度の混ぜ合わせより、混ぜた結果の彩度が落ちた量
（ΔC = (1−t)・C0 + t・C1 − C。C は Oklab の a・b の長さ、t は重み）に比例して、Oklab の明るさ L を持ち上げます。

`L' = min(1, L + k・ΔC)`、`k` は 段階ごとに 0・0.25・0.5・0.75・1。

補色どうしの真ん中のように彩度が落ちる所ほど明るくなり、分岐点の上と、彩度が落ちない混ぜ（同じ色相どうし）では変わりません。既定は「高」です。

## 混合率曲線

色の分岐点から次の分岐点までの区間ごとに、混ざり方を曲線で決められます（その分岐点の「混合率曲線」のチェック）。横が 2 つの分岐点の間の位置、縦が左の分岐点の色（下）から
右の分岐点の色（上）への混ざり具合です。

- 曲線を使い始めるときは、今の中点と同じ向きの曲線から始まります（(0,0)・(中点,0.5)・(1,1) を通る）。曲線を使う区間では中点を使いません（外すと中点が戻ります。中点の値は消えません）。
- 点は 16 個まで。何も無い所を押すと追加し、ドラッグで動かし、右クリックか枠の外へ離すと消します（両端は横に動かせません）。
- 曲線の端の高さが 0 と 1 でないと、分岐点の上で色が跳びます。
- 分岐点を追加すると、曲線のある区間は分岐点の所で左右に分かれます（標本にして作り直すので、見た目はほぼ保たれます）。分岐点を消すと、両隣の区間は 1 つにつながり、曲線なしに戻ります。
  位置・色を変えても曲線は残ります。

「値のカーブ」（塗りつぶしのグラデーションにある、入力からランプの位置へのゆがめ方）とは別のもので、混合率曲線は区間の中の混ざり方だけを決めます。評価の順は、
入力 → 値のカーブ → どの区間か → 区間の重み（混合率曲線があればそれ、無ければ中点）→ 混色モード、です。

## グラデーションセット

ランプの見本の一覧で、組（グループ）ごとに並びます。組み込みの組は 基本・陰影・色味・空と光・特殊、最後の「自分」が自分のグラデーションの組です。

- 見本を押すと、そのグラデーションを当てます。セットが持つのは分岐点の並び・混合率曲線・値のカーブで、**混色モードと輝度の補正は今のものを残します**。混色を持てない塗りつぶしのグラデーションに当てるときは、
  混合率曲線を外します。値のカーブの欄が無いグラデーションマップに当てるときは、値のカーブを直線にします（見えず直せないカーブを入れないため）。塗りつぶしのグラデーションには値のカーブも当たります。
- 「基本」の「メイン→サブ」「メイン→透明」「白→黒」は、そのときの描画色で作ります。
- 追加ボタンは、今のランプを「自分」の組へ追加します（名前は「グラデーション N」）。名前を変える・消すボタンは「自分」の組の選んでいる見本にだけ効きます。組み込みは変えられません。
- 自分のグラデーションは 128 個までです。

### 保存

設定のフォルダの `gradients/user.ylgrad` に保存します（サブツールの `.ylsubtool` と同じ流儀）。1 行目が `yolupainter-gradients 1`、あとは `key=value` の行です
（UTF-8、8 MiB まで、空行は読み飛ばします）。

```text
yolupainter-gradients 1
ramp.1.name=夕空
ramp.1.colors=0:1a2040:0.5;0.5:cc5060:0.3;1:ffd080:0.5
ramp.1.opacities=0:1:0.5;1:1:0.5
ramp.1.curve=0:0;0.5:0.6;1:1
ramp.1.segment.0=0:0;0.3:0.8;1:1
```

- `colors` は `位置:RRGGBB:中点` を `;` でつなぎます。`opacities` は `位置:不透明度:中点`。`curve`（値のカーブ。無ければ直線）と `segment.<区間>`（その区間の混合率曲線。無ければ中点）は `x:y` の列です。
- 番号は 1 から、セットは番号の順です。知らない項目・重なった項目・範囲を外れた値・名前や色の無いもの・多すぎるものがあるファイルは、ファイルごと読み込まず、理由を知らせます
  （そのファイルへは保存しません。版が新しいファイルも触りません）。
- 書き込みは、一時ファイルへ書いて読み戻して確かめてから、最後の 1 回の置換で確定します（途中で落ちても前の版が残ります）。保存できないときは、追加・名前を変える・消すをせず、理由を知らせます。起動のときに読めなかったファイルが残っているあいだも同じです
  （上書きしないので、一覧にだけ残して再起動で消える、ということをしません）。そのファイルを直すか、退けて、アプリを開き直すと、また追加できます。

## 保存と PSD

- `.ylp` では、混色（通常でない混色モード・混合率曲線）を使うグラデーションマップのある文書だけが正本の版 25 になります。使わない文書は今までの版のままです。
  0.4.x までの Unity 版は版 22 以上の文書を開けません。形式の詳細は [YLP_FORMAT.md](YLP_FORMAT.md) の「色調補正の欄」。
- 塗りつぶしのグラデーションのランプは、0.4.x までの Unity 版も読める並び（正本の版 21）で保存するため、混色・混合率曲線を持てません（欄にも出しません）。
- PSD の調整レイヤーのグラデーションは、sRGB の値の線形な補間（中点つき）だけを持ちます。混色や混合率曲線のあるグラデーションマップは、そのままは書けません。
  「焼き込んで書く」では、輝度の 256 点で元の色を調べて停止点の列（色・不透明度それぞれ 32 個まで、位置は 1/4096）へ展開します。近似なので、展開した停止点の数と
  書き出した合成の最大の差を、書く前の「PSD の書き出しの確かめ」のウィンドウにレイヤーの名前つきで出します。展開した理由は、使っていたものだけを言います（値のカーブだけなら「カーブ」、混色だけなら「混色」、両方なら「カーブ・混色」）。PSD を開き直しても混色モードは戻りません。
