# はじめに

[English](en/GUIDE_START.md)

この頁では、画面の見方、文書（プロジェクト）の作り方と開き方、最初の一筆、2D の表示の動かし方、パネルの並べ方を説明します。起動すると、2048 × 2048 のキャンバスと試しの立方体が開きます。初めのレイヤーは、一番下に白の単色の塗りつぶしレイヤー（「塗りつぶし 1」）、その上に空の「レイヤー 1」で、空のレイヤーを選んだ形で始まります。

## 画面の見方

| 場所 | 中身 |
|---|---|
| メニューバー（上端） | ファイル・編集・レイヤー・選択範囲・フィルター・表示・ウィンドウ・ヘルプ。右端にプロジェクトの名前（保存していない変更があると「•」が付きます）と、Live Link の入り口の Unity の印が並びます |
| オプションバー（その下） | 左端にモード（ペイント・編集・ポーズ・ハイド）。その右に、選んでいるツールでよく使う設定を 2〜3 個。ツールプロパティと同じ値です |
| ツールバー（左端） | ツールのボタン（編集・ポーズのモードでは、選択・移動・回転・拡縮の 4 つ。ハイドのモードでは、面を選ぶ・隠すボタン）。いちばん下にメインの色とサブの色があります |
| 左のドック | 上から縦に「サブツール」（英語の表示は Tools）・「ツールプロパティ」・「ブラシサイズ」、いちばん下に「カラー」・「カラーセット」 |
| 中央 | 左に「3D ビュー」、右に「キャンバス」（2D）が並びます。どちらもタブなので、重ねて切り替えることもできます |
| 右のドック | 上から「テクスチャセット」・「チャンネル」・「アセット」、「レイヤー」・「ログ」、「プロパティ」・「マテリアル」・「ヒストリー」。「ナビゲーター」は閉じていて、「ウィンドウ」のメニューで開くと「テクスチャセット」の組に入ります（開いている間はチェックが付き、もう一度押すと閉じます。「アクション」も同じです） |
| 状態の帯（下端） | 右端にバージョンとビルド（例: `0.7.0 · a1b2c3d`）、使っているメモリ。左端には、直前の操作の結果が 1 行の知らせとして出ます（下の「知らせとログ」） |

「サブツール」「ツールプロパティ」「ブラシサイズ」のパネルは、選んでいるツールに合わせて中身が変わります。ブラシの選び方と設定は [GUIDE_PAINT.md](GUIDE_PAINT.md) にあります。「プロパティ」には、選んでいるレイヤーの中身が出ます（[GUIDE_LAYERS.md](GUIDE_LAYERS.md)）。「マテリアル」には、今のテクスチャセットの見た目の設定が出ます（[GUIDE_3D.md](GUIDE_3D.md)）。ポーズのパネルは、ボーンのあるモデルを読み込むと現れます（[GUIDE_3D.md](GUIDE_3D.md)）。

## モード

描くのは「ペイント」のモードです。「編集」「ポーズ」「ハイド」のモードでは描きません。2D のキャンバスは見るだけになり（表示の移動・回転・拡大と、右ボタンのスポイトは使えます）、3D ビューにも描きません。ブラシと色のパネルは暗くなって押せません。ポーズのモードは、ボーンのあるモデルを読んでいるときだけ選べます（[GUIDE_3D.md](GUIDE_3D.md)）。編集のモードでは、3D ビューの印で塗りつぶしの投影・グラデーションデカール・フィルターの形・点・3D のパス・3D の定規を選んで `G`・`R`・`S` で動かし、ポーズのモードでは、選んだボーンを同じキーで動かします（[GUIDE_3D.md](GUIDE_3D.md) の「物を選んで動かす」）。ハイドのモードでは、3D ビューごとに UV アイランドとボーンで面を隠します（[GUIDE_3D.md](GUIDE_3D.md) の「面を隠す（ハイドのモード）」）。

モードは次のどれかで替えます。描いている最中は替えられません。

- オプションバーの左端のドロップダウン。
- `Ctrl+Tab` のパイメニュー（ポインタの所に開きます。キーを押したまま項目の向きへ動かして離すか、すぐ離して項目をクリック。使い方は [GUIDE_KEYS.md](GUIDE_KEYS.md)）。
- 「表示 → モード」。
- 描くツールを選ぶと（「編集」のメニューのツールなど）ペイントに、ポーズのパネルの「ボーン」の木でボーンを選ぶとポーズになります。

## 文書を作る・開く・保存する

### 新しいプロジェクトを作る

「ファイル → 新規プロジェクト…」（`Ctrl+N`）で、次の項目を決めて「作成」を押します。

- 「テンプレート」: 「PBR（すべてのチャンネル）」・「lilToon（カラー・ノーマル・エミッション）」・「カラーのみ」。初めのレイヤーで使うチャンネルが変わります。どのテクスチャセットも、一番下に白の単色（「塗りつぶし 1」。Color のチャンネルだけ）、その上に空の「レイヤー 1」を選んだ形で始まります（Color を使わないテンプレートでは、白は置かず空のレイヤーだけです）。
- 「メッシュ」: 「モデルを選ぶ…」で FBX を選ぶと、モデルのマテリアルごとにテクスチャセットを作れます。選ばなければ 2D で描く文書になり、モデルはあとから選べます。
- 「テクスチャセット」: 作るテクスチャセットの行です。モデルを選ぶと、マテリアルごとに 1 行ずつ並びます。行ごとに名前・大きさ（512・1024・2048・4096・8192）・マテリアルを決めます。マテリアルの欄では複数のマテリアルを選べ、ほかの行のマテリアルを選ぶとその行から移ります。マテリアルの無くなった行は作られません。
- 「ノーマルマップの形式」と「作成後にメッシュマップをベイクする」。

作ったあとの変更は「ファイル → プロジェクト設定…」でします。新規プロジェクトと同じ行で、テクスチャセットの追加と削除、名前、割り当てるマテリアル（複数も選べます）、大きさ、モデルの差し替えと読み直し、ノーマルマップの形式を直せます。

### テクスチャセット

テクスチャセットは、モデルのマテリアルに貼るテクスチャです。1 つのテクスチャセットを複数のマテリアルに割り当てると、そのマテリアルの面が同じテクスチャを使います。1 つのプロジェクトに最大 64 個まで持てます。レイヤー・取り消しの履歴・選択範囲はテクスチャセットごとに分かれています。「テクスチャセット」のパネルで、セットの切り替え、名前の変更（ダブルクリック）、セットの追加（今のセットと同じ大きさとチャンネル。白の単色と空のレイヤーで始まります）、今のセットの削除、3D ビューと Unity へ見せるかどうかの切り替え（目の印）ができます。複数のマテリアルを割り当てたセットの行には、マテリアルの名前が並びます。1 つのテクスチャセットの中には、レイヤーのまとまり（レイヤーセット）を複数持てます（[GUIDE_LAYERS.md](GUIDE_LAYERS.md) の「レイヤーセット」）。

### 開く・保存する

「ファイル → 開く…」（`Ctrl+O`）で `.ylp` を開きます。`.ylp` のファイルをウィンドウへドラッグ＆ドロップしても開けます。保存していない変更があるときは、「保存していない変更があります。」と聞きます。「変更を確認」（初めから選ばれていて `Enter`）は開かずにアプリへ戻り、「変更を破棄」は変更を捨てて開き、「キャンセル」（`Esc`）はやめます。「ファイル → 最近開いたプロジェクト」には、開いた・保存した `.ylp` が新しい順に 10 件まで並びます（ポインタを乗せるとフルパスが出ます。「一覧を消す」で消せます。見つからないファイルは開かずに一覧から外します）。FBX のファイルをドロップすると 3D ビューに読み込み、PSD と画像（PNG・JPEG・TGA）は「ファイルの取り込み」のウィンドウで入れ先を選んで取り込みます（[GUIDE_FILES.md](GUIDE_FILES.md)）。

保存は「保存」（`Ctrl+S`）と「別名で保存…」（`Ctrl+Shift+S`）です。書き出し・PSD・配布用の保存・復旧は [GUIDE_FILES.md](GUIDE_FILES.md) にまとめています。0.4.x までの Unity ブリッジとの `.ylp` の受け渡しは [UNITY.md](UNITY.md) を見てください。

## 最初の一筆

1. 色を決めます。ツールバー下端のメインの色か、「カラー」のパネルで選びます。
2. 「サブツール」のパネルでブラシを選びます（キーは `B`）。
3. 「レイヤー」のパネルで描くレイヤーを選びます。新しく作るなら `Ctrl+Shift+N` です。
4. 「キャンバス」か「3D ビュー」を左ドラッグします。
5. 間違えたら `Ctrl+Z` で取り消し、`Ctrl+Shift+Z`（か `Ctrl+Y`）でやり直します。「ヒストリー」のパネルで行を押すと、その段まで一度に戻れます。
6. `Ctrl+S` で保存します。

## 2D の表示を動かす

表示だけを動かします。保存する画像は回転も反転もしません。

| 操作 | 入力 |
|---|---|
| 拡大・縮小 | ホイール、または `Ctrl+Space` を押しながら左ドラッグ（左右に動かします。押した点が中心です） |
| 移動 | 中ボタンドラッグ、または `Space` を押しながら左ドラッグ |
| 回転 | `Alt` を押しながら左ドラッグ（15° 刻み。`Shift` も押すと自由）。`Shift+R` で戻します |
| 左右反転 | `H` |
| 画面に合わせる | `Ctrl+0` |

「表示」メニューには、上から、UV ワイヤーフレームと重なった UV の入り切り（[GUIDE_3D.md](GUIDE_3D.md)）、ズームイン、ズームアウト、画面に合わせる、（区切り線）表示を左に回す、表示を右に回す、回転を戻す、表示を左右反転、（区切り線）定規にスナップ・特殊定規にスナップ・スナップする特殊定規の切り替え（[GUIDE_PAINT.md](GUIDE_PAINT.md)）、（区切り線）モード、3D ビューでモデル全体を見る、があります。「ナビゲーター」のパネルでは、キャンバス全体の縮小図を押すかドラッグして見る場所を動かせます（今の表示範囲が枠で出ます）。「拡大率」と「回転」のスライダーと、左右反転・全体を表示・100%・回転を戻すのボタンもあります。3D ビューの動かし方は [GUIDE_3D.md](GUIDE_3D.md) にあります。

キャンバスの右上には、2 つのボタンが重なっています。左の「目・UV・▽」は、目と UV の文字を押すと UV ワイヤーフレームの表示を入り切りし、▽ で線の色と不透明度を変えます。右は描くチャンネルのボタンで、押すと「テクスチャセット」「レイヤーセット」「描くチャンネル」の 3 つの列の欄が開きます。行を押すとそのテクスチャセット・レイヤーセット・チャンネルに替わり（チャンネルは描く先。右の目で 2D のキャンバスに見せるチャンネル）、列の見出しの「＋」でテクスチャセットとレイヤーセットを追加します。描いているあいだは押せません。

## パネルを並べ替える

タブをドラッグして、ほかのタブの組へ入れたり、縁へ落として並べたりできます。キャンバスと 3D ビューを並べると、両方を見ながら描けます。並び（タブの組・分け方・大きさ・前に出ているタブ）とウィンドウの大きさ・位置・最大化は、設定のフォルダの `YoluPainter/layout.json` に覚え、次の起動で戻します。仕切りもタブも動かしていない間は、ウィンドウの幅を変えると右の列の幅が追いかけます（幅の約 19%、下限あり）。動かした後は変わりません。読めない、知らないタブがある、タブが足りない・重なる、といった並びのときは、既定の並びで始めます。ただし、前のバージョンが保存した並びに無い「ツールプロパティ」「ブラシサイズ」「マテリアル」は、並びを捨てずに、読んだときに追加します（ツールプロパティとブラシサイズは「サブツール」の組の下に縦に、マテリアルは「プロパティ」のすぐ後ろに）。ほかのタブの並びは変えません（前のバージョンの並びでは、「アセット」「チャンネル」「ナビゲーター」も今までの組のまま、キャンバスと 3D ビューも今までのとおり 1 つの組です）。0.5.x は、この 3 つのタブのあるファイルを読むと、知らないタブがあるので既定の並びで始めます。保存した位置が、今つながっている画面のどこにも見えないときは、位置は戻さず大きさだけ戻します。画面より大きいウィンドウは、起動のあと 1 度だけ画面に収めます。0.4.x は、別ウィンドウのあるこのファイルを読むと、既定の並びで始めます。

「ウィンドウ」メニューには、パネルの一覧が並びます。開いているパネルには印が付き、押すと前に出ます。閉じているパネルは開きます。「パネルの並びを戻す」で既定の並びに戻り、別ウィンドウは閉じます。

### UI を隠す

`Tab` を押すと、メニューバーとビュー（キャンバスと 3D ビュー）だけを残して、ツールバー・オプションバー・ビューでないパネル・ビューのタブの見出し・ビューの中のボタンを隠します。もう一度 `Tab` で戻ります（キーは「ショートカット」の「UI を隠す・戻す」で替えられます）。隠しているあいだも状態の帯は出て、右に「UI を非表示中です、Tab キーで復帰できます。」と出ます。並びは変えないので、戻すと元の並びと広さに戻ります。別ウィンドウに出したパネルは隠しません。描いている最中は切り替えられません。

### 別ウィンドウに出す

ドックのタブを右クリックして「別ウィンドウで開く」を選ぶか、タブをメインウィンドウの外へドラッグして離すと、そのパネルが OS の別ウィンドウになります。別のモニターにも置けます。キャンバスと 3D ビューも別ウィンドウで描けます。キー・ペンの筆圧・ファイルのドロップは、フォーカスのあるウィンドウで同じように効きます。

- 別ウィンドウどうしは、タブをドラッグして組にできます。
- ドックへ戻すには、タブをメインウィンドウのドックの上で離すか、右クリックの「ドックに戻す」を選ぶか、ウィンドウを閉じます。閉じたときは、出す前にいた組へ戻ります。
- 位置・大きさ・中のタブは次の起動で戻ります。外したモニターにあったウィンドウは、メインウィンドウの上に開きます（Windows。Linux は覚えた位置のまま開きます）。
- Windows の別ウィンドウは、タスクバーに出ず、メインウィンドウの前に留まり、メインウィンドウを最小化すると一緒に隠れます。OS のタイトルバーは無く、タブの行の何も無い所を引くと動き、ダブルクリックで最大化と元に戻すを切り替え、右端の閉じるでドックへ戻り、縁を引くと大きさが変わります。
- 「アセット」の品を別ウィンドウのパネルへドラッグして落とすことはできません（同じウィンドウの中だけです）。別ウィンドウのパネルでは、ペンのサイドボタンが右クリックになりません。キャンバスと 3D ビューのサイドボタンの操作は効きます。

### Windows の上の帯

Windows では OS のタイトルバーを使わず、メニューバーの右端に最小化・最大化（最大化中は元に戻す）・閉じるを置きます。帯の何も無い所を引くとウィンドウが動き、ダブルクリックで最大化と元に戻すを切り替え、縁を引くと大きさが変わります。Mac と Linux は OS の枠のままです。

### 一覧のスクロール

一覧と欄のスクロールは、どこも同じです。ホイールで送れます。右の縁のつまみを掴んで動かせます。溝を押すと、つまみが押した所へ移り、そのまま動かせます。ペンの押して動かす入力でも、マウスと同じようにつまみを動かせます。一覧（レイヤー・ブラシ・アセット・プロパティ・チャンネルなど）の上で右ボタンを押したまま動かすと、一覧がポインタについてスクロールします（押し始めた一覧は、ポインタがパネルの外へ出ても続けて送ります）。左のツールバーの上で右ボタンを押したまま動かすと、ポインタが通ったツールを選びます。動かさずに離せば、今までどおり右クリックのメニューです。つまみは普段は細く、ポインタを近づけたり掴んだりすると太くなります。

## 知らせとログ

操作の結果や、できなかった理由は、状態の帯の左端に 1 行の知らせとして出て、消えます。右端の表示に届く長い文は「…」で切り、全文はポインタを乗せると出ます。

- 済んだ知らせは 4 秒、断り・注意・失敗は 12 秒で消えます。押すとすぐ消えます。ポインタを乗せているあいだは消えません（乗せ続けても、初めて出てから 3 倍の 12 秒・36 秒で消えます）。
- 断りと失敗は「何が（なぜ）」の 1 文です。
- 「ログ」のパネルには、起動してからの注意とエラーが時刻・種類・出どころ・文で並びます（最大 1,000 行。同じ知らせが続くと 1 行にまとめて「×3」のように回数を出します）。上の帯のボタンで、エラーだけに絞る、選んだ行を写す、全部を写す、ログを消す、ができます。行は押して選び、`Ctrl` で追加と解除、`Shift` で範囲を選びます。済んだ知らせと断りはログに入りません。「ヘルプ → ログのフォルダを開く」で、診断の記録のファイルがあるフォルダを開けます。
- まだ読んでいないクラッシュの記録があるときは、メニューバーに「!」が出ます。押すと「クラッシュの報告」が開き、内容のコピー、フォルダを開く、GitHub の報告の頁を開く、ができます。自動では送りません。

状態の帯の右端のメモリの表示にポインタを乗せると、内訳（アプリ全体・レイヤーのメモリ・取り消しの履歴・GPU）が出ます。GPU の量は、取得できるときだけ並びます。外からの操作を受けているときは、その左に小さな丸が出ます（[GUIDE_SETTINGS.md](GUIDE_SETTINGS.md)）。
