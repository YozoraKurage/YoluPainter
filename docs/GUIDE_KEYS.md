# キーの一覧

[English](en/GUIDE_KEYS.md)

キーボードとマウス・ペンの操作の一覧です。キーとマウスの組み合わせは、アプリの「編集 → 設定…」の「ショートカット」の区分で見て、変えられます（下の「ショートカットを変える」）。下の「既定の割り当て」の表は、アプリの表から作った、変える前の割り当てです。Mac では、表の `Ctrl` を `Command` に読み替えてください（メニューにも `Cmd` と出ます）。ただし、モードのパイメニューの `Ctrl+Tab` は Mac でも `Control` です。

## ショートカットを変える

「編集 → 設定…」（`Ctrl+,`）の左で「ショートカット」を押すと、キーとマウスの組み合わせを見て、変えられます。その下に並ぶ区分（どこでも・視点／ペイント／編集／ポーズ／途中の操作／パイメニュー）を選び、右の表で操作の名前・キー・マウスを見ます。

| 操作 | 入力 |
|---|---|
| キーを変える | キーの欄を押して、入れたいキーを押す（修飾キーだけでは決まりません）。`+` の欄で、キーをもう 1 つ加えます。押している間だけ効くキー（`Space` など）と途中の操作のキーは、修飾の無いキー 1 つだけです |
| やめる / キーを外す | 待っている間の `Esc` / `Backspace` |
| マウスの組み合わせを変える | マウスの欄を押して、その欄の上で、修飾キーを押しながら入れたいボタン（左・右・中・戻る・進む）を押す。ボタンも修飾も変わります。ステンシルを回す間の刻みの行は、修飾だけが変わります（修飾の無い押しでは決まりません） |
| 名前で探す / キーで探す | 表の上の欄に名前を打つ / 「キーで探す」を押して、探すキーを押す（そのキーの行だけを、全部の区分から出します。もう一度押すと戻ります）。設定のウィンドウの一番上の「設定を探す」は、ほかの設定の項目を探す欄で、この表は絞りません |
| 1 行を既定に戻す / 全部を既定に戻す | 変えた行の右端の印 / 下の「既定に戻す」 |
| 書き出す / 読み込む | 下の「書き出し…」 / 「読み込み…」（キー・マウス・パイメニューの全部。読み込みは今の変更を置き換えます。知らない操作は飛ばして、その数を知らせます） |

- 同じ区分・同じ場面で同じキーが別の操作を指すと、その行が赤くなり、相手の名前がツールチップに出ます。ぶつかりが残っている間は、変えた割り当ては効きますが、ファイルには保存しません（下の帯に理由が出ます）。
- モードの区分（ペイント・編集・ポーズ）のキーが、どこでもの区分の同じキーより先に取るのは、ぶつかりではありません（ツールチップに、先に取る操作が出ます）。
- マウスでは、2D と 3D の表示を動かす操作（動かさずに離したときの操作も）を修飾の無い左ボタンにすると、描く操作とぶつかります。2D のキャンバスは、表示を動かす操作・選択範囲の作り方・スポイトの順に押しを見るので、同じ組み合わせのほか、前の操作の組み合わせに修飾を足しただけの組み合わせを後の操作に当てても、ぶつかりです（例: 回転が `Alt`＋左ボタンのとき、選択範囲の追加を `Alt+Shift`＋左ボタンにする）。
- マウスの組み合わせは、書いていない修飾を足して押しても当たります（`Alt`＋左ボタンの回転は、`Alt+Shift`＋左ボタンでも回します）。動かさずに離したときの操作と 2D のスポイトは、書いたとおりの修飾のときだけです。
- クリップボード（コピー・カット・結合してコピー・ペースト）のキーと、`Esc`・`Enter`・`Backspace` の決まった働き、編集のモードで物を選ぶ左クリックは変えられません。
- 変えた割り当ては、設定のフォルダの `keymap.json` に、既定から変えた所だけを保存します。読めない `keymap.json` があるときは既定のキーで始めて知らせ、ファイルは消さずに残します（次に保存するとき、`keymap.broken.json` に移してから書きます。同じ名前があれば `keymap.broken-2.json` のように番号を付けます）。
- 「パイメニュー」の区分では、パイを選んで、名前・開くキー・8 か所の項目（操作・別のパイ・yolu-ops の命令・記録したアクション）を決めます。`+` でパイを追加し、ごみ箱の印で削除します（最初からあるモードと視点のパイは、中身だけを変えられます）。
- メニュー・ツールチップに出るキーは、変えた割り当てに付いてきます（今のモードで効くキーだけを出します）。
- ツールのキー（ペイントの区分のツールの行）は、行の右の欄（見出しは「マウス・動き方」）で、キーごとに動き方を選べます。
  - **押すと切り替え**（既定）: 押すとそのツールに替わります。離しても戻りません。
  - **押している間だけ**: 押している間だけそのツールになり、離すと押す前のツール（ブラシの設定も）に戻ります。
  - **短く押すと切り替え・長押しで押している間だけ**: 0.25 秒以内に離すと、そのツールのままです。0.25 秒より長く押してから離すか、押している間に描くと、離したとき押す前のツールに戻ります。
  - 描いている途中で離したときは、その線（選択の形・グラデーション・図形・定規のドラッグも）を描き終えてから戻ります（2D・3D、マウス・ペンとも。多角形選択は、閉じるか取りやめるまで戻りません）。同じ線のうちに同じキーを押し直したときは、そのまま続きます。押している間にツールバー・別のキー・パイメニュー・ブラシの一覧でツールやブラシを選ぶと、戻さずにその選びが残ります。押している間に別の「押している間だけ」のキーを押したときは積み重ねになり、後から押したキーを離すと先のキーのツールへ、先のキーを先に離したときは、後のキーを離すと最初のツールへ戻ります。モードを替えるときは、離したものとして扱い、押す前のツールへ戻してから替えます。ウィンドウがフォーカスを失ったり、メニューやダイアログが開いたり、文字の入力欄を使い始めたりしたときは、離したものとして扱います。すでに選んでいるツールのキーを押しても、何も変わりません。押している間は、戻る先のツールのボタンに点が付きます。`Shift` などの修飾キーを含むキーは、修飾キーを先に離しても、キーを離すまで続きます。

## モードとパイメニュー

モードは、ペイント・編集・ポーズの 3 つです。描くのはペイントのモードだけです。ツールのキー、ブラシの大きさ（`[` / `]`）、色の入れ替えと初期設定の色（`X` / `D`）、パスと点のグラデーションのキー、クイックマスク（`Shift+Q`）、移動・変形の矢印キー、画面の色を取得（Windows）、画素を変えるキー（選択範囲を消去の `Delete`、カットの `Ctrl+X`、ペーストの `Ctrl+V`、下と結合の `Ctrl+E`、表示を結合の `Ctrl+Shift+E`）は、ペイントのモードだけで効きます。メニューとボタンの操作は、どのモードでも使えます（メニューに出るキーも、今のモードで効くものだけです）。

| 操作 | 入力 |
|---|---|
| モードのパイメニュー | `Ctrl+Tab`（ポインタの所に開きます。マウスのボタンを押している間とドラッグの途中は開きません） |
| パイメニューの項目を選ぶ | キーを押したまま項目の向きへ動かして離す。すぐ離したときは開いたままなので、項目をクリック。`1`〜`8`（上から時計回り）でも選べます |
| パイメニューを閉じる | `Esc`・右クリック・真ん中のクリック。キーを長く押して、動かさずに離したときも閉じます |

## 編集とポーズのモード

編集のモードでは、3D ビューの白い印で、塗りつぶしの投影の箱・デカール、グラデーションデカール、フィルターの形、点のグラデーションの点、3D のパス、3D の定規を選び、`G`・`R`・`S` で動かします。ポーズのモードでは、選んだボーンを動かします。2D のキャンバスでは動かせません（見るだけです）。

| 操作 | 入力 |
|---|---|
| 物を選ぶ（編集） | 3D ビューの印をクリック（その物のレイヤーも選びます）。重なった印は、同じ所でもう一度クリックすると次の物。何も無い所をクリックすると外します |
| 移動 / 回転 / 拡縮 | `G` / `R` / `S`（ポインタの所から始まり、マウスを動かした量で変わります。点は移動だけです）。ツールの帯の移動・回転・拡縮を選んで、印（ポーズのモードは選んだボーンの面）から左ドラッグしても同じです（離すと決まります。ペンでも） |
| 軸を決める | `X` / `Y` / `Z`（もう一度押すと物の向きの軸、3 回目で軸なし）。`Shift+X` / `Shift+Y` / `Shift+Z` はその軸を除いた面。拡縮の軸は、投影の箱・デカール・形・ボーンでは 1 回目から物の向きの軸です（もう一度押すと軸なし） |
| 値を打つ | 数字・`.`・`-`（符号を替える）・`Backspace` |
| 決める / やめる | 左クリックか `Enter` / 右クリックか `Esc`（やめると始める前に戻り、取り消しの履歴にも残りません） |
| スナップ | `Ctrl` を押している間（既定は移動 0.1・回転 5°・拡縮 0.1。オプションバーで変えられます）。`Shift+Tab` で常にスナップ（そのあいだ `Ctrl` は逆） |
| 位置 / 回転 / 大きさを戻す | `Alt+G` / `Alt+R` / `Alt+S` |
| 選んだ物の印を隠す / 全部出す（編集） | `H` / `Alt+H` |
| 選んだ物を消す（編集） | `Delete`（投影の箱・デカールと、点のグラデーションの最後の点は消せません。押したままでも 1 つだけ消します） |
| 形の取っ手を隠す / 出す（編集） | `Q` |

1 回の移動・回転・拡縮が、取り消し 1 回です（ボーンはポーズの取り消し 1 段）。3D のパスは、決めたときに、動かした点を近くの面の点へ載せ直します（描いた面と同じ向きの面だけ。薄い板の表に描いたパスは、裏へ移りません）。面から離れすぎた点があるときは決められないので、続けて動かすか、やめます。隠したレイヤー（グループの目を消したときも）の物は、選べず、動かせません。

## 描くときの修飾キー

| 操作 | 入力 |
|---|---|
| 前のストロークの終わりから直線を引く | ブラシ・消しゴムで `Shift` ＋クリック（前の点が無いときは、`Shift` を押したままドラッグすると 45° 刻みの向きに固定。2D・3D とも、マウスもペンも） |
| クローンの元を決める | クローンのブラシで `Alt` ＋クリック（動かさずに離す。2D・3D とも。動かせば、2D は回転、3D はスナップ回転です） |
| どのツールからでも色を取る（スポイト） | 2D は右ボタンを押す（押したまま動かすと、ポインタの見本の色が付いてきます。離した所の色を取ります。`Esc` で取りやめ）。3D は右ボタンを動かさずに離す（動かせば視点を回すだけです）。ポリゴン塗りつぶしでは、右ボタンはアイランドのメニューです |
| 図形を 45° 刻み・正方形・正円にする / 中心から描く | `Shift` / ドラッグを始めたあとの `Alt` |
| 定規にスナップのオン・オフ | `Ctrl+1` |
| 特殊定規にスナップのオン・オフ | `Ctrl+2` |
| スナップする特殊定規の切り替え | `Ctrl+4`（ポインタが乗っているビューの空間の特殊定規を回します。どちらのビューにも乗っていなければ、最後にツールで描き始めたビュー。それも無ければ、描ける先が 3D ビューだけのときは 3D、そうでなければ 2D） |
| 描いているストローク・図形や定規のドラッグ・選択の途中・パスの点の移動を取り消す | `Esc`（何も無ければ選んだ点を外し、点も無ければ選択範囲を解除します。入力欄・メニュー・ウィンドウが使っている間は、そちらが先です） |

## 視点の操作と `Alt`

視点の操作は、2D と 3D でそろえてあります。`Alt` は、ボタンを押した瞬間に持っていれば視点の操作（2D は表示の回転、3D はスナップ回転）で、押したあとに押せば、そのツールの修飾（図形・長方形・楕円の「中心から」、パスの取っ手を折るなど）です。選択範囲や図形のドラッグを `Alt` を押したまま始めると、ドラッグは視点の回転になります。

次の組み合わせは使えなくなりました。3D の `Shift` ＋右ドラッグと `Alt`＋`Shift`＋左ドラッグ（移動。`Shift` を押していても、右ドラッグは回転、`Alt`＋左ドラッグはスナップ回転になります）、2D の `R` ＋左ドラッグと `Shift` ＋中ボタンドラッグ（回転。`Shift` を押していても、中ボタンドラッグは移動です）、2D の `Alt` ＋クリックの一時的なスポイト（`Alt` ＋左ドラッグは回転に、スポイトは右ボタンに替わりました）、3D の `Alt` ＋左ドラッグの自由な回転（吸い付くスナップ回転に替わりました）。

## 場面のキーと補足

- 選択範囲のツールは、押し始めに `Shift`（追加）・`Ctrl`（削除）・`Shift+Ctrl`（共通）を持っていると作り方が替わります（オプションバーでも選べます。選択ペンは `Shift` が選択ペン、`Ctrl` が選択消し）。押し始めたあとの `Shift` は縦横比の固定、`Alt` は中心から。
- 多角形選択は `Enter`（始めの点やダブルクリックでも）で閉じ、`Backspace` で最後の点を消します。移動・変形は `Enter` で確定、`Esc` で取りやめ、矢印キーで 1 画素（`Shift` で 10 画素）動かします。
- `Ctrl+J` は、選択範囲があれば選択範囲をコピーして新しいレイヤーに、無ければレイヤーの複製です。
- パスのツールの `Delete` / `Backspace` は、選んだ点（無ければ最後の点）を消します。点のグラデーションの点を選んでいる間は、その点を消します。
- レイヤーの一覧では、`Ctrl` ＋クリックで追加・解除、`Shift` ＋クリックで範囲、`Ctrl+Shift` ＋クリックで範囲を追加して選びます。
- 拡大・縮小はホイールでもできます。`Ctrl+Space` ＋左ドラッグは左右に動かし、押した点が中心です（動かさずに離すと拡大、`Alt` も押すと縮小）。
- 2D の表示の回転は 15° 刻みで、`Shift` も押していれば自由です。3D のスナップ回転は、向きが軸の向き（正面・背面・右・左・上・下）の 15° 以内に入ると、その向きに吸い付きます。
- 表示を右に回すのは `^` の文字で、`=` のキーでも回ります（配列によってキーの位置が違うため）。
- 3D ビューで右ボタンを押している間は、`W` / `S`・`A` / `D`・`Q` / `E` で視点を前後・左右・下上へ動かします（`Shift` で速く。この間、これらのキーはツールの切り替えなどに使われません）。正投影の間の `W` / `S` は寄る・引くです。
- 3D の軸の視点（正面・背面・右・左・上・下）と正投影の切り替えは、視点のパイメニューと、3D ビューの右上の軸の印から使います（どちらも、最初はキーを割り当てていません）。軸の視点を選ぶ・スナップ回転で軸に吸い付くと正投影になり、軸から外れると透視へ戻ります（[GUIDE_3D.md](GUIDE_3D.md) の「軸の視点と正投影」）。
- 編集のモードの `H` は選んだ物の印を隠すので、2D の表示の左右反転は「表示 → 表示を左右反転」から使います。
- ステンシルは、`Y` を押したまま左ドラッグで回し（`Shift` で 15° 刻み）、中ボタンドラッグか `Ctrl` ＋左ドラッグで動かし、右ドラッグか `Alt` ＋左ドラッグで大きさを変えます（2D・3D とも）。`N` を押している間は使いません。
- ゆがみのツールには、既定のキーがありません。

## ペン

サイドボタンは右ボタンの扱いです（2D では色を取る、3D では回す・動かさずに離すと色を取る。2D のポリゴン塗りつぶしでは何もしません）。`Alt`・`Space`・`Ctrl+Space` は、マウスの左ボタンと同じ働きをします。描くのは、`Ctrl` もサイドボタンも押していないペン先（と消しゴムの端）だけで、`Shift` を押したペン先は直線になります（2D・3D とも）。
