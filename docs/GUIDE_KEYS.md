# キーの一覧

[English](en/GUIDE_KEYS.md)

キーボードとマウス・ペンの操作の一覧です。アプリの「ヘルプ → ショートカット」にも、同じ割り当てが出ます。Mac では、表の `Ctrl` を `Command` に読み替えてください（メニューの表示は `Ctrl` です）。

## ツール

| ツール | キー |
|---|---|
| ブラシ / 消しゴム | `B` / `E` |
| バケツ / グラデーション / ポリゴン塗りつぶし | `G` / `Shift+G` / `4` |
| 図形（直線・長方形・楕円）/ 定規 | `U` / `Shift+U` |
| スポイト | `I` |
| 長方形選択 / 楕円形選択 | `M` / `Shift+M` |
| なげなわ / 多角形選択 | `L` / `Shift+L` |
| 自動選択 / 選択ペン / ID の色で選択 | `W` / `S` / `Shift+W` |
| 移動・変形 | `V` |
| パス | `P` |
| テキスト | `T` |
| ブラシを小さく / 大きく | `[` / `]` |
| メインとサブの色を入れ替え / 初期設定の色 | `X` / `D` |

ゆがみのツールには、キーがありません。

## 描くときの修飾キー

| 操作 | 入力 |
|---|---|
| 前のストロークの終わりから直線を引く | ブラシ・消しゴムで `Shift` ＋クリック（前の点が無いときは、`Shift` を押したままドラッグすると 45° 刻みの向きに固定。2D・3D とも、マウスもペンも） |
| クローンの元を決める | クローンのブラシで `Alt` ＋クリック（動かさずに離す。2D・3D とも。動かせば、2D は回転、3D はスナップ回転です） |
| どのツールからでも色を取る（スポイト） | 2D は右ボタンを押す（押したまま動かすと、ポインタの見本の色が付いてきます。離した所の色を取ります。`Esc` で取りやめ）。3D は右ボタンを動かさずに離す（動かせば視点を回すだけです）。ポリゴン塗りつぶしでは、右ボタンはアイランドのメニューです |
| 図形を 45° 刻み・正方形・正円にする / 中心から描く | `Shift` / ドラッグを始めたあとの `Alt` |
| 定規へのスナップのオン・オフ | `Ctrl+1` |
| 描いているストローク・図形や定規のドラッグ・選択の途中・パスの点の移動を取り消す | `Esc`（何も無ければ選んだ点を外し、点も無ければ選択範囲を解除します。入力欄・メニュー・ウィンドウが使っている間は、そちらが先です） |

## パス・塗りつぶしの点

| 操作 | キー |
|---|---|
| パスの選んだ点（無ければ最後の点）を消す | `Delete` / `Backspace` |
| パスの編集を終える（次の点は新しいパスを始めます） | `Enter` |
| 点のグラデーションの選んだ点を消す | `Delete` / `Backspace` |
| 塗りつぶしの投影・グラデーションの箱のハンドルを隠す / 出す | `Q` |

| 操作 | キー |
|---|---|

| 選択範囲を追加 / 削除 / 共通 | 選択ツールで `Shift` / `Ctrl` / `Shift+Ctrl` ＋ドラッグ（オプションバーでも選べます。選択ペンは `Shift` が選択ペン、`Ctrl` が選択消し） |
| 縦横比を固定 / 中心から | 押し始めたあとの `Shift` / `Alt` |
| クイックマスク | `Shift+Q` |
| 選択範囲を消去 | `Delete` |
| 選択範囲をコピーして新しいレイヤーに | `Ctrl+J`（選択範囲が無いときの `Ctrl+J` は、レイヤーの複製） |
| 多角形を閉じる / 最後の点を消す | `Enter`（始めの点やダブルクリックでも）/ `Backspace` |
| 移動・変形を確定 / 取りやめ | `Enter` / `Esc` |
| 移動・変形で 1 画素 / 10 画素動かす | 矢印キー / `Shift` ＋矢印キー |
| コピー / カット / 結合してコピー / ペースト | `Ctrl+C` / `Ctrl+X` / `Ctrl+Shift+C` / `Ctrl+V` |

| 保存 / 別名で保存 | `Ctrl+S` / `Ctrl+Shift+S` |

## 視点の操作と `Alt`

視点の操作は、2D と 3D でそろえてあります。`Alt` は、ボタンを押した瞬間に持っていれば視点の操作（2D は表示の回転、3D はスナップ回転）で、押したあとに押せば、そのツールの修飾（図形・長方形・楕円の「中心から」、パスの取っ手を折るなど）です。選択範囲や図形のドラッグを `Alt` を押したまま始めると、ドラッグは視点の回転になります。

次の組み合わせは使えなくなりました。3D の `Shift` ＋右ドラッグと `Alt`＋`Shift`＋左ドラッグ（移動。`Shift` を押していても、右ドラッグは回転、`Alt`＋左ドラッグはスナップ回転になります）、2D の `R` ＋左ドラッグと `Shift` ＋中ボタンドラッグ（回転。`Shift` を押していても、中ボタンドラッグは移動です）、2D の `Alt` ＋クリックの一時的なスポイト（`Alt` ＋左ドラッグは回転に、スポイトは右ボタンに替わりました）、3D の `Alt` ＋左ドラッグの自由な回転（吸い付くスナップ回転に替わりました）。

## 2D の表示

| 操作 | 入力 |
|---|---|
| 拡大・縮小 | ホイール、または `Ctrl+Space` ＋左ドラッグ（左右に動かします。押した点が中心です。動かさずに離すと拡大、`Alt` も押すと縮小） |
| ズームイン / ズームアウト | `Ctrl++`（`Ctrl+=` でも）/ `Ctrl+-` |
| 移動 | 中ボタンドラッグ、または `Space` ＋左ドラッグ |
| 回転 | `Alt` ＋左ドラッグ（15° 刻み。`Shift` も押していれば自由。動かさずに離すと、クローンのブラシではクローンの元になります） |
| 表示を左に回す / 右に回す | `-` / `^`（`=` のキーでも） |
| 回転を戻す / 左右反転 | `Shift+R` / `H` |
| 色を取る | 右ボタンを押す（押したまま動かして、離した所の色を取ります） |
| 画面に合わせる | `Ctrl+0` |

## 3D ビュー

| 操作 | 入力 |
|---|---|
| 回転 | 右ドラッグ |
| スナップ回転 | `Alt` ＋左ドラッグ（向きが軸の向き（正面・背面・右・左・上・下）の 15° 以内に入ると、その向きに吸い付きます） |
| 視点の前後・左右・下上の移動 | 右ボタンを押している間の `W` / `S`・`A` / `D`・`Q` / `E`（`Shift` で速く。この間、これらのキーはツールの切り替えなどに使われません） |
| 移動 | 中ボタンドラッグ、または `Space` ＋左ドラッグ |
| 拡大・縮小 | ホイール、または `Ctrl+Space` ＋左ドラッグ（2D と同じ） |
| 色を取る | 右ボタンを動かさずに離す |
| 選んだテクスチャセットを画面に収める | `.` |
| 操作を取りやめ | `Esc` |

## ステンシル

| 操作 | 入力 |
|---|---|
| 回す / 動かす / 大きさを変える | `Y` を押したまま、左ドラッグ（`Shift` で 15° 刻み）/ 中ボタンドラッグか `Ctrl` ＋左ドラッグ / 右ドラッグか `Alt` ＋左ドラッグ（2D・3D とも） |
| ステンシルを使わない | `N` を押しているあいだ |
| 操作を取りやめ | `Esc` |

## ペン

サイドボタンは右ボタンの扱いです（2D では色を取る、3D では回す・動かさずに離すと色を取る。2D のポリゴン塗りつぶしでは何もしません）。`Alt`・`Space`・`Ctrl+Space` は、マウスの左ボタンと同じ働きをします。描くのは、`Ctrl` もサイドボタンも押していないペン先（と消しゴムの端）だけで、`Shift` を押したペン先は直線になります（2D・3D とも）。

## 迷ったとき

- モデル全体を見失ったら「表示 → 3D ビューでモデル全体を見る」を使います。
- パネルを元に戻すには「ウィンドウ → パネルの並びを戻す」を使います。
- `.ylp` はウィンドウへドラッグ＆ドロップしても開けます。
