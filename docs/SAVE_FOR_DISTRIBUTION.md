# 配布用に保存

「ファイル → 配布用に保存…」は、開いているプロジェクトの**写し**を、作った人が気づかないまま .ylp に残る物を除いて別のファイルに書きます。.ylp を販売物や配布物に入れるときのためのもので、いつもの保存（作業用のファイル）には何も変わりません。作業用のファイルに残る情報はそのままです（Undo の履歴・消したレイヤー・自動保存・時刻は、もともと .ylp に入りません）。

## 流れ

1. メニューを選ぶと、今の状態（保存していない変更も含む）の写しを裏で作ります。開いている文書・プロジェクト・未保存の印・Undo・開いているファイルは 1 バイトも変わりません。描いている最中は始められません。
2. 除ける物がある種類だけがウィンドウに並びます（0 件の種類は出ません。除ける物が 1 つも無ければウィンドウなしで保存先の選びに進みます）。種類ごとに切り替えを外すと、その種類は残します。既定は全部除きます。
3. 「保存…」で保存先を選びます。既定の名前は今の名前に `-dist` を付けたものです。**開いている作業用のファイルと同じ場所・名前は選べません**。既にあるファイルは、確かめてから置き換えます（前の写しは残しません）。.ylp として読めないファイルは置き換えません。
4. 書き込みは裏で行い、検証した一時ファイルから 1 回の置き換えで確定します。取消・失敗のときは何も書かず、保存先は元のままです。配布用の写しの隣に `-backups~` は作りません（前の版の退避は作業用のファイルの仕事です）。

## 除くもの

| 種類 | 除くもの | 残すもの |
|---|---|---|
| PSD の原本 | `sets/<ID>/imported-original.psd`（0.4.x までの Unity 版が PSD の取り込みで持った、原本の全バイト） | レイヤーに取り込んだ内容 |
| 使っていないアセット | どのレイヤー（塗りつぶしの画像・グラデーションの形・Generator など、正本がアセットを ID で指すもの全部）からも、見た目の設定の画像の割り当てからも使われていないアセット（画像・スマート素材・ブラシ） | 使っている素材（中身も出どころも） |
| 素材の出どころのパス | アセットの出どころのうち、取り込んだファイルの絶対パス（`file`）・Unity のアセットのパス（`unityAsset`）・置き場の相対パス（`library`）。出どころを `none` にします。テキストレイヤーのフォントのファイルの場所（絶対のパス。ユーザーのフォルダに入れたフォントは、ユーザー名を含みます）は、ファイル名だけにします | 画素・名前。内蔵の素材のキーと版（パスではありません）。フォントの SHA-256・ファミリー名・PostScript 名・太さ・斜体（写しを開くと、OS に入っているフォントを名前で探します） |
| モデルの参照 | `view.json` のモデルのファイルの場所と Unity のモデルの GUID、モデルの中のレンダラーの表示の印、根の `pose.json`（モデルのポーズ。どのモデルのものか分からなくなるため）、根の `livelink.json`（Live Link で開いたモデルの記録。FBX と絵のファイルの場所・Unity のプロジェクトの場所・書き出しの置き場・ポーズを持ちます） | セットの目・選んだチャンネルなどの表示の状態 |
| メッシュマップ | `sets/<ID>/meshmap-*.bin`（モデルの形から焼いた派生物） | 焼き直せます（Generator が使うマップは、開いたあとにモデルから焼き直すまで、そのセットが読むだけになることがあります） |
| Unity のマテリアルの値 | 見た目の設定（`look.json`）の `received`（Live Link で Unity のマテリアルから受けた値） | 利用者の見た目の設定 |
| 覚えた選択範囲 | 名前を付けて残した選択範囲（`sets/<ID>/selections.json` と `selection-*.bin`。作業の補助で、絵ではありません）。形式 8 のエントリなので、除くと写しは 0.4.x までの Unity 版でも開ける形式 7 になります | 今の選択範囲（`selection.bin`。絵の一部） |
| 古いサムネイルなど | 根の `thumbnail.png`・`brush.json`・`model.json`（0.4.x までの Unity 版が残したもの。スタンドアロン版は更新しません） | |
| 知らないエントリ | このアプリが知らないエントリ（新しい版が書いたものなど。開くときに「保存すると残らない」と知らせるもの） | |

何が「使っている」かは、除いた後に残る見た目の設定で決まります（Unity の値を除くなら、その中の割り当ては数えません）。ウィンドウの一覧は選びに合わせて変わり、写しに残る物と一致します。

## 除かないもの・保証しないこと

- レイヤー・マスク・チャンネル・今の選択範囲・合成の PNG（絵そのもの）、セットの名前・マテリアルの参照は除きません。写しのレイヤーの画素は、準備を始めた時点の開いている文書と同じです（そのあとの描き込みは入りません）。
- アセットのファイル（`.ylsmart`・`.ylbrush`）は、ファイルごと残すか除くかです。中身は書き換えないので、スマート素材の中の画像の出どころは取り除きません。
- 0.4.x までの Unity 版が残した `brush.json` などの状態のエントリを残す選びのとき、それが指すアセットの画像は「使っている」とは数えません（その Unity 版は状態を読めなければ既定に戻して開きます）。
- レイヤーの名前・セットの名前・素材の名前など、作った人が付けた名前は写しに残ります。フォントのファイル名も残ります。
- 写しの正本を書き直すセット（フォントのファイルを使ったテキストレイヤーがあるセット）は、その間メモリに読みます。正本が 512 MiB を超えて読めないセットは書き直せないので、写しを作れません（理由が出ます。「素材の出どころのパス」を外せば作れますが、フォントの場所は写しに残ります）。
- ディスクキャッシュから読めなくなった、保存したことの無いセットは、いつもの保存と同じく写しに入りません（[RECOVERY.md](RECOVERY.md) の「ディスクキャッシュとの関係」）。

## 互換性

写しは今のファイルと同じ形式（形式 7。覚えた選択範囲を残す写しは形式 8。正本の版も同じ）で、スタンドアロン版で開けます（書いた写しを読み直す試験で確かめています）。覚えた選択範囲を残す写し（形式 8）は、0.3.x のスタンドアロンと 0.4.x までの Unity 版が「新しい形式」として断るので、それらで使う写しでは除いたままにします（既定）。0.4.x までの Unity 版が開けるのは、**正本の版 21 のセットだけを含む写し**です。配布用の写しは正本の版を変えないので、正本の版 22 以上のセット（ユーザーチャンネル・ノイズ・グランジの段・グラデーションマップの混色などを使った文書）を 1 つでも含む写しは、その Unity 版では「Unsupported archive version」で断られて開けません（[YLP_FORMAT.md](YLP_FORMAT.md) の「読み手ごとの範囲」）。その Unity 版でも開ける写しにするには、スタンドアロン版でその機能を消して保存し直し、版を 21 に戻してから、配布用に保存します。

除く物はどれも、0.4.x までの Unity 版の読み手が無くても開けるもの（PSD の原本・状態・派生のエントリ）か、索引と合わせて書き直すアセットで、索引にある素材は中身と必ず揃います（素材が 1 つも残らなければ `resources.json` を書きません）。その Unity 版で開けることは、読み手のコードと形式の決まりを読んで確かめたもので、**Unity 版で実際に開いてはいません**。

## いつもの保存と取り込み直した PSD

PSD を「今のテクスチャセットに」取り込み直して文書を替えたセットは、次のいつもの保存から、そのセットの古い `imported-original.psd` を持ち越しません（新しい文書の原本ではないため）。復旧用の書き置きも同じで、書き置きから復旧して開いたあとの保存にも古い原本は戻りません。同じ文書への描き足しでは、0.4.x までの Unity 版が取り込んだ原本はそのまま残ります。前の版は退避（設定の「退避を残す数」）に残ります。
