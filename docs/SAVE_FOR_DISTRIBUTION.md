# 配布用に保存

「ファイル → 配布用に保存…」は、開いているプロジェクトの**写し**を、作った人が気づかないまま .ylp に残る物を除いて別のファイルに書きます。.ylp を販売物や配布物に入れるときのためのもので、いつもの保存（作業用のファイル）には何も変わりません。作業用のファイルに残る情報（Undo の履歴・消した層・自動保存・時刻・OS のユーザー名や機械名は、もともと .ylp に入りません）はそのままです。

## 流れ

1. メニューを選ぶと、今の状態（保存していない変更も含む）の写しを裏で組みます。開いている文書・プロジェクト・未保存の印・Undo・開いているファイルは 1 バイトも変わりません。描いている最中は始められません。
2. 除ける物がある種類だけが窓に並びます（0 件の種類は出ません。除ける物が 1 つも無ければ窓なしで保存先の選びに進みます）。種類ごとに切り替えを外すと、その種類は残します。既定は全部除きます。
3. 「保存…」で保存先を選びます。既定の名前は今の名前に `-dist` を付けたものです。**開いている作業用のファイルと同じ場所・名前は選べません**。既にあるファイルは、確かめてから置き換えます（前の写しは残しません）。.ylp として読めないファイルは置き換えません。
4. 書き込みは裏で行い、検証した一時ファイルから 1 回の置き換えで確定します。取消・失敗のときは何も書かず、保存先は元のままです。配布用の写しの隣に `-backups~` は作りません（前の版の退避は作業用のファイルの仕事です）。

## 除くもの

| 種類 | 除くもの | 残すもの |
|---|---|---|
| PSD の原本 | `sets/<ID>/imported-original.psd`（Unity 版が PSD の取り込みで持つ、原本の全バイト） | 層に取り込んだ内容 |
| 使っていない棚の素材 | どの層（塗りつぶしの画像・グラデーションの形・Generator など、正本が棚を ID で指すもの全部）からも、見た目の設定の画像の割り当てからも使われていない棚の画像・スマート素材・ブラシ | 使っている素材（中身も出どころも） |
| 素材の出どころのパス | 棚の素材の出どころのうち、取り込んだファイルの絶対パス（`file`）・Unity のアセットのパス（`unityAsset`）・置き場の相対パス（`library`）。出どころを `none` にします | 画素・名前。内蔵の素材のキーと版（パスではありません） |
| モデルの参照 | `view.json` のモデルのファイルの場所と Unity のモデルの GUID、モデルの中のレンダラーの表示の印 | セットの目・選んだチャンネルなどの表示の状態 |
| メッシュマップ | `sets/<ID>/meshmap-*.bin`（モデルの形から焼いた派生物） | 焼き直せます（Generator が使うマップは、開いたあとにモデルから焼き直すまで、そのセットが読むだけになることがあります） |
| Unity のマテリアルの値 | 見た目の設定（`look.json`）の `received`（Live Link で Unity のマテリアルから受けた値） | 利用者の見た目の設定 |
| 古いサムネイルなど | 根の `thumbnail.png`・`brush.json`・`model.json`（Unity 版が残したもの。スタンドアロン版は更新しません） | |
| 知らないエントリ | このアプリが知らないエントリ（新しい版が書いたものなど。開くときに「保存すると残らない」と知らせるもの） | |

何が「使っている」かは、除いた後に残る見た目の設定で決まります（Unity の値を除くなら、その中の割り当ては数えません）。窓の一覧は選びに合わせて変わり、写しに残る物と一致します。

## 除かないもの・保証しないこと

- 層・マスク・チャンネル・選択範囲・合成の PNG（絵そのもの）、セットの名前・マテリアルの参照は除きません。写しの層の画素は、準備を始めた時点の開いている文書と同じです（そのあとの描き込みは入りません）。
- 棚の素材ファイル（`.ylsmart`・`.ylbrush`）は、ファイルごと残すか除くかです。中身は書き換えないので、スマート素材の中の画像の出どころは取り除きません。
- Unity 版の `brush.json` などの状態のエントリを残す選びのとき、それが指す棚の画像は「使っている」とは数えません（Unity 版は状態を読めなければ既定に戻して開きます）。
- 層の名前・セットの名前・素材の名前など、作った人が付けた名前は写しに残ります。

## 互換性

写しは今のファイルと同じ形式（形式 7、正本の版も同じ）で、スタンドアロン版で開けます（書いた写しを読み直す試験で確かめています）。Unity 版（0.2.0）が開けるのは、**正本の版 21 のセットだけを含む写し**です。配布用の写しは正本の版を変えないので、正本の版 22 以上のセット（ユーザーチャンネル・ノイズ・グランジの段・グラデーションマップの混色などを使った文書）を 1 つでも含む写しは、Unity 版 0.2.0 では「Unsupported archive version」で断られて開けません（Unity 版のパッケージの `Documentation~/YLP_FORMAT.md` の「スタンドアロン版（YoluPainter-rs）が書く正本の版 22・23」の節）。Unity 版でも開ける写しにするには、スタンドアロン版でその機能を消して保存し直し（版 21 に戻る）てから、配布用に保存します。

除く物はどれも、Unity 版の読み手が無くても開けるもの（PSD の原本・状態・派生のエントリ）か、索引と合わせて書き直す棚の素材で、索引にある素材は中身と必ず揃います（素材が 1 つも残らなければ `resources.json` を書きません）。Unity 版で開けることは、Unity 版の読み手のコード（`YlpFormat.Open` など）と形式の決まりを読んで確かめたもので、**Unity 版で実際に開いてはいません**。

## いつもの保存と取り込み直した PSD

PSD を「今のセットの文書へ」取り込み直して文書を替えたセットは、次のいつもの保存から、そのセットの古い `imported-original.psd` を持ち越しません（新しい文書の原本ではないため）。復旧用の書き置きも同じで、書き置きから復旧して開いたあとの保存にも古い原本は戻りません。同じ文書への描き足しでは、Unity 版が取り込んだ原本はそのまま残ります。前の版は退避（設定の「退避を残す数」）に残ります。
