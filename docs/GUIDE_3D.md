# 3D ビューとモデル

[English](en/GUIDE_3D.md)

モデルを 3D ビューで見て、動かして、面に描く頁です。FBX を開く、ポーズを付ける、メッシュマップをベイクする、重なった UV を扱う、Unity から開く、もここにあります。

## 3D ビューを動かす

右ドラッグで回します。`Alt`＋左ドラッグでも回り、向きが軸の向き（正面・背面・右・左・上・下）の 15° 以内に入ると、その向きに吸い付きます。右ボタンを押している間は、`W` / `S` で前後、`A` / `D` で左右、`Q` / `E` で下上に視点を動かせます（`Shift` で速く）。中ボタンのドラッグか `Space`＋左ドラッグで動かし、ホイールか `Ctrl+Space`＋左ドラッグで寄る・引きます。右ボタンを動かさずに離すと、その面の値を描画色に取ります（スポイト。ポリゴン塗りつぶしではアイランドのメニュー）。3D ビュー上の `.` は今のテクスチャセットの面を画面に収め、右上の「モデル全体が見える位置へ戻す」は全体を収めます。キーの全部は [GUIDE_KEYS.md](GUIDE_KEYS.md) にあります。

### 軸の視点と正投影

3D ビューの右上のアイコンの下に、軸の印（X は赤・Y は緑・Z は青の丸）があります。軸の名前の付いた丸を押すと、その軸の側から見る視点になります（X は右の視点、Y は上の視点、Z は正面の視点。名前の無い小さい丸は反対の側の左・下・背面）。真ん中の丸を押すと、透視と正投影を切り替えます（正投影の間は、真ん中の丸が白く塗られます）。印の上をドラッグすると回ります。光・環境・トーンマッピングの設定のパネルを開いている間は、印は出ません。視点のパイメニューにも、正面・背面・右・左・上・下の視点と正投影の切り替えがあります（パイを開くキーは、最初は割り当てていません。[GUIDE_KEYS.md](GUIDE_KEYS.md) の「ショートカットを変える」）。

軸の視点を選んだときと、`Alt`＋左ドラッグで軸の向きに吸い付いたときは、正投影になります。回して軸の向きから外れると、透視へ戻ります。真ん中の丸・パイメニューで切り替えた投影は、回しても戻りません。設定のウィンドウの「3D ビュー」の「軸の向きで正投影」を切ると、軸の向きでも透視のままです。

正投影では、奥のものも手前のものも同じ大きさに見え、ブラシの円も奥行きによらず同じ大きさで面に描きます。描く・色を取る・選ぶ・パスの点を置くのは、正投影でも見えているとおりの所に当たります。ホイールの拡大・縮小は見える範囲の大きさを変え、右ボタンを押している間の `W` / `S` も前後へは動かずに寄る・引くになります。透視へ戻すと、そのときの大きさのまま透視になります。視点（向きと投影）はファイルに保存しません。

## モデルを開く

モデルが無いあいだ、3D ビューには「新規プロジェクト…」（ファイルメニューの新規プロジェクトと同じです）と「試しの立方体を読む」が出ます。モデルは、新規プロジェクトとプロジェクト設定の「モデルを選ぶ…」、ポーズのパネルの「FBX を開く」、ウィンドウへの .fbx のドロップのどれかで開きます。Unity から開くときは、この頁の最後の Live Link を見てください。

モデルのマテリアルごとにテクスチャセットが付き、「テクスチャセット」のパネルで切り替えます。描けるのは、今のセットのマテリアルの面だけです。

## 3D の見た目を変える

3D ビューの右上に 3 つのアイコンがあります。

- 「3D の表示」: マテリアル (PBR)（Unity の Standard と同じ BRDF。Roughness・Metallic・Normal・Emission が見える）、中立、チャンネルだけ（Color・Roughness・Metallic・Normal・Emission・Height）、焼いたメッシュマップだけ、から選びます。
- 「光・環境・トーンマッピング」: 設定のパネルを開きます。
- 「モデル全体が見える位置へ戻す」。

設定のパネルは 3 つの面に分かれています。

- 「表示」: 環境（なし・空・スタジオ。明るさ・回転・背景に映す・ぼかし）、ライト（強さ・方位・高さ・影・やわらかさ）、トーンマッピング（なし・ニュートラル・ACES、露出）と「既定に戻す」。光の強さ 1 は、Unity の白・強さ 1 のディレクショナルライトと同じ明るさです。
- 「画質」: アンチエイリアスとブルーム。
- 「視点」: 回転の中心とズームの中心。

3D ビューに上げる表示用のテクスチャは、UV の外へ塗り広げてあるので、離れて見てもアイランドの縁がにじみません（保存と書き出しは変わりません）。GPU のメモリの予算などで 3D の絵が縮んでいるときは、右上に印が出ます。質感の詳しい比べ方と速さは [PREVIEW.md](PREVIEW.md) にあります。

右のドックの「マテリアル」のパネルの「見た目」では、テクスチャセットごとに「標準（PBR）」か「lilToon」を選びます。lilToon にすると、lilToon の見た目の再現で描き、色設定・ノーマルマップ・光沢設定・拡張設定の値を欄で直せます。「lilToon のひな形」は、入れた機能のマスクにするユーザーチャンネルを作って割り当てます。

Unity から受けたマテリアルの値は「Unity の値」に出て、「Unity に合わせる」で欄で変えた値を外し、Unity の値で描きます。シェーダーの名前が似ているだけでは lilToon として描きません（[PREVIEW.md](PREVIEW.md)）。

## 3D のモデルに描く

3D に描くのは、ペイントのモードのときです（[GUIDE_START.md](GUIDE_START.md) の「モード」）。3D ビューで使えるのは、ブラシ・消しゴム・スポイト・バケツ・ポリゴン塗りつぶし・長方形選択・楕円形選択・なげなわ・多角形選択・自動選択・選択ペン・ID の色で選択・パス・グラデーション・図形・定規です（パスは [GUIDE_PATHS.md](GUIDE_PATHS.md)、グラデーション・図形・定規は下の「画面の上で引いて描く」、長方形選択からの 4 つと自動選択・選択ペンは「画面の上で引いて選ぶ」）。移動と変形・ゆがみ・テキストは、2D のキャンバスだけで使います。クイックマスクが入っているあいだは、3D ビューのブラシと消しゴムも、2D のキャンバスと同じく選択ペン・選択消しとして働き、押した面のテクスチャの画素を選択範囲に加える・外します（直径・硬さ・不透明度・筆圧は今のブラシ。1 回のストロークが 1 回の取り消し。レイヤーの画素は変えません）。赤い重ねは、3D ビューの面の上にも、2D のキャンバスにも出ます（[GUIDE_SELECT.md](GUIDE_SELECT.md)。3D ビューの面の上の選択範囲は、下の「画面の上で引いて選ぶ」）。

ブラシの設定は、3D ビューでも 2D のキャンバスと同じ式で効きます。直径・硬さ・アンチエイリアス（帯の幅はテクスチャの画素）・流量・不透明度・筆圧、画像の筆先（角度・真円率・左右反転と上下反転・線の向きに従う）、ストローク（手ぶれ補正・曲線）、入り抜きとペン（フェード・傾き・回転・速さ）、ゆらぎ、テクスチャ、デュアルブラシ、色・色の揺らぎ（「描点ごとに適用」も）・色の混ぜ・消しゴム・ステンシル、効果のブラシ（ぼかし・指先・クローン）です。

- 筆先の形は画面の上で決まり、カメラから面へ写して塗ります（面の向きに沿わせて貼るのではありません）。
- ダブは、2D と同じく線の長さで間隔ごとに置きます。入力の点が細かく来ても粗く来ても、ストロークの濃さとフェードの長さは同じです。間隔は、区間の始まりの面の奥行きで直径を画面へ直して決めます。
- 手ぶれ補正・入り抜き・速さの長さと速さは、3D ビューでは画面の点で測ります（2D のキャンバスでは文書の画素）。
- テクスチャは、塗る所の文書の画素の位置で読みます。2D で描いた所と 3D で描いた所で、質感の目がそろいます。
- 3D の対称は、文書の 3D の対称定規（モデルの空間）が決める写しです。線対称は筆先を鏡の面で左右に反転し（線が 4 本以上のときは、軸のまわりに回した写しも）、回転対称は筆先を軸のまわりに回します。2D の対称定規も効き、塗ったテクスチャの画素をキャンバスの上で写します（[GUIDE_PAINT.md](GUIDE_PAINT.md) の「対称で描く」）。3D の対称定規の作り方は、下の「画面の上で引いて描く」の「定規」です。
- 1 回の操作のメモリに入らない筆の跡があると、2D のキャンバスと同じくストロークごと取り消します（塗り残しを作りません）。
- 大きなブラシを速く動かしたときは、画面が固まらないように、1 フレームに塗る時間（と、塗った分を 3D の表示へ反映する時間）を 8〜40 ミリ秒の間で区切ります。溜まった分の見込みが約 0.3 秒を超えると区切りを広げて追いつき、超えなければ 8 ミリ秒のままです。塗りはペンに少し遅れ、ペンを離したあとも塗り終えるまで続きます（目安は 0.5 秒以内。ペンがとても速く長い・文書が大きいなどで塗りが追いつかないときは、遅れが線の長さに比例して伸びます）。離したあと塗り終えるまでのあいだに、次の操作（取り消し・保存・新しい線・ツールのキー・ホイール・ウィンドウを閉じるなど）を始めると、先に残りを塗って確定してから、その操作を受けます。`Esc` も同じで、離したあとの線は捨てません（離す前の `Esc` は線ごと取り消します）。塗り終えると 1 回の取り消しになります。

3D ビューが出ているあいだ、ブラシのプロパティには「3D」の欄が加わります。

| 欄 | 効き方 |
|---|---|
| 隠れた所も塗る | ブラシの円の中で、手前の面に隠れた所にも塗ります |
| 裏の面も塗る | カメラに背を向けた面にも塗ります |
| 面の向きで弱める | 面が視線に対して傾くほど薄く塗ります（「弱め始め」「塗らない角度」） |
| 継ぎ目のにじみ | UV アイランドの縁から外へ塗る幅で、継ぎ目に線が出ないようにします |

### 画面の上で引いて描く

グラデーションと図形は、3D ビューの画面の上でドラッグして形を決めます。離したところで、カメラから見えている面へ写して描きます（ドラッグのあいだは何も変えません。`Esc` で取りやめです）。正投影でも同じです。定規は、モデルの面を押して引き、離したところで 3D の定規を作ります（下の「定規」）。ツールプロパティの欄は 2D のキャンバスと同じです。

- **グラデーション**: 見えている面のテクスチャの画素ごとに、その画素が画面に写る所の色で塗ります。線形なら、始点の側は始点の色、終点の側は終点の色、その間は 2D と同じ補間です。選択範囲・マスクを描くとき・マテリアルで塗るときの働きも 2D と同じです。
- **図形の「塗る」**: 画面の形の中に写る、見えている面を塗ります。縁は 2D のキャンバスの「塗る」と同じく、テクスチャの画素を 4 × 4 の点で見て、形の中にある点の割合で塗ります（ブラシの「アンチエイリアス」では変わりません）。2D と同じく対称は使いません。長方形の「角の丸み」は、画面の点で測ります。
- **図形の「線で描く」**: 輪郭を、3D ビューのブラシのストロークとして描きます。ブラシの設定と対称が効きます（筆圧は一定、手ぶれ補正と曲線は使いません。2D と同じです）。
- グラデーションと図形の「塗る」は、隠れた所と裏の面を、ブラシの「3D」の欄によらず塗りません。「面の向きで弱める」と「継ぎ目のにじみ」は欄のとおりです。
- グラデーションと図形は、離したところで 1 回の取り消しです。ロックしたレイヤー・読むだけのテクスチャセット・1 回の操作のメモリに入らないときは、何も変えずに断ります。
- **定規**: 定規のツールで、モデルの面を押して引くと、選んでいるレイヤーに 3D の定規を作ります（ツールプロパティの「編集レイヤーに作成」を切ると、新しいレイヤー「定規」に作ります）。3D の定規はモデルの空間の値で、レイヤーが持ち、`.ylp` に保存します（視点を回しても、モデルの同じ所に残ります。2D のキャンバスの定規とは別です）。押した所がモデルの外なら作りません。作るのは離したところで、1 回の取り消しです（`Esc` で取りやめ）。
  - **直線定規・平行線・同心円・パース**: 押した面の点が `a`、離した点が `b`（面に当たらない所は、押した点を通ってカメラに向いた面の上の点）で、押した面の法線が定規の向きです。引かずに離したときは作りません。パースの 1 点と 2 点は、ツールプロパティで選びます。
  - **対称**: 引くと、押した面の点を通り、画面で引いた線と視線を含む面が、最初の鏡の面になります（`Shift` を押していると、鏡の法線をモデルの X・Y・Z のいちばん近い軸へ寄せます）。引かずに離すと、モデルの境界の中心を通る X の鏡です。線の本数と線対称はツールプロパティで決めます。
  - 特殊定規（平行線・同心円・パース・対称）は、作ると印が付いて「特殊定規にスナップ」が入ります（3D の特殊定規は、2D とは別に 1 つだけ効きます）。「スナップする特殊定規の切り替え」（`Ctrl+4`）は、ポインタが乗っているビューの空間の特殊定規を順に回します。どちらのビューにも乗っていなければ、最後にツールで描き始めたビューの空間（ブラシ・図形・グラデーション・塗りつぶし・定規などで押したビュー）を回し、それも無ければ、描ける先が 3D ビューだけのときは 3D、そうでなければ 2D のキャンバスの空間を回します。
  - **見え方**: 見えている 3D の定規が、3D ビューの上に重なります（表示の範囲と目は、2D の定規と同じです）。対称は、線対称 2 本なら鏡の面の四角と軸の線、それ以外は軸の線と、軸に直交する面の上の中心からの線です。直線定規は a・b を通る線と端の丸、平行線は向きの線を数本、同心円は円を 3 つ、パースは消失点とそこからの線です。効いていない定規（特殊定規は印の無いもの、直線定規は「定規にスナップ」が切のとき）は薄く、選んでいる定規（選んでいるレイヤーに作った直後の定規と、プロパティの行で選んだ定規。「編集レイヤーに作成」を切って作った定規は選ばれません）は橙で描きます。2D の定規は 3D ビューには出ません。
  - **スナップ**: 「定規にスナップ」「特殊定規にスナップ」を入れているあいだ、3D ビューのブラシと消しゴムのストロークの点を、描き始めのカメラで画面に写した線へ寄せます（ストロークの途中でカメラは動きません）。直線定規は a・b を写した直線へ、描き始めが線の近く（画面で 26 点ほど）のときだけ寄せます。平行線は押した面の点を通る向き `a`→`b` の線へ、パースは押した面の点と消失点を結ぶ線へ（2 点なら、最初に動いた向きに近いほう）寄せます。同心円は、`a` を通る軸（定規の向き）のまわりの、押した面の点の高さの円（押した点を通る円で、押した点から離れた円へは跳びません）を、256 に分けて画面に写した線の上へ寄せます（描く輪は `a` の高さの円です）。押した所がモデルの外のときは、直線定規のほかは寄せません。対称は寄せずに、写します。

3D の指先とクローンは、UV アイランドの継ぎ目をまたいで読みます。クローンの元は、`Alt` を押して動かさずに離したクリックで決めます（動かすとスナップ回転になります）。「揃える」は前のストロークの位置関係を続け、「全レイヤーから」は見えているレイヤーの重なりを読みます。この 2 つは 2D のキャンバスと同じ設定です。3D の元は面の点で決まるので、3D ビューだけを出しているあいだ、クローンの「ずれ X」「ずれ Y」の欄は薄くなります。テクスチャセットを替えると、元は忘れます。

`Shift` を押しながらクリックすると、前のストロークの終わり（面に当たった最後の点）から、クリックした点まで直線を引けます（マウスもペンも。前の点が無いときは、`Shift` を押したままドラッグすると、最初に動かした向きを 45° 刻みに固定します）。`Ctrl` を押した接触は、ペンは描かず、マウスは描きます。指などのタッチの力は筆圧になります。これらも 2D のキャンバスと同じです（[GUIDE_PAINT.md](GUIDE_PAINT.md)）。バケツの「近い色」も、押した面の UV が指す画素から、2D と同じ範囲を塗ります。

### 画面の上で引いて選ぶ

長方形選択（`M`）・楕円形選択（`Shift+M`）・なげなわ（`L`）・多角形選択（`Shift+L`）は、3D ビューの画面の上で形を決めます。離したところ（多角形は、`Enter`・始めの点・ダブルクリックで閉じたところ）で、カメラから見えている面のテクスチャの画素へ写して、2D のキャンバスと同じ選択範囲にします（ドラッグのあいだは何も変えません）。透視でも正投影でも同じです。自動選択（`W`）は、押した所の面のテクスチャの画素から、2D のキャンバスと同じ自動選択を行います。

- 隠れた所と、カメラに背を向けた面は選びません。ブラシの「3D」の欄の「隠れた所も塗る」「裏の面も塗る」によりません。「面の向きで弱める」と「継ぎ目のにじみ」は欄のとおりです（弱められた所は量が薄くなり、にじむ画素は選ばれます）。
- 縁は、テクスチャの画素を 4 × 4 の点で見て、形の中にある点の割合です（2D のキャンバスの楕円・なげなわ・多角形と同じ）。長方形は、「角の丸め」（画面の点で測ります）を入れたときだけ縁が滑らかで、ほかの形は「アンチエイリアス」に従います。
- 「新規」「追加」「削除」「共通」（オプションバーと `Shift`・`Ctrl`）と、「縦横比を固定」「中心から」（押し始めたあとの `Shift`・`Alt` も）は、2D のキャンバスと同じです。動かさずに離すと、「新規」のときは選択範囲を解除します。
- なげなわと多角形の点は、視点を回しても画面の同じ所に残ります（面には貼り付きません）。多角形の途中では、`Backspace` と `Ctrl+Z` で最後の点を消します。
- 自動選択は、2D のキャンバスと同じく、押した画素から、テクスチャの上で色が近くつながる範囲を選びます。モデルの上のつながりは見ないので、見えていない面の画素も、UV の継ぎ目の向こうの画素も、テクスチャで色が近くつながっていれば選びます。押した所がモデルに当たらないときは、何も選ばずに理由を知らせます。
- `Esc`・ウィンドウがフォーカスを失う・ツールを替えるで、引いている形と打った点を、何も選ばずに捨てます。離したのを取りこぼしたとき（ウィンドウの外で離した・ペンの押しを OS に奪われたときなど）も、何も選びません（2D のキャンバスは、最後の位置で選びます）。
- 1 回の選択が取り消し 1 回で、選択範囲はテクスチャセットごとに `.ylp` へ保存されます。読むだけのテクスチャセットでは押したところで、1 回の操作のメモリに入らないときは選択範囲を変えずに、断ります。
- 選択ペン・選択消し（`S`）は、3D ビューでは、押した面のテクスチャの画素に塗って、選択範囲へ追加・削除します（クイックマスクのブラシ・消しゴムと同じ道です）。直径・硬さ・不透明度・筆圧は今のブラシで、面の上の大きさは 3D のブラシと同じ決まり（モデルの大きさに対する割合）です。追加か削除かは、`Shift`（追加）・`Ctrl`（削除）・ペンの消しゴムの端・選択消しのオプションで決め、2D のキャンバスと同じです。対称は使いません。1 回のストロークが取り消し 1 回です。`Esc` で捨て、フォーカスを失ったり OS にペンの押しを奪われたりしたときは、そこまでを選びます（3D のブラシと同じ）。
- 選択範囲は、3D ビューの見えている面の上にも、縁（白と黒の点線）で出ます（今のテクスチャセットの面だけ。点線は流れず止まったままです。クイックマスクのあいだは、縁でなく赤い重ねです。選択ペンで塗っている間は、追加する側が青、削除する側が橙の重ねも出ます）。拡大・縮小しても線の太さは変わりません。縁はテクスチャの上で引くので、モデルの上で継ぎ目をまたいで続く選択範囲でも、隣のアイランドの画素が選ばれていなければ、継ぎ目に線が出ます（3D の選択のツールは、継ぎ目のにじみの画素も選ぶので、にじみの幅の内では出ません）。縁と重ねの絵は、文書と同じ大きさの GPU のメモリを使い、3D の絵の予算（設定の「GPU のメモリ」）に入ります。入らないとき（文書の幅か高さが GPU のテクスチャの上限を超えるときも）は出さず、3D ビューの隅の警告のアイコンで知らせます。

## 物を選んで動かす（編集のモード）

編集のモードでは、3D ビューに、見えているレイヤーの物の印（白い点）が出ます。物は、塗りつぶしの投影の箱とデカール（投影が UV のときは無し）、グラデーションデカール、フィルターの形、モデルの空間の点のグラデーションの点、3D のパス（今のモデルで描いたもの）、3D の定規（表示を入れているもの。表示の範囲によらず、印が出ます）です。

- 印をクリックすると、その物と、その物のレイヤーを選びます。選んだ物は、印と枠・線が橙になります。形は、塗りつぶしやフィルターの欄から編集するときと同じ取っ手も出ます（`Q` で隠せます）。
- 印が重なっているときは、同じ所でもう一度クリックすると、次の物を選びます。何も無い所をクリックすると、選びを外します。
- `G`（移動）・`R`（回転）・`S`（拡縮）は、ポインタの所から始まり、マウスを動かした量で変わります。`X`・`Y`・`Z` で軸を決め（もう一度で物の向きの軸。拡縮は 1 回目から物の向きの軸）、数字で値を打てます。左クリックか `Enter` で決め、右クリックか `Esc` でやめます。キーの全部は [GUIDE_KEYS.md](GUIDE_KEYS.md) の「編集とポーズのモード」にあります。
- キーを使わないときは、左のツールの帯で移動・回転・拡縮を選び、印から左ドラッグします（離すと決まります。ドラッグの間も `X`・`Y`・`Z` と `Ctrl` のスナップが効きます。ペンでも使えます）。キーで始めたときも、帯のそのツールが光ります。
- 1 回の移動・回転・拡縮が、取り消し 1 回です。動かしている間は、粗い表示で追いかけます。
- 点は移動だけです。3D のパスは、パス全体を動かし、決めたときに、点を近くの面の点へ載せ直します。描いた面と同じ向きの面だけに載せるので、薄い板の表に描いたパスは裏へ移りません（面から離れすぎた点があるときは決められません）。
- `Alt+G`・`Alt+R`・`Alt+S` で、形の位置・回転・大きさを、作ったときと同じ置き場（モデルの外形に合わせた所）へ戻します。
- 3D の定規は、印が 2 点の真ん中（直線・平行線・2 点のパース）か中心（同心円・対称・1 点のパースは `a`）に出ます。選ぶと、線が橙になり、移動の矢印と回す輪（大きさのつまみは出ません）と、端の点の四角が出ます。端の四角は、直線・平行線・2 点のパースが `a` と `b`、同心円と対称が `b`（半径・最初の線）で、ドラッグすると、面に当たればその面の点へ、当たらなければ前の点を通ってカメラに向いた面の上へ動きます。`G`・`R`・`S` は、移動が `a`・`b` を動かし、回転が中心のまわりに `a`・`b` と向きを回し、拡縮が中心から `a`・`b` の距離を変えます（定規の向きは変えません。軸を絞った拡縮では、`a`・`b` がその軸に沿って伸びるので、`a`→`b` の向きは変わります）。軸の 2 回目は定規の向きの軸（X が `a`→`b`、Y が定規の向き、Z は X と Y に直交）です。どれも、続けて変える操作で、決めたところが取り消し 1 回です。`Alt+G` は中心をモデルの境界の中心へ、`Alt+R` は向きをモデルの軸へ（定規の向きを近い軸へ、`a`→`b` をその次に近い軸へ）、`Alt+S` は `a`〜`b` の距離をモデルの外形の対角線の 4 分の 1 へ戻します。
- `H` で選んだ物の印を隠し、`Alt+H` で全部出します（表示だけで、ファイルは変わりません）。`Delete` で選んだ物を消します（投影の箱とデカールは、塗りつぶしレイヤーの投影なので消せません。定規は消せて、取り消しで戻ります）。

隠したレイヤー（グループの目を消したときも）の物は、印が出ず、選べません。アセットの画像を 3D ビューのモデルへ落としてデカールを置くと、編集のモードでは置いたデカールを選びます。欄の「3D ビューで編集」を押したときも、その物を選びます。2D のキャンバスでは動かせません（編集のモードの 2D は見るだけです）。動かせる物は、1 度に 1 つです。

## ポーズを付ける

FBX のボーンを持つモデルを読むと、プロパティと同じ組に「ポーズ」のタブが出ます（別のウィンドウにも出せます）。

1. 「ボーン」の木からボーンを選ぶと、ポーズのモードに入り、3D ビューにギズモの輪が出ます。輪を左ドラッグで回し、面を押してボーンを選ぶこともできます。オプションバーの左端のモードのドロップダウン、`Ctrl+Tab` のモードのパイメニュー、メニューバーの「表示 → モード」、ポーズのパネルの頭のボタンでも替えられます（[GUIDE_START.md](GUIDE_START.md) の「モード」）。ポーズのモードでは描きません（2D のキャンバスも見るだけです）。選んだボーンは、`G`・`R`・`S` でも、ツールの帯の移動・回転・拡縮を選んでボーンの面から左ドラッグしても動かせます（使い方は編集のモードと同じです。[GUIDE_KEYS.md](GUIDE_KEYS.md) の「編集とポーズのモード」）。
2. 選んだボーンの位置・回転・大きさは、数値でも直せます（回転は Unity のインスペクターと同じ並びのオイラー角）。項目・ボーン・ボーンと子・全部と、BlendShape の 1 つずつを戻せます。
3. ポーズの操作 1 つがポーズの取り消し 1 段です（ポーズのモードでは `Ctrl+Z`）。プリセットとテイクは、描いている最中は当てられません。

FBX の中にテイク（アニメ）があるモデルには、「テイク」の節が出ます。テイクの箱とフレームのつまみを選んで「ポーズにする」を押すと、その時刻のボーンと BlendShape の重みを今のポーズに当てます（つまみを動かすだけでは当てません）。当てたあとも手で直せます。

「ポーズのプリセット」は、今のポーズに名前を付けて、設定のフォルダの `pose_presets/` に残します。休みの形と違うボーンの位置・回転・大きさの差を、ボーンの名前の道で持つので、同じ名前のボーンを持つモデルに当てられます（BlendShape は持たず、合わないボーンは理由つきで飛ばします）。名前を押して当てる・左右を反転して当てる・今のポーズで上書き・名前を変える・消す、ができます。左右の反転は `.L`/`.R`・`_L`/`_R`・`Left`/`Right`・左/右の名前の決まりで、対のボーンへ移します。

「面を隠す」は、選んだボーンの影響のある面（面の 3 頂点のウェイトの平均が「しきい値」以上。「子を含める」で子孫も）を 3D ビューから隠します。隠した面は、描く・範囲・スポイトの当たりにも使いません（2D のキャンバスと保存には影響しません）。隠し方は名前を付けて `hide_presets/` に残せ、複数を同時に入れられます。

プロジェクトのモデルのポーズは `.ylp` に保存され、同じモデルを開くと戻ります（合わないボーンや BlendShape は理由つきで飛ばします）。

## メッシュマップをベイクする

「テクスチャセット」のパネルの下の帯の「メッシュマップをベイク…」のボタン（炎のアイコン。帯が狭くてボタンが隠れるときは、セットの行の右クリックのメニューの「メッシュマップをベイク…」）で、3D ビューのモデルから、チェックしたテクスチャセットごとに、ワールド法線・位置・アンビエントオクルージョン（AO）・曲率・厚み・接空間法線・ハイト・ID・ベントノーマル・不透明度を焼きます。別のスレッドで進み、進み具合と取消があります。

「メッシュマップをベイク…」は、既定のキーの無い操作として「ショートカット」の「どこでも・視点」の表にもあり、キーを割り当てたり、パイメニューの項目にしたりできます（[GUIDE_KEYS.md](GUIDE_KEYS.md)）。

左の一覧でマップをチェックして、「チェックしたマップをベイク」を押します。一覧の右の状態（最新・古い・未・未確認）と目のアイコンで、焼いたマップを 2D のキャンバスに重ねて見られます。「共通の設定」には余白とアンチエイリアス、「焼く場所」（自動・GPU・CPU）があります。

- 自動は、使えるハードウェアの GPU があれば GPU、なければ CPU で焼きます。GPU が使えない・予算を超える・途中で失敗したときは、理由を出して CPU で焼き直します。
- GPU で、光線を飛ばすマップ（AO・厚み・ベントノーマル）は、RT コア（ハードウェアの光線追跡。Windows は Vulkan、macOS は Metal）を持つ GPU なら RT コアで焼きます。同じ光線を RT コアを使う道と使わない道（compute）の両方で飛ばして答えが合ったときだけ使い、合わない・使えないときは compute で焼きます。使った道は、ベイクのウィンドウの最後のベイクの行に出て、使わなかった理由は、その行を指すと出ます。ドライバーが固まる PC では、「編集 → 設定…」の「表示」の「ベイクで RT コアを使う」を切ると、常に compute で焼きます（既定は入）。環境変数 `YOLUPAINTER_BAKE_RAY_QUERY=0` でも切れます。
- GPU の値は CPU と全バイト一致しません（AO・厚み・ベントノーマルは最大でおよそ 3%。測った値は [`crates/yolu-gpu/README.md`](https://github.com/YozoraKurage/YoluPainter/blob/main/crates/yolu-gpu/README.md)）。
- 高ポリからの投影は選べないので、接空間法線・ハイト・不透明度は一様です。

焼いたマップは `.ylp` にセットごとに保存されます。モデルや設定が変わったマップは「古い」と表示し、書き出しの AO にも使いません。

### ID マップと手動の色

ID のマップは、「色の分け方」（スロット・メッシュ・UV アイランド・メッシュの部品）ごとに単色で塗り分けます。ID の色で選択ツール（`Shift+W`）のプロパティの「部品の手動の色」で、部品ごとに色を決められます（16 進でも決められ、「自動」で戻します）。手動の色は ID マップの色になり、`.ylp` に保存されます。別のモデルで付けた色は、全部やめることだけできます。

## 重なった UV を扱う

同じテクセルを 2 つ以上の三角形が覆う UV（ミラーで重ねた左右など）では、ベイクはどれか 1 つのアイランドの値を焼きます。塗りでは、重なった両側に同じ画素が乗るので、片側だけには描けません（ストロークが重なったテクセルに当たると、セットごとに 1 度だけ知らせます）。

- 見る: メニューバーの「表示」の「重なった UV」を入れると、2D のキャンバスに、重なったテクセルの色と、重なりに関わるアイランドの縁が出ます。色と不透明度は、「編集」→「設定…」の「UV ワイヤーフレーム」の行の右の見本で変えます。
- ベイクで優先する側を決める: ベイクのウィンドウの「重なった UV」の「優先」で、重なったテクセルにどの値を焼くかを選びます。「番号」は番号の小さい三角形（はじめの設定）、「面積」は 3D の面積の大きいアイランド、「+X」「−X」はモデルの +X または −X の側のアイランド（ミラーの片側）です。「0〜1 の外のアイランドを焼かない」も選べます。
- アイランドを手で選ぶ: 「優先するアイランド」「焼かないアイランド」の ＋ を押してから、2D のキャンバスか 3D ビューでアイランドを押すと一覧に入ります（入っているアイランドをもう一度押すと外れ、`Esc` で終わります）。右の見取り図では、アイランドを押してメニューの「優先する」「焼かない」「外す」を選べます。指したアイランドはキャンバスと 3D ビューでも強調されます。
- ポリゴン塗りつぶしからも: ポリゴン塗りつぶしで、2D のキャンバスか 3D ビューのアイランドを右クリックして、「優先して焼く」「焼かない」を選べます。2D で重なった所を続けて押すと、前の塗りを取り消して次のアイランドを塗ります。

ベイクの優先は、テクスチャセットごとに `.ylp` に保存され、1 回の取り消しで戻ります。手で選んだアイランドは、三角形の数・UV・スロット・レンダラーが同じモデルでだけ使えます。

## Unity から開く（Live Link）

同じ PC の Unity エディターから、シーンのモデル（アバターなど）をこのアプリで開けます。Unity の Live Link のウィンドウで開くと、このアプリが FBX と絵を読み、マテリアルごとにテクスチャセットを作って、ポーズとマテリアルの値を当てます。描いて書き出すと、書いた PNG を Unity が取り込みます。「ファイル」の「Live Link」で受け付けを入り切りでき、使い方は [UNITY.md](UNITY.md)、受け渡しの仕様は [LIVELINK.md](LIVELINK.md) にあります。
