# 3D ビューとモデル

[English](en/GUIDE_3D.md)

モデルを 3D ビューで見て、動かして、面に描く頁です。FBX を開く、ポーズを付ける、メッシュマップをベイクする、重なった UV を扱う、Unity から開く、もここにあります。

## 3D ビューを動かす

右ドラッグで回します。`Alt`＋左ドラッグでも回り、向きが軸の向き（正面・背面・右・左・上・下）の 15° 以内に入ると、その向きに吸い付きます。右ボタンを押している間は、`W` / `S` で前後、`A` / `D` で左右、`Q` / `E` で下上に視点を動かせます（`Shift` で速く）。中ボタンのドラッグか `Space`＋左ドラッグで動かし、ホイールか `Ctrl+Space`＋左ドラッグで寄る・引きます。右ボタンを動かさずに離すと、その面の値を描画色に取ります（スポイト。ポリゴン塗りつぶしではアイランドのメニュー）。3D ビュー上の `.` は今のテクスチャセットの面を画面に収め、右上の「モデル全体が見える位置へ戻す」は全体を収めます。キーの全部は [GUIDE_KEYS.md](GUIDE_KEYS.md) にあります。

## モデルを開く

モデルが無いあいだ、3D ビューには「試しの立方体を読む」だけが出ます。FBX は、メニューバーの「表示」→「3D ビューに FBX を開く…」、ポーズのパネルの「FBX を開く」、ウィンドウへの .fbx のドロップのどれかで開きます。Unity から開くときは、この頁の最後の Live Link を見てください。

モデルのマテリアルごとにテクスチャセットが付き、「テクスチャセット」のパネルで切り替えます。描けるのは、今のセットのマテリアルの面だけです。

## 3D の見た目を変える

3D ビューの右上に 3 つのアイコンがあります。

- 「3D の表示」: マテリアル (PBR)（Unity の Standard と同じ BRDF。Roughness・Metallic・Normal・Emission が見える）、中立、チャンネルだけ（Color・Roughness・Metallic・Normal・Emission・Height）、焼いたメッシュマップだけ、から選びます。
- 「光・環境・トーンマッピング」: 設定のパネルを開きます。
- 「モデル全体が見える位置へ戻す」。

設定のパネルは 3 つの面に分かれています。

- 「表示」: 環境（なし・空・スタジオ。明るさ・回転・背景に映す・ぼかし）、ライト（強さ・方位・高さ・影・やわらかさ）、トーンマッピング（なし・ニュートラル・ACES、露出）と「既定に戻す」。光の強さ 1 は、Unity の白・強さ 1 のディレクショナルライトと同じ明るさです。
- 「画質」: アンチエイリアスとブルーム。
- 「視点」: 回転の中心とズームの中心。

3D ビューに上げる表示用のテクスチャは、UV の外へ塗り広げてあるので、離れて見てもアイランドの縁がにじみません（保存と書き出しは変わりません）。GPU のメモリの予算などで 3D の絵が縮んでいるときは、右上に印が出ます。質感の詳しい比べ方と速さは [PREVIEW.md](PREVIEW.md) にあります。

プロパティの「マテリアル」のタブの「見た目」では、テクスチャセットごとに「標準（PBR）」か「lilToon」を選びます。lilToon にすると、lilToon の見た目の再現で描き、色設定・ノーマルマップ・光沢設定・拡張設定の値を欄で直せます。「lilToon のひな形」は、入れた機能のマスクにするユーザーチャンネルを作って割り当てます。

Unity から受けたマテリアルの値は「Unity の値」に出て、「Unity に合わせる」で欄で変えた値を外し、Unity の値で描きます。シェーダーの名前が似ているだけでは lilToon として描きません（[PREVIEW.md](PREVIEW.md)）。

## 3D のモデルに描く

3D に描くのは、ペイントのモードのときです（[GUIDE_START.md](GUIDE_START.md) の「モード」）。3D ビューで使えるのは、ブラシ・消しゴム・スポイト・バケツ・ポリゴン塗りつぶし・ID の色で選択・パスです（パスは [GUIDE_PATHS.md](GUIDE_PATHS.md)）。選択範囲・移動と変形・ゆがみ・図形・定規・グラデーション・テキストは、2D のキャンバスだけで使います。

ブラシの設定は、3D ビューでも 2D のキャンバスと同じ式で効きます。直径・硬さ・流量・不透明度・筆圧、画像の筆先（角度・真円率・左右反転と上下反転・線の向きに従う）、ストローク（手ぶれ補正・曲線）、入り抜きとペン（フェード・傾き・回転・速さ）、ゆらぎ、テクスチャ、デュアルブラシ、色・色の揺らぎ（「描点ごとに適用」も）・色の混ぜ・消しゴム・ステンシル、効果のブラシ（ぼかし・指先・クローン）です。

- 筆先の形は画面の上で決まり、カメラから面へ写して塗ります（面の向きに沿わせて貼るのではありません）。
- ダブは、2D と同じく線の長さで間隔ごとに置きます。入力の点が細かく来ても粗く来ても、ストロークの濃さとフェードの長さは同じです。間隔は、区間の始まりの面の奥行きで直径を画面へ直して決めます。
- 手ぶれ補正・入り抜き・速さの長さと速さは、3D ビューでは画面の点で測ります（2D のキャンバスでは文書の画素）。
- テクスチャは、塗る所の文書の画素の位置で読みます。2D で描いた所と 3D で描いた所で、質感の目がそろいます。
- 3D の対称の写しでは、ミラーは筆先を左右に反転し、放射状は筆先を回します。

3D ビューが出ているあいだ、ブラシのプロパティには「3D」の欄が加わります。

| 欄 | 効き方 |
|---|---|
| 隠れた所も塗る | ブラシの円の中で、手前の面に隠れた所にも塗ります |
| 裏の面も塗る | カメラに背を向けた面にも塗ります |
| 面の向きで弱める | 面が視線に対して傾くほど薄く塗ります（「弱め始め」「塗らない角度」） |
| 継ぎ目のにじみ | UV アイランドの縁から外へ塗る幅で、継ぎ目に線が出ないようにします |

3D の指先とクローンは、UV アイランドの継ぎ目をまたいで読みます。クローンの元は、`Alt` を押して動かさずに離したクリックで決めます（動かすとスナップ回転になります）。「揃える」は前のストロークの位置関係を続け、「全レイヤーから」は見えているレイヤーの重なりを読みます。この 2 つは 2D のキャンバスと同じ設定です。3D の元は面の点で決まるので、3D ビューだけを出しているあいだ、クローンの「ずれ X」「ずれ Y」の欄は薄くなります。テクスチャセットを替えると、元は忘れます。

`Shift` を押しながらクリックすると、前のストロークの終わり（面に当たった最後の点）から、クリックした点まで直線を引けます（マウスもペンも。前の点が無いときは、`Shift` を押したままドラッグすると、最初に動かした向きを 45° 刻みに固定します）。`Ctrl` を押した接触は、ペンは描かず、マウスは描きます。指などのタッチの力は筆圧になります。これらも 2D のキャンバスと同じです（[GUIDE_PAINT.md](GUIDE_PAINT.md)）。バケツの「近い色」も、押した面の UV が指す画素から、2D と同じ範囲を塗ります。

## 物を選んで動かす（編集のモード）

編集のモードでは、3D ビューに、見えているレイヤーの物の印（白い点）が出ます。物は、塗りつぶしの投影の箱とデカール（投影が UV のときは無し）、グラデーションデカール、フィルターの形、モデルの空間の点のグラデーションの点、3D のパス（今のモデルで描いたもの）です。

- 印をクリックすると、その物と、その物のレイヤーを選びます。選んだ物は、印と枠・線が橙になります。形は、塗りつぶしやフィルターの欄から編集するときと同じ取っ手も出ます（`Q` で隠せます）。
- 印が重なっているときは、同じ所でもう一度クリックすると、次の物を選びます。何も無い所をクリックすると、選びを外します。
- `G`（移動）・`R`（回転）・`S`（拡縮）は、ポインタの所から始まり、マウスを動かした量で変わります。`X`・`Y`・`Z` で軸を決め（もう一度で物の向きの軸。拡縮は 1 回目から物の向きの軸）、数字で値を打てます。左クリックか `Enter` で決め、右クリックか `Esc` でやめます。キーの全部は [GUIDE_KEYS.md](GUIDE_KEYS.md) の「編集とポーズのモード」にあります。
- キーを使わないときは、左のツールの帯で移動・回転・拡縮を選び、印から左ドラッグします（離すと決まります。ドラッグの間も `X`・`Y`・`Z` と `Ctrl` のスナップが効きます。ペンでも使えます）。キーで始めたときも、帯のそのツールが光ります。
- 1 回の移動・回転・拡縮が、取り消し 1 回です。動かしている間は、粗い表示で追いかけます。
- 点は移動だけです。3D のパスは、パス全体を動かし、決めたときに、点を近くの面の点へ載せ直します。描いた面と同じ向きの面だけに載せるので、薄い板の表に描いたパスは裏へ移りません（面から離れすぎた点があるときは決められません）。
- `Alt+G`・`Alt+R`・`Alt+S` で、形の位置・回転・大きさを、作ったときと同じ置き場（モデルの外形に合わせた所）へ戻します。
- `H` で選んだ物の印を隠し、`Alt+H` で全部出します（表示だけで、ファイルは変わりません）。`Delete` で選んだ物を消します（投影の箱とデカールは、塗りつぶしレイヤーの投影なので消せません）。

隠したレイヤー（グループの目を消したときも）の物は、印が出ず、選べません。アセットの画像を 3D ビューのモデルへ落としてデカールを置くと、編集のモードでは置いたデカールを選びます。欄の「3D ビューで編集」を押したときも、その物を選びます。2D のキャンバスでは動かせません（編集のモードの 2D は見るだけです）。動かせる物は、1 度に 1 つです。

## ポーズを付ける

FBX のボーンを持つモデルを読むと、プロパティと同じ組に「ポーズ」のタブが出ます（別のウィンドウにも出せます）。

1. 「ボーン」の木からボーンを選ぶと、ポーズのモードに入り、3D ビューにギズモの輪が出ます。輪を左ドラッグで回し、面を押してボーンを選ぶこともできます。オプションバーの左端のモードのドロップダウン、`Ctrl+Tab` のモードのパイメニュー、メニューバーの「表示 → モード」、ポーズのパネルの頭のボタンでも替えられます（[GUIDE_START.md](GUIDE_START.md) の「モード」）。ポーズのモードでは描きません（2D のキャンバスも見るだけです）。選んだボーンは、`G`・`R`・`S` でも、ツールの帯の移動・回転・拡縮を選んでボーンの面から左ドラッグしても動かせます（使い方は編集のモードと同じです。[GUIDE_KEYS.md](GUIDE_KEYS.md) の「編集とポーズのモード」）。
2. 選んだボーンの位置・回転・大きさは、数値でも直せます（回転は Unity のインスペクターと同じ並びのオイラー角）。項目・ボーン・ボーンと子・全部と、BlendShape の 1 つずつを戻せます。
3. ポーズの操作 1 つがポーズの取り消し 1 段です（ポーズのモードでは `Ctrl+Z`）。プリセットとテイクは、描いている最中は当てられません。

FBX の中にテイク（アニメ）があるモデルには、「テイク」の節が出ます。テイクの箱とフレームのつまみを選んで「ポーズにする」を押すと、その時刻の骨と BlendShape の重みを今のポーズに当てます（つまみを動かすだけでは当てません）。当てたあとも手で直せます。

「ポーズのプリセット」は、今のポーズに名前を付けて、設定のフォルダの `pose_presets/` に残します。休みの形と違うボーンの位置・回転・大きさの差を、ボーンの名前の道で持つので、同じ名前のボーンを持つモデルに当てられます（BlendShape は持たず、合わないボーンは理由つきで飛ばします）。名前を押して当てる・左右を反転して当てる・今のポーズで上書き・名前を変える・消す、ができます。左右の反転は `.L`/`.R`・`_L`/`_R`・`Left`/`Right`・左/右の名前の決まりで、対のボーンへ移します。

「面を隠す」は、選んだボーンの影響のある面（面の 3 頂点のウェイトの平均が「しきい値」以上。「子を含める」で子孫も）を 3D ビューから隠します。隠した面は、描く・範囲・スポイトの当たりにも使いません（2D のキャンバスと保存には影響しません）。隠し方は名前を付けて `hide_presets/` に残せ、複数を同時に入れられます。

プロジェクトのモデルのポーズは `.ylp` に保存され、同じモデルを開くと戻ります（合わない骨や BlendShape は理由つきで飛ばします）。

## メッシュマップをベイクする

「表示」→「メッシュマップをベイク…」で、3D ビューのモデルから、チェックしたテクスチャセットごとに、ワールド法線・位置・アンビエントオクルージョン（AO）・曲率・厚み・接空間法線・ハイト・ID・ベントノーマル・不透明度を焼きます。別のスレッドで進み、進み具合と取消があります。

左の一覧でマップをチェックして、「チェックしたマップをベイク」を押します。一覧の右の状態（最新・古い・未・未確認）と目のアイコンで、焼いたマップを 2D のキャンバスに重ねて見られます。「共通の設定」には余白とアンチエイリアス、「焼く場所」（自動・GPU・CPU）があります。

- 自動は、使えるハードウェアの GPU があれば GPU、なければ CPU で焼きます。GPU が使えない・予算を超える・途中で失敗したときは、理由を出して CPU で焼き直します。
- GPU の値は CPU と全バイト一致しません（AO・厚み・ベントノーマルは最大でおよそ 3%。測った値は [`crates/yolu-gpu/README.md`](https://github.com/YozoraKurage/YoluPainter/blob/main/crates/yolu-gpu/README.md)）。
- 高ポリからの投影は選べないので、接空間法線・ハイト・不透明度は一様です。

焼いたマップは `.ylp` にセットごとに保存されます。モデルや設定が変わったマップは「古い」と表示し、書き出しの AO にも使いません。

### ID マップと手動の色

ID のマップは、「色の分け方」（スロット・メッシュ・UV アイランド・メッシュの部品）ごとに単色で塗り分けます。ID の色で選択ツール（`Shift+W`）のプロパティの「部品の手動の色」で、部品ごとに色を決められます（16 進でも決められ、「自動」で戻します）。手動の色は ID マップの色になり、`.ylp` に保存されます。別のモデルで付けた色は、全部やめることだけできます。

## 重なった UV を扱う

同じテクセルを 2 つ以上の三角形が覆う UV（ミラーで重ねた左右など）では、ベイクはどれか 1 つのアイランドの値を焼きます。塗りでは、重なった両側に同じ画素が乗るので、片側だけには描けません（ストロークが重なったテクセルに当たると、セットごとに 1 度だけ知らせます）。

- 見る: メニューバーの「表示」の「重なった UV」を入れると、2D のキャンバスに、重なったテクセルの色と、重なりに関わるアイランドの縁が出ます。色と不透明度は、「編集」→「設定…」の「UV ワイヤーフレーム」の行の右の見本で変えます。
- ベイクで優先する側を決める: ベイクのウィンドウの「重なった UV」の「優先」で、重なったテクセルにどの値を焼くかを選びます。「番号」は番号の小さい三角形（はじめの設定）、「面積」は 3D の面積の大きいアイランド、「+X」「−X」はモデルの +X または −X の側のアイランド（ミラーの片側）です。「0〜1 の外のアイランドを焼かない」も選べます。
- アイランドを手で選ぶ: 「優先するアイランド」「焼かないアイランド」の ＋ を押してから、2D のキャンバスか 3D ビューでアイランドを押すと一覧に入ります（入っているアイランドをもう一度押すと外れ、`Esc` で終わります）。右の見取り図では、アイランドを押してメニューの「優先する」「焼かない」「外す」を選べます。指したアイランドはキャンバスと 3D ビューでも強調されます。
- ポリゴン塗りつぶしからも: ポリゴン塗りつぶしで、2D のキャンバスか 3D ビューのアイランドを右クリックして、「優先して焼く」「焼かない」を選べます。2D で重なった所を続けて押すと、前の塗りを取り消して次のアイランドを塗ります。

ベイクの優先は、テクスチャセットごとに `.ylp` に保存され、1 回の取り消しで戻ります。手で選んだアイランドは、三角形の数・UV・スロット・レンダラーが同じモデルでだけ使えます。

## Unity から開く（Live Link）

同じ PC の Unity エディターから、シーンのモデル（アバターなど）をこのアプリで開けます。Unity の Live Link のウィンドウで開くと、このアプリが FBX と絵を読み、マテリアルごとにテクスチャセットを作って、ポーズとマテリアルの値を当てます。描いて書き出すと、書いた PNG を Unity が取り込みます。「ファイル」の「Live Link」で受け付けを入り切りでき、使い方は [UNITY.md](UNITY.md)、受け渡しの仕様は [LIVELINK.md](LIVELINK.md) にあります。
