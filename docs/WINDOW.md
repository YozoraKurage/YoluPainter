# 画面まわり（設定・スクロール・上の帯・下の帯・並びの保存）

## 設定

「編集 → 設定…」（Ctrl+,）で開きます。Unity の Edit ▸ Preferences と同じく、編集のメニューの一番下です。ウィンドウは節に分かれています。

| 節 | 中身 |
|---|---|
| 一般 | 言語、Unity からの頼みを受けるか（Live Link）、Unity から受けたマテリアルの値の保存、書き出しの余白 |
| メモリ | 取り消し履歴・レイヤーのメモリ・1 回の操作の予算、最小の取り消し段数 |
| 処理 | CPU のスレッド、表示の合成、GPU のメモリ |
| 3D ビュー | 回転の中心（画面の中心・面の位置（自動深度）・モデルの中心・テクスチャセットの中心）、ズームの中心、UV ワイヤーフレームの色 |
| ファイル | ライブラリの場所、退避を残す数 |

3D ビューの回転とズームの中心は、3D ビューの表示の設定の「視点」と同じ値です（どちらで変えても同じ設定が変わります）。
画面が低くて収まらないときは、ウィンドウの中をスクロールして最後の行まで届きます。

## スクロール

一覧と欄のスクロールはどれも同じ振る舞いです。

- ホイールで送れます。
- 右の縁のつまみを掴んで動かせます。溝を押すと、つまみが押した所へ移り、そのまま動かせます。
- ペンの押して動かす入力は、マウスと同じ経路（ポインタの押す・動かす・離す）でつまみを動かします。
- つまみは普段は細く、ポインタを近づける・掴むと太くなります。掴める幅はいつも 10 点です（カラーセットの欄と同じ）。

## 上の帯

Windows では OS のタイトルバーを使わず、メニューの帯の右端に最小化・最大化（最大化中は元に戻す）・閉じるを置きます。帯の何も無い所を引くとウィンドウが動き、ダブルクリックで最大化と元に戻すを切り替え、ウィンドウの縁を引くと大きさが変わります（Mac と Linux は OS の枠のままです）。

別ウィンドウ（パネルを外へ出したウィンドウ）も、Windows では OS のタイトルバーを使いません。タブの並ぶ行の何も無い所を引くと動き、ダブルクリックで最大化と元に戻すを切り替え、縁を引くと大きさが変わります。行の右端の閉じるは、OS の閉じると同じく、中のパネルを出す前の組へ戻します。最小化と最大化のボタンは置きません（メインウィンドウを最小化すると一緒に隠れます）。

## 状態の帯と知らせ

状態の帯（ウィンドウの下の端）の左は空です。直前の操作の結果や理由は、帯のすぐ上に小さな知らせとして出て、消えます。

- 普通の知らせは 4 秒、「〜できません」のような断りや失敗は 12 秒で消えます。押すとすぐ消え、ポインタを乗せているあいだは消えません（置きっぱなしでも、初めて出てから 3 倍の 12 秒・36 秒で消えます）。
- 同じ文を続けて書く操作（保存を続けて押す、開けないファイルをもう一度開く）は、押して消したあとも時間切れのあとも、そのたびに知らせが出ます。最後の文は、知らせが消えたあとも内部では残ります。
- 右端には、版とビルド（例: `0.1.0 · a1b2c3d`）と、このアプリが使っているメモリの量が出ます。GPU は、量が取得できるときだけ並びます。
  乗せると内訳（アプリ全体・レイヤーのメモリ・取り消しの履歴・GPU）が出ます。

## 画面の並びの保存

ドックの並び（タブの組・分け方・大きさ・どのタブが前か）と、別ウィンドウへ出したパネル（ウィンドウごとの中のタブの組・位置と大きさ・戻る先の組）と、ウィンドウの大きさ・位置・最大化を、
設定のフォルダの `YoluPainter/layout.json` に書き、次の起動で戻します。並びが変わったとき（1 秒おき）と、終わるときに書きます。

- 読めない・形の版が違う・知らないタブがある・タブが足りない／重なる・ファイルが 1 MiB を超える・値が合わない（前のタブの番号が組の外、空の組、分け方が 0 と 1 の間でない、
  分けた所の片側が無い、ウィンドウの位置が範囲の外、など）のときは、そのファイルのドックは使わず、既定の並びで始めます（理由は診断のログだけです）。
- 別ウィンドウは、どのタブが入っているか・どれが前か・位置と大きさを戻します。位置はメインウィンドウと同じく、書いたときの画面の拡大率つきの点で持ち、Windows では
  画素に直して今の画面と突き合わせます（上の帯がどの画面にも見えなければ、メインウィンドウの上の中央に開きます。見えていれば作業領域に収まるよう寄せます）。Linux は覚えた位置のまま開きます。
- メインウィンドウのドックと別ウィンドウを合わせて、どのタブも 1 つずつのときだけ使います。別ウィンドウの中身が読めない・タブが重なる／足りないときは、並び全体を既定へ戻します。
  別ウィンドウの位置の値だけが正しくなければ、そのウィンドウはメインウィンドウの上の中央に開きます。
- 前の版の、アプリの中の浮いたウィンドウは、読んだあと別ウィンドウとして開きます（メインウィンドウの内側の左上からの位置のまま）。別ウィンドウを持つファイルを前の版が読むと、
  メインウィンドウのドックのタブが足りないので、既定の並びで始めます（落ちません）。
- 画面より大きいウィンドウは、起動のあと 1 度だけ画面に収めます（保存したあとで画面が小さくなったとき）。
- ウィンドウの大きさと位置は、ドックとは別に確かめます。保存した位置が今つながっている画面のどこにも見えないとき（画面を外したあと）は、位置は戻さず大きさだけ戻します。
- 最大化したまま終わったときは、最大化の印と、戻したときの大きさを残します。
- 「ウィンドウ → パネルの並びを戻す」で既定の並びへ戻ります（別ウィンドウは閉じます）。
