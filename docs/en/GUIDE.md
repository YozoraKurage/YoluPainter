# Features and controls

[日本語](../GUIDE.md)

## Features

- Paint with brushes and an eraser. Includes 13 built-in brushes, Size, Hardness, Spacing, Opacity, Flow, image tips, Jitter, paper texture, Dual Brush, Color Dynamics, Fade, pen tilt and rotation, Speed, Stabilizer and Taper, and effect brushes (Blur, Smudge, Clone). Windows Ink pressure can control Size, Opacity, Flow, and Hardness, and each one has a minimum (the value at zero pressure) and a curve. How pressure comes out differs from pen to pen: View → Pen Pressure… sets a low and high limit and a curve (it can also work them out from strokes you draw in its frame at your usual strength, and you can add, move, and remove curve points in the frame). It is a per-device setting and is not stored in documents or brushes.
- Sub tools and the brush interface: the Tools panel on the left changes with the selected tool. For the brush it lists brushes by group tab (initially Pen, Brush, Airbrush, Effects, Special, plus Imported when you have imported brushes), with each brush's name and a sample stroke drawn using its settings. The eraser has its own groups, not shared with the brushes. The bucket, polygon fill, gradient, shape, ruler, eyedropper, move and liquify tools list sets of settings, and the selection tools list the same selection tools as the tool strip (the sets of settings and how your own are saved are described in [docs/SUBTOOLS.md](../SUBTOOLS.md)). Click a row to switch, or use the buttons below the list to save the current settings as your own brush (as your own eraser for the eraser), duplicate, rename (double-click), delete (this only removes the brush from the layout; the file stays), and reset brushes. The “+” (Add Brushes) opens a window listing built-in, bundled Krita, imported, and your own brushes by kind, with a name search; the selected ones are placed in the current group. Tools in the toolbar on the left, group tabs, and brush rows can be added, renamed, deleted, reordered, and moved to another tool or group with right-click and drag, so any set of brushes can become one tool (the tool layout; see [docs/SUBTOOLS.md](../SUBTOOLS.md)). Changing a built-in brush's settings marks it as “modified.” Below the list, Tool Properties (for the brush and eraser: Size, Opacity, Hardness, Flow, Spacing, pressure toggles, Stabilizer; for the other tools, all of that tool's settings) and the preset diameter circles in Brush Size (only for tools that have a size) provide quick adjustments. The adjustment button opens Brush Details (Shape, Stroke, Pressure, Taper & Pen, Jitter, Texture, Dual Brush, Color Dynamics, Effect, Symmetry). Pressure sets, for each of Size, Opacity, Flow, and Hardness, whether pressure is used, its minimum, and its curve (add, move, and remove points). This window can be moved and kept open while painting. The eraser (`E`) uses the eraser last selected in the eraser list. Custom brushes and erasers are saved as individual files in `brushes/` in the settings folder, and the layout in `tools.json`; damaged files are skipped and reported at startup. A brush that uses a pressure minimum or curve is written in a newer format (version 2); an older app that reads only version 1 skips it and reports why (brushes that do not use them keep the same version and contents as before).
- Add, delete, duplicate, rename, and drag to reorder layers; nested, collapsible groups; layer masks (enable, invert, density, painting on masks); fills; adjustments (Invert, Levels, Hue/Saturation/Lightness); clipping; visibility; opacity; 26 blend modes; undo and redo.
- Select multiple layers (`Ctrl`/`Shift`-click) to delete, duplicate, group, merge, toggle visibility, move up or down one position, drag, or lock them together. Painting still targets a single layer.
- Merge layers: Merge Down (`Ctrl+E`), groups, selected layers, or Merge Visible (`Ctrl+Shift+E`). A single undo restores the original layers. If merging would change the appearance by more than one rounding step, the number of affected pixels is shown for confirmation. When merging is unavailable (no layer below, hidden layers, locks, etc.), a short reason is shown and nothing changes.
- Layer locks (alpha, pixels, position, all). Toggle them through the lock icon in a layer row (click to remove the layer's own lock), the context menu, or Lock in Properties. A group's locks apply to its contents. Locks are saved and restored in `.ylp`, PSD (`lspf`), and `.ylsmart`.
- Move / Transform (`V`). Use the bounding-box handles to move, scale (`Shift` preserves the aspect ratio), or rotate (`Shift` snaps to 15°) the selected layer, including its contents if it is a group, all selected layers if several are selected, or the selected pixels and selection itself if a selection exists. While dragging, only the transformed outline is shown. Release the pointer or press `Enter` to apply; `Esc`, loss of window focus, or switching tools cancels without changes. Arrow keys move by 1 pixel (`Shift`: 10). Rotate 90°, Flip Horizontal, and Flip Vertical are available through the Layer and Edit menus and the options bar; numeric transforms and interpolation (Bilinear, Nearest) are in Tool Properties in the Tools panel on the left (interpolation is also in the options bar). Each operation can be undone in one step.
- Material painting: in the Material tab, choose channels from Color, Roughness, Metallic, Height, Normal, and Emission, and paint them in one stroke using their respective values (the drawing color for Color, a color for Emission, 0–1 for data channels, and tilt for Normal). Works in 2D, 3D, Fill, and Polygon Fill. A single undo restores all channels.
- Fill (`G`) and Polygon Fill (`4`): target triangles, mesh parts, UV islands, or materials (Fill also supports similar colors in 2D). The region under the pointer is highlighted as faces in 3D and UV outlines in 2D. Fill paints only inside the current selection. Polygon Fill adds regions as you drag and creates one undo step when released.
- Path (`P`): draw editable curves through successive points on the 2D canvas or a 3D model's surface. Click to add points, click a curve to insert a point into that segment, drag points to move them, and press `Delete` to remove them. Paths can be open or closed, with per-point width (a substitute for pressure, smoothly interpolated along the curve), a path brush (Size, Hardness, Spacing, Opacity, Flow, and toggles for width to affect Size, Opacity, and Flow), and the set of channels selected in Brush Material (painted together in one operation). Each point operation is one undo step; dragging a point redraws the path on release (`Esc` cancels, while loss of window focus commits the movement so far). Path layers cannot be painted on by hand, and locked layers refuse edits. Rasterize (also available in the layer context menu) removes the path while keeping its current pixels. 3D paths are bound to model triangles and barycentric coordinates and saved in `.ylp`. Paths drawn on a different model cannot be edited. Replacing the model rebinds paths to nearby faces of the same material and redraws them. Paths that cannot be rebound, including those that cannot be redrawn because of pixel or alpha locks, are removed while retaining the current pixels; layers with an all lock retain their binding to the previous model. The result reports counts and the first reason. Curves are Catmull–Rom curves passing through the points; there are no Bézier handles. A closed path has its first and last points at the same location, forming a corner there.
- ID Color Select (`Shift+W`): create a selection from colors in a baked ID map (`Shift` to add, `Ctrl` to subtract). You can also assign manual ID colors to individual mesh parts. Manual ID colors are saved in the `.ylp` and come back when it is reopened. If a different model is opened, they stay as another model's colors, and editing them and baking the ID map are refused.
- Selections: combine Rectangle Select, Ellipse Select, Lasso, Polygon Select, and Magic Wand (tolerance, contiguous, all layers) using replace, add, subtract, or intersect. Modify them with Invert, Expand, Contract, Border, Feather, and Sharpen Edge. Brushes and the eraser affect only the selection. Selections you remember by name (the Remembered Selections window, opened from the Select menu or the Remember button of the bar below the selection; up to 32 per texture set) can be recalled with replace, add, subtract, or intersect, renamed, and deleted; each is one undo step, and resizing the canvas resamples them like the current selection (any that nothing is left of after a shrink are dropped, and the result says so). Selections are created on the 2D canvas, and both the current selection and the remembered ones are saved per texture set in `.ylp` (a `.ylp` that uses remembered selections is format 8; the 0.3.x standalone and the Unity version refuse it with a reason; see [docs/en/UNITY.md](UNITY.md)).
- Symmetry: 2D offers vertical, horizontal, both, and radial (2–16), with a movable center and axes shown on the canvas. 3D offers mirroring across planes perpendicular to the model's X, Y, or Z axis and radial symmetry (2–16) around an axis. Planes can be placed at the model origin or the center of its bounds, with an option to paint copies onto hidden faces; planes and axes appear in the 3D view. A copy that misses the surface or lands on a different texture set is skipped. Symmetry cannot be combined with Smudge or Clone.
- Channels: six standard channels plus user channels (add, name, type). Choose the painting channel and the channel displayed in 2D. Each layer can have its own enable state, blend mode, and opacity per channel.
- Japanese and English interface (switch through the View menu).
- Zoom, pan, rotate, and flip the 2D view horizontally. These change only the view; saved images are not rotated or flipped.
- 2D canvas compositing: when a usable GPU is available, changed tiles are composited on the same GPU that renders the application. Adjustment layers (all kinds), isolated groups, Normal channels and effects (filters, generators, fill gradients and projections, mask filters; the effects are computed on the CPU and the resulting pixels are uploaded to the GPU) are composited on the GPU too. Compositing falls back to the CPU for software GPUs, documents whose painted tiles exceed the GPU memory budget (512 MiB; tiles have both GPU and CPU copies; layers with effects are counted at the most tiles they can occupy), sizes beyond the device's texture limit (8192 by default), or groups nested too deeply (more than 32 levels of isolated groups). This applies only to the displayed composite; saving, export, and the 3D view always use CPU results (GPU pixels can differ from the CPU result by about 2). Override the choice with the `YOLUPAINTER_CANVAS` environment variable (`auto`, `gpu`, `cpu`).
- Paint on the demo cube in the 3D view or on a model received through Live Link. Switch texture sets by material. In 3D, Size, Hardness, Flow, Opacity, pressure, color, Color Dynamics, erasing, stencils, and effect brushes (Blur, Smudge, Clone) work; image tips, Jitter, Texture, Dual Brush, Fade, pen tilt and rotation, Speed, and Stabilizer are limited to the 2D canvas. 3D Smudge and Clone sample across UV island seams. Set the clone source with an `Alt`-click released without moving. Aligned preserves the offset from the previous stroke, and All layers samples the visible layer composite.
- 3D appearance: switch between Material (PBR with the same BRDF as Unity Standard, showing Roughness, Metallic, Normal, and Emission), Neutral, and Channel in the header. A small panel provides environment (Sky, Studio), lighting, and tone-mapping settings. See [docs/PREVIEW.md](../PREVIEW.md).
- Open FBX models, pose them with bone rotations and BlendShapes, and paint on the posed surface (the pose of the project's model is saved in `.ylp` and comes back when the same model is opened, skipping bones and BlendShapes that do not fit, with reasons; the pose of a Live Link target is saved in the `.ylp` file's `livelink.json`). Poses can be saved by name as pose presets in `pose_presets/` in the settings folder (the differences of the bones that differ from rest, held by bone name path, so a preset applies to a model with the same bone names and skips bones that do not fit, with reasons; BlendShapes and `.ylp` are not included). Applying a preset is one pose undo step and is refused while painting; it can also be applied mirrored, using the left/right naming (`.L`/`.R`, `_L`/`_R`, `Left`/`Right`, 左/右) to move it to the paired bone (bones without a pair stay as they are; a pair whose rest poses are not mirror images is skipped with a reason), overwritten with the current pose, renamed, or deleted. Each material has a texture set; you can paint on the faces assigned to the current set's material.
- Create, open, and save `.ylp` files. See the [Working with Unity](UNITY.md#exchanging-ylp-files-with-the-unity-version) for compatibility with the Unity version.
- Saving runs in a background thread (the job card at the lower right shows “Saving” with its progress; it cannot be canceled). You can keep painting and viewing during a save, but what you paint during it is not part of that save, and the document stays marked as modified afterwards. While a save runs, another save, Open, New, and Save for Distribution are refused with a reason. Closing or quitting during a save waits for the save to finish and then closes, after asking about unsaved changes if any remain. If a save fails, nothing is changed and the reason is shown.
- Recovery after a crash. When there are unsaved changes, a background thread writes a recovery generation 15 seconds after detecting a change (or 15 seconds after the previous checkpoint while continuously painting), after 10 completed strokes, on loss of focus, or on exit. Checkpoints are not taken during a stroke or PSD import; they wait until painting finishes. Generations use the same structure as `.ylp`, sharing unchanged sets with the previous generation. The on-disk storage layout matches the Unity version, and generations written by Unity can be read. Generations containing composite PNGs from an opened `.ylp` cannot be read by the Unity version. Checkpoint failures show a reason in a notice at the bottom of the window without interrupting painting. On the next launch after a crash, the Recovery window lists generations (original name, number of sets, elapsed time) to open or discard. It is also available at any time through File → Recovery…. Recovered documents are named “Untitled (Recovered)” and do not overwrite the original `.ylp`; choose a destination when saving. The interval (10 seconds to 5 minutes) and retained generations (2–20) can be selected in the window and are written to `recovery.conf` (`interval`, `strokes`, `generations`, `directory`) in the settings folder. Generations from cleanly closed sessions are retained up to the configured total, while those from crashed sessions remain until discarded. If `recovery.conf` cannot be read, recovery uses the default interval and reports the reason in a notice at the bottom of the window; because the retention setting is unknown, generations are not pruned and the configuration file is not overwritten. Composite PNGs and mesh maps are omitted from generations as derived data, although those already present in an opened `.ylp` are preserved. This has not yet been verified on physical Windows hardware.
- Mesh map baking (View → Bake Mesh Maps…). Bake world normals, position, AO, curvature, thickness, ID, and other maps from the 3D view's model for each checked texture set in a background thread, with progress and cancellation. Choose Auto, GPU, or CPU. Auto uses a usable hardware GPU if available, otherwise the CPU. If the GPU is unavailable, exceeds its budget, or fails during baking, a reason is shown and baking restarts on the CPU. GPU results are not byte-identical to CPU results: f32/f64 rounding and ray hit differences produce deviations up to roughly 3% for AO, thickness, and bent normals; measurements are in [`crates/yolu-gpu/README.md`](https://github.com/YozoraKurage/YoluPainter/blob/main/crates/yolu-gpu/README.md). The baking device is not saved, so rebaking with the same settings on a GPU-equipped machine can change values within those differences, including exported AO PNGs. Baked maps are saved per set in `.ylp` and can be overlaid on the 2D canvas. Maps whose model or settings have changed are marked stale and are not used for exported AO. High-poly projection cannot be selected.
- Effects (separate Add Filter and Add Generator entrances: the layer and mask sections in Properties, the bar below the layer list, and the right-click menu; the Filter menu in the menu bar lists filters only, and generators are in the Layer menu): indented rows below each layer show one side (higher rows are applied later): the mask anchors and mask effects for the selected layer when the mask is the target, and the anchors and pixel effects for every other layer. Add Gaussian Blur, Directional Blur, Slope Blur, Warp, Median, Sharpen (Unsharp Mask), High Pass, Glow (color channels only), Edge Detect, Dilate / Erode, Noise, Levels, Histogram Scan, Histogram Range (Edge Detect, Dilate / Erode and the two histogram filters work on scalar channels and masks only), Invert, Normalize (Layer), color adjustments, generators that derive values from baked mesh maps (Edge Wear, Dirt, Position Gradient, Shape Gradient, Thickness, Direction, Light, Mask Builder, ID Color, Anchor), or generators that read no maps (Noise, Grunge, Pattern) to the painting channel's pixels or a mask. On the selected layer, clicking the layer thumbnail targets its pixels and clicking the mask thumbnail targets the mask (the target thumbnail has a blue frame); effect buttons, menus and Properties follow the current target, and clicking a mask effect row targets the mask too. While the mask is not the target, a small mark on the thumbnail of a mask that has effects shows that they are hidden; hovering it shows how many in the tooltip. Right-clicking the mask thumbnail adds filters or generators to the mask, and inverts, enables or deletes the mask. Toggle effects using the eye icon, move them up or down, delete them, or click a row to show its settings in Properties (values, strength, input maps and their status, range, breakup, blending). Each operation is one undo step, and slider drags are grouped into one step. Effects cannot be added to layers locked with All, including inherited group locks; pixel, alpha, or position locks alone allow them. If a generator's input map is missing, stale, or cannot be matched to the model, its row is marked with a reason and it passes the input through unchanged; baking makes it take effect. Named anchors can be placed on layers or masks and read by an Anchor generator on a layer above. References invalidated by reordering or deletion are reported in the status area. For an ID Color generator, use Pick from ID Map in Properties, then click the 2D canvas or 3D view to add that color (`Ctrl` removes it, up to 32 colors). Shape Gradient ramps and handles in the 3D view, and baking filters into pixels, are not yet available.
- Template export (File → Export → Template). Write packed PNGs for Unity Standard / URP Lit, HDRP Lit, and lilToon into a folder for all texture sets, named `<name>[_<set-name>]_<image>.png`. Colors are extended beyond UV boundaries (padding, omitted when there is no model), and baked AO is used when available. Existing files are replaced only after confirmation. Cancellation or failure before the final replacement begins leaves the original files unchanged. Export includes the same effects as the display (filters, generators reading mesh maps, and image assets). If effects remain inactive, for example because an input map is missing, the application reports that they are absent from the exported images.
- Import PSD (RGB8) through File → Import, either adding a new texture set or replacing the current set's document (dropping a .psd on the window imports it as a new texture set through the same flow; with several dropped, only the first is imported), and export through File → Export → PSD. PSDs are imported as copies that are never written back to the original file, with raster layers, groups, solid-color fills, adjustments (Invert, Levels, Hue/Saturation, Gradient Map, Tone Curve, Color Balance, Brightness/Contrast, Threshold, Posterize), masks, and clipping becoming layers. The six color adjustments are read and written as Photoshop adjustment layers (`grdm`, `curv`, `blnc`, `brit` with `CgEd`, `thrs`, `post`); contents the application cannot represent (noise-type gradients, curves with more than 16 points, with end inputs other than 0 and 255, or with neighboring points too close, legacy Brightness/Contrast, and so on) are dropped on import. Whatever is dropped or would look different (layer effects, smart objects, unsupported adjustments, and so on) is listed by layer name before importing; files with only information that does not affect the look are imported without the check. Files are read as a stream, and the size limit follows the Layer memory budget in the settings. PSB, non-RGB8, and over-budget files show a reason and leave everything unchanged (see `docs/PSD.md` for the full list). Layer locks (alpha, pixels, position, all) are written to `lspf` on export and restored on import; bits not represented by PSD are reported in the import result. The export window (File → Export → PSD…) chooses the mode (Bake, or Flat as a single layer) and the channels (Color only by default), and writes one PSD per channel (several channels are written as `name_channel.psd` files; blend mode, opacity, and visibility are that channel's values, and Normal follows the document's file direction). Baking evaluates what PSD has no form for (filters, generators, fill images, projections, decals, gradients, translucent fills, mask filters and inversion, clipped groups, paths) and writes it as pixels; it drops anchors, inactive filter stages, and the clipping mark of a group that clips nothing; it rounds adjustments that fall between PSD's steps (Levels, Hue/Saturation, Tone Curve, Color Balance, Brightness/Contrast, Gradient Map) to the nearest step and keeps them as adjustment layers (Threshold and Posterize have no between-step values); and it expands a Gradient Map's value curve, which PSD gradients cannot hold, into lists of color and opacity stops (up to 32 each) kept as an adjustment layer. The expansion aims for the smallest count where that layer's own output differs by at most 1 (worst case over the colors beneath it, with normal blend mode and 100% opacity), relaxes to 2 and then 4 when opacity moves, and refuses by layer name when it still does not fit in 32 stops and the layer shows in the exported channel's composite (a hidden layer, or one that does not apply to the channel, is written hidden with the best expansion). That difference is not a bound on the document's composite, which blend modes and layers above can amplify, so the notes show the measured maximum difference of the composite. Everything done is listed by layer name in the check window before writing (rounding with its values and the maximum composite difference, expansion with the stop counts and the maximum difference), and nothing is written until you press Write. Export works on a copy and leaves the document unchanged (effects stay in the document; baked layers carry no effect settings, so re-importing the PSD does not bring the effects back). Layers that do not apply to the channel (disabled, no surface or value, Color-only adjustments) are written hidden. The composite read back from the written file matches the exported channel's current composite as checked by Yolu's own reader, except for rounded or expanded adjustments, opacities and mask densities outside 1/255 steps (PSD rounds them), and where Normal layers overlap (PSD blends them as colors; the window notes it). Where baked inverted masks overlap layers, a pixel can rarely differ by 1 in the last floating-point digit. A Normal channel with the DirectX file direction is written with the green inverted, and export is refused for a Levels layer that a single PSD Levels cannot carry. A Tone Curve in a scalar channel uses only the whole-RGB curve, so the R, G, and B curves are written as straight lines. The color adjustment formulas are the application's own, and the merged image of an exported PSD is the result of those formulas; opening it in Photoshop or CLIP STUDIO, where the adjustment layers are re-evaluated, can change the look (not verified on real hardware). Imported PSD files are not overwritten (replacing the same file is checked before the replacement).
- Assets (the Assets panel on the left). Use Save Layer or Save Mask to store the selected layer (including a group's contents) or its mask as a Smart Material or Smart Mask. Place the project's assets into the current texture set by double-clicking, using the context menu or Place, or dragging into the layer list. Smart Materials go between rows or inside groups; Smart Masks go onto the target row's mask. Placement is one undo step. Assets are stretched to fit texture sets of a different size. The project's assets are saved in `.ylp` resources and restored on opening. Import and export external `.ylsmart` files, including by dropping them onto the window. Image assets can be placed as individual layers. Assets containing embedded images, generator rebinding, or content the core cannot represent, such as certain filters, are listed but cannot be placed; a reason is shown. Exporting them preserves the original for use in Unity. Brushes and materials are also listed only. Layers using user channels or Noise/Grunge (generator types exclusive to the Rust version) cannot be written to `.ylsmart` and are refused with a reason; layer locks are retained in assets. After the project's assets come 14 built-in Smart Materials (rusted iron, chipped painted metal, wood, etc.), constructed procedurally without images and all using Noise/Grunge. They can only be placed: they cannot be deleted, exported, or captured with Save Layer, and do not enter the project's assets. Placed groups are ordinary layers, and their `.ylp` uses document format 23 as described in the table below. The project's assets hold up to 256 items; additions beyond that are refused with a reason. Save Layer for large assets, or when the project's assets are nearly full, runs in a background thread, during which deletion and import are refused. Deletion and import can pause the application for several seconds with several hundred MiB of project assets, depending on their size.
- Stencil (the Stencil tab in Properties). Load a PNG and paint through the translucent image overlaid on either the 2D canvas or the 3D view. Grayscale images supply an amount (luminance × alpha), and color images supply color; choose Auto, Amount, or Color. Adjust repeating (horizontal, vertical, both), inversion, overlay opacity, size, and angle. The stencil stays fixed to the screen; hold `T` and drag to move it (see the [controls table](#basic-controls)). It also works with effect brushes (Blur, Smudge, Clone) in both 2D and 3D. Stencils are application state, saved neither in `.ylp` nor in brush presets, and remain when creating or opening a document. This feature has been verified in Linux tests; physical Windows Direct3D 12/Vulkan hardware, pens, and high-DPI displays have not yet been verified.
- Eyedropper (`I`): pick the value at a point in the 2D canvas or 3D view as the drawing color for the painting channel. By default it reads only the selected layer; the options bar can switch to the composite of all layers. With material painting enabled, it samples all six channels into the material values without changing the set of channels being painted. In 2D, `Alt`-click temporarily picks a value while using Brush, Eraser, Fill, or Polygon Fill (`Alt` orbits in 3D).
- Channel export (File → Export → Channel as PNG… / All Channels as Images…): export the painting channel to a single PNG, or all used channels from all texture sets into a folder. Values are the channel composites as-is, without packing or tinting; only Normal follows the file Y direction in the Normal settings. Names are `<name>[_<set-name>]_<channel>.png`. Padding beyond UV boundaries, overwrite confirmation, and cancellation work as in template export.
- Normal settings (Normal in the Channels panel): Height → Normal (strength, clamp/wrap edges) and file Y direction (OpenGL/DirectX). These document settings are saved in `.ylp` and changes can be undone. The same values apply to the 3D preview and exported Normal.
- Settings (Edit → Settings…, Ctrl+,): language (the first launch starts in the OS language, or English if that is not Japanese: the display language on Windows, `LC_ALL`, `LC_MESSAGES` and `LANG` on Linux, with the environment variable `YOLUPAINTER_LANG` (`ja` or `en`) taking precedence; the language you choose is saved and used from then on), export padding, memory budgets (undo history and layer memory are project-wide totals; the current texture set receives the configured budget minus the other sets' usage; the per-operation budget is also used by export, while the minimum undo count is per set; Auto derives budgets from physical memory (half for layer memory, 1/8 for undo history, 1/16 for one operation, each capped); each is a ceiling and nothing is reserved up front; opening `.ylp` reads pixels up to the configured budget, with a 256 MiB minimum), CPU threads (from the next launch), display compositing (2D canvas only; save, export, and the 3D view always use CPU results), Library folder, Backups to Keep, and Accept external commands (off by default; only while on, it listens at `http://127.0.0.1:<port>/mcp` (inside this PC only; the port is 17347 by default and can be changed in Port, shown below it while it is on) for commands from AI assistants (MCP) and the command line, and shows a small dot at the right end of the status bar with the URL in its tooltip; there is no password, so while it is on programs of other accounts on this PC can connect too; one command is one step of the screen's undo, edits are refused with a reason while drawing, while saving and in read-only texture sets, commands that switch the open document are not accepted, and only deleting, overwriting saves and replacing exports are announced briefly when done; turning it off stops listening and answers requests still waiting that it stopped accepting; [details](MCP.md)). Only non-default values are written to `YoluPainter/settings.conf` in the settings folder. Invalid values reset only the affected setting to its default, with the reason shown in the status area.
- Fill images and projection: in a fill layer's Image field, choose the image for the painting channel by dragging from the Assets panel or clicking the field to open a list, which also allows importing a PNG file. Projection offers UV, Tri-planar, Planar, Spherical, Cylindrical, and Decal, with tiling, offset, rotation, triplanar blending, decal depth, and backface edge settings. Non-UV projections show a box and handles in the 3D view (movement arrows with a centre square, rotation rings, and face-size handles, all on one gizmo; `Shift` for both sides, `Ctrl` for snapping). Use them to move the projection, and `Q` to hide or show them. Center, rotation, and size can also be entered numerically. Data channels read image values directly; color channels convert linear images to sRGB. Images are read with anisotropic filtering by default (images projected at an angle or tiled unevenly are sampled along each pixel's long footprint, up to 16 samples, so they blur less); turn it off with Anisotropic filtering in the Image field (a document with such an image is saved as document version 29, which 0.4.x cannot open). Projection positions and normals come from baked mesh maps. While maps are missing or stale, the field shows a reason and the constant value is displayed instead of the image. Images from the project's assets and positions/normals from baked maps are passed to evaluation. Sets in an opened `.ylp` remain read-only while maps or images are missing, showing the missing inputs; baking or adding images to the project's assets makes them editable.
- Decals: drag an image asset onto a model in the 3D view to add a fill layer in one undo step, oriented toward the face at the drop point and sized to the image's aspect ratio (view up becomes image up). Move it with the handles and adjust culling in Projection. Until position and normal maps are supplied for evaluation, the field shows a reason and the image is not displayed.
- Gradient decals: in a fill layer's Gradient Decal, set a Box, Sphere, or Plane volume using 3D view handles to vary values in the painting channel (except Normal). Values depend on model position, avoiding UV seams. Color stops (value stops for data channels) and opacity stops are separate, with midpoints between stops, five ramp presets, and a value curve (four presets, adding and moving points). A Position mesh map is required. Until it is supplied for evaluation, the field shows a reason and the constant value is used.
- Point gradients: in a fill layer's Point Gradient, place points on the painting channel (except Normal); each point's colour and opacity blend smoothly by distance. The space is Model (position on the model's surface, continuous across UV seams; needs a Position mesh map) or UV. While Edit Points is on, press on the surface in the 3D view or the 2D canvas to add a point (main colour), drag a marker to move it, and press `Delete` to remove the selected point (each is one undo step). Clicking the selected point's Color field opens the colour window for that point (one drag in the window is one undo step; selecting another point while it is open switches the window to that point). Spread sets how flat the colour is around each point. Up to 64 points. A document with a point gradient is saved as document version 29, which 0.4.x cannot open.
- Gradient (`Shift+G`): drag on the 2D canvas to paint a linear or radial gradient from the starting point (drawing color) to the endpoint (transparent or the secondary color), using premultiplied-alpha interpolation. It affects the painting channel of the selected layer, all selected material channels when material painting is enabled (including between two materials by setting the current material as the endpoint), or the mask when painting a mask (white/black). One undo restores it. Unavailable in the 3D view.

PNG import is limited to stencils and fill images (added as image assets). `.ylsmart` files can be imported into the project's assets.

## Basic controls

At startup, a 2048 × 2048 canvas and a demo cube appear. Choose a color in the Color panel and left-drag in the 2D or 3D view to paint. Select the painting layer in the Layers panel and add layers from the Layer menu as needed.

Copy and Cut take pixels from the selection (or the entire layer if there is no selection) in the painting channel, or the mask if painting a mask, and also put the same pixels on the OS clipboard as an image. On Linux, the OS clipboard uses Wayland when data-control is supported, otherwise X11.

On Mac, read `Ctrl` in this table as `Command`; menus still display `Ctrl`. You can also open `.ylp` files by dragging them onto the window. If you lose sight of the model, use View → Frame the Model in the 3D View. To restore panels, use View → Reset Panel Layout.
