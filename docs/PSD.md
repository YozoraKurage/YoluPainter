# PSD の読み込み

YoluPainter は PSD（RGB 8 bit）を、**元のファイルへ書き戻さない写し**として取り込みます。取り込んだ文書を PSD へ書き出すときは、いつも新しい PSD になります（取り込んだファイルと同じ場所へ書くときは、置き換える前に確かめます）。

## 取り込みの流れ

「ファイル → インポート」の「PSD を新しいテクスチャセットに…」（新しいセットへ）と「PSD を今のテクスチャセットに…」（今のセットの文書を置き換える）のほか、ウィンドウに .psd を落としても同じ流れで取り込みます（落としたときの行き先は新しいテクスチャセット。複数を落としたときは最初の 1 つだけで、取り込まなかった件数を結果の文に出します。描いている間は断ります）。

Live Link で開いた Unity のマテリアルの Color の元の絵が PSD（sRGB）のときも、同じ取り込みで、レイヤーのままテクスチャセットに入ります（[LIVELINK.md](LIVELINK.md) の「スタンドアロンの受け方」の元の絵）。
読み方・予算（PSD 1 つごとに設定の「レイヤーのメモリ」）・落とす・変わるものの仕分けは手で取り込むときと同じで、確かめのウィンドウは出さずに、落とす・変わるものを知らせに出します。
元の PSD は読むだけです。取り込めない PSD（予算を超えるなど）は、理由を知らせて重ねた 1 枚の絵にします。

1. ファイルを先頭から流して読みます。ファイル全体をメモリに置かず、レイヤーの画素は 1 枚ずつ復号して文書へ入れます。元のファイルの大きさに上限はありません。
2. レイヤーの数・キャンバス・レイヤーの画素・レイヤー 1 枚の付加情報（効果やスマートオブジェクトの中身など）の上限は、設定の「レイヤーのメモリ」の予算から決まります（レイヤーの数は予算 1 MiB につき 1 枚、256〜32767 枚）。超えるときは理由とともに断ります。設定で予算を上げると取り込めることがあります。ただし、取り込んだ文書を .ylp に保存できるよう、辺 8192・レイヤー 2048 枚（グループも数えます。区切りの記録は数えません）・グループの入れ子 64 段は、予算を上げても取り込めません。
3. 落とす・変わるものが 1 つでもあれば（無視だけなら確かめずに取り込みます）、取り込む前に「PSD の取り込みの確かめ」のウィンドウへ、レイヤーの名前と機能の名前で並べます。「取り込む」を押すまで何も入れません。1 つもなければウィンドウは出ません。
4. 取り込んだ文書の合成を PSD に保存された統合画像と照らし、差が 2（0〜255）を超えれば最大の差と差のある画素の割合をウィンドウに出します。2 以下は合成の丸めの違いとして知らせません。

## 扱いの 3 種類

| 扱い | 意味 |
|---|---|
| 無視 | 見え方にも内容にも効かない情報。持ちません |
| 落とす | レイヤーの画素は残しますが、その機能の設定・元のデータは持ちません。画素を持たない未対応の調整はレイヤーごと落とします |
| 変わる | 評価できない効果など、合成が PSD の統合画像と変わり得るもの。レイヤーの画素のまま取り込みます |

## 仕分けの表

### 合成にも内容にも効かないもの（無視）

| 情報 | 例 |
|---|---|
| 全体マスク | 全体マスクの表示の設定 |
| 画像リソース | 解像度・サムネイル・チャンネル名など。ICC（sRGB 以外）と画素の縦横比は下の「変わる」 |
| 文書のタグ | `Patt`・`Txt2` など |
| レイヤーのメタデータ | `lnsr`・`shmd`・`fxrp`・`lyvr` など、知らないタグ |
| レイヤーの色ラベル・グループの開閉・PSD のロック（透明部分・画素・位置・すべて。下の「書き出す中身」）にないビット・フラグ | |
| 透明部分が形を決める設定（`tsly`） | 効果は評価しないので、値によらず無視 |
| レイヤー名の文字 | NUL・Unicode 名のない非 ASCII 名 |
| レイヤー情報の余り・色モードデータ・統合画像の追加チャンネル | |
| レイヤー ID の欠落・重複・不正 | そのレイヤーだけに新しい ID を振ります（有効で一意な ID は、順番によらず変えません）。名前では対応付けません。写しとして取り込むので、元の PSD とは ID で対応付けません |

### 合成に効くのに評価できないもの（変わる）

| 情報 | 取り込み方 |
|---|---|
| レイヤー効果（`lfx2` など） | レイヤーの画素のまま。効果は評価しません |
| ベクターマスク | レイヤーの画素のまま。評価しません |
| 未対応の合成モード（ディゾルブなど） | 通常にします |
| ブレンド条件（Blend If）・クリップしたレイヤーのグループ合成・内部効果のグループ合成・ノックアウト・チャンネルの合成制限 | 評価しません |
| 塗りの不透明度（`iOpa`） | レイヤーの不透明度に掛けます。合成モードによっては Photoshop と少し変わります |
| マスクの未対応のフラグ・ぼかし・ユーザーマスクとベクターマスクの組 | マスクの画素のまま |
| マスクの既定値が 0・255 以外 | 近いほうの 0 か 255 にします。矩形の外の見え方が変わります（既定値 100 なら、外が全部隠れます） |
| 画素の値のないマスク（矩形の定義だけでチャンネルが無い） | 既定値だけのマスクにします。矩形の中の見え方が変わることがあります（矩形が空なら元から既定値だけなので知らせません） |
| sRGB 以外のカラープロファイル | 色は変換せず、画素の値のまま |
| 正方形でない画素の縦横比 | 正方形の画素として |

### レイヤーの画素は持つが設定を持たないもの（落とす）

| 情報 | 取り込み方 |
|---|---|
| スマートオブジェクト | レイヤーの画素のまま。元のデータは持ちません |
| テキスト | レイヤーの画素のまま。文字のデータは持ちません |
| グラデーション・パターンの塗りつぶし、ベクターマスクを持つ塗りつぶし | レイヤーの画素のまま。設定は持ちません |
| 未対応の調整レイヤー（特定色域・チャンネルミキサー・フォトフィルター・自然な彩度・白黒・カラールックアップ・露光量など） | 画素を持たないのでレイヤーごと落とします |
| 読めない内容の調整（チャンネル別のレベル補正・Colorize・表せない曲線など） | レイヤーごと落とします |
| キャンバスの外の画素・マスクの値 | 切り捨てます（透明の画素だけが外にあるときは何も失わないので知らせません） |
| グループ自身の画素・RGB のチャンネルが揃わないレイヤー | 落とします |

### 取り込める調整（そのままレイヤーになります）

反転・レベル補正（RGB 一括）・色相/彩度・グラデーションマップ・トーンカーブ・カラーバランス・明るさ/コントラスト・2 値化・ポスタリゼーション。
色調補正の 6 種（グラデーションマップ・トーンカーブ・カラーバランス・明るさ/コントラスト・2 値化・ポスタリゼーション）は、Photoshop の調整レイヤー（`grdm`・`curv`・`blnc`・`brit` と `CgEd`・`thrs`・`post`）として読み書きします。
このアプリで表せない中身は、取り込みでレイヤーごと落とします（上の「読めない内容の調整」）。

- グラデーションマップ: ディザ、なめらかさが 100% でないもの、ノイズ型、RGB 以外の色、分岐点の数・並び・中点が表せないもの。
- トーンカーブ: 点が 16 を超える曲線、両端の入力が 0 と 255 でない曲線（Photoshop の「自動」はよくある例）、隣の点が 6 刻みより近い曲線。
- 明るさ/コントラスト: 旧式の記録（`brit` だけ、または旧式を指す `CgEd`）、自動、Lab、範囲外、`brit` と `CgEd` の食い違い。

### 取り込めないもの（断ります）

| 理由 | 備考 |
|---|---|
| PSB 形式 | |
| RGB 8 bit 以外（CMYK・グレースケール・16 bit など） | |
| レイヤーのない PSD（統合画像だけ） | |
| 予算を超える（レイヤーの数・キャンバス・レイヤーの画素・レイヤー 1 枚の付加情報） | 設定の「レイヤーのメモリ」を上げると取り込めることがあります |
| 壊れている・途中で切れている | レイヤーのデータが切れているとき。統合画像だけが切れていてもレイヤーは取り込み、照合を省略と知らせます |

読める圧縮は、非圧縮・PackBits（RLE）・ZIP・予測つき ZIP です。

# PSD の書き出し

書き出しは、チャンネルごとに 1 つの PSD を、今の文書の写しから書きます（文書は変わりません）。「ファイル → PSD を書き出す…」の「PSD の書き出し」のウィンドウで方式（焼き込んで書く・平らに 1 枚）とチャンネルを選び、「書き出し…」を押します。焼く・丸める・落とすものがあれば、書く前に「PSD の書き出しの確かめ」のウィンドウへレイヤーの名前つきで並べ、「書く」を押すまで書きません。

## 書き出す中身

「PSD の書き出し」のウィンドウでチャンネルを選びます（既定は Color だけ）。チャンネルごとに 1 つの PSD を書き、複数のチャンネルは `<名前>_<チャンネル>.psd` を並べて書きます。
レイヤーの合成モード・不透明度・表示はそのチャンネルの値で、Normal は文書のファイルの向きで書きます。
そのチャンネルに効かないレイヤー（無効・面や値が無い・色のチャンネルだけの調整）は、隠したレイヤーで書きます。

レイヤーのロック（透明部分・画素・位置・すべて）は `lspf` に書き、取り込むとレイヤーのロックに戻ります（PSD が持たないビットは、取り込みの結果に「ロックのビット」として出ます）。

「焼き込んで書く」では、PSD に形の無いものを次のように書きます。した事は、書く前の確かめにレイヤーの名前つきで並びます。

| 中身 | 書き方 |
|---|---|
| レイヤーのフィルター（Generator も）・塗りつぶしの画像/投影/デカール/グラデーション・半透明の塗りつぶし | 評価した画素のレイヤーにする（焼く） |
| マスクのフィルター・反転したマスク | 評価・反転した値をマスクの画素にする（焼く） |
| クリッピングされたグループ | グループの合成を 1 枚のレイヤーにする（クリッピングの印は付けたまま） |
| パス・テキストレイヤー | 画素のレイヤーのまま。パスの情報・テキストの値は PSD に残らない |
| Anchor・効いていないフィルターの段 | 落とす（画素は変わらない） |
| 何にもクリッピングされないグループのクリッピングの印 | 外して普通のグループにする（見た目は同じ） |
| PSD の刻みの間の調整（レベル補正・色相/彩度・トーンカーブ・カラーバランス・明るさ/コントラスト・グラデーションマップ） | 調整レイヤーのまま、最寄りの刻みへ丸める（値と合成の最大の差を並べる） |
| グラデーションマップの値のカーブ（混色も） | 調整レイヤーのまま、カーブを通した色・不透明度の停止点の列に展開する（停止点の数と合成の最大の差を並べる） |

- 2 値化・ポスタリゼーションは整数の設定だけで刻みの間が無いので、丸めません。
- グラデーションマップの停止点は、色・不透明度それぞれ 32 個までです。展開は、その調整レイヤー 1 枚の出力の差（通常の合成モード・不透明度 100% で、下の色によらない最悪）が 1 以下になる最小の数を目指し、不透明度が動いて足りなければ 2・4 まで緩めます。
  それでも 32 個に収まらないものは、そのチャンネルの合成に出るレイヤーならレイヤーの名前つきで断ります（表示を切ったレイヤー・そのチャンネルに効かないレイヤーは、最良の展開を隠したレイヤーで書きます）。
- この差は文書の合成の差の上限ではありません。レイヤーの合成モード・上のレイヤーで増えることがあるので、確かめのウィンドウの注記には、文書の合成の実測の最大の差が出ます。
- 書き出しは文書の写しで、文書は変わりません。効果は文書に残りますが、焼いたレイヤーは効果の設定を持たないので、PSD を取り込み直しても効果は戻りません。
- ファイルの向きが DirectX の Normal は、レイヤーの緑を反転して書きます。PSD の 1 つのレベル補正で書けないレベル補正のレイヤーがあれば断ります。
- 色のチャンネル以外（スカラーのチャンネル）のトーンカーブは RGB 全体の曲線だけが効くので、R・G・B の曲線は直線で書きます。

書いた PSD を読み戻した合成は、書き出したチャンネルの今の合成と一致することを確かめていますが（書き出しのたびではなく、試験で）、次のものは一致しません。

- 丸める・展開する調整。
- 1/255 の刻みの外のレイヤーの不透明度とマスクの濃度（PSD が丸めます。確かめには出ません）。
- Normal のレイヤーが重なる所（PSD は色の式で重ねるため、法線として重ねるこのアプリと違います。確かめのウィンドウに注記が出ます）。
- 反転したマスクを焼いたレイヤーが重なる所（浮動小数の最後の桁の違いで、まれに 1 画素が 1 ずれます）。

色調補正の 6 種の式はこのアプリのもので、書き出した PSD の統合画像もこのアプリの式の結果です。Photoshop・CLIP STUDIO で開いて調整レイヤーが再評価されると、見た目が変わることがあります（実機では確かめていません）。

## 書き出しの流れ

1. 計画（何を焼き・丸め・落とすか）と確かめのあと、別のスレッドで書きます。
2. レイヤーは 1 枚ずつ評価して（焼くものは焼いて）圧縮し、書き先と同じフォルダの一時ファイルへ流して書きます。メモリに持つのはレイヤー 1 枚ぶんとレイヤーの記録の表だけで、全レイヤーの画素の合計には上限がありません。
3. 書き終えた一時ファイルを、全レイヤー・マスク・統合画像のすべての行まで流して読み戻して確かめます（行の復号、長さとレイヤーの数が書いたものと合うこと、取り込みで落とす・変わるものが無いこと）。あわせて、読み戻したファイルが書いたバイト列と一致するかを、書きながら数えた CRC-32 と長さで確かめます（バイト単位の完全な比較ではなく、化けを 2^-32 の確率で見逃します）。書いた画素が文書の画素と同じかは、書き出しのたびには比べません（読み戻した合成が書き出した文書と同じになることは、実物の大きさの文書で確かめています）。すべてのチャンネルが済んでから、最後に置き換えます。途中の失敗・取消・異常終了では一時ファイルを消し、元のファイルは変えません。

Normal の焼き込みと「平らに 1 枚」だけは、統合画像を書いたレイヤーから作る（Normal）か、1 枚のレイヤーそのもの（平ら）なので、全レイヤーをメモリ上に作ってから書きます。この作り方の画素の合計は、下の予算が上限です。

テキストレイヤーは、描いた結果の画素のレイヤーとして書きます（テキストの値は PSD に残らず、「PSD の書き出しの確かめ」にレイヤーの名前つきで並びます）。PSD の取り込みでテキストレイヤーを画素のまま取り込む扱いは、上の表のとおりです。

## 上限

| 項目 | 上限 |
|---|---|
| キャンバス | 設定の「レイヤーのメモリ」の予算に画素（1 画素 4 バイト）が入る範囲。辺は 30000 まで |
| レイヤーの記録 | 予算 1 MiB につき 1 件（256〜32767 件）。グループは区切りの記録も 1 件数えます |
| レイヤー 1 枚の画素 | キャンバスの範囲 |
| 全レイヤーの画素の合計 | 流して書く書き出しは上限なし。メモリ上に作る書き出し（Normal の焼き込み・平ら）は予算まで |
| ファイル | 2 GiB（PSD の形式の上限。圧縮したあとの大きさで、書きながら見ます） |
| グループの入れ子 | 64 段（文書そのものの上限で、書き出しも取り込みも同じ） |

超えるときは、レイヤーの名前つきの理由（キャンバスは大きさ、レイヤーの記録は件数と上限）で断り、何も書きません。予算で断った理由は、設定の「レイヤーのメモリ」を上げると書き出せることがあります（ファイルの 2 GiB と辺の 30000 は形式の上限なので、上げても書けません）。キャンバス・レイヤーの記録・レイヤーの画素は、取り込みと同じ予算の決め方です。

## 圧縮

レイヤー・マスク・統合画像のチャンネルを RLE（PackBits。Photoshop の既定）で書きます。レイヤーとマスクのチャンネルは 1 本ずつ、圧縮して大きくなるもの（乱数のような画素）は無圧縮のまま書きます。統合画像は全チャンネルで 1 つの圧縮なので、小さくならなければ無圧縮です。行ごとの長さの表は PSD の仕様のとおりで、このツールの読み込み（原本を保つ読みと写しとしての取り込み）で読み直せます。Photoshop・CLIP STUDIO の実機では確かめていません。

色の面が多い 4096²・34 レイヤー（半透明・合成モード・マスク・グループ・調整・焼くフィルター）の文書では、ファイルは 63 MiB で、無圧縮で書くときの 6% でした。乱数のような圧縮できない画素が多い文書は、無圧縮に近い大きさになります。
