# PSD の読み込み

YoluPainter は PSD（RGB 8 bit）を、**元のファイルへ書き戻さない写し**として取り込みます。取り込んだ文書を PSD へ書き出すときは、いつも新しい PSD になります（取り込んだファイルと同じ場所へ書くときは、置き換える前に確かめます）。

## 取り込みの流れ

1. ファイルを先頭から流して読みます。ファイル全体をメモリに置かず、層の画素は 1 枚ずつ復号して文書へ入れます。元のファイルの大きさに上限はありません。
2. 層の数・キャンバス・層の画素・層 1 枚の付加情報（効果やスマートオブジェクトの中身など）の上限は、設定の「レイヤーの画素」の予算から決まります（層の数は予算 1 MiB につき 1 枚、256〜32767 枚）。超えるときは理由とともに断ります。設定で予算を上げると取り込めることがあります。
3. 落とす・変わるものが 1 つでもあれば（無視だけなら確かめずに取り込みます）、取り込む前に「PSD の取り込みの確かめ」の窓へ、層の名前と機能の名前で並べます。「取り込む」を押すまで何も入れません。1 つもなければ窓は出ません。
4. 取り込んだ文書の合成を PSD に保存された統合画像と照らし、差が 2（0〜255）を超えれば最大の差と差のある画素の割合を窓に出します。2 以下は合成の丸めの違いとして知らせません。

## 扱いの 3 種類

| 扱い | 意味 |
|---|---|
| 無視 | 見え方にも内容にも効かない情報。持ちません |
| 落とす | 層の画素は残しますが、その機能の設定・元のデータは持ちません。画素を持たない未対応の調整は層ごと落とします |
| 変わる | 評価できない効果など、合成が PSD の統合画像と変わり得るもの。層の画素のまま取り込みます |

## 仕分けの表

### 合成にも内容にも効かないもの（無視）

| 情報 | 例 |
|---|---|
| 全体マスク | 全体マスクの表示の設定 |
| 画像リソース | 解像度・サムネイル・チャンネル名など。ICC（sRGB 以外）と画素の縦横比は下の「変わる」 |
| 文書のタグ | `Patt`・`Txt2` など |
| 層のメタデータ | `lnsr`・`shmd`・`fxrp`・`lyvr` など、知らないタグ |
| 層の色ラベル・グループの開閉・ロックのビット・フラグ | |
| 透明部分が形を決める設定（`tsly`） | 効果は評価しないので、値によらず無視 |
| 層名の文字 | NUL・Unicode 名のない非 ASCII 名 |
| 層情報の余り・色モードデータ・統合画像の追加チャンネル | |
| 層 ID の欠落・重複・不正 | その層だけに新しい ID を振ります（有効で一意な ID は、順番によらず変えません）。名前では対応付けません。写しとして取り込むので、元の PSD とは ID で対応付けません |

### 合成に効くのに評価できないもの（変わる）

| 情報 | 取り込み方 |
|---|---|
| レイヤー効果（`lfx2` など） | 層の画素のまま。効果は評価しません |
| ベクターマスク | 層の画素のまま。評価しません |
| 未対応の合成モード（ディゾルブなど） | 通常にします |
| ブレンド条件（Blend If）・クリップした層のグループ合成・内部効果のグループ合成・ノックアウト・チャンネルの合成制限 | 評価しません |
| 塗りの不透明度（`iOpa`） | 層の不透明度に掛けます。合成モードによっては Photoshop と少し変わります |
| マスクの未対応のフラグ・ぼかし・ユーザーマスクとベクターマスクの組 | マスクの画素のまま |
| マスクの既定値が 0・255 以外 | 近いほうの 0 か 255 にします。矩形の外の見え方が変わります（既定値 100 なら、外が全部隠れます） |
| 画素の値のないマスク（矩形の定義だけでチャンネルが無い） | 既定値だけのマスクにします。矩形の中の見え方が変わることがあります（矩形が空なら元から既定値だけなので知らせません） |
| sRGB 以外のカラープロファイル | 色は変換せず、画素の値のまま |
| 正方形でない画素の縦横比 | 正方形の画素として |

### 層の画素は持つが設定を持たないもの（落とす）

| 情報 | 取り込み方 |
|---|---|
| スマートオブジェクト | 層の画素のまま。元のデータは持ちません |
| テキスト | 層の画素のまま。文字のデータは持ちません |
| グラデーション・パターンの塗りつぶし、ベクターマスクを持つ塗りつぶし | 層の画素のまま。設定は持ちません |
| 未対応の調整レイヤー（特定色域・チャンネルミキサー・フォトフィルター・自然な彩度・白黒・カラールックアップ・露光量など） | 画素を持たないので層ごと落とします |
| 読めない内容の調整（チャンネル別のレベル補正・Colorize・表せない曲線など） | 層ごと落とします |
| キャンバスの外の画素・マスクの値 | 切り捨てます（透明の画素だけが外にあるときは何も失わないので知らせません） |
| グループ自身の画素・RGB のチャンネルが揃わない層 | 落とします |

### 取り込める調整（そのまま層になります）

反転・レベル補正（RGB 一括）・色相/彩度・グラデーションマップ・トーンカーブ・カラーバランス・明るさ/コントラスト・2 値化・ポスタリゼーション。

### 取り込めないもの（断ります）

| 理由 | 備考 |
|---|---|
| PSB（大きな文書） | |
| RGB 8 bit 以外（CMYK・グレースケール・16 bit など） | |
| レイヤーのない PSD（統合画像だけ） | |
| 予算を超える（層の数・キャンバス・層の画素・層 1 枚の付加情報） | 設定の「レイヤーの画素」を上げると取り込めることがあります |
| 壊れている・途中で切れている | 層のデータが切れているとき。統合画像だけが切れていても層は取り込み、照合を省略と知らせます |

読める圧縮は、非圧縮・PackBits（RLE）・ZIP・予測つき ZIP です。

# PSD の書き出し

書き出しは、チャンネルごとに 1 つの PSD を、今の文書の写しから書きます（文書は変わりません）。書く前の確かめ（焼く・丸める・落とす）の扱いは「ファイル → 書き出し → PSD…」の窓の注記のとおりです。

## 書き出しの流れ

1. 計画（何を焼き・丸め・落とすか）と確かめのあと、別のスレッドで書きます。
2. 層は 1 枚ずつ評価して（焼くものは焼いて）圧縮し、書き先と同じフォルダの一時ファイルへ流して書きます。メモリに持つのは層 1 枚ぶんと層の記録の表だけで、全層の画素の合計には上限がありません。
3. 書き終えた一時ファイルを、全層・マスク・統合画像のすべての行まで流して読み戻して確かめます（行の復号、長さと層の数が書いたものと合うこと、取り込みで落とす・変わるものが無いこと）。あわせて、読み戻したファイルが書いたバイト列と一致するかを、書きながら数えた CRC-32 と長さで確かめます（バイト単位の完全な比較ではなく、化けを 2^-32 の確率で見逃します）。書いた画素が文書の画素と同じかは、書き出しのたびには比べません（読み戻した合成が書き出した文書と同じになることは、実物の大きさの文書で確かめています）。すべてのチャンネルが済んでから、最後に置き換えます。途中の失敗・取消・異常終了では一時ファイルを消し、元のファイルは変えません。

Normal の焼き込みと「平らに 1 枚」だけは、統合画像を書いた層から作る（Normal）か、1 枚の層そのもの（平ら）なので、全層をメモリに組んでから書きます。この組み方の画素の合計は、下の予算が上限です。

## 上限

| 項目 | 上限 |
|---|---|
| キャンバス | 設定の「レイヤーの画素」の予算に画素（1 画素 4 バイト）が入る範囲。辺は 30000 まで |
| 層の記録 | 予算 1 MiB につき 1 件（256〜32767 件）。グループは区切りの記録も 1 件数えます |
| 層 1 枚の画素 | キャンバスの範囲 |
| 全層の画素の合計 | 流して書く書き出しは上限なし。メモリに組む書き出し（Normal の焼き込み・平ら）は予算まで |
| ファイル | 2 GiB（PSD の形式の上限。圧縮したあとの大きさで、書きながら見ます） |
| グループの入れ子 | 128 段 |

超えるときは、層の名前つきの理由（キャンバスは大きさ、層の記録は件数と上限）で断り、何も書きません。予算で断った理由は、設定の「レイヤーの画素」を上げると書き出せることがあります（ファイルの 2 GiB と辺の 30000 は形式の上限なので、上げても書けません）。キャンバス・層の記録・層の画素は、取り込みと同じ予算の決め方です。

## 圧縮

層・マスク・統合画像のチャンネルを RLE（PackBits。Photoshop の既定）で書きます。層とマスクのチャンネルは 1 本ずつ、圧縮して大きくなるもの（乱数のような画素）は無圧縮のまま書きます。統合画像は全チャンネルで 1 つの圧縮なので、小さくならなければ無圧縮です。行ごとの長さの表は PSD の仕様のとおりで、この道具の読み込み（原本を保つ読みと写しとしての取り込み）で読み直せます。Photoshop・CLIP STUDIO の実機では確かめていません。

色の面が多い 4096²・34 層（半透明・合成モード・マスク・グループ・調整・焼くフィルター）の文書では、ファイルは 63 MiB で、無圧縮で書くときの 6% でした。乱数のような圧縮できない画素が多い文書は、無圧縮に近い大きさになります。
