# パス

[English](en/GUIDE_PATHS.md)

パスのツール（`P`）は、点を順に通る編集できる曲線を、2D のキャンバスとモデルの面の上に引きます。点や設定を直すたびに、曲線から画素を描き直します。キー操作は [GUIDE_KEYS.md](GUIDE_KEYS.md) にあります。

## パスを引く

1. 左のツールバーでパスのツール（`P`）を選び、描くレイヤーを選びます。
2. キャンバス、または 3D ビューのモデルの面を押して、最初の点を置きます。ふつうのレイヤーを選んでいるときは、その上に新しいパスのレイヤーができます。パスのレイヤーか塗りつぶしレイヤーを選んでいるときは、そのレイヤーのパスになります。
   点を置く前にレイヤーだけ作るには、「レイヤー」メニュー（と右クリック）の「新規パスレイヤー」を使います。選んでいるレイヤーのすぐ上に、点の無いパスを持つレイヤーを作ってパスのツールに替え、最初の点（2D でも 3D でも）はそのレイヤーのパスになります。
3. 続けて押すと、終わりに点が加わります。曲線の上を押すとその区間に点が入り、点を掴んでドラッグすると動きます。
4. 選んでいる点は `Delete`（`Backspace`）で消えます。点を選んでいなければ最後の点が消えます。
5. `Enter` でそのパスの編集を抜けます。次に押した点は、同じレイヤーの新しいパスを始めます。`Esc` は、ドラッグ中ならドラッグをやめ、そうでなければ点の選びを外し、点も選んでいなければ編集を抜けます。

3 点以上あれば、ツールの帯の「閉じる」で輪にできます（始めと終わりの点が同じ場所になります）。輪は「開く」で戻せます。`Shift` を押したままドラッグすると、四角で囲んだ点をまとめて選べて、太さ・角・取っ手・削除がその全部に効きます。

点の操作 1 回が取り消し 1 回です。点のドラッグは離したときに描き直し、フォーカスを失うとそこまでを確定します。キャンバスの外には点を置けません。パスのレイヤーには手で描けず、ロックされたレイヤーと描いている間は編集を断ります。

## 点の太さを変える

ツールの帯の「太さ」は、選んでいる点の太さ（筆圧の代わり）です。点ごとに変えると、曲線に沿って滑らかに変わります。パスのブラシの「太さで直径を変える」「太さで不透明度を変える」「太さで流量を変える」を入れると、描く大きさと濃さに効きます。

## 角と取っ手で曲がりを決める

点の前後は、はじめ滑らかにつながっています。選んでいる点で次のように変えられます。

- 「角」: その点で曲線を折ります。点をダブルクリックしても切り替わります。
- 「取っ手」: 点に取っ手が出て、取っ手のドラッグで曲がりを決めます。出しただけでは形は変わりません。ドラッグすると反対側の取っ手が向きを合わせてついてきます。ドラッグを始めたあとに `Alt` を押すと動かした側だけ（押したまま始めると視点の操作になります）、`Ctrl` を押しながらなら両側を同じ割合で伸ばします。
- 同じボタンをもう一度押すと、滑らかな点に戻ります。

## 1 つのレイヤーに何本ものパスを置く

ツールプロパティの「パス」に、レイヤーのパスが上から（上が後に描かれる）並びます。行を押すとそのパスを編集し、ダブルクリックで名前を変えられます。目のアイコンで隠したパスは画素に入りませんが、点と設定は残ります。

下のアイコンは、新しいパス（`Enter`）・パスを複製・上へ移動・下へ移動・パスを削除です。右クリックのメニューには、名前を変更・表示・コピー・貼り付け・複製・設定を貼り付け・位置を貼り付け・上へ移動・下へ移動・パスを削除があります。コピーしたパスは別のレイヤーへ貼り付けられ、パスの無いレイヤーに貼ると新しいパスのレイヤーになります。「設定を貼り付け」はブラシと塗るチャンネルの組だけ、「位置を貼り付け」は点の位置だけを写します。

1 つのレイヤーのパスは 256 本まで、全部が 2D か、全部が 3D のどちらかです。後のパスが上に重なり、消しゴムのパスは前のパスの画素を消します。

## パスで何を描くか

「パスのブラシ」の「種類」で、曲線に沿って描く物を選びます。

| 種類 | 描く物 |
|---|---|
| ストローク | 丸い筆先か画像の筆先を、曲線に沿って並べます |
| リボン | アセットの画像を曲線に沿って並べます。「並べ方」は、画像を 1 つずつ並べる「並べる」（間隔は「並べる間隔」）と、パス全体に 1 枚を伸ばす「伸ばす」。アセットに画像が無いと選べません |
| 塗り | 閉じた曲線の内側を塗ります。開いたパスは、終わりから始めへ閉じて塗ります |
| 指先 | 曲線に沿って前の画素を引きずります。「強さ」を変えられます |
| 消しゴム | 曲線に沿って消します |

筆先は「筆先」で丸・組み込みの筆先・今のブラシの筆先から選び、画像の筆先では「角度」と、曲線の進む向きに回す「パスに沿う」が使えます。直径（リボンは「幅」）・硬さ・アンチエイリアス・間隔・不透明度・流量は、パスごとに持ちます。

「ブラシを使う」は、今のブラシと、ツールプロパティの「塗るチャンネル」で選んだチャンネルの組でパスを描き直します。組を選んでいれば、1 本のパスが複数のチャンネルを一度に描きます（[GUIDE_FILL.md](GUIDE_FILL.md)）。種類・ブラシ・チャンネルの組・筆先・深さ・対称の入り切りは、「プリセット」で名前を付けて残せます（設定のフォルダの `path_presets/`）。

## 3D のモデルの上のパス

3D ビューでも同じ操作でパスを引けます。点はモデルの三角形に結び付き、`.ylp` に保存されます。ほかのテクスチャセットの面とモデルの外には点を置けません。

- パスはポーズを付けない形（FBX の休みの形）の上で描くので、ポーズを変えても UV の上の太さと間隔は変わりません。
- 曲線から面を探す深さは、はじめは点の間の長さとブラシの大きさから決まります。「投影の深さを自動にする」を切ると、「投影の深さ」を自分で決められます。浅いと、面から離れた所は描きません。
- 塗りの種類は、点が全部 1 つの UV アイランドの中にあるときだけ描けます。
- 別のモデルで描いたパスには「別のモデルで描かれています」と出て、編集できません。
- モデルを差し替えると、近い同じマテリアルの面へ付け直して描き直します。付け直せないパスは、今の画素を残してパスを外します（「すべて」をロックしたレイヤーのパスだけは、前のモデルに結び付けたまま残ります）。結果は件数と最初の理由で知らせます。

## 対称と向き

「対称」を入れると、映したパスも一緒に描きます。入れたときに、そのパスのレイヤーから見えて効いている対称定規の値をパスに写します（2D のパスは 2D の対称定規、3D のパスは 3D の対称定規。効いている対称定規が無ければ入りません）。線対称（斜め・6 本以上も）も回転対称も写せます。3D のパスは、線対称 2 本（鏡の面 1 枚）の対称定規だけが写せ、ポーズを付けているあいだは入れられません。パスの中に自分で値を持つので、あとで定規を動かしても、描いたパスは変わりません。映した側は点を持たず、描くときに作ります。「向きを反転」は点の並びを逆にして、筆先やリボンの向きを変えます。

## 塗りつぶしレイヤーにパスを置く

塗りつぶしレイヤーを選ぶと、プロパティの「パス」の節の「パスを追加」から、パスのツールで新しいパスを始められます。パスは塗りつぶしと効果の上に重なり、効果を受けません。塗りつぶしレイヤーのパスは画素にできません。

## 画素にする

ツールの帯の「ラスタライズ」（レイヤーの右クリックの「パスをラスタライズ」でも）は、今の画素を残してパスを外し、ふつうのレイヤーに戻します。
