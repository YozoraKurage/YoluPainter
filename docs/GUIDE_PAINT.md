# 描く

[English](en/GUIDE_PAINT.md)

ブラシと消しゴム、ペンの筆圧、直線・図形・定規、対称、バケツとグラデーション、色、ステンシル、テキストの使い方です。塗りつぶしレイヤーとマテリアルで塗る方法は [GUIDE_FILL.md](GUIDE_FILL.md)、パスは [GUIDE_PATHS.md](GUIDE_PATHS.md)、3D ビューへ描く方法は [GUIDE_3D.md](GUIDE_3D.md) にあります。

## ブラシで描く

ブラシ（`B`）と消しゴム（`E`）は、2D の「キャンバス」にも「3D ビュー」にも描けます。消しゴムは、消しゴムの一覧で最後に選んだ消しゴムで消します。描く先は、「レイヤー」のパネルで選んだレイヤー（マスクを選んでいればマスク）の、描くチャンネルです。

左の「ツールプロパティ」のパネルで、直径・不透明度・硬さ・流量・間隔・手ぶれ補正をすぐ変えられます。直径は `[` と `]` でも変わります。その下の「ブラシサイズ」のパネルは、決まった直径の丸です（ブラシ・消しゴム・選択ペンのときだけ出ます）。調整のボタン（「ブラシの詳細」）で、設定の全部を項目ごとに分けたウィンドウが開きます。動かせて、開いたまま描けます。

| 項目 | 中身 |
|---|---|
| 形状 | 筆先（丸・組み込みの画像・取り込んだ画像）、硬さ、アンチエイリアス（なし・弱・中・強。縁の画素の段をならす）、真円率、角度、線の向きに従う、反転 |
| ストローク | 直径・間隔・流量・不透明度、手ぶれ補正、曲線。3D の塗り方は [GUIDE_3D.md](GUIDE_3D.md) |
| 筆圧 | 直径・不透明度・流量・硬さそれぞれの、筆圧を使うかどうか・最小値・曲線 |
| 入り抜きとペン | 入り抜き、フェード、ペンの傾き・回転、筆の速さ |
| ゆらぎ・テクスチャ・デュアルブラシ・色の揺らぎ | 散らばり、紙の質感、2 つ目の筆先の重ね、色相・彩度・明るさの変化 |
| 色の混ぜ・効果 | 下の色を拾って混ぜる（油彩・ガッシュ・混色の筆が使います）。ぼかし・指先・クローン |
| 対称 | 下の「対称で描く」 |

項目の仕様は [BRUSH.md](BRUSH.md) にあります。

クローンのブラシは、`Alt` を押しながらクリックした所（動かさずに離す）を元にして、次のストロークから写します。2D のキャンバスも 3D ビューも同じです（動かすと、2D は表示の回転、3D はスナップ回転になります）。元の位置には十字が出て、2D では描いているあいだ、今写している点へ動きます。「揃える」を入れていると、元を決めた後のストロークの始めの点で元までのずれが決まり、続くストロークは同じずれで続けます（`Esc` で取りやめたストロークと、何も変わらなかったストロークでは決まらず、次のストロークで決めます）。決まったずれは、消しゴムとの往復やブラシの選び直しのあとも続きます。切ると、ストロークごとに始めの点が元に重なります。「全レイヤーから」は、見えているレイヤーの重なりを読みます。この 2 つの設定は、2D と 3D で一つです。文書やテクスチャセットを替えると、元は忘れます。元を決めていない 2D は、「効果」の「ずれ X」「ずれ Y」で写します。元を決めた 2D では、この欄は決まったずれを見せ、元から決めたずれはブラシの「変更あり」に数えません（欄で直したずれは数えます）。揃えないときと、3D ビューだけを出しているときは、欄では決まらないので薄くなります。

どのツールを選んでいても、2D は右ボタンを押す（押したまま動かすと見本の色が付いてきます。離した所の色を取ります）、3D は右ボタンを動かさずに離すと、一時的にスポイトになります。ポリゴン塗りつぶしの右ボタンは、アイランドのメニューです（`Alt` は視点の操作です）。描いているあいだ、パネルの部品は押しても何も起きません。見た目は描き始める前のままで、灰色に変わりません。

## ブラシを選ぶ・組み替える

ブラシは、「サブツール」のパネルの一覧から選びます。グループのタブ（はじめはペン・筆・エアブラシ・効果・特殊。取り込んだブラシがあれば取り込み）ごとに、各ブラシの名前と、その設定で描いた見本のストロークが並びます。消しゴムの一覧は、ブラシと別のグループです。設定を変えたブラシには「変更あり」の印が付きます。

- 一覧の下の帯のボタンで、元の設定に戻す、複製、今の設定を新しいブラシにする、削除ができます。行のダブルクリックで名前を変えられます。
- 「ブラシを追加」（帯の「＋」）は、組み込み・同梱の Krita・Photoshop・CLIP STUDIO・取り込んだブラシ・自分のブラシを種類ごとに並べ、名前で探せるウィンドウです。選んだ物を今のグループに置きます。
- 他のアプリのブラシ（ABR・GBR・GIH・VBR・PNG・PAT）は「ブラシを取り込む」、CLIP STUDIO のブラシは「CLIP STUDIO から取り込む」で読み込みます。ウィンドウへ落としても読み込めます（PNG は、ブラシの一覧の上に落としたときだけ。[BRUSH_IMPORT.md](BRUSH_IMPORT.md)）。

### ツールバーとグループを並べ替える

左のツールバーのツール、グループのタブ、ブラシの行は、ドラッグで並べ替えられます（`Esc` でやめます）。グループのタブとブラシの行は、ブラシ・消しゴムのツールの上で離すと、そのツールへ動きます。ブラシの行は `Ctrl` を押して離すと写しを置きます。右クリックのメニューは次のとおりです。

| 場所 | メニュー |
|---|---|
| ツールバー | 「ツールを追加」、「このツールを削除」、「名前を変更」、「アイコンを変更」、「前に区切り」、「最初の並びに戻す…」 |
| グループのタブ | 「グループを追加」、「名前を変更」、「複製」、「削除」 |
| ブラシの行（消しゴムの行も） | 「ブラシの設定…」、「名前を変更」、「複製」、「グループへ移す」、「この設定で登録」、「元に戻す」、「削除」 |

「ブラシの設定…」は、そのブラシに替えて「ブラシの詳細」のウィンドウを開きます。「名前を変更」は行の中で名前を打ち替えます（`Enter` で決め、`Esc` でやめます）。「グループへ移す」には、そのツールのグループが並び（今のグループは押せません）、ブラシを持つほかのツールがあれば、ツールごとの入れ子の下にそのグループが並びます。ブラシの行を引いているあいだは、落とせるグループのタブが光ります。描いている間・並びのファイルが読めない間・取り込み中など、押せない項目は、乗せると理由が出ます。

「ツールを追加」には、ブラシと消しゴム、ツールバーから外した組み込みのツールが並びます。ブラシのツールと消しゴムのツールは、いくつでも置けて、それぞれが自分のグループを持つので、好きなブラシだけを集めたツールを作れます。それぞれ最後の 1 つは削除できません。削除は並びから外すだけで、ブラシのファイルは残ります。並びは設定のフォルダの `tools.json` に保存され、文書には入りません。自分のブラシは同じフォルダの `brushes/` にあります（壊れたファイルは読み飛ばし、起動のときに知らせます）。上限や形式は [SUBTOOLS.md](SUBTOOLS.md) にあります。

## ペンの描き心地を整える

- **筆圧**: ツールプロパティの直径・不透明度・硬さ・流量の行にあるペンのボタンで、その項目に筆圧を使うかどうかを決めます。最小値（筆圧 0 のときの値）と曲線は、「ブラシの詳細」の「筆圧」で決めます。指やペンの入力がタッチとして届き、力を送ってくるときは、その力が筆圧になります（2D のキャンバスも 3D ビューも。次の「筆圧の調整」を通ります）。
- **ペンごとの違い**: 「編集 → 設定…」の「ペン」の「筆圧の調整」で、下限・上限・曲線を合わせます。普段の強さで何本か描いて「自動調整」を押すと、描いた線の筆圧の分布から決められます。端末ごとの設定で、文書にもブラシにも入りません。
- **Windows のタブレット**: Windows では、既定で Windows Ink からペンの筆圧・傾き・回転・消しゴムの端・サイドボタンを読みます。Wacom などのドライバーが WinTab を出す PC では、「編集 → 設定…」の「ペン」の「ペンの入力」で WinTab に替えられます（WinTab が使えないときは Windows Ink のままです）。
- **Mac のタブレット**: Mac では、Wacom・XP-Pen などのドライバーが macOS の標準のイベントで送る筆圧・傾き・消しゴムの端・サイドボタンを読みます（試し）。「編集 → 設定…」の「ペン」の「タブレットの筆圧（試し）」で切り替えます（既定は入。切ると、ペンはマウスと同じに描きます）。
- **線が出るまでの遅れ**: 既定では、画面の更新を垂直同期まで待たずに出して、ペンの入力から線が画面に出るまでの遅れを縮めています。画面の上下のずれ（テアリング）が気になるときは、「編集 → 設定…」の「表示」の「垂直同期」を入れます（遅れが増えます。次の起動から効きます）。
- **手ぶれ補正**: ツールプロパティの「手ぶれ補正」（0〜200 px）は、筆が入力に引かれる糸の長さです。0 で切れます。
- **入り抜き**: 線の始めと終わりを細くする設定は、「ブラシの詳細」の「入り抜きとペン」にあります。
- **3D ビューでも**: 手ぶれ補正・入り抜き・ゆらぎなどの設定は、3D ビューに描く線にも同じ式で効きます。手ぶれ補正と入り抜きの長さ（px）は、3D ビューでは画面の点で測ります（[GUIDE_3D.md](GUIDE_3D.md)）。

## 直線・図形・定規

- **直線**: ブラシ・消しゴム・効果のブラシで `Shift` を押しながらクリックすると、前のストロークの終わりの点から、クリックした点まで直線を引きます（1 回の取り消しで戻ります）。そのままドラッグすると、続きを普通に描きます。前の点が無いとき（文書やテクスチャセットを替えたあと）は、押した点から描き始め、`Shift` を押したままドラッグすると、最初に動かした向きを 45° 刻みに固定します。マウスもペンも、2D のキャンバスも 3D ビューも同じです。3D ビューでは、前のストロークの終わり（面に当たった最後の点）を面の点で覚え、今のカメラで画面へ写した点から、クリックした点までを画面の直線で引きます（塗るのは、今の投影で見える面だけです）。モデルが替わったあとと、面に一度も当たらなかったストロークのあとは、前の点が無いものとして扱います。`Ctrl` を押した接触は、ペンは描かず、マウスは描きます（2D と 3D で同じです）。
- **図形**（`U`）: 「直線」「長方形」「楕円」を、ドラッグで決めて描きます。「線で描く」は今のブラシで輪郭を 1 本のストロークとして描き、「塗る」は描画色で形の中を塗ります（選択範囲があればその中だけ）。長方形は「角の丸み」を決められます。`Shift` で 45° 刻み・正方形・正円、ドラッグを始めたあとに `Alt` を押すと中心から、`Esc` で取りやめです。離したところで 1 回の取り消しになります。3D ビューでも使え、画面の上でドラッグした形を見えている面へ写して描きます（[GUIDE_3D.md](GUIDE_3D.md)）。
- **定規**（`Shift+U`）: 「直線定規」「平行線」「同心円」「パース」（1 点・2 点）を、ドラッグで置きます。端点か線をドラッグして動かし、「削除」で消します。2D のキャンバスでは 1 つのテクスチャセットに 1 つで、画面に薄い線で重ねます。3D ビューにも別に 1 つ置け、視点を動かしても画面の同じ所に残ります。種類・点の数・「削除」は、2D と 3D の両方の定規に効きます。表示の状態なので、`.ylp` には保存しません。
- **スナップ**（「定規にスナップ」、`Ctrl+1`）: 入れているあいだ、ブラシと消しゴムのストローク（`Shift` の直線も）の点を、定規の線の上へ寄せます（3D ビューのストロークは、3D ビューの定規へ画面の上で寄せます）。`Shift` と合わせたときは、定規の寄せ先が優先です。

## 対称で描く

「ブラシの詳細」の「対称」か、オプションバーの対称のメニューで決めます。2D の対称も 3D の対称も、2D のキャンバスと 3D ビューのどちらに描いても効きます。両方を入れると、3D の写しを作ってから、元と 3D の写しのそれぞれを 2D の対称で写します（写しの数は掛け算になります）。どの写しも、元と同じストロークなので、1 回の取り消しで戻ります。指先とクローンの効果のブラシとは組み合わせられません（どちらかの対称が入っていると、描き始めません）。クイックマスクのブラシと消しゴムは、対称を使いません。

- **2D**: 「縦」「横」「両方」「放射状」（写しの数 2〜16）から選びます。「中心 X」「中心 Y」で軸の通る点を動かし、「キャンバスの中心」で戻します。「軸を表示」で、キャンバスに軸を出します。3D ビューに描いたときは、塗ったテクスチャの画素を、キャンバスの上で同じ軸で写します（モデルの上ではなく、UV の平面の上の写しです）。
- **3D**: モデルを開いているあいだ、「2D」の下に「3D」の欄が出ます。「ミラー」は、モデルの X・Y・Z に直交する面で左右に写します。面は「中心」の数値か、「原点」「境界の中心」のボタンで置きます。「放射状」は、モデルの軸のまわりに回して写します（ミラーと一緒に使えます）。「見えない面にも」を入れると、3D ビューでは写しをカメラから見えない面にも塗ります。「面を表示」で、3D ビューに面と軸を出します。2D のキャンバスに描いたときは、筆の中心が指す UV の下の面の点を写し、写した先の面の UV に同じ形を置きます（写した先のテクスチャの細かさと UV の向きに合わせます）。同じ UV を持つ面が重なっている所では、その全部の面から写します。どの面の UV にも無い所の筆は写しません。2D のキャンバスには視点が無いので、「見えない面にも」によらず写しを塗ります。写しが面に届かないときと、別のテクスチャセットの面のときは、その写しだけ飛ばして知らせます。2D のキャンバスでは、UV が潰れているか、テクスチャの細かさが大きく違う面への写しも飛ばして知らせます。

## 塗りつぶす

- **バケツ**（`G`）: 押した所を塗ります。範囲はサブツールで、「近い色」、「三角形」「メッシュの塊」「UV アイランド」「マテリアル」から選びます。「塗る」「消す」を選べ、今の選択範囲があれば、その内側だけです。「近い色」には、「許容」「隣接」「参照」（編集しているレイヤー・全部のレイヤー・参照レイヤー）、「知覚の色差」「隙間閉じ」「領域の拡縮」「塗り残し部分に塗る」があります。3D ビューでは、押した面の UV が指す画素から、2D のキャンバスと同じ範囲を求めます（塗り残しは、なぞった面の UV の画素を通った線で求め、面の外と UV の継ぎ目ではつなぎません）。
- **ポリゴン塗りつぶし**（`4`）: ドラッグで通った範囲を足していき、離したときに 1 回の取り消しにまとめます。範囲の種類はバケツと同じ（「近い色」を除く）です。重なった UV での扱いは [GUIDE_3D.md](GUIDE_3D.md) にあります。
- ポインタの下の範囲は、3D では面で、2D では UV の輪郭で強調されます。
- **グラデーション**（`Shift+G`）: 2D のキャンバスか 3D ビューをドラッグして、始点（描画色）から終点（透明か、サブの色）へ、「線形」か「放射」で塗ります。選んだレイヤーの描くチャンネルに、マスクを描いているときはマスクに塗ります（「白（見せる）」「黒（隠す）」）。「プロパティ」の「マテリアル」のタブで「複数のチャンネルを一度に塗る」を入れているときは、組の全部のチャンネルに塗り、「2 つのマテリアルの間」で終点を別のマテリアルにもできます（[GUIDE_FILL.md](GUIDE_FILL.md)）。3D ビューでは、見えている面の画素を、その画素が画面に写る所の色で塗ります（[GUIDE_3D.md](GUIDE_3D.md)）。

## 色を選ぶ・取る

- **色を決める**: ツールバー下端のメインの色とサブの色、または「カラー」のパネルで決めます。「カラー」は、色相の円か、四角と色相の帯（右上のボタンで切り替え）、16 進（`#RRGGBB`）、アルファです。`X` でメインとサブを入れ替え、`D` で初期設定の色に戻します。
- **色のウィンドウ**: 塗りつぶしレイヤーの色、lilToon の色、グラデーションの色などの見本を押すと、色のウィンドウが開きます。色相の円、16 進、不透明度、カラーセットの色から、その場で当てられます。「描画色を入れる」で今の描画色を入れます。外を押しても閉じないので、ほかの欄を触りながら色を変えられます。`Esc` で、開いたときの色に戻して閉じます。
- **カラーセット**: 「カラーセット」のパネルで、色のセットを使います（新規・複製・名前の変更・削除、GPL と ACO の読み込み、GIMP パレットの書き出し）。色を押すとメインの色、`Alt` を押しながらだとサブの色になります。「履歴」と、四隅の色の「中間色」も並びます。
- **スポイト**（`I`）: 2D のキャンバスと 3D ビューの押した所の値を、描くチャンネルの描画色に取ります。取っている間は、ポインタにスポイトの絵と輪（上半分が今の色、下半分がポインタの下の色。スカラーのチャンネルは灰色の濃さ）が出ます。選んだレイヤーだけを見ます。オプションバーの「全レイヤーを対象」を入れると、全レイヤーの合成から取ります。「複数のチャンネルを一度に塗る」を入れているときは、標準の 6 つのチャンネルの値をブラシのマテリアルの値に取ります。
- **画面の色**（Windows のみ）: 「編集」メニューの「画面の色を取得」（`Ctrl+Alt+I`）と「ウィンドウを隠して画面の色を取得」（`Ctrl+Alt+Shift+I`）で、デスクトップの色を取ります。

## ステンシルを通して塗る

画面に半透明で重ねた画像を通して、2D のキャンバスにも 3D ビューにも塗れます。効果のブラシ（ぼかし・指先・クローン）にも効きます。設定は、「プロパティ」の「ステンシル」のタブにあります。

- 「画像」: 「画像を読む…」で PNG を読みます（PNG をここへ落としても読めます）。「ステンシルを外す」で使わなくなります。
- 「読み方」: 「量（マスク）」は、画像の明るさが塗りを通す量（白は塗り、黒と透明は止める）。「色」は、画像の色で塗ります。「自動」は、灰色の画像なら量、それ以外は色です。「反転」は量のときに効きます。
- 繰り返し（「繰り返さない」「横に繰り返す」「縦に繰り返す」「縦横に繰り返す」）、「重ねの不透明度」、「大きさ」、「角度」。
- `Y` を押したまま、左ドラッグで回し（`Shift` で 15° 刻み）、中ボタンか `Ctrl` ＋左ドラッグで動かし、右ドラッグか `Alt` ＋左ドラッグで大きさを変えます（2D・3D とも）。「置き場を戻す」で戻します。置き場は画面に貼り付きます。`N` を押しているあいだは、ステンシルを使いません。

ステンシルはアプリの状態で、`.ylp` にもブラシのプリセットにも保存しません。

## 文字を入れる

テキスト（`T`）は、2D のキャンバスを押した所から文字を打ちます。最初の 1 文字でテキストレイヤーが追加されます。`Enter` で改行し、`Esc` で打ち終わります。箱の外を押すと、打ち終わって、その場所から新しい文字を打てます。かな漢字の変換も使えます。打った分は 1 回の取り消しで戻り、文字が残らなければレイヤーは残りません。

- **打ち直す**: テキストレイヤーを選んで箱の中を押すか、移動・変形ツール（`V`）で箱をダブルクリックします。
- **あとから変える**: 「フォント」「サイズ」「色」「行間」「字間」「揃え」（左・中央・右）「折り返しの幅」を、ツールプロパティ・オプションバー・レイヤーのプロパティの「テキスト」で直せます。フォントは、同梱の「BIZ UDPゴシック」（標準と太字）、「インストール済みのフォント」、「ファイルから…」（`.ttf`・`.otf`・`.ttc`）から選びます。
- **文字の色**: ツールプロパティの「テキストの色」で、色の元を選びます。「描画色」（はじめの設定）は、新しい文字を描画色で作り、テキストのツールを使っている間に、テキストレイヤーを選んでいる・打っているテキストの色を、描画色を変えるたびに同じ色にします（色の円のドラッグは 1 回の取り消しです）。ブラシなどほかのツールで描画色を選んでも、選んだままのテキストの色は変わりません。ロックしたレイヤーは変えません。このときの「色」の欄は描画色を見せ、押すと描画色の色のウィンドウが開きます。「ツールの色」は、欄の色で新しい文字を作り、欄の色を変えるとテキストの色も変わります（描画色には追従しません）。色の元の選びは、アプリを開いている間だけ覚えます。テキストは 1 つのレイヤーに 1 色で、文字ごとの色は付けられません。レイヤーのプロパティの「テキスト」の色の欄は、そのレイヤーだけの色を見せて変えます。
- **移動・変形**: テキストレイヤーの位置・回転・サイズが変わります。反転、縦横の比を変える拡大、傾け、選択範囲の中だけの変形はできません。
- **ラスタライズ**: 手で描けるレイヤーにするには、「レイヤー」メニューか右クリックの「テキストをラスタライズ」で、今の画素を残してテキストの値を外します。描くのは Color のチャンネルです。
- **フォントは `.ylp` に入りません**。場所・名前・中身の SHA-256 だけを覚えます。開いたときに見つからないフォントのレイヤーは、描いた画素のまま見せ、打ち直しを断ります。中身の違う同名のフォントが見つかったときは知らせ、打ち直すとそのフォントで描き直します。

テキストレイヤーのある文書は、0.4.x では開けません。PSD へは画素のレイヤーとして書き出します。形式は [YLP_FORMAT.md](YLP_FORMAT.md) にあります。
