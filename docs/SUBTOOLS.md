# サブツールとツールプロパティ

左のドックの先頭のタブ「サブツール」（英語の表示は Tools）は、今選んでいる道具のサブツールの一覧・設定・ブラシサイズを 1 か所に出します。道具を替えると中身が替わります。
右の「プロパティ」には道具の設定を出さず、選んでいる層（ペイントの層・マスク・塗りつぶし・調整・効果の行）の中身だけを出します。上のオプションバーは、その道具でよく使う
2〜3 個の項目だけで、ツールプロパティと同じ値を見せます（別の値を持ちません）。

## 構成

上から次の順に並びます。

1. **サブツールの一覧**: 道具ごとの一覧です（下の表）。行を押すとそのサブツールの設定が今の設定になります。選んでいる行が青く、設定を変えたままにしている行には
   「変更あり」の印が付きます。
2. **ツールプロパティ**: 今の道具の設定の全部です。オプションバーと同じ値の欄も、ここにあります。
3. **ブラシサイズ**: 決まった直径の丸です。大きさを持つ道具（ブラシ・消しゴム・選択ペン）のときだけ出ます。

窓が小さいときは、パネルの全体がスクロールします。

## 道具ごとのサブツール

| 道具 | サブツールの一覧 |
|---|---|
| ブラシ | ブラシの一覧（ペン・筆・エアブラシ・効果・特殊・取り込み。グループのタブ）。消しゴムのグループは出しません |
| 消しゴム | 消しゴムの一覧（ブラシと共有しません）。自分の消しゴムも保存できます |
| バケツ | 近い色・三角形・メッシュの塊・UV アイランド・マテリアル |
| ポリゴン塗りつぶし | 三角形・メッシュの塊・UV アイランド・マテリアル |
| グラデーション | 線形・放射と、終点（透明へ・サブの色へ）の組 |
| 図形 | 直線・長方形・楕円 |
| 定規 | 直線定規・平行線・同心円・パース（1 点）・パース（2 点） |
| スポイト | 選んだレイヤー・全レイヤー |
| 移動・変形 | 通常・自由・遠近・メッシュ |
| ゆがみ | プッシュ・右回転・左回転・縮小・膨張・戻す |
| 選択の道具 | 長方形・楕円形・なげなわ・多角形・自動選択・ID の色で選択・選択ペン（ツールの帯の選択の組と同じ並び。行を押すと道具が替わります） |
| パス | パス（1 つ） |

ブラシと消しゴムの一覧は `.ylbrush` のブラシです。ほかの道具の一覧は、設定の組（バケツなら範囲の種類・許容・隣接・参照・色差・隙間閉じ・領域の拡縮・塗り残し・囲みの最大面積）です。
設定を変えて、別のサブツールの設定とちょうど同じになったときは、選んでいる印がそのサブツールへ移ります。別のサブツールへ替えても、変えたままの設定は覚えていて、戻ると
その設定に戻ります（保存はしません）。

## 自分のサブツール

一覧の下の帯のボタンで、元に戻す・複製・今の設定を新しいサブツールに（＋）・削除ができます。行のダブルクリックで名前を変え、右クリックのメニューから「この設定で登録」
（変えたままの設定を、そのサブツールの基準にする）もできます。組み込みのサブツールは消せず、名前も変えられません。

ブラシと消しゴムは、設定のフォルダの `brushes/` に `.ylbrush` で保存します。ほかの道具は、設定のフォルダの `subtools/` に、道具ごとに 1 ファイル
（`fill.ylsubtool`・`polygon-fill.ylsubtool`・`gradient.ylsubtool`・`shape.ylsubtool`・`ruler.ylsubtool`・`eyedropper.ylsubtool`・`move.ylsubtool`・`liquify.ylsubtool`）で保存します。
利用者のサブツールが 1 つも無くなればファイルを消します。サブツールは `.ylp` には入りません。

### ファイルの形式（`yolupainter-subtools 1`）

1 行目が `yolupainter-subtools 1`、あとは `key=value` の行です（UTF-8、512 KiB まで、空行は読み飛ばします）。

```text
yolupainter-subtools 1
tool=fill
preset.1.name=自分のバケツ
preset.1.by_color=true
preset.1.tolerance=48
```

- `tool` は 2 行目で、ファイルの名前の道具と同じこと。
- `preset.<番号>.name` は名前（40 文字まで）。ほかは道具の欄の名前で、数は Rust の表記のまま、選びは名前（`kind=triangle` など）で書きます。
  書かれていない欄は既定で読むので、欄が増えても古いファイルを読めます。
- 番号は 1 から、サブツールは番号の順に並びます（組み込みが先）。1 つの道具につき 256 個まで（256 個は、どの道具のどんな値でも 1 ファイルの上限に収まります。256 個に達すると、足す・複製する操作は理由を知らせて断ります）。

知らない項目・重なった項目・範囲を外れた値・名前のないサブツール・別の道具のファイル・多すぎるサブツールは、そのファイルだけを読み飛ばし、起動のときに状態の帯で知らせます
（ほかの道具のファイルは読みます）。版が新しいファイルは触らずに読み飛ばします。読めなかったファイルのある道具では、そのファイルを壊さないよう、サブツールの追加・複製・
削除・名前の変更・登録を断ります。書き込みは、一時ファイルに書いて読み戻して確かめてから、最後の 1 回の置換で確定します（途中で落ちても前の版が残ります）。

この形式のファイルは、スタンドアロンの Rust 版だけが使います（`.ylp` には入らないので、Unity 版（0.2.0 など）の読み書きには関わりません）。

## 道具の登録とキー

道具の名前・キー・サブツールの種類・ツールプロパティ・オプションバー・キャンバスと 3D ビューの入力は、`crates/yolu-app/src/tools/` の道具の表（`TOOLS`）が持ちます。
キーボードの割り当て・マウスと修飾キーの組み合わせ・ビューの中のキーは `crates/yolu-app/src/keymap.rs` の表が持ち、キーの処理もヘルプの「ショートカット」の窓も同じ表を読みます。
