# サブツールとツールプロパティ

左のドックの上には、今選んでいるツールのサブツールの一覧・設定・ブラシサイズが、縦に並ぶ 3 つのパネルに分かれて出ます。ツールを替えると中身が替わります。
3 つのパネルは別のタブなので、ほかのパネルと同じに、ドラッグして並べ替えたり、別ウィンドウへ出したり、「ウィンドウ」のメニューで開いたりできます。
右の「プロパティ」にはツールの設定を出さず、選んでいるレイヤー（ペイントのレイヤー・マスク・塗りつぶし・調整・効果の行）の中身だけを出します。上のオプションバーは、そのツールでよく使う
2〜3 個の項目だけで、ツールプロパティと同じ値を見せます（別の値を持ちません）。

## 構成

初めの並びでは、上から次の順に並びます。

1. **サブツール**（パネル）: ツールごとの一覧です（下の表）。行を押すとそのサブツールの設定が今の設定になります。選んでいる行が青く、設定を変えたままにしている行には
   「変更あり」の印が付きます。
2. **ツールプロパティ**（パネル）: 今のツールの設定の全部です。オプションバーと同じ値の欄も、ここにあります。ブラシ・消しゴム・バケツ・ポリゴン塗りつぶし・グラデーション・図形・
   パス・スポイトには、終わりに「塗るチャンネル」の区分があり（複数のチャンネルを一度に塗る設定。初めは閉じています）、マスクに描いているあいだは、その区分がレイヤーマスクの欄に替わります。
3. **ブラシサイズ**（パネル）: 決まった直径の丸です。大きさを持つツール（ブラシ・消しゴム・選択ペン）のときだけ丸が出ます。

パネルの中身が入りきらないときは、そのパネルの中だけがスクロールします（一覧は一覧の中で、ツールプロパティはパネルの中で）。

## ツールごとのサブツール

| ツール | サブツールの一覧 |
|---|---|
| ブラシ | ブラシのグループ（タブ。はじめはペン・筆・エアブラシ・効果・特殊、取り込むと取り込み）。グループとその中のブラシは、ツールごとに自分で並べられます（下の「ツールの並び」） |
| 消しゴム | 消しゴムのグループ（ブラシと共有しません）。並べ方はブラシと同じです |
| バケツ | 近い色・三角形・メッシュの塊・UV アイランド・マテリアル |
| ポリゴン塗りつぶし | 三角形・メッシュの塊・UV アイランド・マテリアル |
| グラデーション | 線形・放射と、終点（透明へ・サブの色へ）の組 |
| 図形 | 直線・長方形・楕円 |
| 定規 | 直線定規・平行線・同心円・パース（1 点）・パース（2 点）・対称定規（線対称 2 本）・回転対称（6 本） |
| スポイト | 選んだレイヤー・全レイヤー |
| 移動・変形 | 通常・自由・遠近・メッシュ |
| ゆがみ | プッシュ・右回転・左回転・縮小・膨張・戻す |
| 選択ツール | 長方形・楕円形・なげなわ・多角形・自動選択・ID の色で選択・選択ペン（ツールの帯の選択の組と同じ並び。行を押すとツールが替わります） |
| パス | パス（1 つ） |

ブラシと消しゴムの一覧は `.ylbrush` のブラシです。ほかのツールの一覧は、設定の組（バケツなら範囲の種類・許容・隣接・参照・色差・隙間閉じ・領域の拡縮・塗り残し・囲みの最大面積・対称定規にスナップ）です。
設定を変えて、別のサブツールの設定とちょうど同じになったときは、選んでいる印がそのサブツールへ移ります。別のサブツールへ替えても、変えたままの設定は覚えていて、戻ると
その設定に戻ります（保存はしません）。

## 自分のサブツール

一覧の下の帯のボタンで、元に戻す・複製・今の設定を新しいサブツールに（＋）・削除ができます。行のダブルクリックで名前を変え、右クリックのメニューから「この設定で登録」
（変えたままの設定を、そのサブツールの基準にする）もできます。組み込みのサブツールは消せず、名前も変えられません（ブラシと消しゴムは、下の「ツールの並び」のとおり、並びから外せます）。

ブラシと消しゴムは、設定のフォルダの `brushes/` に `.ylbrush` で保存します。ほかのツールは、設定のフォルダの `subtools/` に、ツールごとに 1 ファイル
（`fill.ylsubtool`・`polygon-fill.ylsubtool`・`gradient.ylsubtool`・`shape.ylsubtool`・`ruler.ylsubtool`・`eyedropper.ylsubtool`・`move.ylsubtool`・`liquify.ylsubtool`）で保存します。
利用者のサブツールが 1 つも無くなればファイルを消します。サブツールは `.ylp` には入りません。

### ファイルの形式（`yolupainter-subtools 1`）

1 行目が `yolupainter-subtools 1`、あとは `key=value` の行です（UTF-8、512 KiB まで、空行は読み飛ばします）。

```text
yolupainter-subtools 1
tool=fill
preset.1.name=自分のバケツ
preset.1.by_color=true
preset.1.tolerance=48
```

- `tool` は 2 行目で、ファイルの名前のツールと同じこと。
- `preset.<番号>.name` は名前（40 文字まで）。ほかはツールの欄の名前で、数は Rust の表記のまま、選びは名前（`kind=triangle` など）で書きます。
  書かれていない欄は既定で読むので、欄が増えても古いファイルを読めます。
- 番号は 1 から、サブツールは番号の順に並びます（組み込みが先）。1 つのツールにつき 256 個まで（256 個は、どのツールのどんな値でも 1 ファイルの上限に収まります。256 個に達すると、追加・複製する操作は理由を知らせて断ります）。

知らない項目・重なった項目・範囲を外れた値・名前のないサブツール・別のツールのファイル・多すぎるサブツールは、そのファイルだけを読み飛ばし、起動のときに知らせます
（ほかのツールのファイルは読みます）。版が新しいファイルは触らずに読み飛ばします。読めなかったファイルのあるツールでは、そのファイルを壊さないよう、サブツールの追加・複製・
削除・名前の変更・登録を断ります。バケツの「対称定規にスナップ」（`snap_symmetry`）は 0.6.0 で増えた欄で、欄の無い古いファイルは入として読みます。0.6.0 が書いたバケツのファイルは、0.5.x では知らない項目として読み飛ばされます。書き込みは、一時ファイルに書いて読み戻して確かめてから、最後の 1 回の置換で確定します（途中で落ちても前の版が残ります）。

この形式のファイルは、スタンドアロンだけが使います（`.ylp` には入らないので、0.4.x までの Unity 版の読み書きには関わりません）。

## ツールの並び

左のツールバー（ツールの順・区切り・名前・アイコン）と、ブラシ・消しゴムのツールが持つグループ（グループの順・名前・中のブラシの順）は、
自分で並べ替えられます。並びは設定のフォルダの `tools.json` に保存し、`.ylp` には入りません。並びの操作は文書の編集ではないので、取り消しの段には入りません
（サブツールと同じです）。

- **ツールバー**: 右クリックで「ツールを追加 ▸ ブラシ／消しゴム」（列から外した組み込みのツールがあれば、その下に）・「名前を変更」・「アイコンを変更」
  （許諾つきのアイコンの組から選んだ 29 個）・「前に区切り」・「このツールを削除」・「最初の並びに戻す…」。ドラッグで並べ替えます（`Esc` でやめます）。
  ブラシと消しゴムのツールはいくつでも置け、それぞれが自分のグループを持ちます（好きなブラシの組を 1 つのツールにできます）。ほかの組み込みのツールは
  列に 1 つまでで、列から外してもキーとメニューからは使えます。ブラシと消しゴムのツールは、それぞれ最後の 1 つを削除できません。キーの `B`・`E` は、
  今のツールが同じ種類ならそのまま、ほかは列の最初の 1 つへ替えます。
- **グループのタブ**: 「＋」でグループを追加、ダブルクリックで名前の変更、右クリックで追加・名前の変更・複製・削除。ドラッグでタブを並べ替え、
  ツールバーのブラシ・消しゴムのツールの上で離すと、そのツールへ動かします（中のブラシも一緒に。消すかどうかは、動かした先のツールが決めます）。
- **ブラシの行**: ドラッグで並べ替え、タブやツールの上で離すと別のグループへ動かします。`Ctrl` を押したまま離すと写しを置きます。右クリックの「複製」で写しを作り、「削除」で並びから外します。
- **ブラシを追加**（一覧の下の帯の「＋」）: 種類（組み込み・同梱の Krita・Photoshop・CLIP STUDIO・そのほかの取り込み・自分のブラシ）ごとの一覧と
  名前の検索のウィンドウを開きます。行を押して複数を選び、「追加」で今のグループの後ろへ置きます。
- **削除**（ツール・グループ・ブラシ）は並びから外すだけです。ブラシのファイルは残り、「ブラシを追加」のウィンドウの自分のブラシ・取り込みの種類から戻せます。
  ファイルを消すのは、そのウィンドウの右クリックの「ファイルを削除…」だけです（取り消せないので確かめます）。
- **最初の並びに戻す**（確かめてから）: 組み込みのツール・グループ・ブラシを最初の並びにし、自分のブラシは各ファイルの元のグループ（`.ylbrush` の `group=`）の
  後ろへ並べ直します。ファイルは消しません。ツールとグループの名前・並びは戻せません。
- **取り込み**（ABR・CLIP STUDIO ほか）: 今のブラシのツール（今のツールがブラシでなければ、今のブラシがあるブラシのツール）の「取り込み」のグループ
  （空きのある最初の物。無ければそのツールの最後に作り、いっぱいなら次を作ります）の後ろへ置きます。消しゴムのツールの中の「取り込み」のグループには置きません。
  取り込んだブラシを全部外しても、タブは残ります。
- **上限**: ツールは 64 個、グループはツールごとに 64 個、1 つのグループのブラシは 512 個まで。超える操作は理由を知らせて断ります。
  最初の並び・「最初の並びに戻す」・古いアプリが追加したファイルを並べるときに 1 つのグループへ入りきらなければ、同じ組み込みのグループを次に作って続きを入れます。
  グループも上限なら並びには置かず（ファイルは残ります）、「ブラシを追加」のウィンドウから置けます。

### 並びのブラシは写し

並びのブラシは、1 つにつき 1 つの `.ylbrush` です。組み込みのブラシは、設定を登録する・名前を変えるまでは組み込みを指したまま（`b:<id>`）で、
同じ組み込みは並び全体で 1 か所だけです。2 つ目を置く（複製・`Ctrl` で写す・「ブラシを追加」でもう一度置く）と、写しのファイルを作ります。
写しを変えても元は変わらず、元のブラシ（組み込み・同梱の Krita・取り込んだファイル）を変えても並びの写しは変わりません。並びに無い自分のブラシ
（外した物）を「ブラシを追加」で置くときは、写さずにそのファイルをそのまま置きます（外して置き直すたびにファイルが増えないように）。
同梱の Krita のブラシを置くと写しのファイルができ、以後は自分のブラシの種類に出ます。

### ファイルの形式（`tools.json`）

設定のフォルダの直下（`brushes/` の隣）の JSON（UTF-8、1 MiB まで）です。

```json
{
  "format": "yolupainter-tools",
  "version": 1,
  "known_tools": ["brush", "eraser", "fill", "…"],
  "known_brushes": ["standard", "hard-round", "…"],
  "user_brushes_through": 12,
  "tools": [
    { "tool": "brush", "groups": [
        { "group": "pen", "brushes": ["b:standard", "u:3"] },
        { "name": "インク", "brushes": ["u:7"] } ] },
    { "tool": "eraser", "groups": [ { "group": "eraser", "brushes": ["b:standard-eraser"] } ] },
    { "tool": "fill" },
    { "tool": "select-rectangle", "gap": true },
    { "tool": "brush", "name": "水彩", "icon": "paint-brush", "groups": [ { "name": "グループ", "brushes": [] } ] }
  ]
}
```

- `tools` はツールバーの上からの順です。`tool` はツールの表の id、`name` が無ければツールの表の名前（言語で替わります）、`icon` は選べるアイコンの名前、
  `gap` はそのツールの前の区切りです。
- `groups` はブラシと消しゴムのツールだけが持ちます。`group`（組み込みのグループの id）があって `name` が無ければ、組み込みの名前（言語で替わります）。
- `brushes` の `b:<id>` は組み込みのブラシ、`u:<番号>` は設定のフォルダの `brushes/brush-<番号>.ylbrush` です。
- `known_tools`・`known_brushes` は、書いたときに知っていた組み込みのツールとブラシです。読んだとき、ここに無い組み込み（新しい版で増えた物）は、
  ツールは列の最後へ、ブラシはその組み込みのグループの最後へ追加します。利用者が外した物は known にあるので戻りません。
- `user_brushes_through` は、書いたときにあった利用者のブラシのファイルの番号の最大です。並びに無いファイルのうち、これより大きい番号の物
  （古いアプリが追加した物・並びを書く前に落ちたときの物）は、ファイルの元のグループ（`group=`）へ追加します。これ以下の番号の物は、利用者が外した物として出しません。

読めない所（JSON でない・形が違う・上限を超える・同じブラシや同じツールが 2 か所・グループを持てないツールにグループ・ブラシか消しゴムのツールが無い）が
あれば、ファイル全体を読めないとし、最初の並びにして知らせます。元のファイルは同じフォルダの `tools.broken.json`（あれば `tools.broken-2.json` …）へ退避します。
退避できないときは、並びを保存しません（元のファイルを上書きしません）。知らないツールの id は、その項目だけを飛ばします。
知らない組み込みのブラシと、フォルダにあるのに読めなかったブラシのファイル（壊れた・新しい版・同期の途中など）の札は、画面には出さずに覚えておき、
並びを書き直すときも元のグループの元の場所へ書き戻します（読めるようになった起動で、元の場所に出ます）。そのグループの札の上限（512）には、覚えている札も数えます。
フォルダに無いファイルの札は覚えず、書き直すと消えます。「最初の並びに戻す」は並べ直すので、覚えた札も戻りません。
並びに書かれていなかった読めないファイルは、読めるようになっても並びには出ず、「ブラシを追加」のウィンドウの自分のブラシから置けます。
版が新しいファイルは触らずに最初の並びで使い、並びを変える操作（並びに置く取り込みも）を理由つきで断ります。
書き込みは、一時ファイルに書いて読み戻して確かめてから、最後の 1 回の置換で確定します。

`tools.json` が無いとき（この並びを持たない版から上げたとき）は、今までのブラシの並び（`brushes/order.conf`）と各ファイルの `group=` から、前と同じ並びを作ります。
`order.conf` はもう書きません（消しもしません）。並びを持たない古いアプリ（0.4.x まで）は `tools.json` を読まず、今までどおり `order.conf` と `group=` で並べるので、
並びから外したブラシや写しも、古いアプリでは元のグループに出ます。この形式のファイルはスタンドアロンだけが使い、0.4.x までの Unity 版の読み書きには関わりません。
