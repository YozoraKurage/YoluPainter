# 保存・書き出し・取り込み

[English](en/GUIDE_FILES.md)

プロジェクト（`.ylp`）の保存、配布用の写し、落ちたときの復旧、PNG と PSD の書き出し・取り込み、大きな文書のためのディスクキャッシュの頁です。新規作成と開く操作は [GUIDE_START.md](GUIDE_START.md) にあります。

## プロジェクトを保存する

「ファイル」の「保存」（`Ctrl+S`）と「別名で保存…」（`Ctrl+Shift+S`）で `.ylp` に保存します。保存先の名前は `.ylp` で終わる必要があり（大文字小文字は問いません）、フォルダがなければ作ります。

- 保存は別のスレッドで進み、右下の札に「保存しています」と進み具合が出ます（取り消しはありません）。保存の間も描けて見られますが、そのあとに描いた分はその保存に入らず、終わったあとも「変更あり」のままです。
- 保存の間は、もう 1 度の保存・開く・新規・配布用に保存は、理由を出して断ります。保存の途中でウィンドウを閉じると、保存が終わるのを待ち、その結果のあとで（保存していない変更が残っていれば確かめてから）閉じます。
- 保存できなかったときは、何も変えずに理由を出します。保存は検証した一時ファイルからの 1 回の置き換えで確定するので、途中で失敗しても元のファイルは前のままです。開いたあとに別のアプリがファイルの中身を書き換えていたときは、上書きを断ります（更新時刻が変わっただけなら書き換えとは見なしません）。同じファイルを 2 つのアプリで同時に編集せず、保存してからもう一方で開き直してください。
- 上書きの前の版は、同じフォルダの `<ファイル名>-backups~/` に新しい順に残ります。残す数は、「編集」→「設定…」の「ファイル」の区分の「退避を残す数」（0〜1000。0 は残しません）で選び、超えた古い版だけを消します。「すべて残す」を入れると消しません（はじめの設定です）。退避の `.ylp` を開くと、保存先のない文書として開き（開いた退避は書き換えません）、「保存」は「別名で保存」になります。モデルのファイルは元の `.ylp` のあるフォルダから探します。

## 配布用に保存する

「ファイル」の「配布用に保存…」は、開いているプロジェクトの写しから、作った人が気づかないまま `.ylp` に残る物を除いて、別のファイルに書きます。除ける物（PSD の原本・使っていないアセット・素材の出どころのパス・モデルの参照・メッシュマップ・Unity のマテリアルの値・覚えた選択範囲など）はウィンドウに種類ごとに並び、切り替えを外すと残せます。作業用のファイルは変わりません。除く物と互換の詳細は [SAVE_FOR_DISTRIBUTION.md](SAVE_FOR_DISTRIBUTION.md) にあります。

## 落ちても失わない

保存していない変更があるあいだ、アプリが裏で復旧用の世代を書き置きます。次のときに書きます。

- 変更を見つけてから一定の時間（はじめは 15 秒。連続して描いているときは前の書き置きから）
- 終わったストロークがたまったとき（はじめは 10 本）
- フォーカスを失ったとき、終わるとき

描いている最中と PSD の取り込みの途中は取らず、描き終えてからです。書き置きの失敗は理由を知らせるだけで、描くのは止めません。世代は `.ylp` と同じ形で、合成の PNG とメッシュマップは入れません。

落ちた次の起動で「復旧」のウィンドウが開きます（「ファイル」の「復旧…」からいつでも開けます）。世代の一覧（元の名前・セットの数・経過時間）から、「開く」か「捨てる」を選びます。開いたものは「名称未設定（復旧）」で、元の `.ylp` には書きません。保存先は保存のときに選びます。

ウィンドウでは、書き置きの間隔（10 秒〜5 分）、残す世代（2〜20）、使う量（自動・少なめ・標準・多め。「詳しく」で GB の指定）を選べます。復旧が使うディスクの量には上限があり、超えたぶんは古い世代から消えます。空きが少ないときは書き置きを見送ります（[RECOVERY.md](RECOVERY.md)）。

## PNG に書き出す

「ファイル」の「テクスチャを書き出す…」で、「テクスチャを書き出す」ウィンドウを開きます。左の一覧で書き出すテクスチャセットにチェックを入れ、右で「出力先」「出力テンプレート」「パディング」を決め、「書き出すファイル」の一覧で書く名前を確かめて「書き出す」を押します。書き始めるとウィンドウは閉じます。選んだ出力テンプレートは設定に残り、次に開いたときも同じです。

- **テクスチャセット**: 書き出せるセットが並び、はじめは全部チェックが入っています。外したセットは書き出しません。チェックはプロジェクトを替えるまで覚えていて、セットを追加するとチェックが入り、名前を変えれば一覧の名前も替わります。読むだけのセットは書き出せないので、錠の印が付いて、チェックが外れたまま触れません。1 つもチェックが無いと「書き出す」は押せません。出力テンプレートが「今のチャンネル」のときは、今のセットだけが並び、外せません。
- **出力先**: 「今のチャンネル」ではファイル、ほかのテンプレートではフォルダで、「選ぶ…」で替えます。選ぶまでの既定は、開いているプロジェクトのフォルダです（Live Link で開いたモデルでは、Unity が知らせたフォルダ）。選んだ先は、別のプロジェクトを開くまで覚えています。出力先が決まっていない間と、書き出しが動いている間は、「書き出す」を押せません。
- **出力テンプレート**: 「今のチャンネル」「チャンネルごと」「Unity Standard / URP Lit」「HDRP Lit」「lilToon」から選びます。
- **パディング**: UV の外へ色を塗り広げる幅で、「なし」「n px 広げる」「無限に広げる」から選びます。設定の「書き出しのパディング」と同じ値です（どちらで替えても同じ）。モデルが無いと塗り広げません。
- **書き出すファイル**: 今の出力テンプレート・チェックしたセット・出力先で、書くファイルの名前と色空間（sRGB かリニア）を、書く前に並べます。書き出しと同じ決め方の名前です。出力先にもうあるファイルには、名前の左に点が付きます。書けない理由（書くものが無い、同じファイルになる名前があるなど）があれば、一覧の代わりにその理由を出します。

もうあるファイルは、置き換える前に確かめます（やめるとウィンドウに戻ります）。取り消したときと、最後の置き換えを始める前の失敗では、元のファイルを変えません。

### テンプレートで書き出す

「Unity Standard / URP Lit」「HDRP Lit」「lilToon」は、そのシェーダーが読む詰め合わせの PNG を、チェックしたテクスチャセットぶん、選んだフォルダへ書きます。名前は `<名前>[_<セット名>]_<画像>.png` で、セット名はセットが複数のときだけ付きます（チェックを外しても、ほかのセットの名前は変わりません）。

- 焼いた AO があれば使い、古い AO は使いません。
- 画面と同じ効果（フィルター・メッシュマップを読むジェネレーター・アセットの画像）が入ります。読むマップが無いなどで効いていない効果が残るときは、書き出した画像に入っていないことを知らせます。
- 読むだけのセットは書き出しません。
- Live Link で開いたモデルでは、出力先の既定は Unity が知らせたフォルダです。

### チャンネルごとに書き出す

「今のチャンネル」は描くチャンネルを 1 枚の PNG に、「チャンネルごと」はチェックしたテクスチャセットの使っている全チャンネルをフォルダに書きます。値はチャンネルの合成そのまま（詰めず、色も掛けません）で、Normal だけは Normal の設定のファイルの Y の向きです。名前は `<名前>[_<セット名>]_<チャンネル>.png` です。

## PSD を読み込む

「ファイル」の「インポート」の「PSD を新しいテクスチャセットに…」か「PSD を今のテクスチャセットに…」で、PSD（RGB 8 bit）を取り込みます。ウィンドウに .psd を落としても、新しいテクスチャセットとして同じ流れで取り込みます（複数を落としたときは最初の 1 つだけです）。

- PSD は、元のファイルへ書き戻さない写しとして取り込みます。ラスター・グループ・単色の塗りつぶし・調整（反転・レベル補正・色相/彩度・グラデーションマップ・トーンカーブ・カラーバランス・明るさ/コントラスト・2 値化・ポスタリゼーション）・マスク・クリッピングは、レイヤーになります。レイヤーのロックも戻ります。
- レイヤー効果・スマートオブジェクト・テキスト・未対応の調整など、落とす物や見え方が変わる物があるときは、取り込む前に「PSD の取り込みの確かめ」のウィンドウに、レイヤーの名前つきで並びます。「取り込む」を押すまで何も入れません。
- PSB・RGB 8 bit 以外・予算を超える PSD は、理由を出して何も変えません。大きさの上限は設定の「レイヤーのメモリ」の予算から決まります。
- 取り込んだ文書の合成を PSD の統合画像と照らし、差が大きければウィンドウに出します。

扱いの仕分けと上限は [PSD.md](PSD.md) にあります。

## PSD に書き出す

「ファイル」の「PSD を書き出す…」で「PSD の書き出し」のウィンドウを開き、方式とチャンネルを選んで「書き出し…」を押します。

- 方式は「焼き込んで書く」（レイヤーを残し、PSD に形の無いフィルター・ジェネレーター・画像・パスなどは、評価した画素にして書く）か、「平らに 1 枚」（合成した絵だけを 1 枚のレイヤーに書く）です。
- チャンネルは、はじめ Color だけです。複数を選ぶと、チャンネルごとに `名前_チャンネル.psd` を書きます。
- 焼く・丸める・落とすものがあるときは、書く前に「PSD の書き出しの確かめ」のウィンドウが、それをレイヤーの名前つきで並べます。「書く」を押すまで何も書きません。
- 書き出しは文書の写しで、文書は変わりません。効果は文書に残りますが、焼いたレイヤーは効果の設定を持たないので、PSD を取り込み直しても効果は戻りません。

Photoshop や CLIP STUDIO PAINT で開くと、調整レイヤーが再評価されて見た目が変わることがあります。書き方と上限は [PSD.md](PSD.md) にあります。

## PNG を取り込む

PNG のファイルを取り込めるのは、次の所です。

- ステンシル（プロパティの「ステンシル」タブ）
- アセットの画像: 塗りつぶしレイヤーの画像の一覧の「ファイルから取り込む…」や、ライブラリの「プロジェクトで使う」で入ります。塗りつぶし・画像のジェネレーター・パスのリボンが使います（[GUIDE_FILL.md](GUIDE_FILL.md)）
- ライブラリ: 「ライブラリへファイルを追加…」か、格子へのドロップ

スマートマテリアルの `.ylsmart` は、アセットとライブラリに読み込めます。

## 大きな文書を扱う

設定の「ディスクキャッシュ」（はじめは入）は、「レイヤーのメモリ」と「取り消し履歴」の予算の合計を超えたタイルを、使っていないものから、キャッシュのファイルへ逃がして、続けて描けるようにします。切ると、予算を超える操作は断ります。

「詳しく」を開くと、使ってよい量の「キャッシュの上限」（自動は 64 GiB と、置き場所の空きの半分の小さいほう）と、「キャッシュの場所」（はじめは OS の一時フォルダ。速いドライブほど戻すのが速い）を決められます。上限まで使い切ると、超える操作は断り、取り消しの古い段は捨てます。

- タイルは圧縮せず書くので、ディスクを使う量は文書の画素の量までです。前の実行が残したキャッシュのファイルは、起動のときに裏で消します。
- ディスクから読めないタイルが出たら、そのテクスチャセットは読み取り専用になり、知らせます。保存は開いたときの中身のまま書きます。保存したことの無いセットは、元の中身が無いので、そのセットだけ保存と復旧の書き置きに入りません。

## ファイルを選ぶウィンドウの始まりの場所

ファイルやフォルダを選ぶウィンドウは、次の順で最初に見つかる、今ある場所から始まります。

- **開く・取り込み・書き出し**: その種類（プロジェクト・モデル・PSD の読み込みと書き出し・画像の取り込みと書き出し・ブラシ・フォント・キーの設定・アセットとライブラリ・カラーセット・配布用に保存・設定の置き場）で前に選んだフォルダ → 今のプロジェクトの `.ylp` のあるフォルダ → OS の書類のフォルダ。
- **保存・別名で保存**: 退避の `.ylp` を開いた文書は、元の `.ylp` のフォルダ → 今のプロジェクトの `.ylp` のあるフォルダ → プロジェクトで前に選んだフォルダ → OS の書類のフォルダ。

前に選んだフォルダは、設定のフォルダの `places.conf` に種類ごとに残ります（消しても、次に選んだときから覚え直します）。無くなったフォルダは使いません。「テクスチャを書き出す」ウィンドウから選ぶときは、出力先がもう決まっていれば（選んだ先、なければ Live Link で開いたモデルでは Unity が知らせたフォルダ、なければプロジェクトのフォルダ）、その場所が先です。保存していない文書のように決まっていないときだけ、上の順で始まります。

## 古い版や Unity 版へ渡す

次の機能を使った `.ylp` は、新しい版の番号で保存され、0.4.x のスタンドアロンと 0.4.x までの Unity 版では開けません（Unity ブリッジは 0.5.0 から `.ylp` を開きません）。

- テキストレイヤー
- 2 本以上のパス・パスの種類・筆先・対称・角や取っ手・塗りつぶしレイヤーのパス（[GUIDE_PATHS.md](GUIDE_PATHS.md)）
- 点のグラデーション、異方性フィルターを切った画像、0.5.0 の効果、「UV の継ぎ目をまたぐ」を切った設定（[GUIDE_FILL.md](GUIDE_FILL.md)）
- ベイクの優先を既定から変えた設定（[GUIDE_3D.md](GUIDE_3D.md)）

使っていない文書は、今までの版のままです。0.4.x までの Unity 版へ戻すときは、その機能を消してから保存し直してください。

パスのブラシのアンチエイリアスが「なし」でないパス（新しく作るパスは今のブラシの段を取り、既定は「中」です。[BRUSH.md](BRUSH.md)）、定規（レイヤーやグループに付けた定規。対称定規も）、斜めの線対称・6 本以上の線対称のパス（[GUIDE_PAINT.md](GUIDE_PAINT.md)）のどれかを使った `.ylp` は、0.5.x までのスタンドアロンでも開けません（版の数だけで、ファイルに触れずに断ります）。パスのアンチエイリアスは、パスごとに「なし」にして保存し直すと、前の版のままになります。パスの対称を切るか、縦か横の向きの 2 本・4 本の対称定規で入れ直してから、定規を全部消して保存し直すと、開けます。どの版がどこまで読めるかは [UNITY.md](UNITY.md) と [YLP_FORMAT.md](YLP_FORMAT.md) にあります。
