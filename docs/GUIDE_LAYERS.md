# レイヤーとチャンネル

[English](en/GUIDE_LAYERS.md)

レイヤーの作り方と整え方、マスク、調整レイヤー、チャンネルの使い方です。塗りつぶしレイヤーと、レイヤーに付ける効果（フィルター・ジェネレーター）は [GUIDE_FILL.md](GUIDE_FILL.md) にあります。

## レイヤーを作る・並べる

「レイヤー」のパネルの下の帯のボタンか、メニューバーの「レイヤー」で作ります。同じ項目は、レイヤーの右クリックと一覧の空白の右クリックにもあります（下の帯のボタンは、新規レイヤー・新規塗りつぶしレイヤー・新規調整レイヤーだけです）。新しいレイヤーは、選んでいるレイヤーのすぐ上（グループの中のレイヤーを選んでいれば、そのグループの中）に作り、選んでいるレイヤーが無いときは一番上に作ります。

| 項目 | 作るもの |
|---|---|
| 新規レイヤー（`Ctrl+Shift+N`） | 画素を持つレイヤー |
| 新規塗りつぶしレイヤー | 単色・グラデーションデカール・画像・デカール（[GUIDE_FILL.md](GUIDE_FILL.md)） |
| 新規調整レイヤー | 下の「調整レイヤー」 |
| 新規パスレイヤー | 点の無いパスを 1 本持つレイヤー。パスのツールに替わり、最初の点を置くと、このレイヤーのパスになります（[GUIDE_PATHS.md](GUIDE_PATHS.md)） |
| 新規グループ | レイヤーを入れる入れ物 |

- **選ぶ**: 行を押します。`Ctrl` ＋クリックで追加・解除、`Shift` ＋クリックで範囲、`Ctrl+Shift` ＋クリックで範囲を追加します。
- **名前**: 行の名前をダブルクリックするか、右クリックの「名前を変更」で変えます。
- **並べ替え**: 行をドラッグします。選んだ行を押してそのままドラッグすると、選んだ全部を運べます。「レイヤーを上へ」「レイヤーを下へ」でも動かせます。
- **表示**: 行の目の印で切り替えます。
- **定規**: 定規を持つレイヤー（グループも）の行には、サムネイルの右に「定規」のアイコンが出ます。押す・`Shift` ＋クリック・ドラッグ・右クリックの使い方は [GUIDE_PAINT.md](GUIDE_PAINT.md) の「定規」にあります。
- **削除・複製**: 「レイヤーを削除」と、右クリックの「複製」（`Ctrl+J`）。取り消しで戻せます。

複数のレイヤーを選ぶと、削除・複製・グループにまとめる・結合・表示の切り替え・1 段上下・ドラッグでの移動・ロックを、選んだ全部にまとめて行えます。描く先は 1 つのままです。

### グループ

「レイヤーをグループ化」（`Ctrl+G`）で、選んだレイヤーをグループに入れます。グループは入れ子にでき、行の矢印で開閉します。「グループ解除」は `Ctrl+Shift+G` です。グループの「通過」を入れると、中身をグループでないかのように下へ重ねます。切ると、中身を先にまとめてから重ねます。

### 結合

| 操作 | キー |
|---|---|
| 下のレイヤーと結合（グループならグループを、複数選んでいればそのレイヤーを結合） | `Ctrl+E` |
| 表示レイヤーを結合 | `Ctrl+Shift+E` |

どちらも 1 回の取り消しで戻ります。結合すると見た目が丸めの 1 段を超えて変わるときは、変わる画素の数を見せて確かめます。結合できない理由（下にレイヤーが無い、非表示のレイヤーがある、ロックなど）は短い文で出し、何も変えません。

### ロック

ロックは 4 種類です。「透明部分」は、描いても各画素の透明度を変えず、色だけを変えます。「画素」は、画素を変えられなくします（移動とマスクへの描画はできます）。「位置」は、動かす・変形することを止めます。「すべて」は、画素・位置・レイヤーの設定を変えられなくします。

付け外しは、行の錠の印（自分のロックは押すと外れます）、右クリックのメニューのロックの項目（「透明部分をロック」「画素をロック」「位置をロック」「すべてをロック」）、「プロパティ」の「ロック」のどれでもできます。グループのロックは中身に効きます。ロックは `.ylp`・PSD・`.ylsmart` に保存して戻ります。

## 合成する

「レイヤー」のパネルの上の行で、選んでいるレイヤーの合成モードと不透明度を決めます（描くチャンネルの値です）。合成モードは 26 種類で、グループにはこれに「通過」が加わります。「下のレイヤーでクリッピング」（右クリックの「クリッピング」）を入れると、下のレイヤーの形の中にだけ重ねます。

チャンネルごとに別の値にもできます。合成モードのメニューの頭の「{チャンネル名} だけの値」を選ぶと、そのチャンネルだけの合成モードと不透明度になります。レイヤーを使うチャンネルは、「プロパティ」の「チャンネル」で選びます（切ってもそのチャンネルの画素は残ります）。

右クリックの「参照レイヤー」は、バケツの「近い色」が色を見るレイヤーに印を付けます（[GUIDE_PAINT.md](GUIDE_PAINT.md)）。

## マスクを使う

マスクはレイヤーの一部を隠します。全チャンネルで共有します。

1. レイヤーを選び、「レイヤーマスクを追加」（下の帯のボタン、右クリック、「プロパティ」のどれでも）を押します。
2. レイヤーの行のマスクのサムネイルを押すと、描く先がマスクになります。画素のサムネイルを押すと、画素に戻ります。右クリックの「マスクに描く」でも切り替えられます。
3. ブラシで描くと隠し、消しゴムで描くと見せます。

マスクは、「濃度」（0% でマスクなしと同じ）、「有効」（切るとマスクなしと同じで、マスクは残ります）、「反転」を「プロパティ」で変えられます。マスクに描いているあいだは、同じ欄（レイヤーマスクの節）が、描くツール（ブラシ・消しゴム・バケツ・ポリゴン塗りつぶし・グラデーション・図形・パス・スポイト）と選択のツール（長方形選択・楕円形選択・なげなわ・多角形選択・自動選択・選択ペン）のツールプロパティの終わりにも出ます。選択範囲からマスクを作るには「選択範囲をレイヤーマスクにする」です（[GUIDE_SELECT.md](GUIDE_SELECT.md)）。「レイヤーマスクを削除」で外します。

## 調整レイヤー

「新規調整レイヤー」から、次の 9 種類を選びます。下のレイヤーの見た目を、画素を書き換えずに調整します。値は「プロパティ」で決めます。

階調の反転、レベル補正、色相・彩度、グラデーションマップ、トーンカーブ、カラーバランス、明るさ・コントラスト、2 値化、ポスタリゼーション。

グラデーションマップのランプの使い方は [GRADIENT_MAP.md](GRADIENT_MAP.md) にあります。

## チャンネルを使う

1 つのレイヤーは、チャンネルごとに画素を持ちます。標準の 6 つは、カラー・ラフネス・メタリック・ハイト・ノーマル・エミッションです。「チャンネル」のパネルで、描く先と見せる物を選びます。

- 行を押す（か、行のブラシの印を押す）と、そのチャンネルが描く先になります。目の印を押すと、そのチャンネルが 2D の「キャンバス」に出ます。右クリックにも「描くチャンネルにする」「キャンバスに表示」があります。
- 「チャンネルを追加」で、自分のチャンネル（ユーザーチャンネル）を作れます。名前はダブルクリックで変え、種類（形式の `sRGB8`・`L8`・`RGB8`）は行の右端で選びます。「チャンネルを削除」で消せるのは、ユーザーチャンネルだけです。

### ノーマルの設定

「チャンネル」のパネルの「ノーマル」の節は、文書の設定です。`.ylp` に保存され、変更は取り消せます。3D ビューと書き出しのノーマルに、同じ値で効きます。

| 項目 | 内容 |
|---|---|
| ハイト → ノーマル | 入れると、ハイトのチャンネルから作った法線を、描いたノーマルのレイヤーの下に足します。ハイトから毎回作り直し、レイヤーには描きません |
| 強さ | ハイトの全範囲（0 → 1）で何テクセル盛り上がるか。マイナスで凸が凹になります |
| 端 | 「クランプ」はキャンバスの端の傾きを端のテクセルで求め、「ラップ（タイル）」は反対側の端を読みます（タイルするテクスチャ向け） |
| ファイルの Y | 書き出す画像の緑の向き。「OpenGL (Y+)」か「DirectX (Y−)」です。Unity は OpenGL で、`.ylp` のテクスチャとプレビューはいつも OpenGL です |
