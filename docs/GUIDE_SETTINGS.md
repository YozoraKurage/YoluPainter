# 設定

[English](en/GUIDE_SETTINGS.md)

「編集 → 設定…」（`Ctrl+,`）の画面にある項目を、区分ごとに説明します。左に区分が並び、押すと右にその区分の項目が出ます。区分は「一般」「ペン」「ショートカット」「表示」「メモリ」「処理」「3D ビュー」「ファイル」「Live Link と外からの操作」「更新」です（「更新」は、更新を確かめる機能のある版だけに出ます）。前に開いた区分は覚えていて、次に開いたときも同じ区分から始まります。右の欄は区分ごとにスクロールします。見出しをドラッグしてウィンドウを動かせます。

上の「設定を探す」の欄に文字を打つと、項目の名前（画面の言語の文字）に合う項目だけが、全部の区分から区分ごとにまとめて右に並びます。左では、合う項目のある区分が光ります。区分の名前に合うときは、その区分の項目が全部並びます。区分を押すと探す欄は空になり、その区分が開きます。`Esc` は、探す欄に文字があれば空にし、なければウィンドウを閉じます。ポップアップ・ポート番号や表の探す欄などの入力欄・キーの割り当て待ち・色のウィンドウが使う `Esc` では、ウィンドウは閉じません。閉じると探す欄は空になり、次に開くと前に開いた区分から始まります。左の区分が列に収まらない低い画面では、列をスクロールします。

値は、設定のフォルダの `YoluPainter/settings.conf` に、既定でない値だけが書かれます（Windows は `%APPDATA%`、Linux は `~/.config`）。正しくない値は、その項目だけ既定に戻し、理由を知らせます。

## 一般

| 項目 | 内容 |
|---|---|
| 言語 | 日本語と English。選ぶとすぐ画面が替わります |

### 言語

設定に言語がまだ無いとき（初めての起動など）は、OS の言語で始まります。日本語なら日本語、それ以外は英語です。OS の言語は、Windows では表示言語、Linux では `LC_ALL`・`LC_MESSAGES`・`LANG` で見ます。環境変数 `YOLUPAINTER_LANG`（`ja`・`en`）があれば、それが先です。言語を選んで設定が保存されたあとは、いつも保存した言語で始まります。

## ペン

| 項目 | 内容 |
|---|---|
| タブレットの筆圧（試し）（Mac） | Wacom・XP-Pen などのドライバーが macOS の標準のイベントで送る筆圧・傾き・消しゴムの端・サイドボタンを読みます。既定は入です。切ると、ペンはマウスと同じに描きます。切り替えはすぐに効きます |
| ペンの入力（Windows） | ペンの筆圧・傾き・回転・消しゴムの端・サイドボタンを読む方式。「Windows Ink」（既定）か「WinTab」（Wacom などのタブレットのドライバーが出す入力）です。切り替えはすぐに効き、別のウィンドウにも同じ選びが効きます。触れていたペンは、切り替えで離したことになります |
| 筆圧の調整 | ペンの筆圧を、ブラシへ渡す前に直します。曲線・下限・上限・描く枠と、「自動調整」「消す」「元に戻す」「既定」のボタンが並びます |

WinTab を選んでも、WinTab のドライバー（`Wintab32.dll`）が無い・ドライバーが応えない・タブレットが繋がっていない・WinTab を開けないときは、Windows Ink で読み、その理由を 1 度だけ知らせます。選びは WinTab のままで、ウィンドウを前に出したときにもう一度試します。ドライバーのマウスモードなどで WinTab の位置がカーソルと合わないときは、点の位置をカーソルの位置にします（筆圧などは WinTab から読みます）。

### 筆圧の調整

ペンの筆圧が強すぎる・弱すぎるときに、ペンの筆圧（曲線の左から右）がブラシへ渡す筆圧（下から上）になる対応を決めます。マウスの筆圧は 1 のまま、調整を通りません。

- 曲線: 何も無い所を押すと点を追加し、ドラッグで動かし、右クリックで消します。`Esc` でドラッグをやめます。薄い棒は、描いた線の筆圧の分布です。
- 「下限」「上限」: 下限以下の筆圧を 0 に、上限以上の筆圧を 1 にします。
- 描く枠: 普段の強さで何本か描きます。描いた線は枠の中だけに持ち、文書には入りません。「ペン」の区分を離れる・設定のウィンドウを閉じると捨てます。
- 「自動調整」: 描いた線の筆圧の分布から、下限・上限・曲線を決めます。線が足りない・筆圧がほぼ一定のときは決めずに、短い理由を出します。「消す」は描いた線を消します。「元に戻す」は「ペン」の区分を開いたときの調整へ、「既定」は下限 0%・上限 100%・直線へ戻します。

決めた調整は設定のファイルに入り（文書にもブラシにも入りません）、2D のキャンバスも 3D ビューも通ります。指やペンがタッチとして力を送ってくるときも、その力が同じ調整を通ります（[GUIDE_PAINT.md](GUIDE_PAINT.md)）。

## ショートカット

キーとマウスの組み合わせ・パイメニューを見て、変えます。左で「ショートカット」を押すと、その下に区分（どこでも・視点／ペイント／編集／ポーズ／途中の操作／パイメニュー）が並び、右に表（操作の名前・キー・マウス）が出ます。表の上に名前で探す欄と「キーで探す」（この 2 つは表の中だけを絞ります）、下に「既定に戻す」「書き出し…」「読み込み…」があります。使い方は [GUIDE_KEYS.md](GUIDE_KEYS.md) の「ショートカットを変える」にあります。

## 表示

| 項目 | 内容 |
|---|---|
| 表示の合成 | 2D のキャンバスに出すレイヤーの合成を、どこで行うか。「自動」「GPU」「CPU」 |
| 垂直同期 | 画面の更新を、モニターの垂直同期まで待たせるか。既定は切（待たない）です。入れると、画面の上下のずれ（テアリング）が出ない代わりに、ペンで描く線が画面に出るまでの遅れが増えます。次の起動から効き、変えたあとは「再起動で反映」と出ます |
| GPU のメモリ | 3D ビュー・キャンバスの GPU の合成・アセットのサムネイルが使ってよい GPU のメモリの量。「自動」「低」「標準」「高」 |
| ベイクで RT コアを使う | メッシュマップのベイクで、GPU の RT コア（ハードウェアの光線追跡）を使うか。既定は入です。使えない GPU や、同じ光線を使わない道と比べて答えが合わないときは、設定にかかわらず RT コアを使わずに焼きます。ドライバーが固まる PC では切ってください。切ると常に RT コアを使わない道で焼きます。画面の描画の方式は変わりません |

**表示の合成**は、画面に出す合成だけが対象です。保存・書き出し・3D ビューの値の合成は、どれを選んでも CPU です（GPU の画素は、CPU の結果と、多段の文書でも 2 以内の差が出ることがあります。表示だけの差です）。自動は、使える GPU があれば GPU で、ソフトウェアの GPU では CPU で合成します。調整レイヤー・独立したグループ・ノーマルのチャンネル・効果のある文書も GPU で合成します（効果の計算は CPU で行い、できた画素を GPU へ上げます）。描いたタイルが、「GPU のメモリ」で配られたキャンバスの予算（標準で 512 MiB）を超える文書、GPU のテクスチャの上限を超える大きさ、グループの入れ子が深すぎる文書は、CPU に切り替えます。環境変数 `YOLUPAINTER_CANVAS`（`auto`・`gpu`・`cpu`）で固定することもできます。

**垂直同期**が切（既定）の間は、画面に出す呼び出しが垂直同期を待ちません。ペンの入力から線が画面に出るまでの遅れが縮む代わりに、画面の上下のずれ（テアリング）が出ることがあります。使っているグラフィックスの環境が待たない出し方を持たないときは、待つ出し方になります。描き直しが続けて頼まれても、CPU と GPU を使い切らないように、アプリが描き直しの間隔に下限をかけます（入力があるときは 1/240 秒より短い間隔では描き直しません。描き直しの頼みだけのときは、ウィンドウのあるモニターのリフレッシュレートの 1 回の長さより短い間隔では描き直しません。リフレッシュレートは Windows だけ読み、60〜240 Hz に収めます。読めないときは 120 Hz です）。入れている間は、垂直同期が間隔を決めるので、下限はかけません。ウィンドウを作るときに決まるので、切り替えは次の起動から効きます。

**ベイクで RT コアを使う**は、環境変数 `YOLUPAINTER_BAKE_RAY_QUERY=0`（`false`・`off`・`no` も同じ）でも切れます（環境変数が切のときは、設定が入でも切のままで、この行は押せません）。変えると、次の確認・ベイクで GPU のデバイスを作り直します。

**GPU のメモリ**が足りないときは、3D ビューが、ほかのテクスチャセットの絵を減らし、今のセットの絵を小さくして見せます（テクスチャと書き出しは変わりません）。「自動」は、GPU のメモリの量が分かるときだけそれに合わせます（少なければ低、多ければ標準の量を増やします）。分からないときは標準です。行の右の「詳しく」を開くと「合計」のスライダーが出て、3D の絵（3D ビューの選択範囲の縁・重ねを含みます）・キャンバスの合成・アセットのサムネイルへ 4 : 4 : 1 に配ります。動かすと、段の選びを置き換えた量の指定になります。

## メモリ

| 項目 | 内容 |
|---|---|
| 取り消し履歴 | 取り消しの履歴に使うメモリの、全テクスチャセットの合計。超えた古い段から捨てます |
| レイヤーのメモリ | 全テクスチャセットの全レイヤーが画素に使うメモリの合計の上限。超える操作は、何も変えずに断ります |
| 1 回の操作 | ストロークや塗りつぶし 1 回が巻き戻し用に持てるメモリ。書き出しの作業にも使います。超える操作は、何も変えずに止めます |
| 最小の取り消し段数 | 取り消しの予算を超えても残す、直近の段数（0〜100）。0 は予算を厳密にします |
| ディスクキャッシュ | 下の「ディスクキャッシュ」 |

3 つのメモリは、「自動」か MiB で選びます。自動は物理メモリから決めます（レイヤーのメモリは半分、取り消し履歴は 1/8、1 回の操作は 1/16。それぞれに下限と上限があります）。どれも使える量の上限で、先に確保はしません。取り消し履歴とレイヤーのメモリはプロジェクト全体の合計です。1 回の操作と最小の取り消し段数は、テクスチャセットごとです。`.ylp` を開くときの画素は、レイヤーのメモリの設定（256 MiB を下回りません）まで読みます。

### ディスクキャッシュ

「ディスクキャッシュ」は、メモリの上限（レイヤーのメモリと取り消し履歴の予算の和）を超えたタイルを、使っていないものからディスクへ移して、大きな文書で描き続けられるようにします。既定は入です。切ると、予算を超える操作は断ります。ディスクから読み戻せないタイルが出たときは、そのテクスチャセットを読むだけにして知らせます。詳しくは [GUIDE_FILES.md](GUIDE_FILES.md) にあります。

行の右の「詳しく」を開くと、次の 2 つが出ます。

- 「キャッシュの上限」: 使うディスクの量。自動は 64 GiB と、置き場所の空きの半分の小さいほうです。満杯なら、超える操作は断ります。
- 「キャッシュの場所」: キャッシュのファイルを置くフォルダを「選ぶ…」で選びます（速いドライブほど、移したタイルを戻すのが速くなります）。「既定に戻す」で OS の一時フォルダに戻ります。

## 処理

| 項目 | 内容 |
|---|---|
| CPU のスレッド | CPU の処理（合成・ブラシ・塗りつぶし・選択範囲など）が同時に使う数。「自動」「1」「2 の冪」「論理プロセッサの数」から選びます。どの値でも結果の画素は同じで、少ないと大きなキャンバスで遅くなる代わりに、ほかのアプリに余裕が残ります。次の起動から効き、変えたあとは「再起動で反映」と出ます |

## 3D ビュー

| 項目 | 内容 |
|---|---|
| 回転の中心 | 3D ビューを回すときの中心。「画面の中心」「面の位置（自動深度）」「モデルの中心」「テクスチャセットの中心」 |
| ズームの中心 | 3D ビューをズームするときの中心。「画面の中心へ」「ポインタの所へ」 |
| 軸の向きで正投影 | 軸の視点を選んだとき・スナップ回転で軸の向きに吸い付いたときは正投影にし、回して軸から外れたら透視へ戻します。既定は入です（[GUIDE_3D.md](GUIDE_3D.md) の「軸の視点と正投影」） |
| UV ワイヤーフレーム | 2 つの色の見本。UV ワイヤーフレームの色と、「重なった UV」の色。押すと色のウィンドウが開き、色と不透明度を決めます |

回転とズームの中心は、3D ビューの表示の設定の「視点」と同じ値です。どちらで変えても同じ設定が変わります（[GUIDE_3D.md](GUIDE_3D.md)）。

## ファイル

| 項目 | 内容 |
|---|---|
| 書き出しのパディング | 書き出しで、UV が触れないテクセルへ UV の縁の色を塗り広げる量。「なし」「2 px 広げる」「4 px 広げる」「8 px 広げる」「16 px 広げる」「32 px 広げる」「64 px 広げる」「無限に広げる」から選びます（既定は「無限に広げる」）。ミップマップや補間で縁に別の色が混ざるのを防ぎます。「ファイル → テクスチャを書き出す…」のウィンドウの「パディング」と同じ値です |
| ライブラリの場所 | 自分のライブラリ（自分のアセットを置くフォルダ）の場所。既定は設定のフォルダの `YoluPainter/Library` です。「選ぶ…」で選び、「既定に戻す」で戻します。絶対パスだけ指定できます |
| 退避を残す数 | 上書き保存で置き換えた前の版（保存先の隣の `<ファイル名>-backups~` フォルダに残ります）を、新しい順にいくつ残すか（0〜1000）。超えた古い版だけを消します。0 は退避しません（すでにある退避は消しません） |
| すべて残す | 入れると、退避を消しません。既定は入です |

## Live Link と外からの操作

| 項目 | 内容 |
|---|---|
| Unity の Live Link を受け付ける | 入れておくと、Unity のエディタの「YoluPainter で開く」で送ったモデルとマテリアルを開きます。`--livelink` を付けて起動したときは、この設定によらず受け付けます（[UNITY.md](UNITY.md)） |
| Unity から受けたマテリアルの値を保存する | Live Link で受けた lilToon の値を `.ylp` に入れます（テクスチャの画素は入れず、開き直すとファイルから読みます）。切ると、次に保存するときに外します |
| 外からの操作を受ける | 下の「外からの操作（MCP）」 |

### 外からの操作（MCP）

「外からの操作を受ける」を入れている間だけ、AI のアシスタント（MCP）やコマンドラインからの操作を `http://127.0.0.1:<番号>/mcp` で待ち受けます。既定は切です。入れると「ポート番号」の行が出ます（既定は 17347、1024〜65535）。変えたら、つなぐ側の番号も同じにします。状態の帯の右端に小さな丸が出て、待っている・つながっている・受けられないが色で分かります（ツールチップに URL や理由）。

- この PC の中だけの通信です。合言葉は無いので、入れている間は、この PC のほかのアカウントのプログラムもつなげます。
- 1 つの命令が画面の取り消しの 1 段になります。描いている最中、保存の途中、読むだけのテクスチャセットへの編集は、理由を言って断ります。文書を開き替える命令は受けません。
- 切ると待ち受けをやめ、つながりも閉じます。

つなぎ方は [MCP.md](MCP.md)、コマンドラインは [CLI.md](CLI.md) にあります。

## 更新

更新を確かめる機能のある版だけに出ます（ソースからビルドしたアプリには、この区分も、ヘルプの「更新を確かめる…」もありません）。

| 項目 | 内容 |
|---|---|
| 起動時に更新を確かめる | 入れると、起動のたびに GitHub へ最新の版を問い合わせます。初めて起動したときに聞かれた選びも、ここで替えられます（[INSTALL.md](INSTALL.md)） |
| 試験版を使う | 正式版より前の試験版も、更新の候補にします。切ると正式版だけを見ます。既定は切です |

手で確かめるときは、「ヘルプ → 更新を確かめる…」を使います。

## 設定の画面の外にある設定

- **復旧**: 「ファイル → 復旧…」のウィンドウで、書き置きの間隔・残す世代・使うディスクの量を決めます（[RECOVERY.md](RECOVERY.md)）。
- **選択範囲のボタンの帯**: 「選択範囲」メニューの「選択範囲のボタンの帯を表示」（[GUIDE_SELECT.md](GUIDE_SELECT.md)）。
- **パネルの並び**: 設定のフォルダの `YoluPainter/layout.json` に覚えます（[GUIDE_START.md](GUIDE_START.md)）。
- **キーとマウスの割り当て・パイメニュー**: 「ショートカット」の区分で変え、設定のフォルダの `YoluPainter/keymap.json` に、既定から変えた所だけを覚えます。ツールのキーの動き方は `tool_keys` に、ツールを選ぶ操作の ID と動き方（`hold` は押している間だけ、`tap_or_hold` は短く押すと切り替え・長押しで押している間だけ）で書きます（例: `"tool_keys": { "tool.eraser": "hold" }`。既定の押すと切り替えは書きません）（[GUIDE_KEYS.md](GUIDE_KEYS.md)）。
