# 設定

[English](en/GUIDE_SETTINGS.md)

「編集 → 設定…」（`Ctrl+,`）の画面にある項目を、節ごとに説明します。ウィンドウは「一般」「メモリ」「処理」「3D ビュー」「ファイル」の 5 つの節（Mac では「3D ビュー」と「ファイル」の間に「ペン」が加わります）に分かれ、見出しをドラッグして動かせます。画面が低くて収まらないときは、中をスクロールして最後の行まで届きます。

値は、設定のフォルダの `YoluPainter/settings.conf` に、既定でない値だけが書かれます（Windows は `%APPDATA%`、Linux は `~/.config`）。正しくない値は、その項目だけ既定に戻し、理由を知らせます。

## 一般

| 項目 | 内容 |
|---|---|
| 言語 | 日本語と English。「表示」メニューでも切り替えられます。行の右の「ショートカット…」は、キーとマウスの割り当てのウィンドウを開きます（[GUIDE_KEYS.md](GUIDE_KEYS.md)） |
| Unity の Live Link を受け付ける | 入れておくと、Unity のエディタの「YoluPainter で開く」で送ったモデルとマテリアルを開きます。`--livelink` を付けて起動したときは、この設定によらず受け付けます（[UNITY.md](UNITY.md)） |
| Unity から受けたマテリアルの値を保存する | Live Link で受けた lilToon の値を `.ylp` に入れます（テクスチャの画素は入れず、開き直すとファイルから読みます）。切ると、次に保存するときに外します |
| 外からの操作を受ける | 下の「外からの操作（MCP）」 |
| 書き出しの余白 | 書き出しで、UV が触れないテクセルへ UV の縁の色を塗り広げる量。「なし」「2」「4」「8」「16」「32」「64 テクセル」「届くかぎり」から選びます（既定は「届くかぎり」）。ミップマップや補間で縁に別の色が混ざるのを防ぎます |

### 言語

設定に言語がまだ無いとき（初めての起動など）は、OS の言語で始まります。日本語なら日本語、それ以外は英語です。OS の言語は、Windows では表示言語、Linux では `LC_ALL`・`LC_MESSAGES`・`LANG` で見ます。環境変数 `YOLUPAINTER_LANG`（`ja`・`en`）があれば、それが先です。言語を選んで設定が保存されたあとは、いつも保存した言語で始まります。

### 外からの操作（MCP）

「外からの操作を受ける」を入れている間だけ、AI のアシスタント（MCP）やコマンドラインからの操作を `http://127.0.0.1:<番号>/mcp` で待ち受けます。既定は切です。入れると「ポート番号」の行が出ます（既定は 17347、1024〜65535）。変えたら、つなぐ側の番号も同じにします。状態の帯の右端に小さな丸が出て、待っている・つながっている・受けられないが色で分かります（ツールチップに URL や理由）。

- この PC の中だけの通信です。合言葉は無いので、入れている間は、この PC のほかのアカウントのプログラムもつなげます。
- 1 つの命令が画面の取り消しの 1 段になります。描いている最中、保存の途中、読むだけのテクスチャセットへの編集は、理由を言って断ります。文書を開き替える命令は受けません。
- 切ると待ち受けをやめ、つながりも閉じます。

つなぎ方は [MCP.md](MCP.md)、コマンドラインは [CLI.md](CLI.md) にあります。

## メモリ

| 項目 | 内容 |
|---|---|
| 取り消し履歴 | 取り消しの履歴に使うメモリの、全テクスチャセットの合計。超えた古い段から捨てます |
| レイヤーのメモリ | 全テクスチャセットの全レイヤーが画素に使うメモリの合計の上限。超える操作は、何も変えずに断ります |
| 1 回の操作 | ストロークや塗りつぶし 1 回が巻き戻し用に持てるメモリ。書き出しの作業にも使います。超える操作は、何も変えずに止めます |
| 最小の取り消し段数 | 取り消しの予算を超えても残す、直近の段数（0〜100）。0 は予算を厳密にします |
| ディスクキャッシュ | 下の「ディスクキャッシュ」 |

3 つのメモリは、「自動」か MiB で選びます。自動は物理メモリから決めます（レイヤーのメモリは半分、取り消し履歴は 1/8、1 回の操作は 1/16。それぞれに下限と上限があります）。どれも使える量の上限で、先に確保はしません。取り消し履歴とレイヤーのメモリはプロジェクト全体の合計です。1 回の操作と最小の取り消し段数は、テクスチャセットごとです。`.ylp` を開くときの画素は、レイヤーのメモリの設定（256 MiB を下回りません）まで読みます。

### ディスクキャッシュ

「ディスクキャッシュ」は、メモリの上限（レイヤーのメモリと取り消し履歴の予算の和）を超えたタイルを、使っていないものからディスクへ移して、大きな文書で描き続けられるようにします。既定は入です。切ると、予算を超える操作は断ります。ディスクから読み戻せないタイルが出たときは、そのテクスチャセットを読むだけにして知らせます。詳しくは [GUIDE_FILES.md](GUIDE_FILES.md) にあります。

行の右の「詳しく」を開くと、次の 2 つが出ます。

- 「キャッシュの上限」: 使うディスクの量。自動は 64 GiB と、置き場所の空きの半分の小さいほうです。満杯なら、超える操作は断ります。
- 「キャッシュの場所」: キャッシュのファイルを置くフォルダを「選ぶ…」で選びます（速いドライブほど、移したタイルを戻すのが速くなります）。「既定に戻す」で OS の一時フォルダに戻ります。

## 処理

| 項目 | 内容 |
|---|---|
| CPU のスレッド | CPU の処理（合成・ブラシ・塗りつぶし・選択範囲など）が同時に使う数。「自動」「1」「2 の冪」「論理プロセッサの数」から選びます。どの値でも結果の画素は同じで、少ないと大きなキャンバスで遅くなる代わりに、ほかのアプリに余裕が残ります。次の起動から効き、変えたあとは「再起動で反映」と出ます |
| 表示の合成 | 2D のキャンバスに出すレイヤーの合成を、どこで行うか。「自動」「GPU」「CPU」 |
| GPU のメモリ | 3D ビュー・キャンバスの GPU の合成・アセットのサムネイルが使ってよい GPU のメモリの量。「自動」「低」「標準」「高」 |

**表示の合成**は、画面に出す合成だけが対象です。保存・書き出し・3D ビューの値の合成は、どれを選んでも CPU です（GPU の画素は、CPU の結果と、多段の文書でも 2 以内の差が出ることがあります。表示だけの差です）。自動は、使える GPU があれば GPU で、ソフトウェアの GPU では CPU で合成します。調整レイヤー・独立したグループ・ノーマルのチャンネル・効果のある文書も GPU で合成します（効果の計算は CPU で行い、できた画素を GPU へ上げます）。描いたタイルが、「GPU のメモリ」で配られたキャンバスの予算（標準で 512 MiB）を超える文書、装置のテクスチャの上限を超える大きさ、グループの入れ子が深すぎる文書は、CPU に切り替えます。環境変数 `YOLUPAINTER_CANVAS`（`auto`・`gpu`・`cpu`）で固定することもできます。

**GPU のメモリ**が足りないときは、3D ビューが、ほかのテクスチャセットの絵を減らし、今のセットの絵を小さくして見せます（テクスチャと書き出しは変わりません）。「自動」は、GPU のメモリの量が分かるときだけそれに合わせます（少なければ低、多ければ標準の量を増やします）。分からないときは標準です。行の右の「詳しく」を開くと「合計」のスライダーが出て、3D の絵・キャンバスの合成・アセットのサムネイルへ 4 : 4 : 1 に配ります。動かすと、段の選びを置き換えた量の指定になります。

## 3D ビュー

| 項目 | 内容 |
|---|---|
| 回転の中心 | 3D ビューを回すときの中心。「画面の中心」「面の位置（自動深度）」「モデルの中心」「テクスチャセットの中心」 |
| ズームの中心 | 3D ビューをズームするときの中心。「画面の中心へ」「ポインタの所へ」 |
| UV ワイヤーフレーム | 2 つの色の見本。UV ワイヤーフレームの色と、「重なった UV」の色。押すと色のウィンドウが開き、色と不透明度を決めます |

回転とズームの中心は、3D ビューの表示の設定の「視点」と同じ値です。どちらで変えても同じ設定が変わります（[GUIDE_3D.md](GUIDE_3D.md)）。

## ペン（Mac）

| 項目 | 内容 |
|---|---|
| タブレットの筆圧（試し） | Wacom・XP-Pen などのドライバーが macOS の標準のイベントで送る筆圧・傾き・消しゴムの端・サイドボタンを読みます。既定は入です。切ると、ペンはマウスと同じに描きます。切り替えはすぐに効きます |

## ファイル

| 項目 | 内容 |
|---|---|
| ライブラリの場所 | 自分のライブラリ（自分のアセットを置くフォルダ）の場所。既定は設定のフォルダの `YoluPainter/Library` です。「選ぶ…」で選び、「既定に戻す」で戻します。絶対パスだけ指定できます |
| 退避を残す数 | 上書き保存で置き換えた前の版（保存先の隣の `<ファイル名>-backups~` フォルダに残ります）を、新しい順にいくつ残すか（0〜1000）。超えた古い版だけを消します。0 は退避しません（すでにある退避は消しません） |
| すべて残す | 入れると、退避を消しません。既定は入です |

## 設定の画面の外にある設定

- **筆圧**: 「表示 → 筆圧の調整…」で、下限・上限・曲線を合わせます（[GUIDE_PAINT.md](GUIDE_PAINT.md)）。
- **復旧**: 「ファイル → 復旧…」のウィンドウで、書き置きの間隔・残す世代・使うディスクの量を決めます（[RECOVERY.md](RECOVERY.md)）。
- **更新**: 「ヘルプ → 更新を確かめる…」「起動時に更新を確かめる」「試験版を使う」（[INSTALL.md](INSTALL.md)）。
- **選択範囲のボタンの帯**: 「選択範囲」メニューの「選択範囲のボタンの帯を表示」（[GUIDE_SELECT.md](GUIDE_SELECT.md)）。
- **パネルの並び**: 設定のフォルダの `YoluPainter/layout.json` に覚えます（[GUIDE_START.md](GUIDE_START.md)）。
- **キーとマウスの割り当て・パイメニュー**: 一般の節の言語の行の右の「ショートカット…」（「ヘルプ → ショートカット」）で変え、設定のフォルダの `YoluPainter/keymap.json` に、既定から変えた所だけを覚えます（[GUIDE_KEYS.md](GUIDE_KEYS.md)）。
