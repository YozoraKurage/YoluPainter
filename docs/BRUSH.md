# ブラシ

ブラシの設定のうち、仕様を文書にしておく価値のあるものをここに書きます。ブラシの詳細のウィンドウの項目は画面で確かめられるので、ここでは式と形式、ほかのツールとの違いだけを扱います。

## 色の混ぜ（厚塗り）

今までのブラシは描く色をそのまま置きます。**色の混ぜ**を使うブラシは、打点（ダブ）ごとに下の色を読み、描く色と混ぜてから置きます。CLIP STUDIO の下地混色（色混ぜ・色重ね・にじみ、絵の具の量・絵の具の濃さ・色延び、混色モード、輝度の補正）に当たる拡張で、式は YoluPainter 独自の決めです（CLIP STUDIO の絵と一致する保証はありません。取り込んだブラシとの近さは [BRUSH_IMPORT.md](BRUSH_IMPORT.md#下地混色の換算) の表）。混ぜ方が「なし」のブラシは、画素もファイルも混ぜを加える前と同じです。

### 設定

ブラシの詳細のウィンドウの「色の混ぜ」で変えます。

| 項目 | 範囲 | 既定 | 意味 |
| --- | --- | --- | --- |
| 混ぜ方 | なし／混ぜる／重ねる／伸ばす | なし | 次の 3 つ（CLIP STUDIO の色混ぜ・色重ね・にじみに当たる） |
| 絵の具の量 | 0〜100% | 50% | 混ぜた色に占める描く色（筆の荷）の割合。100% は下の色を拾わず、0% は下の色だけになる |
| 絵の具の濃さ | 0〜100% | 100% | 置く量。ストロークの不透明度の天井に掛ける倍率 |
| 色延び | 0〜100% | 50% | 前の打点で拾った色を次の打点へ引きずる割合。伸ばすでは、読む位置の遅れの長さにも効く |
| 全レイヤーから | 入／切 | 切 | 切: 描いているレイヤーだけを下地にする。入: 見えているレイヤーの重なりを下地にする |
| 混色モード | 標準／知覚的 | 標準 | 混ぜた色を作る空間。標準は sRGB の値の補間（これまでのすべて）、知覚的は絵の具のように混ざる（[知覚的な混ぜ](#知覚的な混ぜ)） |
| 輝度の補正 | 0〜4（なし〜最高） | 0 | 知覚的のときだけ働く。大きいほど、混ざって暗くなる分が小さい |
| にじむ強さ | 大きさに連動／固定値 0〜8 画素 | 大きさに連動 | 伸ばすだけに効く。下の色を平均する箱の半径（連動は打点の半径の 1 割、1〜8 画素。固定値の 0 は 1 画素）。3D の面で対称と組み合わせないときは、箱の平均を使わない（下の「効く範囲」）ので効かない |
| 初めの絵の具の量 | 0〜100% | 100% | 最初の打点の荷のうち、描く色の割合（残りは最初の打点の下の色）。100% は描く色だけ。小さいと、描き始めが薄く、描き進めるにつれて描く色が荷へ足されて濃くなる |
| 筆圧（量・濃さ） | 入／切、最小値、曲線 | 切 | 筆圧で量・濃さを変える。応えは [筆圧の応え](#筆圧の応え)と同じ（最小値と曲線） |

混ぜ方:

- **混ぜる**: 打点の下の同じ画素の色（ストロークを始める前の絵）と、筆の荷を混ぜて置く。同じストロークが何度重なっても、画素に残る色は最後に覆った打点の混ぜた色で、重ねるたびに描く色へ寄ることはない。
- **重ねる**: 今の面（ストロークが先に置いた分を含む）の同じ画素を読み、荷と混ぜて置く。混ぜると違い、置いた色の上に次の打点が重なる（重なった画素は、先の打点が置いた色を読んで混ぜ直す）。動きの向きも箱の平均も使わない。
- **伸ばす**: 前の打点から今の打点への動きの分だけ後ろの下の色（今の面。ストロークが先に置いた分を含む）を、小さな箱（にじむ強さ。既定は打点の半径の 1 割、1〜8 画素）で平均して読み、荷と混ぜて置く。ぼかしと指先の中間のように、色が線に沿って伸びる。後ろを読む長さは動きの `1 + 2 × 色延び` 倍で、打点の大きさを超えない。

### 式

色は straight RGBA（0〜255）で扱います。α は 0〜1。精度は式ごとに違います。筆の荷 `C`・`L` の計算（1. と 4.）は倍精度（4. の下地の合計は、画素ごとの積が単精度、足し算が倍精度）、画素の混ぜた色 `M`（2.）と重ね（3.）は単精度（f32）です。

1. **筆の荷 `C`**: 最初の打点は描く色（[初めの絵の具の量](#設定)が 1 未満なら、描く色と最初の打点の下の色を、その割合で混ぜた色）。次の打点からは `C = L × 色延び + 描く色 × (1 − 色延び)`。`L` は前の打点が終わった後の荷。色延び 0 は毎回描く色から、1 は荷をそのまま引きずる。
2. **画素の混ぜた色 `M`**: 下の色 `U` と荷 `C` を、絵の具の量 `A` で α を重みにして混ぜる。
   `wu = U.α × (1 − A)`、`wc = C.α × A`、`M.rgb = (U.rgb × wu + C.rgb × wc) / (wu + wc)`、`M.α = C.α`。
   効果のブラシ（ぼかし・指先）の混ぜ方と同じ重みで、**透明な下の色は混ざらない**（透明なレイヤーに描いても、描く色のまま薄まらない）。`wu + wc` が 0 の画素は塗らない。
3. **置く**: 今までのブラシと同じ道。ストロークの覆い（不透明度 × 筆圧 × ゆらぎ × 紙の質感 × **絵の具の濃さ**を天井に、流量で寄せていく）で、画素ごとの色 `M` へ寄せ、ストロークを始める前の画素へ通常の合成（`blend`）で重ねる。
4. **荷の更新**: 打点が終わった後、`L = 荷と、打点の下の色の平均（被覆 × α で重みを付けた平均）を量 A で混ぜた色`。荷のうち量 A の分だけが次へ残り、残りは下の色へ入れ替わる（量が多いほど引きずりが長く続く）。下の色が全部透明で何も拾えなければ `L = C`（荷は変わらない）。引きずりの長さは 1 打点あたりの入れ替わりなので、打点の間隔が狭いほど短い距離で入れ替わる。

式の「混ぜる」（2.・4.・1. の `L` と描く色の混ぜ）は、混色モードが標準なら上の重みつきの補間、知覚的なら [知覚的な混ぜ](#知覚的な混ぜ)（重みは同じ。輝度の補正は 2. だけに掛け、荷の混ぜ・拾いには掛けない）です。標準で初めの絵の具の量が 1（既定）のブラシは、これまでと同じ画素になります。

筆圧で量・濃さを変えるときは、`A × 応え(筆圧)`、`濃さ × 応え(筆圧)` を使います（応えの既定は筆圧そのもの）。軽く触れると量が下がって下の色を伸ばし、強く押すと描く色を置く、という使い方ができます。

### 知覚的な混ぜ

標準の混ぜは sRGB の値を重みで補間するので、青と黄は灰色に沈み、白に少量の黄を混ぜると薄い黄になります。知覚的は絵の具に近く、青と黄は暗い緑、白に少量の黄は強い黄になります。式は YoluPainter 独自で、錐体応答（LMS）の空間で吸収の積に近い混ぜをします（`t` は後ろの色の重み = 荷の割合）。

1. 線形の光から錐体応答 `x = M·lin + 0.005` を求める。`M` は Hunt-Pointer-Estevez の錐体基本（D65 で正規化。[LMS color space](https://en.wikipedia.org/wiki/LMS_color_space)）に sRGB（D65）の原色を合わせた 3×3。0.005 は応答が 0 の色が積を 0 に潰さない床。
2. 8 乗根の冪平均 `P = (1 − t)·a^(1/8) + t·b^(1/8)`（`a`・`b` は 2 つの色の `x`）。指数 1/8 は幾何平均（吸収の積）に近く、平方根 3 回で求められる。
3. 混ぜた応答 `P^8`。輝度の補正は、混ざって暗くなる分の指数を 5 段で変える: 輝度の補正 `k`（0〜4）で `P^(16 − 2k)` を、`s·g` だけ `P^8` から寄せる（`s = min(1, min(t, 1 − t) / 0.05)`、`g = min(1, Δ / 0.16)`、Δ は 2 つの色の `x` の 8 乗根の差の最大）。最高（4）は寄せない（指数 1）、なし（0）は指数 2。両端（`t` = 0・1）と、同じ色どうしは動かない。
4. 応答から 0.005 を引き、`M` の逆行列で線形の光へ、sRGB へ戻す。

式は + − × ÷ と平方根と表引きだけで書いてあり（OS の数学の関数を使わない）、式の上では、スカラー・SSE4.1・AVX2・NEON のどの道・スレッドの数・OS によらず同じバイトになる形にしてあります。1 画素ごとに錐体応答への変換と平方根・sRGB への変換を通るので、標準の混ぜより 1 桁ほど重く、ワーカーで描く大きさの見積もりもそれに合わせてあります。

### 下地の読み方

- 打点の前に、読む範囲の画素を枠へ凍結してから、どの画素を書くより前に済ませます。書いている間に面を読み返さないので、ワーカーで描いても順に描いても同じ画素になります。
- **混ぜる**は、ストロークを始める前の絵を読みます（今のレイヤーだけのとき、もう手を付けたタイルは巻き戻しの写しから読みます）。同じストロークが先に置いた画素は読まないので、ブラシの間隔や、同じ場所を何度通るかで混ざり方が変わりません。荷の引きずりだけが、ストロークの中で色を運びます。
- **重ねる**と**伸ばす**は、今の面を読みます（このストロークが先に置いた画素を含む。指先と同じ）。先に引きずった色や置いた色を後の打点が運びます。重ねるは同じ画素、伸ばすは動きの後ろを箱で平均して読みます。
- **全レイヤーから**（見えているレイヤーの重なりを下地にする）は、今の評価の道（合成のモード・不透明度・効果・マスクを含む）で、最初の打点の前に合成して凍結します。混ぜるでは、今のレイヤーだけのときと違うのは下のレイヤーなどが入ることだけです。重ねる・伸ばすでは、凍結した絵を読むので、先に引きずった色・置いた色は運ばれず、元の絵の色が読まれます。凍結した合成は、クローンの「全レイヤーから」と同じくストロークの予算に数え、超えたらストロークごと取り消します。
- 読む枠もストロークの予算に数えます。伸ばすは箱の平均のための積分画像の分も数えます。超えたらストロークごと取り消し、画素・履歴は元のままです。

### 効く範囲

- 色のチャンネルを色で塗るブラシだけに効きます。Roughness などのデータのチャンネル、ノーマル、レイヤーのマスクでは混ぜません（値が壊れるため）。複数のチャンネルを 1 回のストロークで塗る（マテリアル）ときは、色のチャンネルだけを混ぜ、データのチャンネルには同じダブを混ぜずに塗ります。
- 消しゴム、ぼかし・指先・クローンの効果のブラシでは混ぜません（設定は残りますが効きません）。
- 選択範囲と透明部分のロックは、ふつうのブラシと同じく効きます。選択外の画素・ロックされた透明な画素は塗らず、半分選ばれた画素は描く前の画素から半分だけ混ぜた色へ寄り、透明部分のロックでは透明な画素の RGB とアルファを守ります。塗らない画素の下の色は荷にも入らないので（混ぜる）、選択外の色を拾って選択内へ運ぶことはありません。伸ばすは動きの後ろの色を読むので、選択外の色も、ぼかしや指先と同じく読みます。
- 3D の面へ描くときも効きます。混ぜる・重ねるは、ダブの画素をまとめて渡し、下の色を書く前に凍結します（ぼかしと同じ道。重ねるは今の面を読む）。伸ばすは、指先と同じく展開の図で UV の継ぎ目をまたいで、直前のダブの側の下の色を読みます（箱の平均はありません）。対称（2D と 3D の対称定規）と組み合わせるときは、写しごとに動きの向きが違うので動きの向きを使わず、同じ画素の周りの箱の平均だけになります（このときの箱は、にじむ強さの固定値も効きます。混ぜる・重ねるは対称でも同じ式で、左右が鏡像になります）。
- 3D の面と対称のダブは、画素を含むタイルがつながる塊ごとに下の色を凍結して塗ります。1 つのダブが UV の離れたアイランドや対称の離れた写しにまたがっても、読む枠は塊ごとの小さな範囲で、外接の箱（キャンバスの大半）を読んで予算を食うことはありません（1 つにつながるダブは今までと同じ 1 つの枠で、凍結した枠のバイトは塊ごとにストロークの予算に数えます）。
- 混ぜるブラシは、画素ごとに塗る入口（`apply_pixel`）では使えません。
- 混ぜは CPU だけで行います。GPU のブラシのプレビュー（`yolu-gpu` の `brush_dabs`）は丸い筆先の覆いと色だけを計算する別の経路で、下の画素の読み戻しとダブごとの荷の更新に依存する混ぜは持ちません。保存と Undo の正本はいつも core のストロークです。

### 保存

利用者のブラシ（`.ylbrush`。設定のフォルダの `brushes/`）は、混ぜ方が「なし」でなければ 1 行目を `yolupainter-brush 3` にして混ぜの項目を書きます。使わないブラシは今までと同じ版とバイトです（筆圧の応えだけを使うブラシは版 2）。
入り抜き・手ぶれ補正を持つブラシ（CLIP STUDIO から取り込んだブラシが持つ分。[BRUSH_IMPORT.md](BRUSH_IMPORT.md)）だけは 1 行目を `yolupainter-brush 4` にして、`assist.stabilizer`・`assist.taper_in`・`assist.taper_out`（画素。0〜10000）を書きます
（版 2・3 の項目も、使っていれば同じファイルに書きます）。入り抜き・手ぶれ補正は描き手の設定でブラシに入らないので、持つのは取り込んだブラシだけで、そのブラシを選んでいる間だけ今の設定に重なります。
[最低 1 ピクセル](#最低-1-ピクセル)を入れたブラシだけは 1 行目を `yolupainter-brush 6` にして `controls.min_one_pixel=1` を書きます（ほかの版の項目も同じファイルに書きます。切のブラシは今までと同じ版・同じバイトで、版 5 までのファイルは切として読みます）。
版 6 までの項目で書けない[影響元](#筆圧の応え)（ランダム、傾き・速さの最小値か曲線、真円率・質感の濃さの影響元、硬さ・絵の具の量と濃さへの傾き・速さ・ランダム）を使うブラシだけは 1 行目を `yolupainter-brush 7` にして、影響元を `influence.<項目>.<入力>.on`・`.min`・`.curve` だけで書きます（項目は `size`・`opacity`・`flow`・`hardness`・`roundness`・`texture_density`・`mix_paint`・`mix_density`、入力は `pressure`・`tilt`・`speed`・`random`。版 2・3 の筆圧の項目と `pressure_size` などの切り替え・`controls.tilt_size` などは書きません）。書けるブラシは今までと同じ版・同じバイトです。
バージョン 7 までの項目で書けないものを使うブラシだけは 1 行目を `yolupainter-brush 8` にします（バージョン 7 と同じ影響元の鍵に加えて書きます）。今は次の 6 つで、どれも使わないブラシは今までと同じバージョン・同じバイトです。バージョン 7 までのファイルにこれらの鍵があれば、知らない項目として断ります。

- 入り抜きを掛ける項目が既定（大きさだけ・最小値 0）でない入り抜きを持つブラシ: `assist.taper.<項目>`（項目は影響元と同じ 8 つ。掛けない項目は `off`、掛ける項目は最小値 0〜1）を 8 行とも書きます。
- 筆先の繰り返し方法の `pingpong`・`hold`・`once`・`shuffle`、筆先の反転の `random`・`fold`、先端同士の比較暗、質感の回転を使うブラシ: `tip.selection` の新しい値・`tip.flip_x_rule`・`tip.flip_y_rule`・`tip.darken=1`・`texture.angle`（度）を書きます。
- [色の変化](#色の変化)を使うブラシ: 先端の変化は `color.tip.hue`（度）・`color.tip.saturation`・`color.tip.value`（3 つとも書く）、サブ描画色混合率は `color.sub_mix`（0 は書かない）、ストロークごとの変化は `color.stroke.hue`（度）・`color.stroke.saturation`・`color.stroke.value`・`color.stroke.sub_mix`（4 つとも書く）、変化対象は `color.target`（`main_and_sub`・`sub`。メインは書かない）です。影響元は `influence.color_hue.<入力>.…`・`influence.color_saturation.<入力>.…`・`influence.color_value.<入力>.…`・`influence.color_sub_mix.<入力>.…` の形で、ほかの項目と同じ `.on`・`.min`・`.curve` を使います。
- [散布効果](#散布効果)を使うブラシ: `spray.size`（粒子サイズ）・`spray.density`（粒子密度）はいつも書き、`spray.link_size=1`（ブラシサイズに連動）・`spray.bias`（散布偏向）・`spray.angle`（粒子の向き、度）・`spray.direction`（`line`・`whole`・`center`）・`spray.random_angle`（ランダムの強さ）は既定（切・0・なし）でないときだけ書きます。影響元は `influence.spray_size.<入力>.…`・`influence.spray_density.<入力>.…` の形で、ほかの項目と同じ `.on`・`.min`・`.curve` を使います（影響元だけを使うブラシもバージョン 8 です）。
- 色の混ぜのバージョン 8 の項目を使うブラシ（混ぜ方が「なし」でないものだけ）: 方式が重ねる（`mix.mode=layer`）、混色モードが知覚的（`mix.space=perceptual`）、輝度の補正が 0 でない（`mix.correction`。0〜4）、にじむ強さが固定値（`mix.blur`。画素、0〜8）、初めの絵の具の量が 100% でない（`mix.load`。0〜1）。どれも既定のときは書かず、使わない混ぜるブラシ・伸ばすブラシは今までと同じバージョン・同じバイトです。バージョン 7 までのファイルにこれらの鍵があれば、知らない項目として断り、`mix.mode=layer` は読めない値として断ります。
- [デュアルブラシ](#デュアルブラシ)の足した項目を使うブラシ: 足した合成モードは `dual.mode` の新しい値（`normal`・`add`・`lighten`・`screen`・`linear-height`）、`dual.link_size=1`（メインのブラシサイズに連動）・`dual.flow`（濃度）・`dual.anti_alias`（2 つ目のアンチエイリアス。`none`・`weak`・`medium`・`strong`）・`dual.angle_tilt=1`・`dual.angle_rotation=1`・`dual.angle_line=1`（向きに足すもの）・`dual.angle_random`（向きのランダムの強さ）を、既定（切・1・主と同じ・0）でないときだけ書きます。影響元は `influence.dual_size.<入力>.…`・`influence.dual_flow.<入力>.…`・`influence.dual_spacing.<入力>.…`・`influence.dual_thickness.<入力>.…` の形で、ほかの項目と同じ `.on`・`.min`・`.curve` を使います（影響元だけを使うブラシもバージョン 8 です）。2 つ目の複数の筆先は `dual.tips`（`tip.images` と同じ並びの書き方）、繰り返し方法は `dual.selection`（`tip.selection` と同じ値。ランダムは書かない）、反転は `dual.flip_x=1`・`dual.flip_y=1`・`dual.flip_x_rule`・`dual.flip_y_rule`（`tip.*` と同じ値）、先端同士の比較暗は `dual.darken=1`、紙質は `dual.texture`（画像）・`dual.texture.depth`・`dual.texture.scale`・`dual.texture.mode`（`texture.*` と同じ値）・`dual.texture.angle`（0 は書かない）、散布効果は `dual.spray.*`（`spray.*` と同じ鍵と書き方）です。今までの 8 つのモードと今までの `dual.*` の鍵だけのブラシは、今までと同じバージョン・同じバイトです。バージョン 7 までのファイルの、足したモードの値は読めない値として断ります。

…（版 1・2 と同じ項目）…

- バージョン 3 の項目はバージョン 1・2 のファイルにあれば、バージョン 4 の項目はバージョン 1〜3 のファイルにあれば、バージョン 5 の項目（[アンチエイリアス](#アンチエイリアス)）はバージョン 1〜4 のファイルにあれば、バージョン 6 の項目（最低 1 ピクセル）はバージョン 1〜5 のファイルにあれば「知らない項目」として断ります。バージョン 9 以上は触らずに読み飛ばし、理由を出します。バージョン 3 までしか知らない古いアプリはバージョン 4 のファイルを、バージョン 4 までしか知らない古いアプリ（0.5.x まで）はバージョン 5 のファイルを、バージョン 5 までしか知らない古いアプリはバージョン 6 のファイルを、「新しい形式」として同じように読み飛ばします。

- 混ぜの項目は Unity 版の `BrushState` に無く、`schema` を上げずに書くと `JsonUtility` が知らない項目を黙って捨てます。そのため、この版はどちらの形式へも混ぜを書きません。
- `.ylp` には混ぜの項目を持ちません（`.ylp` のアセットのブラシは 0.4.x までの Unity 版の携帯形式のまま、中身を変えずに持ち運びます）。

### 取り込み

Photoshop の ABR は、混合ブラシの設定のうちブラシの記述に入っているもの（ウェット・混合のゆらぎ）を、取り込んだブラシの「表せなかった項目」に載せます。混合ブラシの基本の値（ウェット・負荷・混合）はツールのオプションにあってブラシの記述に入らないので、写せません。ウェット・混合のゆらぎのキー名（`wetnessControl`・`mixControl`）は、実物の ABR ではまだ確かめていません（合成のデータでの試験だけです）。実物でキー名が違うと、この注記は出ず、混合ブラシのゆらぎの設定は黙って取り込まれません。

## アンチエイリアス

丸い筆先の縁と小さなダブを、画素の段（ギザギザ）にしないための設定です。ブラシの詳細のウィンドウの「形状」と、パスのブラシの欄で選びます（2D のキャンバスにも 3D のビューにも効きます）。

| 段 | 縁の帯の幅 |
| --- | --- |
| なし | 帯なし（硬さだけで縁が決まる。今までの式） |
| 弱 | 0.5 画素 |
| 中 | 1 画素 |
| 強 | 2 画素 |

帯の幅は描く先のテクスチャの画素（テクセル）です。3D のビューでも、テクスチャの解像度とモデルの見え方から、テクセル 1 つが画面で何点になるかを求めて、帯をテクセルの幅にそろえます。

- 丸い筆先（真円率 1・画像なし）は、塗るテクセルごとに、その場所のテクセルの画面の大きさ（向きごと）で帯を直します。近づいても遠ざかっても、斜めの面でも、帯はテクセルの幅のままです。ただし、ダブの中心のテクセルの 2 倍より大きく写るテクセルでは、帯をダブの届く範囲に収まる幅で止めます（そこでは帯がテクセルより細くなります）。
- 潰した丸・画像の筆先・デュアルブラシの 2 つ目の筆先は、ダブの中心のテクセルの大きさ 1 つで直します（ダブの中でテクセルの大きさが変わる所では近似です）。
- ダブの中心が面に無いときは、直前に面に当たったダブの値を使います。
- 3D のパスと、見えない面にも塗る対称の写し（モデルの空間の球のダブ）は、三角形ごとのテクセルの大きさで直します。

### 式

覆いは画素の中心の 1 点で測ります。中心からの距離を半径で割った値を d、硬さを h とします。

- **なし**: d が h 以下なら 1、1 を超えたら 0、その間は smoothstep（`t = (1 − d) / (1 − h)`、`t² (3 − 2t)`）。
- **ほかの段**: ぼかしの幅を `max(半径 × (1 − h), 帯)` にし、帯の中心を、なしの式で覆いが半分になる所（`d = (1 + h) / 2`。硬さ 1 ならもとの半径）に置きます。帯がぼかしの幅を超える所だけが変わり、見た目の太さ（覆いが半分になる所）は変わりません。
  帯がぼかしの幅以下になる柔らかい筆先（エアブラシなど）・大きな柔らかい筆先は、どの段でも なし と同じ画素です。
- **潰した丸（真円率・角度）**: 帯は縁に垂直な向きの幅です（距離の勾配で画素ごとに直す）。帯の式の距離は、覆いが半分になる楕円の外接の箱から外への距離で下から押さえ、細い楕円でも帯が長い軸の先の外へ伸びません。短い軸が帯の半分より細い楕円は、短い軸を帯の半分まで広げ、その軸の濃さで面積を保ちます。
- **小さなダブ**: 覆いが半分になる半径が帯の半分より小さい軸は、その軸を帯の半分まで広げ、その軸の濃さを `半径 / (帯の半分)` にします。1 画素より小さいダブ（中）は、当たった画素に 1 画素分の濃さを置かず、ダブの面積に見合う濃さで周りの画素に分けて置きます（画素の間を通るダブも消えません）。弱は、半径 1 画素より細い線では帯を 1 画素まで広げます（0.5 画素のままでは、細い線のダブが画素の中心にかからず消えるため）。
- **画像の筆先**: 画像の補間は今のままで、小さなダブの濃さだけに効きます（画像の幅が帯の半分より狭い向きを帯の半分まで広げ、その向きの濃さを掛けます）。縁が透明な画像では、置き場所によって、広げた縁に画素の中心が乗ってまだ消えることがあります。
- デュアルブラシの 2 つ目の筆先・2D の対称の写し・ぼかし・指先・クローンも同じ式です。

### 既定と保存

- アプリの既定のブラシと、組み込みのブラシのうちペン・筆・消しゴムのグループで硬さ 0.5 以上の丸い筆先のものは **中**、ほかの組み込み（エアブラシ・画像の筆先・効果のブラシなど）は **なし** です。
- 利用者のブラシのファイルは、なし でないブラシだけ 1 行目を `yolupainter-brush 5` にして `anti_alias=weak`（`weak` / `medium` / `strong`）を書きます。なし のブラシは今までの版・同じバイトで、版 4 までのファイルは なし として読みます（前に保存したブラシの見た目は変わりません）。
- パスのブラシは `.ylp` の正本の版 34 に入ります（[YLP_FORMAT.md](YLP_FORMAT.md)）。なし のパスだけの文書は前の版のままで、版 33 までの文書のパスは なし として読みます。新しく作るパスは今のブラシの段を取る（既定は 中）ので、パスを新しく作った文書はふつう版 34 になり、0.5.x までのアプリでは開けません。パスのプリセット（`path_presets/`）は、なし でないときだけ `"anti_alias": "medium"` のように書きます。
- CLIP STUDIO のブラシ（`.sut`）は、アンチエイリアスの値（`AntiAlias`）を写します（[BRUSH_IMPORT.md](BRUSH_IMPORT.md)）。ほかの形式（ABR・GIMP など）から取り込んだブラシは なし（今の見た目）です。
- GPU のブラシのプレビュー（`yolu-gpu` の `brush_dabs`）はアンチエイリアスを持たず、なし でない設定は理由を添えて断ります（保存と Undo の正本は core のストロークです）。

## 色の変化

描く色を、ダブごとに色相・彩度・明度で動かし、サブ描画色へ寄せます。CLIP STUDIO の「ブラシ先端色の変化」「サブ描画色混合率」「ストロークごとのランダム変化」「変化対象」に当たる拡張です。今までのブラシ（色のゆらぎだけのブラシ・Photoshop の ABR から取り込んだブラシを含む）は、色の変化を持たず、画素もファイルも変わりません。

| 項目 | 範囲 | 既定 |
|---|---|---|
| 先端の色相 | −360〜360 度 | 切 |
| 先端の彩度・明度 | −1〜1（ポイントの 1/100） | 切 |
| サブ描画色混合率 | 0〜1 | 0 |
| ストロークごとの色相 | 0〜180 度 | 切 |
| ストロークごとの彩度・明度・サブ描画色混合率 | 0〜1 | 切 |
| 変化対象 | メイン・メインとサブ・サブ | メイン |

- **先端の変化量** = 値 × その項目の[影響元](#筆圧の応え)の係数の積（色相・彩度・明度・サブ描画色混合率それぞれに影響元があります）。使っている入力の係数を掛け合わせ、どの入力も使わなければ 1 で、値のまま一定です。色相・彩度・明度の影響元だけ、応えの最小値を −1〜1 にできます（式は `最小値 + (1 − 最小値) × 曲線(x)` のまま）。ランダムで最小値 −1 なら係数は `−1 + 2u`（u は 0〜1 の一様乱数）で、基準から ±値の一様なばらつきになります。筆圧で最小値 0 なら係数は筆圧そのもので、変化は筆圧 0 で 0、筆圧 1 で値になり、値の符号が向き（＋は上がる・−は下がる）です。
- **サブ描画色混合率**は、影響元を使わなければダブごとに一定（1 でサブ描画色そのもの）です。ランダム（最小値 0）なら 0〜値の一様なばらつきです。先端の色の変化の切り替えによらず効きます。
- **ストロークごと**の変化は、ストロークの始めに 1 回だけランダムに決めます。色相・彩度・明度は `値 × (2u − 1)`（±値）、サブ描画色混合率は `値 × u`（0〜値）で、そのストロークの全部のダブに同じ変化量を足します。先端の変化量とは足し算です（色相は度で足して 1 周で回します）。
- **色の作り方**（ダブ 1 つ）: 色のゆらぎを当てた色（使っていなければ描画色）を、① サブ描画色へ（混合率だけ）寄せ、② HSV で色相・彩度・明度を足します。寄せるのは RGB で、アルファは描画色のままです。彩度・明度は足したあとに 0〜1 に収めます（上側・下側で頭打ち）。サブ描画色混合率は先端とストロークごとの値を足してから 0〜1 に収めます。
- **変化対象**: このアプリはいつもメイン描画色で描くので、「メイン」「メインとサブ」は先端とストロークごとの変化を当て、「サブ」は色相・彩度・明度・ストロークごとの変化を当てません（色は変わりません）。先端のサブ描画色混合率は変化対象によらず当てます。
- ダブごとの乱数は、ストロークの乱数の種から決まる列（色のゆらぎ・影響元・デュアルブラシとは別）から、ランダムを使う項目ごとに、色相・彩度・明度・サブ描画色混合率の順に 1 つずつ引きます（値が 0 の項目も、ランダムを使っていれば引きます）。ストロークごとの 4 つは、また別の列から始めに引きます。2D の描点と 3D の面のダブは同じ関数で色を作るので、同じ設定・同じ入力の点の列なら、同じ色の列になります。
- ダブごとの色が要るのは、先端の変化を入れたとき、またはサブ描画色混合率が 0 より大きく影響元で動くときだけです。どちらでもなければストロークの始めに作った色で塗ります（変化のないブラシと同じ速い道）。
- 色のチャンネルを色で塗るブラシだけに効きます（消しゴム・効果のブラシ・データのチャンネル・マスクでは色を変えません）。GPU のブラシのプレビュー（`yolu-gpu` の `brush_dabs`）は丸い筆先だけの別の経路で、色の変化を持ちません。保存と Undo の正本はいつも core のストロークです。
- 保存は上の「保存」のとおりです。CLIP STUDIO の `.sut` の色の変化を写します（[BRUSH_IMPORT.md](BRUSH_IMPORT.md)）。

## 散布効果

描点 1 つに、ブラシの届く円の中へ、先端を粒子として散らして置きます。CLIP STUDIO の「散布効果」に当たります。散布効果を持たないブラシ（既定）は、画素もファイルも今までと同じです。

| 項目 | 範囲 | 既定 |
|---|---|---|
| 粒子サイズ | 0 より大きく 10000 まで（文書の画素の直径） | 10 |
| ブラシサイズに連動 | 入・切 | 切 |
| 粒子密度 | 1〜100 | 5 |
| 散布偏向 | −1〜1 | 0 |
| 粒子の向き | −360〜360 度 | 0 |
| 向きに足すもの | なし・線の方向・散布全体の向き・散布中心に集中 | なし |
| 向きのランダム | 0〜1（1 で ±180°） | 切 |

- 散布効果を入れている間は、描点の散布（`jitter.scatter`）と数（`jitter.count`）を使わず、描点ごとに次の数の粒子を置きます。
- **粒子の数** = `round(粒子密度 × 粒子密度の影響元の係数)`（四捨五入。0 なら何も置きません）。
- ブラシの半径が 0 の描点（筆圧 0・入り抜きの端・大きさのゆらぎで 0）は、粒子を置きません。
- **届く半径 R** は、その描点のダブの半径（筆圧・入り抜き・フェード・大きさのゆらぎを当てた後の半径）です。粒子の中心は、描点の中心から角度は一様、距離は `R × u^(0.5 × 4^偏向)`（u は 0〜1 の一様乱数）の所です。偏向 0 は円の中に一様、+1 は中心に寄り、−1 は縁に寄ります。粒子の中心は、いつも半径 R の円の中です。
- **粒子の直径** = 粒子サイズ × 粒子サイズの影響元の係数です。ブラシサイズに連動を入れると、さらに「そのダブの直径 ÷ 設定のブラシの直径」を掛けます（筆圧などでブラシが細くなると、粒子も小さくなります）。[最低 1 ピクセル](#最低-1-ピクセル)を入れたブラシは、粒子の直径も 1 画素を下回りません。
- **粒子の向き** = 粒子の向き + 足すもの（線の方向: 線の向き、散布全体の向き: ブラシ先端の角度の設定、散布中心に集中: 粒子の位置から描点の中心への向き）+ ランダム（強さ × 一様な ±180°）です。ブラシの角度・ペンの傾きの向き・角度のゆらぎは、粒子には当てません。
- 粒子 1 つは 1 つのダブで、不透明度・流量・硬さ・真円率・質感・筆先の選びと反転・色（色のゆらぎと[色の変化](#色の変化)の先端の色も粒子ごと）は、今のダブと同じ規則で決まります。
- [影響元](#筆圧の応え)は、粒子サイズと粒子密度の 2 つです（最小値は 0〜1）。粒子密度のランダムは描点ごとに、粒子サイズのランダムは粒子ごとに引きます。
- 乱数は、ストロークの乱数の種から決まる散布の列（ゆらぎ・色・影響元・デュアルブラシ・反転・並べ替え・色の変化とは別）から、描点ごとに粒子密度のランダム（使うとき）、粒子ごとに粒子サイズのランダム（使うとき）・距離・角度・向きのランダム（使うとき）の順に引きます。2D の描点と 3D の面のダブは同じ関数で粒子を作るので、同じ設定・同じ入力の点の列なら、同じ粒子の列になります（3D では、粒子サイズの文書の画素を、ブラシの半径と同じ換算でモデルの大きさにします）。
- GPU のブラシのプレビュー（`yolu-gpu` の `brush_dabs`）は丸い筆先だけの別の経路で、散布効果を持ちません。保存と Undo の正本はいつも core のストロークです。
- CLIP STUDIO の固定点は持ちません。デュアルブラシの 2 つ目の散布効果は[デュアルブラシ](#デュアルブラシ)の節です。保存は上の「保存」のとおりです。CLIP STUDIO の `.sut` の散布効果を写します（[BRUSH_IMPORT.md](BRUSH_IMPORT.md)）。

## デュアルブラシ

主の筆先と同じ道筋に、2 つ目の筆先のダブを自分の間隔で置き、ストロークの間、画素ごとにいちばん大きい覆いを溜めます。主のダブは、そのダブの位置までに置いた 2 つ目の溜まりと合成モードで合わせた覆いで塗ります。今までの項目（筆先・半径・硬さ・間隔・角度・真円率・散布・数・8 つのモード）に、CLIP STUDIO の「デュアルブラシ」に当たる次の項目を足しています。足した項目を使わないブラシ（Photoshop の ABR から取り込んだブラシを含む）は、乱数の列も画素もファイルも今までと同じです。

| 項目 | 範囲 | 既定 |
|---|---|---|
| 合成モード | 乗算・比較(暗)・オーバーレイ・覆い焼きカラー・焼き込みカラー・焼き込み(リニア)・ハードミックス・減算・通常・加算(発光)・比較(明)・スクリーン・高さ(リニア) | 乗算 |
| メインのブラシサイズに連動 | 入・切 | 切 |
| 濃度 | 0〜1 | 1 |
| 向きに足すもの | ペンの向き・ペン軸の回転・線の方向（いくつでも） | なし |
| 向きのランダム | 0〜1（1 で ±180°） | 0 |
| 2 つ目のアンチエイリアス | なし・弱・中・強 | 主と同じ |
| 複数の筆先 | 1〜256 枚 | なし（筆先 1 枚） |
| 繰り返し方法 | 主の筆先と同じ 6 種 | ランダム |
| 左右・上下の反転 | なし・反転・ランダム・折り返し時に反転 | なし |
| 先端同士を比較暗で合成 | 入・切 | 切 |
| 紙質 | 画像・濃さ・拡大率・合わせ方・回転（主の紙の質感と同じ） | なし |
| 散布効果 | 粒子サイズ・粒子密度・散布偏向・粒子の向き（主の散布効果と同じ） | なし |

- **合成モード**: 主の覆いを m、2 つ目の溜まりを d（どちらも 0〜1）として、通常は m（d を使わない）、加算(発光)は min(1, m + d)、比較(明)は max(m, d)、スクリーンは 1 − (1 − m)(1 − d)、高さ(リニア)は m − d × (1 − m) です（今までの 8 つも含め、m が 0 の所は 0、結果は 0〜1 に収めます）。高さ(リニア)は、CLIP STUDIO の説明（減算に近く、減算より濃い）に合わせた近い式です。2D と 3D の面は同じ式で合わせます。
- **メインのブラシサイズに連動**: 2 つ目の半径に、その描点の主のブラシの半径 ÷ 設定の主の半径（筆圧・入り抜き・フェード・傾き・速さを当てた後、大きさのゆらぎの前）を掛けます。切ると、2 つ目の大きさは筆圧・入り抜き・フェードの影響を受けません（今までどおり）。[最低 1 ピクセル](#最低-1-ピクセル)を入れたブラシは、主の半径が下限で残る分も比に入ります（主の線が残る間は、2 つ目の半径も 0 になりません）。
- **濃度**: 2 つ目のダブが溜まりへ置く覆いに掛けます。
- **向き**: 2 つ目の角度に、線の方向・ペンが倒れた向き・ペン軸の回転・ランダム（強さ × 一様な ±180°）を、主の筆先の角度と同じ規則で足します。
- **[影響元](#筆圧の応え)**: 2 つ目のサイズ（半径に）・濃度（濃度に）・間隔（次の 2 つ目のダブまでの間隔に。下限は設定の間隔の 0.01 倍）・厚さ（真円率に。下限 0.01）の 4 つです（最小値は 0〜1）。入力（筆圧・傾き・速度）は、その 2 つ目のダブを道の上に並べた所の値です。主の項目の影響元とは別に持ちます。
- 乱数は、ストロークの乱数の種から決まるデュアルの影響元の列（ゆらぎ・色・影響元・2 つ目の散布・2 つ目の筆先・反転・並べ替え・散布効果・色の変化とは別）から、2 つ目のダブを並べるごとに、サイズ・濃度・間隔・厚さのランダム（使う項目だけ）、向きのランダム（使うとき）の順に引きます。2D の描点と 3D の面のダブは同じ関数で 2 つ目のダブを作るので、同じ設定・同じ入力の点の列なら、同じ 2 つ目のダブの列になります。
- **2 つ目のアンチエイリアス**は 2D のキャンバスに効きます。3D の面の 2 つ目のダブは、今までどおり縁を広げない式です。
- **複数の筆先・繰り返し方法・反転**: 2 つ目のダブごとに、主の筆先と同じ規則で筆先を選び、反転を決めます（並べた順に数え、一巡のみ・ランダムに一巡は並びを使い切った後の 2 つ目のダブを置きません）。
- **先端同士を比較暗で合成**: 2 つ目の溜まりは、いつも画素ごとに覆いの大きい方を残すので、入れても切っても描き方は同じです（取り込んだ設定を保つために持ちます）。
- **紙質**: 主の紙の質感が天井に掛ける式を、2 つ目のダブが溜まりへ置く覆いに掛けます（乗算は 覆い × (1 − 濃さ × (1 − 質感))、ほかの合わせ方は 覆い + (合わせた値 − 覆い) × 濃さ）。質感はキャンバスに固定で、文書の画素の位置で読みます（3D の面も、塗るテクセルの文書の画素の位置）。
- **散布効果**: 2 つ目のダブの所に、主の散布効果と同じ規則で粒子を散らします（届く半径は 2 つ目のダブの半径、ブラシサイズに連動は 2 つ目の半径 ÷ 設定の 2 つ目の半径、散布全体の向きは 2 つ目の角度）。入っている間は 2 つ目の散布・数を使いません。粒子サイズ・粒子密度の影響元は持ちません。
- 2 つ目の筆先の選び（乱数で選ぶとき）・ランダムな反転・並べ替え・散布の粒子は、ストロークの乱数の種から決まる 2 つ目の列（今までのどの列とも別）から、主の筆先と同じ順に引きます。複数の筆先・反転・散布を使わない 2 つ目は、何も引きません。
- RGB 値の適用・連続吹き付け・リボンは持ちません。保存は上の「保存」のとおりです。CLIP STUDIO の `.sut` のデュアルブラシを写します（[BRUSH_IMPORT.md](BRUSH_IMPORT.md)）。

## 最低 1 ピクセル

ブラシの設定の「ストローク」の「最低 1 ピクセル」を入れると、筆圧・フェード・傾き・速さ・入り抜き・サイズのゆらぎで細くなったあとのダブの直径に、下限 1 画素を掛けます（直径が 0 になるダブも 1 画素で残るので、筆圧 0 の線や入り抜きの先も途切れません）。切（既定）は今までと同じストロークです。

- 自由に描くストローク（2D のキャンバスと 3D の面）に効きます。パスのツール（`P`）のパスは、パスのブラシの欄の設定（`BrushSettings`）だけで描くので、この設定は効かず、パスのツールを選んでいるあいだはチェックを押せません（パスのプリセットと `.ylp` のパスにも入りません）。
- 1 画素は文書の画素です。3D の面の塗りでは、当たった面のテクスチャの画素（テクセル）で数え、半径をテクセルの半分以上にします（テクスチャの画素の密度が低い面でも、1 テクセルは塗れます）。ブラシの大きさ（文書の画素）をモデルの単位へ直す換算は今までのままです。
- ダブの間隔は、公称の大きさ（筆圧などで細くなる前）で決まる今までの式のままです。下限で 1 画素になったダブは、間隔を詰めずに並びます。
- アンチエイリアスの小さなダブの式（広げと濃さ）は、下限を掛けたあとの大きさに掛かります。直径 1 画素のブラシで描いたのと同じ結果です。
- 保存は上の「保存」のとおりです。CLIP STUDIO の `.sut` の `BrushAtLeast1Pixel` を写します（[BRUSH_IMPORT.md](BRUSH_IMPORT.md)）。

## 筆圧の応え

ブラシの項目（大きさ・不透明度・流量・硬さ、色の混ぜの量・濃さ）ごとに、筆圧 p（0〜1）を係数へ写します（傾き・速さ・ランダムの入力と、真円率・質感の濃さの項目も同じ形の影響元で持ちます。画面で変えられるのは筆圧と、大きさ・不透明度・流量の傾き・速さの切り替えです）。`係数 = 最小値 + (1 − 最小値) × 曲線(p)`。最小値は筆圧 0 のときの係数（0〜1。[色の変化](#色の変化)の色相・彩度・明度の影響元だけ −1〜1）、曲線は点を通る単調な 3 次エルミート補間（点は 2〜16 個、両端は入力 0 と 1、間隔は 0.02 以上、値は 0〜1）です。最小値 0・直線の既定は筆圧そのものを返し、応えを加える前と画素までバイト単位で同じです。項目を筆圧で変えるかどうかの切り替えは、応えとは別に持ちます。

## グループと並び

利用者のブラシのファイル（`brushes/brush-<番号>.ylbrush`）の `group=` は、そのブラシの元のグループです。どのツールのどのグループに、どの順で出すかは
ファイルではなく、設定のフォルダの `tools.json`（ツールの並び。[SUBTOOLS.md](SUBTOOLS.md) の「ツールの並び」）が持ちます。`group=` を使うのは、
最初の並びに戻すときの置き場と、並びに無い新しいファイル（古いアプリが追加した物など）を追加する先と、並びを持たない古いアプリ（0.4.x まで）の並べ方だけです。

並びのブラシは 1 つにつき 1 つのファイルで、組み込みのブラシは設定を登録する・名前を変えるまで組み込みを指したまま、2 か所目に置くと写しのファイルを作ります。
並びから外してもファイルは消えません。ファイルの形式（版 1〜4）は並びのために変えていません。
