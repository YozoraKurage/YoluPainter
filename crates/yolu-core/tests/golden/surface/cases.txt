# yolu-core の面の計算（geometry）と Unity 版の SurfaceGeometry（Editor/Preview の原文）を照らし合わせる事例（両方がこの台本を読む）。
# 書き方（1 行 1 命令、# から行末はコメント）:
#   case 名前
#   clear                                      三角形を空に
#   cube R S M                                 試しの立方体（Unity 版の LoadDemoMesh と同じ）を足す（R・S・M はレンダラー・スロット・マテリアルの組）
#   sphere N 半径 R S M [面]                    立方体を n × n に分けて膨らませた球（yolu-core の cube_sphere）。面は含める面の番号の文字（既定 012345）
#   plate X0 Y0 X1 Y1 Z R S M                   Z の高さの四角（2 つの三角形、UV 0〜1。法線は −Z）
#   soup 種 個数 大きさ R S M                     乱数の三角形（splitmix64）
#   build 世代 [溶接の許し]                       SurfaceGeometry を作る
#   out                                        形の指紋（三角形の数・非多様体の辺・箱・遮蔽の許し・隣り合わせ・BVH の節点と並び）
#   ray OX OY OZ TX TY TZ 裏を見ない 届く距離     O から T へのレイ（届く距離は inf も可）
#   rays 種 本数 裏を見ない                       箱のまわりから中へ向けた乱数のレイの当たりの指紋
#   budget default | budget 鍵=値…              ダブの予算（triangles pixels rays tests visits）
#   cache new | cache none                     遮蔽の結果を覚えるもの（ストロークの間）
#   dab CX CY CZ TX TY TZ 半径 幅 高さ 硬さ [ignore]   カメラ C から T へのレイの当たりで面の上のダブ
#   closest PX PY PZ 届く距離 FX FY FZ 節点の上限 マテリアル   最近点
#   region 三角形 Triangle|UvIsland|MeshPart|Material
# 小数は 2 進で割り切れるか短い 10 進だけ（読み方の違いは params の指紋で見張る）。
