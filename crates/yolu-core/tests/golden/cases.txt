# YoluPainter-rs の yolu-core と Unity 版の C# の Core を照らし合わせる事例（両方がこの台本を読む）。
# 書き方（1 行 1 命令、# から行末はコメント）:
#   case 名前                      事例の始まり
#   canvas 幅 高さ タイル            空の文書
#   layer 名前 モード 不透明度 [hidden] [clip] 中身    層を一番上へ（中身: empty | random:種 | sparse:種 | solid:R,G,B,A）。
#                                    層の行は準備なので、行ごとに履歴を消す
#   stroke 層 キー=値…              Color へのストロークを始める（radius hardness spacing opacity flow color=R,G,B,A
#                                    psize popacity pflow erase。書かないキーは C# の BrushSettings の既定値）
#   point X Y 筆圧                  入力の点（時刻 0）
#   walk 種 個数 X0 Y0 歩幅          乱数の歩みの点（筆圧 0.1 + 0.9·u、次に x、y を ±歩幅·(2u − 1) 動かす）
#   pixel X Y 覆い 筆圧              ApplyPixel（メッシュのダブ）
#   commit | cancel | undo | redo
#   visible 層 0|1  /  opacity 層 値  /  mode 層 モード  /  clip 層 0|1  /  move 層 新しい位置  /  remove 層  /  add 名前
#   out composite  /  out layer 層  /  out region X Y W H
# 乱数は splitmix64。色の成分は 1/8 で 0、1/8 で 255、ほかは一様。アルファは 1/4 で 0、1/4 で 255、ほかは一様。
# 層の番号は今の並び（下から 0）。小数は 2 進で割り切れるか短い 10 進だけ（読み方の違いは params の指紋で見張る）。
