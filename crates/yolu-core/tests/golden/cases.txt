# YoluPainter-rs の yolu-core と Unity 版の C# の Core を照らし合わせる事例（両方がこの台本を読む）。
# 書き方（1 行 1 命令、# から行末はコメント）:
#   case 名前                      事例の始まり
#   canvas 幅 高さ タイル            空の文書
#   layer 名前 モード 不透明度 [hidden] [clip] 中身    層を一番上へ（中身: empty | random:種 | sparse:種 | solid:R,G,B,A）。
#                                    層の行は準備なので、行ごとに履歴を消す
#   stroke 層 キー=値…              Color へのストロークを始める（radius hardness spacing opacity flow color=R,G,B,A
#                                    psize popacity pflow erase。書かないキーは C# の BrushSettings の既定値）
#                                    M2: channel=名前 seed tip=筆先 tips=筆先,… tipsel=random|seq angle roundness follow
#                                    sizejit anglejit roundjit opjit flowjit scatter count texture=筆先 tdepth tscale
#                                    stabilizer taperin taperout curve secondary=R,G,B,A fbj huejit satjit brightjit purity
#                                    pertip fadesize fadeop fadeflow tiltsize tiltop tiltflow tiltangle
#                                    effect=Blur|Smudge|Clone blur=半径 smudge=強さ clone=X,Y
#                                    dual=round|筆先 と、その後に dradius dhard dspacing dangle dround dscatter dcount dmode
#                                    （筆先は組み込みの名前。1 か 0 の旗は 1 で入）
#   point X Y 筆圧                  入力の点（時刻 0）
#   tpoint X Y 筆圧 時刻 傾きX 傾きY  時刻と傾きの付いた入力の点
#   walk 種 個数 X0 Y0 歩幅          乱数の歩みの点（筆圧 0.1 + 0.9·u、次に x、y を ±歩幅·(2u − 1) 動かす）
#   twalk 種 個数 X0 Y0 歩幅         傾きも動く歩み（筆圧、傾き X・Y を ±1.5·(2u − 1)、次に x、y。時刻 0）
#   pixel X Y 覆い 筆圧              ApplyPixel（メッシュのダブ）
#   dab 中心X 中心Y 筆圧 X:Y:覆い…   ApplyDab（面のダブ。効果は読み元を凍結）
#   dabdisc 中心X 中心Y 半径 筆圧     円板の面のダブ（中心が円の中の画素、覆い 1 − 距離/半径、下の行から）
#   resetdir                         ResetEffectDirection（指先の前の位置を忘れる）
#   stats                            進行中のストロークのダブ・点・タイルの数と巻き戻しのバイト数を出来事に書く
#   budget バイト                     ストロークの予算（ActiveStrokeBudgetBytes）
#   enable 層 チャンネル              チャンネルを有効にして履歴を消す（Rust は面をストロークで作るので履歴だけ消す）
#   stencil モード 繰り返し 反転 写し 画像 色空間 チャンネル
#                                    今のステンシルを作る（stroke の stencil=1 で付ける）。モード Auto|Mask|Color、繰り返し
#                                    None|Horizontal|Vertical|Both、写しは none か xx,xy,x0,yx,yy,y0、画像は grey:種:W:H・
#                                    color:種:W:H・varied:W:H・half:W:H、色空間 Unspecified|Srgb|Linear、チャンネルは - か名前,…
#   pixelat X Y 覆い 筆圧 SX SY 幅     ステンシルの上の点つきの ApplyPixel
#   dabdiscat 中心X 中心Y 半径 筆圧 写し  円板の面のダブを、画素の中心を写しで写した点で（ApplyDab の点つき）
#   commit | cancel | undo | redo
#   visible 層 0|1  /  opacity 層 値  /  mode 層 モード  /  clip 層 0|1  /  move 層 新しい位置  /  remove 層  /  add 名前
#   out composite [ch]  /  out reference [ch]（画素ごとの参照の式）  /  out layer 層 [ch]  /  out region X Y W H [ch]
#   out mask 層  /  out normal（Normal の出力）  /  out normalfile（ファイルの Y の向き）  /  out derive（Height → Normal だけ）
# M2（層の種類とチャンネル）:
#   paint 層 ch 中身                 ラスターの層のチャンネルを中身で埋める（面を作って有効にする。準備なので履歴を消す）
#   group 名前 モード 不透明度 [hidden] [clip]      空のグループを一番上へ（準備）
#   fill 名前 モード 不透明度 [hidden] [clip] ch=R,G,B,A…   塗りつぶしの層を一番上へ（準備）
#   adjust 名前 モード 不透明度 [hidden] [clip] [only=ch,ch] 調整   調整の層（invert | levels:黒,白,ガンマ,出力の黒,出力の白 |
#                                    hsl:色相,彩度,明度。only が無ければ使えるチャンネル全部）を一番上へ（準備）
#   mask 層 中身 [inverted] [off] [density=v]       マスクを足して中身（m で始まる中身はアルファだけ）で埋める（準備）
#   groupof 名前 層…  /  ungroup 層  /  into 層 グループ|top 位置  /  duplicate 層 [名前]   グループ化・解除・移動・複製（Undo できる）
#   addmask 層  /  removemask 層  /  maskprop 層 有効 反転 濃度  /  maskstroke 層 キー=値…（マスクへのストローク）
#   chblend 層 ch モード|- 不透明度|-  /  chenable 層 ch 0|1  /  fillvalue 層 ch R,G,B,A|none  /  setadjust 層 調整
#   normal 作る(0|1) 強さ clamp|wrap gl|dx       Normal の出力の設定
#   stroke の channel=ch でチャンネルを選ぶ。ch は C# の PaintChannel の名前。
#   out composite  /  out layer 層  /  out region X Y W H  /  out channel 層 チャンネル
# 乱数は splitmix64。色の成分は 1/8 で 0、1/8 で 255、ほかは一様。アルファは 1/4 で 0、1/4 で 255、ほかは一様。
# 層は今の並びの番号（下から 0）か @名前。小数は 2 進で割り切れるか短い 10 進だけ（読み方の違いは params の指紋で見張る）。
