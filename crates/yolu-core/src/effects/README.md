# レイヤーに付ける効果

レイヤーとマスクにはフィルターの並び（`filters`）、レイヤーには Generator の設定、Anchor の参照、塗りつぶしの画像と投影、チャンネルごとのグラデーション、2D・3D のパス（`LayerPath`）を持たせられます。効果は標準チャンネル（Color・Roughness・Metallic・Height・Normal・Emission の 0〜5 番）だけが対象です。どれも `Document` の編集 API で変え、1 つの編集が 1 回の Undo になります。強さ・設定・投影・グラデーションのドラッグは続けて 1 回にまとまります。断った編集は何も変えません。

## 評価

効果はキャッシュを正本にしません。保存するのは設定と元の画素だけで、合成のときに既存の `filter`・`generator`・`fill_image` の評価を呼んで、レイヤーの出力を作ります。式はここで繰り返さず、単体の評価と同じバイト列になります。

評価は正方形のブロック（既定 256 画素）ごとに行い、元の画素・設定・入力・Anchor の読む先が変わったブロックだけを評価し直します。ブロックの大きさで結果は変わりません。足りないブロックは作業用メモリの予算内で並べて評価し、取り消せます。全域の統計（正規化）と画像のミップマップは、並べる前に 1 回ずつ作ります。予算を超える設定は、編集のときに `WorkingBudgetExceeded` などで断ります。

## 外から渡すもの

メッシュマップ・モデルのルート・画像はこの文書の外のものです。`Document::set_effect_inputs` で `EffectInputs` を渡します。保存せず、Undo の対象でもありません。同じ内容の再設定では何も評価し直しません。渡されるまで、それを使う Generator と塗りつぶしは入力のまま通り、`inactive_effects()` が効かない効果を 1 行ずつ返します。`yolu-io` の `Project::image_inputs()` は .ylp の画像リソースから画像の入力を作ります。

## Anchor

Anchor はレイヤーまたはマスクに置く名前の付いた接続点です。レイヤーの Anchor はそのレイヤーまでのスタックの結果（全チャンネル）、マスクの Anchor はマスクがレイヤーを見せる量を指します。それより上のレイヤーの Anchor Generator が読みます。読む先を選んでいない・無い・読むレイヤーより下に無いときは、Generator は入力のまま通り、`anchor_issues()` が理由を返します。Anchor を読むレイヤーは、読む先の画素が変わると評価し直されます。

## パス

パスレイヤーは設定（パスと描き方）から画素を作ります。手で描く・塗る・選択範囲の塗りつぶし・マテリアルの描き込みは断ります。`rasterize` でパスを外すと画素のレイヤーに戻ります。

## ロック

効果の設定（段の追加・削除・設定・強さ・チャンネル・並び、Anchor の追加・削除・読む先、投影の変更のうち画素を変えないもの）は、画素を変えないので「すべてをロック」だけで断ります（Anchor の名前の変更は断りません）。画素を決め直すもの（塗りつぶしの画像・グラデーション・値、画像のあるレイヤーとデカールの投影、パスの付け替え）は、画像のロックと透明部分のロックでも断ります。パスで描かれたレイヤーへの手の書き込みは、ロックを先に確かめ、通ればパスレイヤーとして断ります（動かすときだけパスレイヤーが先）。親のグループのロックは中のレイヤーと、これから中へ入るレイヤーにも効きます。

## レイヤーの操作

複製は、効果と Anchor に新しい ID を付け、写しの中の Anchor を読む段は写しの Anchor を読みます（外の Anchor はそのまま）。削除では、消えた Anchor を読む段が入力のまま通ります。結合は効果とパスを画素に焼き込み（結果は効果を持たない）、効いていない効果を含むと断ります（分離の結合は下のレイヤーのマスクの効果も焼くので、そのマスクの効いていない Generator も断ります。C# はここを見ず、黙って落とします）。上のレイヤーの Anchor は結果へ移り、下のレイヤーの Anchor は無くなります。残すマスクの段は、新しい ID で結果へ写ります。画像の大きさの変更は、ぼかし・シャープの半径を倍率に合わせ（範囲へ収めた分は知らせる）、2D のパスは点と半径を合わせて描き直します（キャンバスだけを動かす変更は、2D のパスの点を画素と同じだけずらして描き直します。C# に対応する操作は無い、Rust 独自の決めです）。モデルの上のパスは残り、報告にレイヤーを挙げます。変形はパスで描かれたレイヤーを断ります。どの操作も、断れば何も変えず、評価の出力は新しい画素・大きさで作り直します。履歴の費用は、C# と照らした操作では同じ数え方です。

## 保存

`yolu-io` の `to_core` / `from_core` が、フィルター・Generator・Anchor・塗りつぶしの画像と投影・グラデーション・パスを .ylp の正本とバイト一致で往復させます。`.ylp` の形式は上げません。正本の版は使う機能で決まり（Unity 版が書ける効果は版 21 のまま、0.5.0 のフィルターの種類 70〜79 と Generator の種類 66〜70 は版 28 以降。表は `docs/YLP_FORMAT.md` の「正本の版の決まり」）、Generator のアルゴリズムの版は、階調（ramp）を持つときだけ 2 になります。効果の種類の一覧は `effects::catalog`、フィルターの式は `filter/README.md`、Generator の式は `generator/README.md` にあります。
