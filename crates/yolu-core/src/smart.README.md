# スマート素材

`Document::capture_smart_material` は選んだレイヤーとグループの子孫を独立した断片にします。`capture_smart_mask` はマスクだけを保存します。元の文書と画素の写しは書き込み時に分離します。

`place_smart_material` は複数の最上位レイヤーを名前付きグループにまとめ、親と位置を選んで一度の Undo で配置します。`SmartPlacement::channels` に含まれないチャンネルは、値と画素を保って無効化します。標準チャンネルは種類で対応します。ユーザーチャンネルは、レイヤーが何かを持つ番号（有効、または無効でも面・塗りつぶしの値・チャンネルごとの合成がある）に、配置先で同じ番号・同じ情報のチャンネルが無ければ拒否します。レイヤーが使っていないチャンネルの定義は断片に持たせません。`apply_smart_mask` の差し替えも一度の Undo で戻せます。

寸法が違うときは、既定で拡大をバイリニア、縮小する軸があれば面積平均にします。最近傍も選べます。タイル寸法だけが違うときは画素をそのまま写します。透明画素の RGB と法線の正規化は C# と同じ規則で、Color・Normal・マスクの結果を C# の出力と全バイトで照合しています（疎な元・タイル寸法だけが違う場合を含む）。読む元のタイルが 1 つも無い目標のタイルは計算せず、元が全部同じ一様な色ならその色で埋めます（結果のバイトは変わりません）。配置前に画素予算とレイヤー数を検査し、拒否時には文書を変更しません。

ファイルとプロジェクトのアセットは `yolu_io::smart::SmartFile` と `yolu_io::shelf::Shelf` で扱います。`SmartFile::to_core` は画素の予算を付けずに開き（`to_core_within` で上限を付けられます）、置く文書の予算は配置のときに検査します。core のレイヤーが保持できる属性だけを編集できます。ユーザーチャンネルを使う素材は、Unity 版が読めない版になるので .ylsmart（形式 1）には保存せず拒否します。画像を含む素材と、ベイクへのピンの付け直しが要る Generator（`repin`）のある素材は、編集用に開けず（`yolu_io::smart` の `REFUSAL_IMAGES`・`REFUSAL_GENERATORS`）、SmartFile の原本を保持します。Generator のピンの付け直し、画像参照を使う塗りつぶしの描画は未対応です。

同梱のスマートマテリアル（`smart_library`）は、塗りつぶしレイヤー（チャンネルごとの値）と、そのマスクのノイズ・グランジの Generator だけで作ります。外の画像も画素のレイヤーも持たないので、どの大きさのテクスチャにも置け、マップを焼く前でも同じ見た目になります。
