# カラーセット

カラーセット、使用した色の履歴（最大 64 色）、4 隅から作る中間色は個人設定です。文書の保存と Undo には含まれません。既定の 16 色は独自に選んだものです。

保存先はアプリの設定フォルダの `colorsets/`。各セットは内部 ID（16 桁の小文字の十六進数）の `.ycolors` ファイルです。名前をファイルパスとして使いません。変更は一時ファイルへの書き込みと同期の後、置換して確定します。書き込み失敗時はセットの編集も確定しません。削除は選んだセットのファイルだけを削除します。最後のセットは残します。

内部形式はビッグエンディアンです。

| 項目 | 内容 |
| --- | --- |
| 識別子 | 4 バイト `YCS\0` |
| 版 | u16、現在 1 |
| セット名 | u16 のバイト長と UTF-8 |
| 色数 | u16 |
| 各色 | 名前（同じ長さ付き UTF-8）、RGBA 各 f32 |

RGBA は straight、RGB は sRGB の符号値、各成分は有限の 0〜1。透明画素の RGB と f32 の値をそのまま保存します。色名・セット名は最大 256 バイト、制御文字不可。ファイルは最大 2 MiB、1 セット 4096 色、128 セット。フォルダ走査は最大 256 項目。走査上限または走査の失敗時は書き込みを止め、既存ファイルを保護します。

`state.conf` も同じバイナリ形式を使用します。セット名の欄は選択中の ID の十進表記、最初の 4 色は左上・右上・左下・右下、それ以降は使用履歴の新しい順です。履歴と 4 隅は変更時に保存します。保存失敗時は知らせ、次の変更で再試行します。壊れた state.conf は自動で上書きしません。読めないセットは理由を知らせて残し、読めたセットだけを利用します。

中間色は 7×7。各成分を sRGB の符号値のまま双線形補間します。アルファも独立に線形補間し、プリマルチプライやリニア光への変換はしません。

GPL は [GIMP の公開仕様](https://developer.gimp.org/core/standards/gpl/)の旧形式と名前付き形式を読み込み、RGB 8 ビットで書き出します。保存された浮動小数は最も近い 8 ビット値へ丸めます。透明度は GPL にないため、透明色を含む書き出しを理由付きで断ります。列数は検証しますが、表示は現在の欄幅に合わせて並べ直します。

ACO は [Adobe の公開仕様](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/#ColorSwatches)に従い v1、v2、v1 に続く v2 を読み込みます。RGB・HSB・グレースケールに対応します。CMYK・Lab・特色は、色管理なしでの色変換を避けるため色空間番号付きで断ります。2 つの一覧がある場合は色の一致を確かめ、v2 の UTF-16 名を使います。切り詰め、範囲外、文字コードの異常、余剰データ、上限超過はセット全体を断り、部分的には取り込みません。

`.ylp`・ブラシ・Unity の文書形式には変更がありません。旧版はこの設定フォルダを使用しません。
