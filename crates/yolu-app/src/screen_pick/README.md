# 画面の色を取得

Windows の編集メニューとスポイトのオプションバーから使えます。キーは既定の割り当てで、設定の「ショートカット」で変えられます。

- 画面の色を取得: `Ctrl+Alt+I`
- ウィンドウを隠して画面の色を取得: `Ctrl+Alt+Shift+I`
- 左クリックで確定、Esc・右クリック・フォーカス喪失で取消。

すべてのモニターを一度だけ撮り、静止画を重ねウィンドウで表示します。ルーペの中心が取得する画素です。取得画像はメモリ内だけに置き、終了時に破棄します。ファイル保存・通信は行いません。ウィンドウを隠した場合は確定・取消・取得失敗のいずれでも戻します。描画中は開始できません。

高 DPI では取得中のスレッドを Per-Monitor V2 に切り替え、取得・表示・カーソルを物理ピクセルで一致させます。元の DPI 状態は終了時に復元します。左・上のモニターの負座標を含めた仮想デスクトップを扱い、ルーペはカーソルのあるモニターの端に収めます。モニター構成の変更時は取り消します。

GDI の 8 bit 出力を sRGB として描画色に入れます。HDR の浮動小数点値やモニターごとの ICC プロファイルを保持する測色機能ではありません。HDR デスクトップでは OS の SDR 変換の結果となり、見た目との一致は保証しません。保護された映像など GDI から読めない表示にも対応しません。

スカラーチャンネルとマスクでは取得した sRGB の値を `0.2126 R + 0.7152 G + 0.0722 B` の灰色にします。文書・Undo・保存形式は変えません。取得画像は最大 128 MiB、取得用 DIB と合わせて最大 256 MiB とし、超える構成は理由を表示して断ります。

Linux の X11・Wayland では入口を表示しません。
